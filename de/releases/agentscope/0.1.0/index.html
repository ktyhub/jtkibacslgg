agentscope v0.1.0

Was hat sich geändert?

Modell APIs

  1. Unterstützen Sie ZhipuAI API (https://github.com/modelscope/agentscope/pull/181)
  2. Unterstützen Sie Yi API (https://github.com/modelscope/agentscope/pull/343)
  3. Unterstützt den Streaming-Modus in AgentScope (https://github.com/modelscope/agentscope/pull/347)
  4. Unterstützt LiteLLM (https://github.com/modelscope/agentscope/pull/204)
  5. Formatieren Sie Eingabenachrichten entsprechend dem Namen des Modells (https://github.com/modelscope/agentscope/pull/381).

Service

Fügen Sie die folgenden neuen Servicefunktionen hinzu

  1. TripAdvisor-Suche
  2. DBLP-Suche
  3. Wikipedia-Suche
  4. Webbrowser-Steuerung
  5. Multimodale Servicefunktionen von OpenAI und DashScope

Andere

  1. Implementieren Sie die MoA-Methode in AgentScope (https://github.com/modelscope/agentscope/pull/327).
  2. Ein neues Prompt-Engineering-Modul (https://github.com/modelscope/agentscope/pull/242)
  3. RAG-Modul verbessern (https://github.com/modelscope/agentscope/pull/184)
