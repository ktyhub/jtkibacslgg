claude-code v2.1.283

Patch Veröffentlicht25. Sept. 2026 Quelleanthropics/claude-code Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Claude-Code v2.1.283

Was hat sich geändert?

– x-claude-code-prompt-id zu den Gateway-Hinweis-Headern hinzugefügt, damit LLM-Gateways die Anforderungen gruppieren können, die eine Benutzeraufforderung bedienen; Melden Sie sich mit CLAUDE_CODE_GATEWAY_HINT_HEADERS=1 an – Verwaltete Einstellung „availableModelsMatch“ hinzugefügt: Mit "exact" lässt ein availableModels-Eintrag nur die Modellversion zu, die er benennt, sodass neue Versionen blockiert bleiben, bis sie aufgelistet werden – deniedModels-verwaltete Einstellung hinzugefügt, um bestimmte Modelle zu blockieren, auch wenn availableModels dies zulässt – MCP-Tool, WebFetch- und WebSearch-Ausgaben zum Span-Ereignis tool.output OpenTelemetry hinzugefügt, wenn OTEL_LOG_TOOL_CONTENT=1

  • /doctor prompt-audit (auch /checkup prompt-audit) hinzugefügt, um Ihre CLAUDE.md-Dateien, Fähigkeiten, Agenten und Befehle auf Eingabeaufforderungsmuster zu prüfen, die für ältere Modelle geschrieben wurden
  • click-to-expand für abgeschnittene Nachrichten aus Ihren anderen Sitzungen im Vollbildmodus hinzugefügt – path zu --plugin-dir-Ladefehlereinträgen im Stream-json system/init plugin_errors hinzugefügt, wobei das Verzeichnis benannt wird, das nicht geladen wurde – Der Claude-Apps-Gateway-Konfiguration wurde ein Opt-in-load_test_mode-Block hinzugefügt: Anfragen werden erstellt und signiert, aber nicht an den Upstream gesendet, und clients erhalten eine vorgefertigte Antwort, sodass eine Bereitstellung einem Lasttest unterzogen werden kann – Dem Claude-Apps-Gateway für den Mantle-Endpunkt von Amazon Bedrock wurde ein mantle-Upstream-Anbieter hinzugefügt – Behoben: SDK-Sitzungen, bei denen ein zurückgestellter Werkzeugaufruf oder ein abgeschlossenes Werkzeugergebnis verloren ging, wenn eine Runde vorzeitig endete, eine angehaltene Genehmigungsaufforderung nach einem Arbeiter-Neustart und ein Nicht-Streaming-Fallback result.usage – Problem behoben, bei dem MCP-Fortschrittsbenachrichtigungen verworfen wurden, sobald ein Werkzeugaufruf mit langer Laufzeit in den Hintergrund verschoben wurde; Die Hintergrundaufgabe zeigt nun den neuesten Fortschritt an – Problem behoben, bei dem stdio-MCP-Server weiterliefen, wenn die Sitzung endete, während sie noch starteten – Es wurde ein kurzer HTTP 404-Fehler von einem zustandslosen Remote-MCP-Server (z. B. einem Proxy während der erneuten Bereitstellung) behoben, der diesen Server für den Rest der Sitzung unbrauchbar machte, obwohl er weiterhin als verbunden angezeigt wurde – Problem behoben, bei dem die MCP-Anmeldung für einen Server ohne gültige URL mit einem undurchsichtigen SDK-Fehler fehlschlug; /mcp bietet für solche Server keine Authentifizierung mehr an – Das wöchentliche Fable-Limit wurde behoben, das in /usage und den VS-Code-Nutzungsanzeigen nicht angezeigt wurde, wenn die Telemetrie deaktiviert war – Problem behoben, bei dem /model Sonnet 4.6 oder Sonnet 5 mit [1m] akzeptierte, wenn die ID ein Datum oder das Suffix -v1:0 trug, in den Fällen, in denen die einfache ID abgelehnt wurde – Problem behoben, bei dem die /model-Auswahl eine fest codierte Haiku-Version und einen Preis anzeigte, wenn ANTHROPIC_DEFAULT_HAIKU_MODEL ein anderes Modell anheftete – Es wurden dynamische Arbeitsabläufe behoben, die während eines Modell-Fallbacks gestartet wurden und bei denen jeder Agent im Fallback-Modell ausgeführt wurde, anstatt das konfigurierte Modell erneut zu versuchen – Problem behoben, bei dem DISABLE_PROMPT_CACHING_HAIKU keine Wirkung hatte, wenn Haiku das Hauptmodell der Sitzung war
  • claude plugin validate behoben, das besagte, dass Claude Code einen Plugin- oder Marktplatznamen akzeptiert, den es nicht installieren kann; Solche Namen in marketplace.json schlagen jetzt bei der Validierung fehl – Problem behoben, bei dem claude plugin validate Plugins übergab, deren Pfade outputStyles, themes, monitors oder lspServers fehlen oder außerhalb des Plugin-Verzeichnisses zeigen – Problem behoben, bei dem claude plugin details 0 MCP-Server für Plugins anzeigte, die ihre Server in plugin.json deklarierten – Problem behoben, bei dem claude plugin marketplace remove nicht angab, welche installierten Plugins es mit dem Marktplatz deinstalliert hat; es listet sie jetzt auf – Problem mit claude plugin uninstall behoben, das das andere von zwei installierten Plugins entfernte, deren IDs sich nur in den Fällen, in den Optionen und Geheimnissen unterscheiden, wenn das benannte Plugin in diesem Bereich keinen enabledPlugins-Eintrag hatte
  • Plugins wurden behoben, die beim letzten Commit ihrer Quelle (nicht der installierten Version) angeben, dass keine Version stillschweigend wiederhergestellt wird, wenn ihre zwischengespeicherten Dateien fehlten – Behoben: Vom Benutzer installierte Plugins und Marktplätze konnten nicht mit „Cache-Miss“ geladen werden, nachdem das Home- oder Konfigurationsverzeichnis verschoben wurde, beispielsweise in Bind-gemounteten Devcontainern – Problem behoben, bei dem installed_plugins.json keine Plugins anzeigte, wenn es einen Datensatz unter einer ungültigen Plugin-ID enthielt; Eine solche Datei wird erneut geladen
  • Problem behoben, bei dem installed_plugins.json neu geschrieben wurde und Datensätze verloren gingen; wenn es einen Datensatz enthielt, konnte diese Version nicht lesen; claude plugin-Befehle benennen jetzt den Datensatz und sagen, wie er wiederhergestellt werden soll
  • Berechtigungsdialoge im Screenreader-Modus wurden korrigiert, in denen zitierte Befehle und Pfade so gelesen wurden, als wären sie der eigene Text des Dialogs – Behoben, dass /context MCP-Serveranweisungen nicht zählte: Sie erscheinen jetzt als eigene Zeile und zählen zur Gesamtsumme
  • Markdown-Links im Warp-Terminal wurden behoben, die als einfacher Text anstelle von clickable-Hyperlinks gerendert wurden – Problem mit der Erfolgsmeldung von claude mcp add, add-json und remove behoben, wenn die Benutzer- oder lokale Konfigurationsdatei nicht geschrieben werden konnte, beispielsweise in einer Sandbox – Problem behoben, bei dem die ersten Wörter einer Antwort in einer Cloud-Sitzung manchmal zu spät angezeigt wurden, statt gestreamt zu werden, während Claude sie schrieb
  • In Claudes integriertem Tastenbelegungsleitfaden wurde behoben, dass Akkorde nach 1 Sekunde statt nach 3 Sekunden ablaufen und cmd als Alias von meta aufgerufen wurde, was zu cmd+-Tastenkombinationen führen konnte, die die meisten Terminals nie senden
  • Problem behoben, bei dem keybindings.json einen falsch geschriebenen Modifikator wie ctl+k stillschweigend akzeptierte; Es gibt jetzt im Debug-Protokoll eine Warnung aus und schlägt die Lösung vor – Problem behoben, bei dem in den Fußzeilenhinweisen immer noch „Zur Ansicht eingeben“ angezeigt wurde, nachdem footer:openSelected in keybindings.json zurückgesetzt oder entbunden wurde – Problem behoben, bei dem schnell zusammen eingegebene Tasten (Voraustippen, Tastenwiederholung, Bursts über SSH oder Tmux) manchmal gegen den veralteten Status gehandhabt wurden – Problem behoben, bei dem Worktree-Auscheckvorgänge bei der Zertifikatsüberprüfung fehlschlugen (z. B. bei Git-LFS-Downloads), wenn das CA-Zertifikat als GIT_CONFIG_COUNT-Umgebungspaare an Git übergeben wurde – Problem behoben, bei dem der Sandbox-Fehler git Anmeldeinformations-Helfer aufforderte, die Anmeldung des Sandbox-Proxys zu speichern, was „Speicherung fehlgeschlagen“ ausgab. – Behoben, dass verwaltete sandbox-Einstellungen vollständig ignoriert wurden, wenn ein verschachtelter Wert ungültig war; Der ungültige Wert wird nun nicht mehr geschlossen und der Rest des Blocks gilt weiterhin – Behoben, dass Claudes Änderungen an seinen eigenen Auto-Memory-Notizen als Schreibvorgänge für sensible Dateien blockiert wurden, wenn Claude Code in einem Unterverzeichnis eines Git-Repositorys gestartet wurde – Problem behoben, bei dem die Fernbedienung bei kostenpflichtigen Plänen nicht verfügbar war, wenn die Telemetrie mit DISABLE_TELEMETRY oder DO_NOT_TRACK deaktiviert war
  • Das /remote-control-Menü hat in schmalen Terminals den QR-Code-Hinweis in der Wortmitte abgeschnitten – Problem behoben, bei dem der vim-Modus . eine neue Zeile mit Umschalt+Eingabetaste fallen ließ, den Cursor innerhalb eines Buchstabens mit Akzent beließ und eine ältere Änderung nach 3J oder im visuellen Modus J in der letzten Zeile wiederholte
  • Die Platzierung des Cursors im Vim-Modus wurde korrigiert: Beim Abrufen einer Eingabeaufforderung mit mehr als 10.000 Zeichen im Normalmodus bleibt der Cursor nicht mehr über dem Ende stehen, und V und dann p landen jetzt auf dem ersten nicht leeren Zeichen – Der Vim-Modus J, der Zeilen mit einem anderen Abstand als Vim verbindet (z. B. ein Leerzeichen vor ) oder nach einem Tabulator), wurde behoben, und 3J oder Visual-Modus J in der letzten Zeile bewegten den Cursor nicht wie bei Vim
  • Windows: Problem mit dem PowerShell-Tool behoben, das es cmd /c rd, rmdir, del oder erase ermöglicht, Laufwerksstämme, den Home-Ordner und andere Ordner zu löschen, die Remove-Item ablehnt
  • Die /mcp-Werkzeugliste wurde verbessert: Sie zeigt mehr Werkzeuge auf einmal an, scrollt mit den Seitentasten und der Maus und markiert Werkzeuge, die Ihre Organisation blockiert hat, mit einem Warnsymbol
  • Verbesserte MCP-Tool-Ergebnisse: Von MCP-Tools zurückgegebene Bilder werden jetzt auch in einer Datei gespeichert, sodass Bash, Read und andere Tools sie öffnen können
  • Verbessertes /tasks: Zeilen zeigen ein Statussymbol, der Name und ganze Fakten, der Titel und Tastenhinweise bleiben bei vielen Aufgaben auf dem Bildschirm und die Liste erhält Seitentasten, das Mausrad und clicks
  • Verbesserte Listen in /help, /hooks, /copy, /chrome, /memory, /ide, /release-notes, /rewind, /diff, /remote-env, /plugin und anderen Pickern mit Seitentasten, Mausrad und clicks
  • Verbesserte Listen neben einem Suchfeld, wie z. B. /skills und /artifacts, um ihren Zeiger abgeblendet zu zeichnen, während das Suchfeld über Tasten verfügt, sodass nur ein Zeiger hervorgehoben ist
  • Der Verdichtungs-Spinner wurde verbessert: Sein Timer startet jetzt, wenn die Verdichtung beginnt, und er zählt die Token der Zusammenfassung, während sie streamen, und ersetzt den Prozentbalken – Die nach der Anmeldung bei einem MCP-Server angezeigte Browserseite wurde verbessert: zentriertes Layout, dunkler Modus und neue Grafik – Die Antwort des Skill-Tools wurde verbessert, wenn ein Skill zu einem Plugin gehört, das nicht geladen werden konnte, sodass Claude Ihnen mitteilt, dass das Plugin nicht geladen werden konnte, anstatt den Skill als deinstalliert aufzurufen
  • Verbesserte prompt-audit zur Claude Code-Konfiguration: Veraltete Pfade, veraltete Befehle und widersprüchliche Anweisungsdateien führen jetzt den Bericht an, und denkende Schlüsselwörter, die Claude Code dokumentiert, werden beibehalten
  • Verbesserte Wiederherstellung von einem installed_plugins.json, der überhaupt nicht gelesen werden kann: Der Inhalt wird in einer Datei daneben gespeichert, bevor er neu erstellt wird, und claude plugin list benennt diese Datei
  • Verbesserte Artefaktdatenbank-Lesevorgänge: Eine geordnete Abfrage, die eine ganze Seite zurückgibt, sagt jetzt, dass es sich um eine Seite handelt und wie der Rest gelesen werden soll – Verbesserte Latenz bei der ersten Antwort: Ein Musterkompilierungsschritt, der am Ende der ersten Antwort einer Sitzung ausgeführt wurde, wird jetzt ausgeführt, während die Antwort eingeht – Verbesserte Latenz bei der ersten Anfrage durch Wiederverwendung der vorab verbundenen API-Verbindung
  • Verbesserter Start: claude -p und Claude Code Remote laden die interaktive Benutzeroberfläche nicht mehr und die Regeln des Auto-Modus-Klassifikators und das Artefakt-Tool werden bei der ersten Verwendung statt beim Start geladen
  • Verbesserter Start für claude.ai-Konten, deren Artifact-Tool-Funktionen noch nicht bekannt sind, wie beim ersten Start: Die Eingabeaufforderung wartet nicht mehr bis zu 1.5, um sie zu überprüfen; Die erste Nachricht wartet bei Bedarf – Interaktive Sitzungen bei Drittanbietern oder bei ausgeschalteter Telemetrie wurden so geändert, dass sie im automatischen Modus starten, wenn kein Berechtigungsmodus konfiguriert ist; permissions.defaultMode überschreibt es immer noch – Der Startdialog von /ultrareview wurde dahingehend geändert, dass bei der Überprüfung eines lokalen Zweigs möglicherweise nicht festgeschriebene Änderungen an verfolgten Dateien hochgeladen werden – Die Opus-Zeile des /model-Pickers und der Name des Standardmodells wurden geändert, um „(1M-Kontext)“ wegzulassen, wo Opus bereits über ein 1M-Kontextfenster verfügt; Das Fenster bleibt unverändert
  • Eingabeaufforderungsvorschläge im Terminal wurden so geändert, dass sie seltener erscheinen, nachdem 20 in Folge ungenutzt geblieben sind; Die Verwendung eines solchen bringt sie zurück
  • --system-prompt und --append-system-prompt geändert, um ihre Text- und -file-Formulare zusammen zu akzeptieren; Der Text der Datei steht an erster Stelle – Die Verweigerungsregeln von Skill(anthropic-skills:<name>) wurden geändert, um diesen Skill auch zu blockieren, wenn Claude Desktop ihn als Plugin bereitstellt, und Skill(skill:<name>) verweigert die Übereinstimmung mit dem Alias und dem Anzeigenamen des Skills – Die Listen /rewind und /diff wurden geändert, um dieselben Tastenkombinationsaktionen wie jede andere Liste (select:*) auszuführen. messageSelector:*/diff:*-Neubindungen funktionieren weiterhin – Die Ausführungsliste /workflows wurde so geändert, dass sie sich wie andere Listen in der Größe verhält: Die Hälfte des Terminals ist inline und der Titel bleibt auf dem Bildschirm, wenn die Eingabeaufforderung unten angezeigt wird – claude plugin eval so geändert, dass Git 2.31 oder höher erforderlich ist, wenn Git installiert ist; Eine Ausführung auf einem älteren Git wird mit einer Meldung mit der Benennung der Version abgelehnt
  • Artefaktbeobachtung geändert: Eine Wache, die automatisch scharfgeschaltet wurde (nicht eine, die Sie gewünscht haben), endet jetzt nach 3.5 Stunden ohne Aktivität; Durch das erneute Veröffentlichen oder Ansehen des Artefakts wird es wieder scharf gemacht – Selbstgehosteter Läufer: Der Git der Lebenszyklus-Hooks wurde geändert, um den Git LFS pre-push-Hook eines Repositorys zu überspringen, ein beschreibbares System core.hooksPath zu ignorieren und Commits ohne --configure-git nicht zu signieren
  • Selbstgehosteter Runner: GIT_SSL_CAINFO und GIT_SSL_NO_VERIFY unter von Anthropic verwaltetem Git geändert: Der eigene Git des Läufers überprüft immer die Git-Route von Anthropic, und Warnzeilen sagen, was wo gilt – Die 2.1.282-Reservierung des claude-ai-Namens wurde rückgängig gemacht: Die so genannten Skills, Befehle, Workflows und MCP-Server-Skills und -Eingabeaufforderungen werden erneut geladen, und die Skill(claude-ai:*)-Regeln sind normale Präfixregeln – [VSCode] Die Anzeige des Berechtigungsmodus wurde korrigiert und zeigte „Standard“ an, während die Sitzung weiterhin im automatischen oder Bypass-Modus ausgeführt wurde, nachdem ein automatisches Ausschalten fehlgeschlagen war. Der Wechsel wird nun wiederholt, bis er landet
  • [VSCode] Eine aus dem Internet teleportierte Sitzung wurde behoben, bei der die gesendeten Nachrichten verloren gingen, während Claude arbeitete – [VSCode] Problem behoben, bei dem eine Websitzung aus der Sitzungsliste ausgeblendet blieb und an ihrer Stelle ein leerer Chat geöffnet wurde, wenn eine ältere Version eine leere lokale Kopie davon gespeichert hatte
  • [VSCode] Es wurde ein Problem behoben, bei dem eine erneut geöffnete Sitzung einen Zug aufteilte, wenn Claude mitten im Zug eine Nachricht erhielt, z. B. eine automatische Fortsetzung – [VSCode] Eine neu geladene Sitzung wurde behoben, bei der eine zurückgespulte Drehung oder nur die Zeilen vor einer Verdichtung angezeigt wurden – [VSCode] Es wurde ein Problem behoben, bei dem das Agenten-Symbol der Fußzeile in schmalen Feldern außermittig dargestellt wurde, mit dem Statuspunkt am Rand – [VSCode] Problem behoben, bei dem bei der Chat-Eingabe der Text etwas unterhalb des Cursors und der Auswahl angezeigt wurde, nachdem Zeilen, die mit einem Zeilenumbruch enden, in eine lange Eingabeaufforderung eingefügt wurden
  • [Cloud-Sitzungen] Das Hinzufügen eines Repositorys zu einer laufenden Cloud-Sitzung wurde verbessert: Ein privates Repository, das Ihr GitHub-Konto lesen, aber nicht pushen kann, wird jetzt zum Lesen angehängt
  • [Cloud-Sitzungen] Problem behoben, bei dem Cloud-Sitzungen gelegentlich einen bereits abgeschlossenen Schritt wiederholten, z. B. das Posten eines doppelten Kommentars oder Pushs, nach der Wiederherstellung nach einem serverseitigen Neustart
  • [Cloud-Sitzungen] Neue Routinepläne wurden so geändert, dass sie standardmäßig einige Minuten nach der vollen Stunde erfolgen, mit dem Hinweis, dass Routinen, die genau auf die volle Stunde eingestellt sind, mehrere Minuten zu spät beginnen können
  • [Claude Tag] Es wurde eine Admin-Einstellung „Channels Claude can search“ hinzugefügt, die Claudes Slack-Suche auf öffentliche Kanäle beschränkt, zu denen sie hinzugefügt wurde, festgelegt pro Organisation, Arbeitsbereich oder Kanal
  • [Claude Tag] Auf der Seite, die nach dem Verbinden Ihres Claude-Kontos angezeigt wird, wurde eine Schaltfläche „Zurück zu Slack“ hinzugefügt, die Sie zu dem Thread zurückführt, von dem aus Sie begonnen haben
  • [Claude Tag] Die Konfigurationsseite eines Kanals wurde korrigiert und listete keine Connectors oder Plugins auf, wenn der Kanal sein Zugriffspaket über eine Anhängeregel erhält. Regelgebundene Bundles werden jetzt angezeigt
  • [Claude Tag] Die Access-Bundle-Repository-Suche mit fehlenden Repositorys bei GitHub-App-Installationen, die auf eine große Liste ausgewählter Repositorys beschränkt sind, wurde behoben
  • [Claude Tag] Problem behoben, bei dem Claude gelegentlich dieselbe Antwort zweimal postete, wenn eine neue Nachricht sie mitten in der Antwort unterbrach
  • [Claude Tag] Es wurden Kanalroutinen behoben, die in älteren privaten Kanälen nicht mehr liefen, deren Slack-Kanal-ID sich geändert hatte, beispielsweise nach einer Slack Connect-Freigabe – [Claude Tag] Behoben: Konversationen in einem Kanal, der auf „Nur Kanal“ eingestellt war, endeten alle, wenn ein Nicht-Gastmitglied beitrat und Slack seine Mitgliedschaft nur langsam bestätigte
  • [Codeüberprüfung] Problem behoben, bei dem „@claude review“-Anfragen stumm blieben, wenn GitHub die Pull-Anfrage nicht zurückgeben konnte: Die Anfrage wird einmal wiederholt und ein Kommentar erklärt, ob sie immer noch fehlschlägt
  • [Codeüberprüfung] Die Abrechnung für eine Überprüfung, die nach Ablauf der Frist ohne Überprüfung abgebrochen wurde, wurde korrigiert: Sie wird jetzt als unvollständig angezeigt, wird nicht in Rechnung gestellt und wird einmal erneut versucht
