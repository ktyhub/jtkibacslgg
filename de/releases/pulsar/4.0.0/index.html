Pulsar v4.0.0

21.10.2024

Änderungen in der Version 4.0.0 seit Beginn der Vorbereitungen für die Version 3.3.0. Die vollständige Liste finden Sie unter vollständige changelog und vollständige PR-Liste. Was ist neu in Apache Pulsar 4.0? behandelt Themen wie:

  • Verbesserte Implementierung des Key_Shared-Abonnements
  • Sichere Docker-Laufzeit basierend auf Alpine Linux und Java 21
  • Verbesserte Quality of Service-Kontrollen für mandantenfähige Bereitstellungen
  • Ratenbegrenzung als Grundlage für die mandantenfähige Ressourcenverwaltung
  • Upgrade-Pfade von früheren Versionen
  • Client-Kompatibilität und Bedeutung der Aktualisierung von Java clients zur Behebung von CVE-2024-47561
