agentescopio v0.1.0

¿Qué ha cambiado?

Modelo API

  1. Compatible con ZhipuAI API (https://github.com/modelscope/agentscope/pull/181)
  2. Soporte Yi API (https://github.com/modelscope/agentscope/pull/343)
  3. Admite el modo de transmisión en AgentScope (https://github.com/modelscope/agentscope/pull/347)
  4. Soporte LiteLLM (https://github.com/modelscope/agentscope/pull/204)
  5. Formatear los mensajes de entrada según el nombre del modelo (https://github.com/modelscope/agentscope/pull/381)

Servicio

Agregue las siguientes nuevas funciones de servicio

  1. Búsqueda en TripAdvisor
  2. Búsqueda doble
  3. búsqueda en wikipedia
  4. Control del navegador web
  5. Funciones de servicio multimodal OpenAI y DashScope

Otros

  1. Implementar el método MoA en AgentScope (https://github.com/modelscope/agentscope/pull/327)
  2. Un nuevo módulo de ingeniería rápida (https://github.com/modelscope/agentscope/pull/242)
  3. Mejorar el módulo RAG (https://github.com/modelscope/agentscope/pull/184)
