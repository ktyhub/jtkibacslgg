año v2.5.13

#Changelog

Mejoras:

  • ReliabilityEval: agregue coincidencia de subconjuntos, validación de argumentos y seguimiento de llamadas de herramientas faltantes con correcciones de recopilación de llamadas de herramientas de múltiples rondas.
  • AgentOS: Mejorar la lista de sesiones API para devolver campos adicionales (id_usuario, id_agente, id_equipo, id_flujo de trabajo, resumen_sesión, métricas, total_tokens, metadatos).
  • AgentOS: agregue el punto final /info API para devolver el recuento de agentes, equipos y flujos de trabajo como metadatos de instancia livianos y no autenticados.
  • ChromaDB: implemente la división dinámica por lotes para grandes operaciones de inserción/consulta.
  • Lector: Propagar chunk_size a las estrategias de fragmentación predeterminadas en las clases de lector.
  • Slack Interfaz: agregue el parámetro show_member_tool_calls y la rotación automática de desbordamiento de la tarjeta: gira a un mensaje nuevo cuando el texto excede un umbral

Corrección de errores:

  • VertexAI/Bedrock Claude: admite el parámetro messages en _prepare_request_kwargs para las subclases de Claude
  • Flujos de trabajo: Se corrigió continue_run para pausar correctamente en los pasos HITL de condición, bucle y enrutador; anteriormente solo se verificaban las instancias de paso.
  • AgentOS: excluye las rutas de interfaz (Slack, Telegram, WhatsApp, A2A) del middleware JWT para que las entregas de webhooks no se rechacen con 401.
  • Seguimiento: se corrigió la agrupación de estadísticas de sesión de seguimiento para usar solo session_id, evitando filas duplicadas cuando una sesión se ejecuta desde diferentes usuarios.
  • SurrealDB: corrigió las estadísticas de la sesión de seguimiento para usar array::first() en lugar de math::max() para los campos de cadena.
  • ReliabilityEval: Se corrigió la extracción de llamadas de herramientas de múltiples rondas para que se recopilen todas las rondas; corrige el error de mutación que modifica los mensajes RunOutput.messages originales; corrija arun() usando una ID incorrecta para guardar el archivo.
