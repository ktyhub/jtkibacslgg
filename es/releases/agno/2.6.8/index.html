año v2.6.8

#Changelog

Nuevas características:

  • Antigravity: Se agregó soporte propio para Antigravity API de Google en dos formas: AntigravityAgent (un BaseExternalAgent servido a través de AgentOS con sesiones/transmisión/UI nativas) y AntigravityTools (un Toolkit que permite a cualquier agente Agno delegar una subtarea a un entorno limitado de Antigravity administrado).
  • Agentes administrados de Gemini: Se agregó compatibilidad con GeminiInteractions para los agentes administrados de Google: Investigación profunda (investigación autónoma con citas, transmisión en segundo plano con reconexión/currículum last_event_id) y Antigravity (agente de uso general en un entorno limitado de Linux administrado). Nuevos campos agent / agent_config / environment, forzado por agente de background y store y soporte para mcp_servers + file_search_store_names en la ruta del agente.
  • Libro de recetas - Etiquetado de datos: Se agregó cookbook/data_labeling/ con 18 flujos de trabajo independientes que cubren texto, imagen, audio, video, documentos y primitivas de etiquetado compuesto (LLM como juez, revisión de calidad).
  • Libro de cocina - Slack HITL: Se agregó una demostración determinista del comandante de incidentes de Slack HITL que muestra pausas estructuradas a través de tool_choice="required", eco de entrada de usuario y terminación limpia a través de stop_after_tool_call=True.

Mejoras:

  • Seguridad de ruta (Seguridad): Seguridad de ruta centralizada en un nuevo módulo agno.utils.path_safety con safe_join y safe_join_subpath. FileGenerationTools, SlackTools, Toolkit._check_path, agno.skills.utils.is_safe_path y FileTools.check_escape reforzados contra ataques de recorrido de ruta, escape de enlace simbólico, inyección de caracteres de control, Windows MagicDot y normalización Unicode. Se introdujo PathSecurityError (FileGenerationSecurityError se mantuvo como alias en desuso). Se pasó de requires-python a >=3.9,<4.
  • MCP paralelo: ParallelMCPBackend ahora envía User-Agent: agno/<version> en cada solicitud para que Parallel pueda atribuir el tráfico a agno.
  • Configuración de evaluaciones: Se eliminó el campo available_models no utilizado de EvalsDomainConfig; el AgentOSConfig.available_models de nivel superior es ahora la única fuente compatible para el menú desplegable de la interfaz de usuario de Evals.
  • Chonkie: Pin de dependencia de chonkie actualizado (seguimiento del n.° 7869).
  • Libro de cocina: Renombrado gemini-3-flash-preview a gemini-3.5-flash en todos los libros de cocina de Gemini Interactions.

Corrección de errores:

  • Equipos AG-UI: Se corrigió un error tipográfico (stream_steps → stream_events) que causaba que los equipos que ejecutaban a través de AG-UI descartaran silenciosamente todos los eventos de transmisión intermedios (ciclo de vida, razonamiento, llamadas de herramientas, delegaciones de miembros) durante aproximadamente 7 meses.
  • Extra de Slack: Se agregó aiohttp>=3.7.3,<4 al extra opcional slack: AsyncWebClient importa aiohttp en la carga del módulo, por lo que pip install agno[slack] se interrumpió para todas las operaciones de Slack.
  • Google Drive: apareció la bandera Drive API incompleteSearch de GoogleDriveTools.search_files() para que las personas que llaman a corpora="allDrives" puedan detectar cuando Drive no buscó en todas las unidades.
  • GeminiInteractions: Se agregó un campo de paso generation_config para controles avanzados (top_k, presence_penalty, etc.) y manejo del historial fijo: cuando se configura previous_interaction_id, solo se envía el nuevo turno en lugar de reproducir el historial completo. Ahora realmente aprovecha el estado del lado del servidor.
  • Herramientas de servidor Anthropic: Se conservaron server_tool_use y bloques de contenido de ejecución de código en el historial de mensajes para que los flujos de herramientas de servidor de múltiples turnos ya no se dividan entre turnos.
  • Endurecimiento antrópico: Seguimiento de lo anterior: se cambió al tipo literal canónico redacted_thinking (el SDK rechaza redacted_reasoning_content), aceptó ambas ortografías en el evento de inicio de transmisión, agregó una protección de deduplicación en los bloques de herramientas del servidor de ida y vuelta, hizo visibles las fallas de coerción a través de log_warning y forzó a enviar elementos de resultados de herramientas sin bloqueo a texto.
  • Errores de Gemini: Los errores genéricos de Gemini ahora incluyen el tipo de excepción cuando str(error) está vacío o es débil, lo que preserva el contexto de error en invoke / invoke_stream / ainvoke / ainvoke_stream.
  • N1N: Se agregó la asignación del proveedor n1n que faltaba en get_model(), por lo que las rutas de cadena del modelo Agent(model="n1n:...") ahora se resuelven correctamente.
