#AstrBot v4.16.0

¿Qué ha cambiado?

Nuevo

  • La plataforma de robot oficial QQ admite mensajes push activos y los escenarios de chat privado admiten la recepción de archivos (#5066)
  • Se agregó la función de mostrar automáticamente "escribiendo", "cargando imágenes" y otros estados cuando se espera la respuesta de AI al adaptador de plataforma Telegram (#5037)
  • Se agregó la capacidad de recibir archivos y leer el contenido de mensajes de referencia (incluidas imágenes, videos, archivos, textos, etc. de referencia) para el adaptador Feishu (#5018)
  • Se agregó soporte para adaptador de plataforma personalizado i18n (#5045)
  • Se agregaron capacidades de procesamiento de archivos temporales, lo que le permite limitar el tamaño máximo del directorio data/temp en la configuración del sistema. (#5026)
  • Se agregó la función de primer anuncio de inicio, admite integración en varios idiomas y WebUI

Arreglar

  • Se corrigió el error de fragmento en el escenario OpenRouter DeepSeek (#5069)
  • Se solucionó el problema de la falta de asignación de carpetas de personalidad durante la copia de seguridad (#5042)
  • Se solucionó el problema de las barras de desplazamiento dobles en el registro de actualización y las ventanas emergentes de documentos oficiales (#5060)
  • Se corrigió la visualización anormal de la clave en la ventana emergente de parámetros adicionales del proveedor. -Se solucionó el problema de las indicaciones de registro de errores inexactas cuando fallaba la conexión.
  • Se corrigió el problema de limpieza de recursos causado por no esperar la rutina de reinicio al regresar temprano (#5033)
  • Mejorar la estabilidad de inicio de la versión empaquetada del escritorio y optimizar el procesamiento de dependencias de complementos (#5031)
  • Agregar rotación de tamaño para registros de electrones y backend (#5029)
  • Reforzar el proceso de carga de dependencias del complemento de tiempo de ejecución de aplicaciones congeladas (#5015)

Optimización

  • Mejorar los mensajes de fusión, la resolución de referencia y la reversión de imágenes, y admitir el control de configuración (#5054)
  • La página de configuración admite el cambio entre configuración normal/configuración del sistema a través de subelementos de la barra lateral, y se agregan correcciones de ruta relevantes.
  • Optimizar la lógica de inicialización del intervalo de respuesta segmentada (#5068)

Documentación y Mantenimiento

  • Sincronizar y corregir el contenido y la ortografía del documento README (#5055, #5014)
  • Se agregaron instrucciones de instalación de AUR (#4879)
  • Realizar formateo de código (ruff)

Qué ha cambiado (ES)

Nuevas características

  • Se agregó soporte de recepción de archivos de chat privado y envío de mensajes proactivos para el adaptador de bot oficial de QQ (#5066)
  • Se agregó visualización automática del estado de "escribiendo..." y "cargando imagen..." mientras se espera la respuesta de AI en el adaptador de Telegram (#5037)
  • Se agregó recepción de archivos y lectura de contenido de mensajes citados (incluidas imágenes, videos, archivos, textos, etc.) para el adaptador Feishu (#5018)
  • Se agregó soporte i18n para adaptadores de plataforma personalizados (#5045)
  • Se introdujo el manejo de archivos temporales y TempDirCleaner (#5026)
  • Se agregó una función de aviso de primer lanzamiento con contenido multilingüe e integración con WebUI

Correcciones

  • Se agregó cambio de pestaña secundaria en la barra lateral para la configuración normal/del sistema y se corrigió el comportamiento de enrutamiento relacionado en la página de configuración.
  • Se corrigieron errores de fragmentos al usar OpenRouter DeepSeek (#5069)
  • Análisis mejorado de cotizaciones reenviadas y respaldo de imágenes con controles configurables (#5054)
  • Se corrigió la asignación de carpetas de personas que faltaban en las exportaciones de respaldo (#5042)
  • Se solucionó el problema de la doble barra de desplazamiento en changelog y los cuadros de diálogo de documentos oficiales (#5060)
  • Se corrigieron problemas de representación clave en el cuadro de diálogo de parámetros adicionales del proveedor.
  • Redacción mejorada del registro de errores para fallas de conexión
  • Se corrigió la limpieza de rutina de reinicio no esperada en devoluciones tempranas (#5033)
  • Se mejoró la estabilidad del inicio del escritorio empaquetado y el manejo de la dependencia de complementos (#5031)
  • Se agregó rotación de registros basada en el tamaño para registros de Electron y backend (#5029)
  • Carga de dependencia de complemento reforzada en el tiempo de ejecución de la aplicación congelada (#5015)

Mejoras

  • Lógica de inicialización optimizada para el intervalo de respuesta segmentada (#5068)

Documentos y mantenimiento

  • Documentos README y errores tipográficos sincronizados y corregidos (#5055, #5014)
  • Se agregaron instrucciones de instalación de AUR (#4879)
  • Formato de código aplicado con ruff.
