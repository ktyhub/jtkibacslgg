código-claude v2.1.271

¿Qué ha cambiado?

  • Modo rápido agregado en las sesiones remotas de Claude Code (ejecudores en la nube y autohospedados): la configuración del modo rápido del host o /fast ingresado en la sesión se aplica donde su organización lo permite.
  • Se agregó compatibilidad con el mouse al panel /config en modo de pantalla completa: la rueda desplaza la lista de configuraciones, un click en el valor de una configuración lo cambia y la fila debajo del puntero se resalta
  • Se agregó claude self-hosted-runner --drain-marker-file <path>: cuando ese archivo existe en un drenaje SIGTERM, el ejecutor informa su salida al servidor como un drenaje de host (solo telemetría)
  • Se agregó allowed_domains por comando a Bash, PowerShell y Monitor en modo automático con sandboxing: los hosts que necesita un comando se revisan con él y se abren solo para él; otros hosts son rechazados
  • Se agregó omitClaudeMd al frontmatter del agente y --agents JSON, lo que permite que los subagentes personalizados y de complementos se ejecuten sin archivos CLAUDE.md locales, de proyecto ni de usuario; Los archivos de políticas administradas aún se cargan.
  • Se agregó --accept-command <sha256> a claude plugin install y claude plugin update para aceptar exactamente el comando mostrado en una ejecución anterior de --json, en lugar de -y.
  • Se agregó soporte para un multiplier superior a 1, hasta 10, en la configuración administrada modelPricing y el bloque pricing de la puerta de enlace de aplicaciones de Claude, para tasas de contracargo internas marcadas.
  • Se agregó una punta giratoria que dirige a los usuarios de Bedrock, Vertex AI, Foundry y LLM gateway a la aplicación de escritorio Claude; el consejo de la aplicación de escritorio claude.ai ahora sugiere /desktop, que ofrece descargar la aplicación
  • Se corrigió una política de organización almacenada en caché que se reutilizaba después de cambiar de cuenta, organización o claves API, y que la política no se actualizaba hasta la verificación cada hora cuando la credencial cambia a mitad de sesión.
  • Se corrigió que las listas de herramientas y comandos no se actualizaran cuando la política de la organización termina de cargarse después del inicio o cambia a mitad de la sesión.
  • Se corrigió un managed-mcp.json empresarial que no se puede leer ni analizar y se ignora: ahora mantiene el control MCP exclusivo (los servidores de usuarios, proyectos y complementos no se cargan) y advierte al inicio
  • Se corrigió que la política de organización fuera obtenida y rechazada por servidores proxy locales de terceros establecidos a través de ANTHROPIC_UNIX_SOCKET; nuevamente se tratan como otras puertas de enlace personalizadas, incluso para control remoto
  • Se corrigieron las sesiones en la nube que rechazaban cada llamada a la herramienta de subagente ("updatedInput... validación de esquema fallida") cuando se aplicaba un flujo de trabajo o aprobación de agente después de que se reiniciaba el trabajador de la sesión.
  • Se corrigió que /fast off respondiera "Modo rápido no disponible" en lugar de desactivar el modo rápido cuando la organización tiene el modo rápido deshabilitado.
  • Se corrigieron las sesiones que comenzaban con el CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK reenviando solicitudes rápidas en cada turno después de que el API rechazaba el modo rápido; El rechazo ahora se mantiene y se muestra su razón.
  • Se corrigió el modo rápido en CLAUDE_CODE_RETRY_WATCHDOG que fallaba al activar un límite de créditos de uso o reintentaba una sobrecarga a velocidad rápida, en lugar de volver a la velocidad estándar.
  • Se corrigieron las comprobaciones de permisos de Bash que faltaban en el archivo que fmt, column y comandos similares leen cuando sigue una opción que el verificador no reconoce.
  • Se corrigieron las comprobaciones de permisos de Bash que omiten archivos a los que se expande un comodín cuando el comodín se encuentra en el patrón de un comando o en el valor de opción (por ejemplo, grep -v dir/* file).
  • Se corrigieron las comprobaciones de permisos de Bash para que los indicadores de declaración de variables de shell no puedan tergiversar el comando que se está ejecutando.
  • Se corrigieron los comandos Bash con dos cambios de directorio, un subshell o una cadena cd+git omitiendo el mensaje bajo permissions.blockReadsOutsideWorkingDirectories en modo bypass y automático.
  • Se corrigió un .git/config.lock obsoleto que interrumpía git checkout -b, git push -u y git config durante el resto de una sesión después de que un comando de espacio aislado no se pudiera iniciar (Linux).
  • Se corrigieron los cambios en los archivos de configuración realizados fuera de la sesión que pasaban desapercibidos en máquinas macOS cuyo servicio de eventos de archivos del sistema estaba saturado; el observador ahora vuelve a las encuestas
  • Se corrigieron las sesiones reanudadas de claude -p cuyas herramientas provienen de servidores MCP fallando con "Al menos una herramienta debe tener defer_loading=false"
  • Se corrigió el error de giro con "API devolvió una respuesta vacía o con formato incorrecto" cuando una puerta de enlace LLM devuelve la respuesta sin transmisión como text/plain.
  • Se corrigió el uso elevado sostenido de CPU y solicitudes repetidas de lista de herramientas cuando un servidor MCP envía notificaciones list_changed en un bucle cerrado.
  • Se corrigió el mal manejo de registros client de MCP OAuth: al negar el consentimiento se forzaba uno nuevo, se reutilizaba uno para otro URI de redireccionamiento y una escritura simultánea podía eliminar uno válido o mantener uno que no coincidía.
  • Se corrigió que la búsqueda de herramientas no devolviera ninguna coincidencia cuando Claude selecciona una herramienta MCP por su nombre simple en lugar de su nombre completo mcp__server__tool.
  • Se corrigió Ctrl+O que cancelaba las reconexiones pendientes del servidor MCP y /mcp enviado desde el control remoto fallaba mientras la vista de transcripción estaba abierta.
  • Se corrigió el mensaje de Claude en Chrome que le indicaba al modelo que cargara herramientas a través de ToolSearch cuando ToolSearch no estaba disponible.
  • Se corrigieron los mensajes entre sesiones retenidos por la política de modo de permiso de la sesión receptora sin dejar rastro: los remitentes sin cabeza ahora reciben un aviso de entrega y los resultados de SendMessage ya no implican que fue leído
  • Se corrigió que Claude iniciara una segunda copia de un comando en segundo plano (como una tarea de vigilancia o un servidor de desarrollo) que aún se estaba ejecutando después de que se compactara la conversación.
  • Se corrigió la advertencia /model sobre la pérdida del caché de la conversación al volver al modelo en el que realmente se ejecutó la conversación.
  • Se corrigió que /reload-skills informara un recuento de habilidades que no concordaba con el menú de barra diagonal después de /cd.
  • Se corrigió que /resume y /continue mostraran solo 1 o 2 sesiones en modo de pantalla completa en terminales cortos.
  • Se corrigió que /resume y /teleport mantuvieran el seguimiento de lectura de archivos de la conversación anterior, para que Claude pudiera editar archivos que la conversación reanudada nunca había leído.
  • Se corrigió que --resume dejara caer la ventana de contexto de 1M ([1m]) cuando la familia de modelos de la sesión reanudada difiere del modelo predeterminado configurado.
  • Se corrigieron los artefactos adjuntos con /artifacts que desaparecían de la sesión después de --resume.
  • Se corrigieron sesiones en segundo plano (claude --bg, claude agents) que no veían los artefactos que publicaban para republicaciones realizadas en otros lugares.
  • Se corrigieron agentes personalizados, comandos de barra diagonal y estilos de salida más allá del primero que no se cargaban desde una unidad virtual que informa el inodo 0, como una bóveda cifrada montada como una unidad de Windows.
  • Se corrigieron sesiones de ejecución autohospedadas que perdían silenciosamente toda la configuración del host (configuraciones, habilidades, complementos, servidores MCP) cuando el directorio de configuración del host supera los 64 MiB; añadido --host-config-snapshot disk|memory
  • Se corrigieron las habilidades sincronizadas desde claude.ai que permanecían en el disco indefinidamente después de cerrar sesión; las copias no actualizadas dentro de cleanupPeriodDays ahora se mueven a la papelera recuperable en el próximo lanzamiento
  • Se corrigieron sugerencias giratorias que sugerían comandos que no están disponibles para su tipo de cuenta o que están deshabilitados en su sesión.
  • Se corrigió la entrada de ruta /add-dir: las teclas de flecha izquierda y derecha ahora mueven el cursor y Enter agrega solo la ruta escrita en lugar de agregar también la finalización resaltada.
  • Se corrigieron los campos de texto fuera del mensaje principal moviendo un ! inicial al final de lo que escribiste (!foo apareció como foo!)
  • Se corrigió que el menú interactivo /hooks fallara cuando un comparador de ganchos tiene el nombre de una propiedad de objeto heredada como __proto__ o constructor.
  • Se corrigió un problema de renderizado en pantalla completa donde el texto mantenía un color de fondo obsoleto después de que el cuadro a su alrededor perdía su fondo.
  • Se corrigió que Eliminar en st y Alt+teclas de flecha en rxvt-unicode no funcionaran en sesiones en segundo plano adjuntas.
  • Se corrigieron las respuestas del terminal a las consultas de capacidad (^[[?1;2c) que aparecen en el símbolo del shell o en un editor cuando Claude Code sale, se suspende o abre un editor justo después de iniciar.
  • Rendimiento de renderizado de terminal mejorado: las diferencias grandes y las transcripciones largas se renderizan más rápido, con menos cuadros lentos
  • Se mejoró ligeramente el tiempo de inicio al omitir una validación redundante de los datos del modelo integrado en cada lanzamiento.
  • Comentarios de gancho mejorados: mientras se ejecuta un gancho SessionStart, UserPromptSubmit, PreToolUse o SessionEnd, el control giratorio lo dice con el tiempo transcurrido y Esc cancela un mensaje en espera en un gancho SessionStart.
  • Se mejoró el estado de la ruleta durante el pensamiento prolongado: ahora dice "pensamiento profundo" después de 45 segundos y muestra "retomar el pensamiento" mientras se recupera del límite de token de salida.
  • Flujos de trabajo dinámicos mejorados para pausar cuando alcanza su límite de uso y continuar automáticamente cuando se reinicia, en lugar de descartar a los agentes afectados
  • Control remoto mejorado para dejar menos sesiones vacías en claude.ai cuando falla la configuración en una red inestable
  • Se mejoró el mensaje de Claude en Chrome en sesiones en la nube cuando no se puede acceder al navegador: ahora dice que la computadora puede estar inactiva antes de sugerir una instalación.
  • claude mcp serve mejorado: una llamada de herramienta en ejecución ahora envía una actualización de progreso cada 30 segundos, por lo que clients muestra que aún se está ejecutando y los tiempos de espera de inactividad no cancelan un comando largo que no imprime nada.
  • Sesiones mejoradas de Foundry y Claude Platform en AWS: un servidor MCP alwaysLoad que termina de conectarse en mitad de la conversación se puede utilizar en el siguiente turno sin un viaje de ida y vuelta de búsqueda de herramientas
  • Archivos Markdown mejorados publicados como artefactos: ahora se muestran como páginas de documentos con estilo (encabezado de título, tipografía de documento, código resaltado de sintaxis)
  • Errores de publicación de la herramienta Artifact mejorados: una publicación sin archivo ahora dice que primero se escriba la página en un archivo y se informa un tipo de archivo no compatible antes de que falte un favicon.
  • Se mejoró el error de la herramienta Artifact cuando una página declara una capacidad de la que carece su versión de contrato: ahora enumera todas las capacidades admitidas y anota cuando la tiene una versión de contrato más nueva.
  • Observación de artefactos mejorada: una sesión ahora puede ver hasta 10 artefactos publicados a la vez para republicaciones realizadas en otro lugar, en lugar de 5
  • PDF @-menciones mejoradas para decir "recuento de páginas desconocido" en lugar de un recuento de páginas adivinado a partir del tamaño del archivo cuando pdfinfo no puede contar las páginas
  • /mobile mejorado para mostrar un código QR único para claude.ai/mobile, que abre la tienda de aplicaciones adecuada para su teléfono
  • Se cambió el modo automático para que los comandos de shell ! en línea de un comando de habilidad o barra diagonal sigan las reglas de permisos del modo predeterminado en lugar del clasificador; un comando que ninguna regla decide se ejecuta como una llamada a una herramienta revisada
  • Se cambió el modo automático para que un subagente informe a la persona que llama a través de una llamada de devolución dedicada que el clasificador de seguridad revisa, en lugar de que su último mensaje se revise después del hecho.
  • Se cambiaron los relojes de monitor para tener siempre una fecha límite (como máximo 30 minutos; 10 en ejecuciones de un solo mensaje de -p) y notificar a Claude que se rearme, reemplazando la opción sin tiempo de espera de persistent.
  • Se cambió el indicador de selección de IDE en el mensaje a una pastilla [⧉ …] que se ajusta al texto en lugar de comprimir mensajes de varias líneas; elimínelo con Retroceso para dejar fuera la selección
  • Se cambió el tamaño predeterminado del flujo de trabajo dinámico a pequeño en los planes Pro y se redujo la pauta de tamaño mediano de 15 a 10 agentes.
  • Se cambiaron las sesiones de puerta de enlace de aplicaciones de Claude, Bedrock, Vertex AI y Foundry para que ya no actualicen el inicio de sesión sobrante de claude.ai que la sesión no utiliza.
  • Se actualizó la habilidad claude-api incluida para habilitar eager_input_streaming en herramientas personalizadas de transmisión y para comenzar a trabajar con agentes administrados en forma de entrega con user.define_outcome.
  • [VSCode] Se agregó una configuración para Adjuntar archivo abierto que, cuando está desactivada, impide que el archivo abierto se agregue a los mensajes; El texto seleccionado todavía está adjunto.
  • [VSCode] Se corrigieron los cuadros de diálogo de reglas de permisos y ganchos que informaban que un guardado falló y el cuadro de diálogo de ganchos se quedaba en blanco bajo un bloqueo de política de solo complemento o mostraba códigos de color en los errores de guardado.
  • [VSCode] Guardado del cuadro de diálogo de ganchos fijos: no hay ganchos duplicados al reemplazar, un nombre de encabezado reescrito en otros capitals mantiene su secreto y settings.local.json se ignora antes de que vuelva a guardarse
  • [VSCode] Se corrigió el historial de sesiones que muestra solo la sesión actual cuando el espacio de trabajo está en una unidad de red asignada de Windows o en una unidad SUBST.
  • [VSCode] Se corrigió el filtro Activo de la lista de sesiones que ocultaba las sesiones inactivas abiertas cuando Abrir también está marcado en el menú de filtro.
  • [VSCode] Se corrigió un nuevo chat que volvía al chat anterior cuando se actualizaba la lista de sesiones.
  • [VSCode] Se corrigieron las pestañas abiertas y la barra lateral manteniendo la carpeta de configuración anterior hasta que se recarga la ventana después de que CLAUDE_CONFIG_DIR cambiara en la configuración de environmentVariables.
  • [VSCode] Se corrigió que las ventanas de la consola parpadearan en Windows cuando la extensión ejecuta comandos en segundo plano como git, ripgrep y la verificación del estado de inicio de sesión.
  • [VSCode] Se corrigió el texto emergente del reloj de caché que aparece solo después de un retraso y el ícono de autocompacto que muestra la información sobre herramientas del navegador junto a su ventana emergente.
  • [VSCode] Se mejoró el cuadro de diálogo Hooks: un guardado rechazado debido al archivo de configuración ahora abre una ventana emergente con un botón "Abrir archivo de configuración" y el motivo detrás del "Error de copia".
  • [VSCode] Se cambió el estado activado de los interruptores de Claude naranja al color del botón del tema del editor.
  • [Claude Code en la web] Se corrigió una sesión en la nube que a veces tardaba unos diez minutos en responder después de que su proceso salía mientras la sesión aún parecía activa; enviar un mensaje ahora lo reinicia de inmediato
  • [Claude Code en la web] Se cambió la página Rutinas en claude.ai/code a un nuevo diseño con pestañas Tuyas y Plantillas y tarjetas de rutinas de dos columnas que muestran el estado de ejecución, y se eliminó su vista de calendario.
  • [Claude Code en la web] Se agregó una opción de acceso a red personalizada al editor de entornos de nube en la configuración de administración, con la misma lista de dominios permitidos que ofrece el cuadro de diálogo de entorno en claude.ai/code.
  • [Claude Code en la web] Se mejoró la página de administración de entornos en la nube: muestra el entorno predeterminado para Claude Tag y Claude Code, con un enlace para cambiarlo y marca el tipo recomendado para crear.
  • [Etiqueta de Claude] Se corrigió que Claude en un canal permaneciera activo y perdiera su contexto de trabajo aproximadamente una vez por hora cuando la conversación se desarrolla principalmente en hilos; La actividad del hilo ahora evita que se reinicie.
  • [Etiqueta de Claude] Se corrigió un hilo que le pedía a Claude que mirara una solicitud de extracción y ya no escuchaba sobre fallas, comentarios y revisiones de CI después de que Claude se reiniciara en ese hilo.
  • [Etiqueta de Claude] Se corrigió la eliminación del primer mensaje de un hilo que Claude ya había respondido al no terminar el trabajo de Claude allí; ahora se detiene, como lo hizo cuando se eliminó un mensaje sin respuestas
  • [Etiqueta de Claude] Se corrigió que Claude retuviera una publicación debido a una instrucción anterior dirigida a un bot o asistente diferente; sólo las instrucciones dirigidas a Claude lo vinculan, y pregunta cuando no está seguro
  • [Etiqueta de Claude] Se corrigió la tarjeta de modo de respuesta que Claude publica al unirse a un canal ocupado diciendo que "ve muchas publicaciones automatizadas" cuando el canal solo es conversador o grande; la tarjeta ahora nombra la verdadera razón
  • [Claude Tag] Se mejoró el selector de entorno en la configuración de administración de Claude Tag: las opciones están etiquetadas como Anthropic-hosted o self-hosted, con enlaces para editar ese entorno o crear uno.
  • [Revisión de código] Se corrigió una solicitud de extracción en un repositorio revisado una vez por PR que a veces no recibía revisión cuando llegaba una confirmación mientras su revisión estaba esperando para comenzar; ahora revisa el compromiso solicitado
  • [Revisión de código] Se corrigió que la revisión de código ocasionalmente publicaba los mismos hallazgos dos o tres veces cuando GitHub reportaba un error para una revisión que de hecho había creado.
  • [Revisión de código] Se corrigieron revisiones de seguimiento que volvían a publicar un hallazgo de seguridad que una persona ya había resuelto cuando un envío posterior movió las líneas a las que estaba anclado.
  • [Revisión de código] Se corrigió la reapertura de una sesión en la nube finalizada/ultrareview en la aplicación Claude y el inicio de toda la revisión nuevamente sin que se le solicite
  • Windows: Se corrigió que los comandos de PowerShell fallaran con el "Código de salida 1" y no generaran resultados cuando la ruta de salida temporal de la sesión alcanza los 260 caracteres.
