código-claude v2.1.275

¿Qué ha cambiado?

  • Se agregó la cuenta iniciada al inicio de sesión de la puerta de enlace de aplicaciones de Claude: cuando la puerta de enlace la nombra, usted la confirma antes de guardar la credencial y /status la muestra.
  • Se agregó una tecla de enviar ahora (ctrl+enter, o ctrl+x ctrl+s) que interrumpe el turno actual y envía todos los mensajes en cola a la vez; Los mensajes enviados y en cola se muestran en gris hasta que el modelo los recibe.
  • Se agregó una advertencia de inicio cuando falla un otelHeadersHelper configurado, para que se noten las sesiones que no exportan telemetría silenciosamente.
  • Se agregó sincronización de las habilidades y complementos habilitados en su cuenta claude.ai con las sesiones de terminal iniciadas con ella; optar por no participar con syncClaudeAiSkills: false o syncClaudeAiPlugins: false
  • Se agregó /plugin install <plugin> --marketplace <source>, que ofrece agregar el mercado antes de instalar el complemento.
  • Se corrigió que la nota de antigüedad de un archivo de memoria restaurada cambiara entre solicitudes después de una compactación o reanudación, lo que causaba errores de caché en el aviso.
  • Se corrigió la salida de flujo --forward-subagent-text-json y SDK que eliminaba los mensajes de los subagentes generados por una habilidad context: fork y de las habilidades bifurcadas invocadas por un subagente u otra habilidad bifurcada.
  • Se corrigió que las sugerencias de archivos con mención @ quedaran ocultas debajo de los recursos de MCP cuando se usaba un comando fileSuggestion personalizado o se escribía @./@./.
  • Se corrigió el modo de pantalla completa que colocaba avisos de finalización de tareas en segundo plano debajo de la fila de herramientas colapsada de un turno largo en lugar de donde llegaron; cada aviso ahora cierra la fila abierta
  • Se corrigió que claude plugin marketplace update eliminara la copia local de un mercado GitHub cuando fallaba la recuperación y el mercado recibía el nombre de su repositorio.
  • Se corrigieron los mensajes del complemento y del mercado, registros y claude plugin marketplace list que mostraban una contraseña o token almacenado en una URL de git, ssh o del mercado.
  • Se corrigió una sesión en la nube reanudada que dejaba una pregunta sin respuesta abierta en la transcripción después de que un mensaje en cola la reemplazara.
  • Se corrigió el modo vim colocando el cursor un carácter justo después de un punto repetido "!" o una "i" escrita rápidamente. cambió un mensaje no vacío al modo shell
  • Se corrigió el modo de pantalla completa que se congelaba o se quedaba en blanco durante varios segundos al desplazarse hacia arriba más allá de una diferencia de archivo grande.
  • Se corrigió una etiqueta de cierre perdida de estilo </ccmemory> que aparecía ocasionalmente en las respuestas.
  • Se corrigieron los mensajes del complemento, los registros y el cuadro de diálogo del complemento VS Code que mostraba el servidor incorrecto para algunas direcciones de git.
  • Se corrigió una terminal API Error: 400 en cada turno para los usuarios detrás de una puerta de enlace de red que reescribe las respuestas de error API cuando se rechaza un encabezado de solicitud beta.
  • Se corrigieron los comandos Bash en el espacio aislado en Linux que informaban el código de salida 0 para comandos fallidos cuando el shell es zsh.
  • Se corrigió que la herramienta de lectura se bloqueara en lugar de informar un error cuando parte de un archivo grande no se podía decodificar bajo presión de memoria.
  • Se corrigió que --resume, la vista previa del selector de currículum, los agentes en segundo plano reanudados y la vista de transcripción fallaran en una sesión cuyo historial guardado contenía un recordatorio de tarea con formato incorrecto o una entrada de archivo @ adjunto
  • Se corrigió un bloqueo al reanudar una conversación cuya transcripción contiene una entrada de mensaje con formato incorrecto y un bloqueo de pantalla completa cuando dicha conversación recibía nuevos mensajes mientras se desplazaba hacia arriba.
  • Se corrigieron sesiones que no se reanudaban o iniciaban cuando su transcripción guardada contenía un bloque de contenido de mensaje con formato incorrecto.
  • Se corrigieron las sugerencias de Grep, Glob y @-file que se bloqueaban o se quedaban sin memoria en búsquedas por encima del límite de salida de 20 MB, y el ripgrep del sistema informaba "no hay coincidencias" en lugar de un error después de una avalancha de advertencias.
  • Se corrigió /rewind en una sesión bifurcada o en segundo plano que restauraba un archivo con ceros o truncado cuando las copias de seguridad del historial de archivos de la sesión no se podían copiar por completo.
  • Se corrigieron sesiones de pantalla completa que a veces salían con "Claude Code salió después de un error de interfaz irrecuperable" al escribir rápido o mantener presionada una tecla con el menú desplegable de comando de barra abierta
  • Se corrigieron sesiones en segundo plano que fallaban y reiniciaban su trabajador cuando un comando alimentado a través de stdin se ejecutaba en una máquina que se había quedado sin descriptores de archivos.
  • Se corrigió un bloqueo en el inicio cuando ~/.claude.json tenía un valor mcpNeedsAuthNoticed mal formado
  • Se corrigió que --resume y --continue dejaran de lado el pensamiento anterior de una conversación cuando una herramienta incorporada con la que comenzó había sido desactivada por un indicador del lado del servidor.
  • Se corrigió el texto seleccionado con el mouse en el selector de sesión de pantalla completa del claude --resume que nunca llegaba al tablero del cli.
  • Se corrigieron las vistas previas de recarga del complemento que reemplazaban los archivos del complemento extraídos de una sesión en ejecución cuando el complemento se cargaba desde un archivo --plugin-dir o --plugin-url.
  • Se corrigió que los corredores autohospedados con --drain-wait-sec perdieran el resultado final de un turno que finalizó durante un drenaje SIGTERM; el corredor ahora espera brevemente a que se informe el turno
  • Se corrigieron los ganchos SubagentStop con un disparo matcher específico para cada subagente detenido cuyo tipo de agente estaba vacío.
  • Se corrigieron los comandos Bash en el espacio aislado que no podían escribir en los directorios del proyecto llamados hooks/ o config/.
  • Se corrigió que las actualizaciones de artefactos fallaran con "Archivo no encontrado" después de que se reanuda una sesión en otra máquina o se borra su área de trabajo: se restaura la última versión publicada de la página.
  • Se corrigió que /update-config escribiera reglas de permiso Write(path), con las que las verificaciones de permisos de archivos no coinciden, en lugar de las reglas Edit(path).
  • Se corrigieron cuatro URL de documentación inactivas (precios, uso de la computadora, habilidades, CLI) en la tabla de fuentes en vivo de la habilidad claude-api incluida.
  • Almacenamiento en caché de mensajes mejorado para un --system-prompt que contiene una línea __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__: el texto encima ahora se almacena en caché globalmente, como ya lo está el formato de matriz del SDK.
  • Se mejoró el error /desktop cuando Claude Desktop no se abre: ahora dice por qué y qué hacer a continuación.
  • Se mejoraron los resultados de publicación y lectura de la herramienta Artifact: ahora dicen quién puede abrir la página y qué ofrece el menú Compartir del propietario.
  • Resultados de publicación de artefactos mejorados: nombran el icono de pestaña enviado, advierten cuando la página contiene un byte NUL y vuelven a intentar una recuperación irregular de la página más nueva para fusionarla después de una publicación obsoleta.
  • Imágenes pegadas y adjuntas mejoradas: ahora se guardan donde Claude puede abrirlas como archivos sin solicitar permiso, incluso en Desktop y VS Code.
  • Se mejoró la guía de la herramienta Artefacto para que Claude actualice un artefacto compartido en su lugar cuando se le dio acceso de edición, en lugar de publicar una copia por separado.
  • Lecturas de uso del plan mejoradas: las ventanas del editor y las sesiones no interactivas en una máquina ahora comparten una lectura realizada en el último minuto en lugar de llamar cada una al punto final de uso.
  • Se mejoró la descripción de la herramienta ListPlugins para que Claude sepa que enumera los complementos habilitados en su cuenta claude.ai, no los complementos instalados localmente con /plugin.
  • Capacidad de respuesta mejorada cuando el terminal está lento o en pausa: la salida ya no se queda atrás mientras el terminal se pone al día
  • Resultados de escritura y edición mejorados para archivos en la carpeta de habilidades de cuenta sincronizadas: ahora dicen que el cambio no se guarda en su cuenta y cómo guardarlo
  • Se actualizó /logout para los inicios de sesión en la puerta de enlace de aplicaciones de Claude para finalizar también la sesión en las puertas de enlace que anuncian la revocación de tokens.
  • Se cambiaron las sesiones alojadas para mantener un mensaje de permiso sin respuesta después de reiniciar el contenedor, en lugar de volver a preguntar.
  • Se cambió la herramienta Artefacto para solicitar un ícono de pestaña de una palabra en una primera publicación en lugar de un favicon emoji.
  • Se modificó Claude en Chrome en modo automático para omitir la verificación por sitio de la extensión para llamadas aprobadas por el clasificador, como lo hace el modo de derivación, solucionando browser_batch "Permiso denegado" después de una redirección.
  • Se modificaron los complementos instalados desde una fuente npm para que se obtengan con npm pack --ignore-scripts y se verifique su integridad, por lo que los scripts de instalación de un paquete ya no se ejecutan.
  • Se cambiaron las rutinas programadas y Ejecutar ahora para guardar datos y volver a publicar la página de un artefacto que puede editar sin preguntar; artefactos públicos, las primeras publicaciones y eliminaciones aún preguntan
  • Se eliminó el aviso de inicio que le indicaba que se había ejecutado una rutina programada única desde su última sesión.
  • [VSCode] Se agregó visualización, edición y eliminación de una memoria guardada dentro del cuadro de diálogo Memoria
  • [VSCode] Se agregó el envío de una imagen adjunta sin escribir ningún texto.
  • [VSCode] Se agregó un enlace Reintentar al cuadro de diálogo de servidores MCP cuando la lista de servidores no se carga
  • [VSCode] Se agregaron botones de aceptar y rechazar debajo de cada cambio en la pestaña de diferencias de cambio propuesto, para que una edición pueda revisarse cambio por cambio.
  • [VSCode] Se corrigió la transcripción que avanzaba hacia el final en pequeños pasos mientras una tarjeta de permiso esperaba y el contenido seguía llegando.
  • [VSCode] Se corrigió que las conversaciones rebobinadas y bifurcadas no mantuvieran el modo de permiso que había elegido para la conversación original.
  • [VSCode] Se corrigió una entrada CLAUDE_CONFIG_DIR vacía en la configuración environmentVariables que hacía que Claude Code mantuviera sus archivos en el espacio de trabajo.
  • [VSCode] Se corrigieron los enlaces de instalación de complementos que abren el cuadro de diálogo Administrar complementos para nombres de complementos y direcciones de mercado que no se pueden usar en un enlace.
  • [VSCode] Se corrigió que el control remoto permaneciera mostrado como conectado después de un apagado que Claude Code informó como fallido; ahora se muestra como apagado
  • [VSCode] Se corrigió el desplazamiento hacia la parte inferior al enviar, deteniéndose antes de la respuesta cuando la respuesta comienza a llegar durante el desplazamiento.
  • [VSCode] Se corrigió el mapa de agentes que mostraba a los agentes un bloqueo que se dejó sin terminar como detenido en lugar de fallar una vez que se reabre la sesión.
  • [VSCode] Se corrigió que el aviso "Continuar con el paso" no apareciera y el límite de continuación se restableciera después de una recarga que siguió a un bloqueo con tareas en segundo plano aún ejecutándose.
  • [VSCode] Se corrigió la lista de sesiones que muestra cuándo se volvió a abrir una sesión por última vez, como después de recargar una ventana, en lugar de cuándo se envió el último mensaje.
  • [VSCode] Se corrigió el error "Bifurcar conversación desde aquí" en el mensaje justo después de enviar uno mientras Claude estaba trabajando.
  • [VSCode] Se corrigió el reloj de caché que mostraba muy pocos minutos después de reabrir una sesión con un mensaje enviado mientras Claude estaba trabajando.
  • [VSCode] Se corrigió un agente en segundo plano que finalizaba mientras Claude estaba ejecutando una herramienta y perdía su aviso de finalización y su resultado en el mapa del agente, después de una recarga de ventana.
  • [VSCode] Se corrigió un caso raro en el que el texto seleccionado en un archivo ignorado por git podía enviarse a Claude después de que la extensión no respondiera durante varios segundos.
  • [VSCode] Se corrigió el cambio de nombre de una sesión en ejecución volviendo al nombre generado (regresión en 2.1.269)
  • [VSCode] Se corrigieron algunas sesiones de claude.ai/code que se abrían en VS Code como una conversación vacía sin mensajes.
  • [VSCode] Se corrigieron los comandos de barra escritos mientras Claude responde y se envían al modelo como texto en lugar de ejecutarse una vez que finaliza la respuesta.
  • [VSCode] Se corrigió el código ilegible en la vista previa del plan y los cuadros de diálogo de reglas de ganchos y permisos con el tema Luz de alto contraste
  • [VSCode] Se corrigió que /remote-control se ignorara mientras el control remoto aún se estaba conectando: ejecutarlo nuevamente ahora apaga el control remoto inmediatamente
  • [VSCode] Se corrigió la conversación que lo arrastraba hacia el final mientras se transmitía una respuesta después de desplazarse hacia arriba, y se agregó una configuración claudeCode.scrollToBottomOnSend para desactivar el salto al enviar.
  • [VSCode] Se corrigió el cuadro de diálogo Administrar complementos que mostraba una contraseña o token que se ingresó en una URL del mercado.
  • [VSCode] Se mejoró el mapa de agentes: la píldora cuenta los agentes en ejecución y se vuelve roja después de una falla, el agente principal permanece a la vista mientras el mapa se desplaza y los agentes se clasifican por estado y luego por hora de finalización.
  • [VSCode] Se cambió Nueva sesión en una pestaña del editor Claude para abrir en la barra lateral cuando la Ubicación preferida está configurada en Barra lateral, en lugar de abrir siempre otra pestaña.
  • [VSCode] Se modificó un mensaje enviado mientras Claude está trabajando para esperar al final de la conversación hasta que Claude comience.
  • [Claude Code en la web] Se agregó un botón "Nueva rutina" a la página que se muestra cuando un enlace de rutina ya no se resuelve, junto al enlace de regreso a su lista de rutinas.
  • [Claude Code en la web] Se corrigieron las notificaciones de rutina "en pausa" y "en espera" que se cortaban a mitad de la frase; El aviso de suscripción pausada ahora dice que vuelvas a la rutina.
  • [Claude Code en la web] Se corrigieron entornos de nube con una lista muy larga de dominios permitidos que guardaban bien y luego fallaban en cada inicio de sesión; El ahorro ahora falla desde el principio y dice cuánto recortar.
  • [Código de Claude en la web] Se corrigió la guía de Claude cuando a una sesión en la nube en una cuenta personal se le niega el acceso a GitHub: ahora se vincula a claude.ai/connect-github en lugar de a una página de configuración de administrador
  • [Código de Claude en la web] Se mejoró lo que Claude te dice cuando te pide que edites, elimines o ejecutes una rutina que no creó: ahora se vincula a la página de la rutina para que puedas hacerlo tú mismo.
  • [Claude Tag] Se agregaron condiciones de adjuntar para acceder a paquetes en la configuración de Claude Tag: un propietario puede permitir que un paquete también se aplique en canales con invitados o canales de Slack Connect, no solo para miembros
  • [Claude Tag] Se agregaron ajustes preestablecidos de Amazon CloudWatch, CloudWatch Logs, Amazon SNS, Google Cloud Monitoring y Cloud Logging a la pestaña Credenciales de un paquete de acceso en la configuración de administración de Claude Tag
  • [Claude Tag] Se agregaron ajustes preestablecidos de Datadog para los sitios US3, AP1, AP2 y US1-FED; Las nuevas conexiones de Datadog ahora están limitadas a las rutas de lectura y consulta API de Datadog.
  • [Etiqueta Claude] Se corrigieron las cargas de S3 de las versiones recientes de AWS CLI y SDK que fallaban con un error 502 cuando se enviaban a través de una conexión de AWS.
  • [Etiqueta de Claude] Se corrigió que Claude tratara un canal como inactivo y omitiera mensajes sin etiquetar allí, mientras todavía estaba publicando en ese canal desde una rutina o un hilo.
  • [Etiqueta de Claude] Se corrigió que el nombre para mostrar "Claude [tarea]" de un hilo volviera a ser "Claude" simple después de que la sesión detrás de ese hilo fuera actualizada o reiniciada.
  • [Etiqueta de Claude] Se corrigió el modelo al que cambiaste en un hilo de Slack volviendo silenciosamente al canal predeterminado después de que la sesión de ese hilo se reiniciaba o actualizaba.
  • [Etiqueta de Claude] Se corrigió que Claude a veces respondiera dos veces cuando otra aplicación o bot lo @mencionaba en un mensaje de canal de nivel superior.
  • [Etiqueta de Claude] Se mejoraron los avisos de Claude en los canales Enterprise Grid compartidos entre espacios de trabajo: ahora dicen cuando aún no hay un espacio de trabajo configurado o por qué solo se aplican los valores predeterminados de la organización.
  • [Revisión de código] Se corrigieron las revisiones que ocasionalmente dejaban parte de su análisis cuando uno de los agentes revisores devolvía sus hallazgos en un formato inesperado.
  • [Revisión de código] Se corrigieron las solicitudes de extracción con más de 100 revisiones de Claude que obtenían una nueva revisión completa de cada fusión limpia desde la rama base en lugar de la revisión más ligera centrada en la fusión.
