claude-code v2.1.277

código-claude v2.1.277

¿Qué ha cambiado?

  • Se agregó compatibilidad con AGENTS.md: en un proyecto sin CLAUDE.md, Claude Code lee AGENTS.md en su lugar; cámbielo en "Instrucciones del proyecto" en /config (aún no en Bedrock, Vertex o Foundry)
  • Se agregó CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 para las puertas de enlace de aplicaciones Claude cuya única salida es un proxy directo: cada solicitud saliente le entrega al proxy el nombre de host en lugar de resolverlo localmente.
  • Se agregó un mapa headers: opcional en la puerta de enlace de aplicaciones de Claude, para enviar encabezados estáticos a un proxy que ejecuta frente a un proveedor.
  • Se agregó una línea que dice que la actualización de una tarea en segundo plano está esperando cuando finaliza mientras un panel como /tasks está abierto.
  • Se corrigieron las sesiones de claude -p y Agent SDK que podían bloquearse sin resultado después de un error interno; ahora informan el error y salen con el código 1
  • Se corrigieron las conversaciones que fallaban en cada solicitud con "los bloques de contenido de texto no deben estar vacíos" cuando un asistente anterior mantenía un bloque de texto vacío junto a otro contenido, incluso después de --resume.
  • Se corrigió el cierre de sesión inesperado cuando una compilación anterior de Claude Code (por ejemplo, CLI incluida en una extensión IDE) se ejecuta en la misma máquina que la actual.
  • Se corrigió el inicio interactivo que se bloqueaba o mostraba un error para los usuarios de ANTHROPIC_API_KEY cuando ~/.claude.json tenía un valor de customApiKeyResponses con formato incorrecto.
  • Se corrigieron los errores de las comprobaciones de actualización cada 30 minutos y claude update se bloqueaba cuando se configuraba una versión mínima o máxima, si un proxy devolvía una versión no válida; un minimumVersion con formato incorrecto ahora se ignora
  • Se corrigió claude update en instalaciones administradas por Winget o apk que informaban "actualizado" cuando fallaba la búsqueda de versión.
  • Se corrigió que claude plugin install a veces fallara y rompiera la copia instalada al reinstalar una versión del complemento que estaba usando una sesión u otro programa; una copia sin cambios ahora se deja sola
  • Se corrigió que Grep y Glob no informaran coincidencias cuando la búsqueda no podía iniciarse porque el sistema no tenía procesos, memoria o identificadores de archivos; ahora devuelven un error diciendo eso
  • Se corrigió que la herramienta de escritura finalizara silenciosamente el turno como un permiso declined cuando la ruta de destino es un directorio existente; ahora informa un error claro
  • Se corrigió que la herramienta de edición tratara una barra invertida seguida de texto uXXXX como un escape \uXXXX, lo que podía hacer que una edición de un carácter no ASCII reescribiera una secuencia de barra invertida con escape.
  • Se corrigió la herramienta de edición que informaba "Expresión regular no válida: expresión regular demasiado grande" en lugar de "Cadena no encontrada en el archivo" cuando una edición muy grande que contenía texto no ASCII no coincidía con el archivo.
  • Se corrigió un turno que terminaba temprano con "La ruta contiene bytes nulos" cuando la ruta del archivo de llamada de una herramienta contenía \u0000 escrito como una secuencia de escape; Los caracteres de control escapados ahora permanecen como texto literal.
  • Se corrigieron las sesiones en segundo plano (claude --bg) que salían cuando el servidor LSP de un complemento salía o cerraba su entrada estándar.
  • Se corrigió un bloqueo ("Error de tipo") al abrir /mcp o /plugin manage con un valor claudeAiMcpEverConnected mal formado en ~/.claude.json.
  • Se corrigió un bloqueo en el lanzamiento cuando ~/.claude.json tenía un valor theme mal formado
  • Se corrigió un bloqueo ("error de interfaz irrecuperable") cuando el mensaje contenía texto que contenía códigos de color del terminal, por ejemplo, un mensaje recuperado del historial o texto cargado desde el editor externo.
  • Se corrigió un bloqueo al reanudar una sesión cuyo historial guardado contiene un mensaje del asistente almacenado como una cadena simple.
  • Se corrigieron sesiones en máquinas lentas o muy cargadas que a veces salían con "Claude Code salió después de un error de interfaz irrecuperable" cuando aparecía el primer control giratorio.
  • Se corrigió un caso raro en el que la pantalla podía dejar de actualizarse durante el resto de la sesión después de un error de renderizado interno.
  • Se corrigió un caso raro en Windows donde un turno podía detenerse con un error como "Sin memoria" justo después de que Claude respondiera, por lo que las llamadas a la herramienta de respuesta nunca se ejecutaban.
  • Se corrigió que las sesiones continuaran después de que /clear (reinicio, --continue, --resume) perdieran parte de su primer mensaje cuando un enlace SessionStart imprimió la salida, lo que provocó una pérdida completa del mensaje de caché.
  • Se corrigieron los mensajes de otros agentes (como el SendMessage de un subagente) que llegaban a mitad de turno y aparecían debajo de la fila "Ejecutó N comandos de shell" en lugar de donde llegaron.
  • Se corrigió el aviso "copiado" que no aparecía después de arrastrar y seleccionar texto en el selector de pantalla completa /resume y otros paneles que cubren el área de aviso.
  • Se corrigió que $TMPDIR se expandiera vacío en los comandos Bash que se ejecutan fuera del sandbox mientras el sandbox está habilitado.
  • Se corrigieron las sesiones de WebFetch y WebSearch en la nube de Cowork que no le decían a Claude por qué se rechazó una solicitud, como un presupuesto de recuperación agotado o una política de administración.
  • Se corrigió el relé de telemetría de la puerta de enlace de aplicaciones de Claude que ignoraba un nombre de host o dominio recopilador enumerado en NO_PROXY cuando se configura un proxy.
  • Se corrigió una entrada strictKnownMarketplaces o blockedMarketplaces con formato incorrecto que deshabilitaba silenciosamente toda la política del mercado empresarial.
  • Se corrigieron actualizaciones automáticas fallidas que dejaban grandes descargas por etapas en ~/.cache/claude/staging.
  • Se corrigió que /plugin no eliminara los caracteres de control del terminal de los mensajes en la pestaña Instalado, como el error de una actualización fallida del complemento.
  • Se corrigió /plugin → Instalado y /skills fallaba cuando una habilidad o comando heredado tenía el nombre de una propiedad de objeto incorporada, como constructor o toString.
  • Se corrigió el cierre de /plugin sin mensaje cuando fallaba cada instalación en una selección múltiple
  • Se corrigieron los complementos desinstalados que reaparecían como filas "no se pudieron cargar" en /plugin Instalado y Eliminar no borraba dicha fila.
  • Se corrigió que los complementos del mercado oficial se registraran sin su confirmación en installed_plugins.json, y installed_plugins.json mantuviera la confirmación anterior después de actualizar un complemento de confirmación fijada.
  • Se corrigieron las vistas previas de recarga de complementos que mantienen cada copia vista previa de un archivo de complemento desempaquetada hasta la salida y sobrescriben el archivo --plugin-url en caché al que recurre una recarga cuando falla la descarga.
  • Se corrigió el error en la contabilidad de sesiones de control remoto cuando ~/.claude.json tenía un registro de marcador de posición con formato incorrecto
  • Se corrigió el error después de un inicio de sesión revocado en claude.ai culpando a un perfil Anthropic vencido; ahora lidera con /login
  • Se corrigió que el texto escrito o pegado ocasionalmente apareciera codificado en la entrada de despacho claude agents durante la repetición de teclas o una entrada muy rápida.
  • Se corrigió un bloqueo ("error de interfaz irrecuperable") al reanudar una sesión cuya transcripción guardada contiene un resumen de detención sin una lista de enlaces bien formada.
  • Se corrigió que Enter en una fila del panel de agente seleccionado no hiciera nada cuando keybindings.json vuelve a vincular Enter en el contexto de Chat, por ejemplo a chat:queueSubmit.
  • Se corrigió el error de lectura de páginas PDF en Windows cuando la ruta de la carpeta de trabajo es larga (alrededor de 120 caracteres o más)
  • Se corrigió un currículum sin cabeza (claude -p --resume, SDK, una recarga de ventana de extensión de VS Code) que iniciaba el costo total de la sesión y el uso en cero; Las sesiones sin cabeza ahora guardan sus totales al salir.
  • Se corrigieron las habilidades del proyecto del repositorio principal que no se cargaban en las sesiones de --worktree cuando .claude/skills no estaba rastreado.
  • Se corrigió un globo sandbox.excludedCommands que eximía un comando Bash compuesto completo del sandbox cuando solo una parte coincidía; cada parte ahora debe coincidir
  • Se corrigió que los subagentes y compañeros de equipo reanudados volvieran a representar las definiciones de la herramienta MCP que habían cargado, lo que rompía el almacenamiento en caché para ese agente.
  • Se corrigió la publicación de artefactos con velocidad limitada que le indicaban a Claude que dejara de volver a intentarlo; Ahora se le dice a Claude que no se publicó nada y cuándo enviar la misma publicación nuevamente.
  • Se corrigieron los archivos adjuntos grabados anteriormente en una conversación que se volvían a representar después de un currículum o reinicio, lo que dejaba de lado el pensamiento extendido y omitía el caché de avisos.
  • Se corrigió el inicio de sesión en la consola que mostraba solo "La solicitud falló con el código de estado 400" cuando el servidor se niega a crear una clave API; ahora muestra el mensaje del servidor
  • Se corrigieron los mensajes escritos mientras Claude todavía estaba trabajando y que a veces el modelo los ignoraba.
  • Inicio de sesión mejorado para SDK y uso sin cabeza (-p): el primer turno ya no espera en la búsqueda CLAUDE.md por directorio
  • Se mejoraron los mensajes de error de bucle invertido de la puerta de enlace de aplicaciones de Claude para llamarlos CLAUDE_GATEWAY_ALLOW_LOOPBACK.
  • /plugin mejorado instalado: un servidor MCP listado aparte de su complemento ahora muestra a qué complemento pertenece
  • claude plugin install mejorado en un complemento ya instalado: ahora dice cuando el mercado ofrece una versión más nueva y nombra el comando claude plugin update
  • Se mejoró la línea de desbordamiento del aviso de inicio debajo del logotipo: ahora dice "N más avisos ocultos" en lugar de "+N más · /status"
  • Manejo de mensajes mejorado: el formato Unicode invisible y los caracteres de etiqueta en un mensaje se eliminan y el mensaje limpio se muestra para su revisión antes de enviarlo.
  • /ultrareview mejorado cuando no hay nada que revisar: los mensajes dicen en qué caso se encuentra, ofrecen un comando que revisa su última confirmación y la primera confirmación de un nuevo repositorio se revisa en su totalidad.
  • Se mejoró el manejo de enlaces de artefactos para que Claude lea los enlaces de artefactos de claude.ai con la herramienta Artifact en lugar de WebFetch cuando esa herramienta esté disponible.
  • Se mejoró el mensaje de permiso de rm peligroso para nombrar el comando rm marcado y sugerir un guardia ${VAR:?}, para que las ejecuciones sin cabeza puedan recuperarse.
  • Se mejoraron las solicitudes de permiso de la herramienta Artefacto: oraciones más cortas, páginas y artefactos nombrados por título o nombre de archivo, y enlaces enumerados después del texto.
  • Se cambió Fable para que siempre aparezca en /model en el Anthropic API; aparece atenuado solo cuando la configuración de su organización lo desactiva
  • Se cambiaron las instrucciones de la zona de pruebas de Bash en Bedrock, Vertex y Foundry a la redacción propia, que enmarca la zona de pruebas como el límite de lo que se asignó a la tarea.
  • Se modificó /ultrareview en sesiones no interactivas para rechazar cuando el repositorio no tiene una rama base o un historial compartido.
  • Se cambiaron los resultados del subagente para que lleguen al agente principal bajo un encabezado que los marca como salida del subagente, con el resultado sangrado, de modo que el texto en el resultado de un subagente no pueda pasar como instrucciones propias de la sesión.
  • Se modificaron los mensajes agent() calculados de los scripts de flujo de trabajo en Bedrock, Vertex y Foundry para llegar al subagente enmarcado como texto escrito por script, de modo que el clasificador de seguridad no los lea como usuario.
  • Se eliminó la solicitud de título automático Haiku en segundo plano de las ejecuciones claude -p iniciadas fuera de un SDK o IDE.
  • Se eliminó la herramienta TaskOutput en desuso; Claude lee el archivo de salida de una tarea en segundo plano con Leer en su lugar, y la configuración taskOutputMaxChars y TASK_MAX_OUTPUT_LENGTH ya no tienen ningún efecto.
  • [VSCode] Se agregó una fila de Cerrar sesión al menú del panel, con /logout en el menú de comando escrito
  • [VSCode] Se agregaron shells en segundo plano y otras tareas en ejecución al mapa del agente, cada una con una parada y un /tasks escrito que lo abre.
  • [VSCode] Se agregó un botón Copiar respuesta en las respuestas y un /copy escrito
  • [VSCode] Se agregó un aviso único cuando las sesiones inactivas se archivan automáticamente y una acción "Desarchivar todo" en el grupo de sesiones archivadas.
  • [VSCode] Se agregó el costo de la sesión y el uso del token al cuadro de diálogo Cuenta y uso y al administrador de sesión donde no se aplican los límites del plan (Vertex, Bedrock, Foundry, clave API).
  • [VSCode] Se corrigió la fila del menú "Configuración general" que muestra el texto de uso de /config en lugar de abrir la configuración, y se hacen que los comandos escritos /mcp, /hooks, /memory, /rewind y similares abran sus cuadros de diálogo.
  • [VSCode] Se corrigió que el nivel del control deslizante de esfuerzo no persistiera en sesiones posteriores en un modelo que ya tenía un nivel guardado con /effort.
  • [VSCode] Se corrigió que faltara Auto en el selector de modo para conversaciones abiertas en un panel ya usado cuando la configuración del modelo guardado es un alias en mayúsculas y minúsculas diferentes, como "Sonnet".
  • [VSCode] Se corrigió que /fast no guardara el modo rápido como predeterminado, por lo que se perdió cuando la extensión relanzó Claude Code.
  • [Claude Code en la web] Se agregaron secciones Personal y Organización al selector de entorno en los planes Team y Enterprise, y los administradores ahora pueden compartir un entorno personal con la organización.
  • [Claude Code en la web] Se cambiaron los entornos de la organización para que se abran como un resumen de solo lectura desde la pestaña Código en los planes Team y Enterprise, con edición en Configuración de administrador → Entornos de nube
  • [Código Claude en la web] Se corrigió un entorno de nube guardado con acceso a red personalizado y ningún dominio regresaba silenciosamente a Trusted; el cuadro de diálogo ahora solicita al menos un dominio
  • [Claude Code en la web] Se cambió la configuración del administrador Claude Code etiquetada "Web" a "Sesiones en la nube" y se eliminó la fila móvil redundante de solo lectura debajo de ella.
  • [Claude Tag] Se corrigieron las rutinas creadas en un canal de Slack en una instalación de Enterprise Grid en toda la organización que no podían leer otros canales públicos en su espacio de trabajo cuando se ejecutaban.
  • [Claude Tag] Se corrigieron los enlaces "Más información" en los ajustes preestablecidos de credenciales en los paquetes de acceso de Claude Tag para abrir la página de configuración de credenciales de cada proveedor en lugar de una referencia genérica de API.
  • [Claude Tag] Se cambió el valor preestablecido de credenciales de Pylon en los paquetes de acceso de Claude Tag para que los administradores puedan apuntar al host de Pylon en la UE.
  • [Claude Tag] Se corrigieron los formularios de credenciales de Google Cloud en los paquetes de acceso a Claude Tag: un archivo de clave rechazada ahora dice por qué, el sitio web y los ámbitos permanecen bloqueados, y una rotación rechazada mantiene la clave pegada.
  • [Claude Tag] Se corrigió el registro de eventos de red en la configuración de administración de Claude Tag que mostraba un estado sin respuesta para solicitudes a través de conexiones que usan firma de AWS, certificados client o una CA personalizada.
