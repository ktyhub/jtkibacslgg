código-claude v2.1.280

¿Qué ha cambiado?

  • Se agregó Claude Opus 5.5 (claude-opus-5-5), ahora el modelo Opus predeterminado: contexto de 1 millón, $4/$20 por Mtok con lecturas de caché de $0.20/Mtok.
  • Se agregó compatibilidad con el mouse a más listas en modo de pantalla completa: la rueda se desplaza por la lista /skills y las opciones de estado de una habilidad en /plugin se pueden seleccionar cli.
  • Se agregó CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH para cambiar el límite de 2048 caracteres en las descripciones de las herramientas MCP y las instrucciones del servidor para cada servidor MCP en la sesión.
  • Se agregaron tamaños de salida de gancho y la cantidad de salidas de gran tamaño guardadas en un archivo para el evento hook_execution_complete OpenTelemetry
  • Se corrigieron las escrituras a través de una ruta con enlace simbólico que se juzgaba por su ortografía en el árbol: los nombres de los mensajes donde aterriza la escritura, y acceptEdits, permiten reglas y el modo automático ya no aprueba un aterrizaje externo.
  • Se corrigió el modo automático que reintentaba una acción una y otra vez cuando un control de seguridad debía revisarla; la acción ahora se deniega una vez, teniendo en cuenta que volver a intentarlo no ayudará
  • Se corrigió el modo automático que negaba acciones una y otra vez sin pausa cuando una verificación de seguridad no daba respuesta; Los reintentos ahora retroceden y el turno se detiene con un mensaje después de diez seguidos.
  • Se corrigieron las llamadas de escritura que fallaban en la validación cuando un modelo envía path, file_text, file_content o un description perdido en lugar de file_path y content.
  • Se corrigió Ctrl+C o Ctrl+D presionado dos veces en la mayoría de los cuadros de diálogo (/model, /effort, /config, /status, /usage, /plugin, /sandbox, /permissions, /artifacts, /mobile, /login, /upgrade, /usage-credits, /install-github-app, /setup-bedrock, /setup-vertex) saliendo de Claude Code en lugar de cerrar el diálogo
  • Se corrigió un click que solo traía la ventana del terminal al frente y también activaba el elemento debajo del puntero: en selectores de búsqueda, barras de pestañas, filas de agente/flujo de trabajo, enlaces de comando de barra diagonal y menús desplegables de sugerencias.
  • Se corrigió un n perdido cerrando los diálogos y un y perdido confirmándolos; Ingrese y Esc acepte y cancele (vincule y/n a confirm:yes/confirm:no en keybindings.json para restaurar)
  • Se corrigieron los campos de texto en los cuadros de diálogo que perdían una letra, dígito o espacio escrito debido a una combinación de teclas en esa tecla.
  • Se corrigió la línea de aviso que permanecía codificada en terminales Windows después de que se eliminaran los caracteres invisibles en Enter; la pantalla ahora está repintada para que puedas revisar el texto exacto que se enviará
  • Se corrigió la limpieza de caracteres invisibles eliminando el no conector de ancho cero que el texto persa y árabe usa para adjuntar un sufijo a una palabra o número latino, como el plural de "PDF".
  • Se corrigió que el dictado de voz no se detuviera con Ctrl+C (el mensaje se borraba pero el micrófono seguía grabando), Esc no se cancelaba mientras se procesaba una transcripción y se mantenía la barra espaciadora al iniciar el dictado desde la vista de transcripción y el modo vim NORMAL.
  • Se corrigió un cambio de modelo realizado desde una aplicación host (Claude Desktop, VS Code, SDK) mientras Claude estaba trabajando, lo que provocaba una pérdida de caché en el siguiente mensaje.
  • Se corrigió que los subagentes de bifurcación reanudados reconstruyeran su lista de herramientas en lugar de volver a enviar la que usaron por primera vez, lo que rompía el almacenamiento en caché para ese agente.
  • Se corrigieron los mensajes de devolución del subagente que mostraban un preámbulo de procedencia interna cuando se expandían fuera del modo detallado.
  • Se corrigió que installed_plugins.json mantuviera la confirmación en el momento de la instalación después de actualizar un complemento desde un repositorio GitHub o una URL de git que rastrea una rama o etiqueta.
  • Se corrigieron las habilidades en ~/.claude/skills/ que se movían a ~/.claude/skills/.trash/ cuando un manifest.json en esa carpeta enumeraba sus nombres.
  • Se corrigió la encuesta de comentarios de la sesión que no mostraba resaltado al pasar el mouse sobre temas claros y ANSI.
  • Se corrigió /workflows que mostraba brevemente una lista de una fila antes de abrir la única ejecución.
  • Se corrigió que la rueda del mouse no se desplazara por las listas de selección con opciones ocultas (como /model y /permissions) en modo de pantalla completa.
  • Se corrigió una habilidad que desactivaste y que mostraba el mismo rojo ✘ que un complemento que no se cargaba en /plugin y /skills; apagado ahora muestra un tenue ◯
  • Se corrigieron las descripciones de las opciones de selección múltiple que tenían sangría debajo del número de opción en lugar de debajo de la etiqueta.
  • Se corrigió que el cuadro de búsqueda en /plugin, /skills y /mcp perdiera su borde derecho en modo de pantalla completa.
  • Se corrigió /mcp que mostraba △ en la lista de servidores pero ⚠ en la vista detallada para el mismo servidor; la lista, las vistas detalladas y /plugin ahora se muestran ⚠
  • Se corrigió que Inicio y Fin no hicieran nada en la lista de configuración de /config y en listas de selección como /model, /memory y solicitudes de permiso.
  • Se corrigió PgUp/PgDn en el menú /skills pasando la primera o última habilidad en lugar de detenerse allí.
  • Se corrigió la pestaña que cambiaba silenciosamente el valor de la configuración seleccionada en la lista /config; ahora no hace nada allí
  • Se corrigió que las conversaciones fallaran en cada turno con un error API de "rol 'sistema' que debe preceder a un mensaje de 'asistente'".
  • Se corrigieron las conversaciones con el asesor sobre fallas en cada turno con el error API 400 "Etiqueta de entrada 'advisor_20260301'" detrás de un proxy o puerta de enlace que no lo admite; la solicitud ahora se vuelve a intentar sin ella
  • Se corrigió una sesión que fallaba en cada turno y /compact cuando su historial guardado mostraba un aviso con formato incorrecto sobre las herramientas MCP que no se podían cargar.
  • Se corrigió un bloqueo al reanudar una sesión cuya transcripción guardada contenía un mensaje del sistema con formato incorrecto o un aviso guardado en la memoria sin su lista de archivos.
  • Se corrigió una de las causas por las que las sesiones de pantalla completa de larga duración salían con "Claude Code salió después de un error de interfaz irrecuperable": ahora se reconstruye una lista de mensajes almacenados en caché dañados.
  • Se corrigió que Claude Code se bloqueara cuando un archivo de configuración, o un archivo que se vuelve a leer después de una edición, se reemplaza por una canalización con nombre en mitad de la lectura.
  • Se corrigió el bloqueo de /config y algunas preferencias de encendido/apagado que se malinterpretaban cuando una preferencia que se había movido a settings.json todavía tenía un valor como null o "false" en ~/.claude.json.
  • Se corrigió la reanudación de una sesión con agentes en segundo plano, shells o flujos de trabajo sin terminar que iniciaban un modelo por sí solo antes de escribir algo.
  • Se corrigió que los mensajes enviados a un subagente en segundo plano se perdieran silenciosamente en sesiones sin cabeza y SDK cuando el subagente estaba terminando su turno.
  • Se corrigió que el informe de un subagente terminado se perdiera cuando la conversación que lo inició se compactaba antes de leer el informe.
  • Se corrigió que los subagentes en segundo plano no pudieran usar la herramienta LSP cuando un complemento LSP estaba activo.
  • Se corrigieron tareas de shell en segundo plano que informaban salidas benignas distintas de cero (por ejemplo, grep sin coincidencias) como fallas.
  • Se corrigió que las sesiones en segundo plano (claude --bg) no pudieran ejecutar git, ganchos, complementos y otros programas auxiliares cuando una variable de entorno entregada a la sesión contenía un carácter NUL.
  • Se corrigió que Ctrl+C necesitara tres o cuatro pulsaciones para salir mientras se ejecutaban los subagentes en segundo plano; dos prensas ahora salen
  • Se corrigió la selección de IDE que se eliminaba cuando un mensaje enviado regresaba a la entrada, como presionar Esc para editarlo, rebobinarlo o presionar Esc mientras se ejecutan los enlaces de inicio.
  • Se corrigió un mensaje en modo shell de ! escondido con Ctrl+S que regresaba como un mensaje simple cuando se restauraba, y / enumeraba las rutas de archivo justo después de guardar uno.
  • Se corrigió claude agents que muestra una pantalla en blanco que no responde en lugar de un error cuando el directorio temporal está lleno, no se puede escribir o es propiedad de otro usuario.
  • Se corrigió un servidor MCP vuelto a agregar con el mismo nombre después de que claude mcp remove aún apareciera como que necesitaba autenticación en lugar de volver a conectarse.
  • Se corrigió la actualización automática del mercado de complementos en segundo plano que ignoraba los asistentes de credenciales de Git, por lo que los mercados de repositorios privados se volvían a clonar en cada ejecución o nunca se actualizaban.
  • Se corrigió que claude plugin update borrara la confirmación registrada de un complemento y lo moviera a la versión "desconocida" cuando el archivo de instantánea del mercado oficial es un enlace o es demasiado grande.
  • Se corrigió que la herramienta Artifact desapareciera silenciosamente cuando la política de su organización no se puede cargar (por ejemplo, detrás de un proxy web); Claude ahora dice qué lo está bloqueando.
  • Se corrigió el artefacto que se vuelve a publicar restableciendo silenciosamente las reglas de acceso a la base de datos almacenadas o eliminando el alcance del perfil del espectador cuando esa capacidad se reenviaba sin ellas; ahora son rechazados
  • Se corrigió que /ultrareview informara una revisión de la nube detenida como completada o como un error para volver a intentarlo, y esperara el tiempo de espera completo cuando se eliminó su sesión o se cambió la cuenta iniciada.
  • Se corrigió la aplicación Claude que mostraba una cifra de uso de contexto obsoleta o faltante para el control remoto y las sesiones en la nube justo después de /compact o /clear.
  • Se corrigió la vista de diferencias de la aplicación Claude para el control remoto y las sesiones en la nube que eliminaban los archivos comprometidos de una rama siempre que también hubiera cambios no confirmados.
  • Se corrigió que las sesiones de ejecución en la nube y autohospedadas fallaran con "Error de autenticación" después de esperar una sobrecarga prolongada durante la cual se rotaba el token de acceso de la sesión.
  • Se corrigieron conflictos de escritura en memoria en sesiones de Cowork que mostraban a Claude solo el inicio y el final de un archivo de memoria de aproximadamente 10,800 caracteres, por lo que la escritura reintentada se perdió en el medio.
  • Ejecutor autohospedado: Se corrigió que las confirmaciones de gancho de ciclo de vida no pudieran firmar bajo --configure-git
  • Windows: Se corrigió la limpieza en segundo plano que eliminaba un enlace simbólico de directorio o unión utilizada para reubicar ~/.claude/session-env, image-cache u otra carpeta limpiada.
  • Corredor autohospedado: se corrigió un giro que terminaba justo en un lanzamiento de --retire-at y perdía su señal de finalización; el corredor ahora espera brevemente a que se informe el turno antes de detener la sesión
  • Se revirtió ctrl+l / cmd+k en modo de pantalla completa borrando la vista de transcripción (agregado en 2.1.260); vuelven a dibujar la pantalla
  • /permissions mejorado: el foco vuelve a la lista de reglas después de ver, agregar o eliminar una regla, y las confirmaciones de eliminación de regla y eliminación de directorio ahora están predeterminadas en No.
  • Navegación de pestañas /permissions mejorada: ←/→ y Tab presionado en una lista de reglas ahora cambian de pestaña sin mover el foco a la barra de pestañas
  • Se mejoraron las causas de pérdida de caché del /cost para nombrar el modo de pensamiento y los cambios en la visualización del pensamiento.
  • Se mejoró la herramienta Artefacto para que cuando Claude no pueda leer el enlace de un artefacto que se le proporcionó, se lo informe al usuario antes de continuar.
  • /install-github-app mejorado: los pasos de verificación y selección de repositorio de GitHub CLI ahora muestran "Esc para cancelar"
  • Se mejoraron las listas /artifacts y /workflows: una barra de desplazamiento en el borde derecho muestra qué parte de una lista larga está oculta y dónde se encuentra en ella.
  • Se mejoró el árbol de progreso del flujo de trabajo: los agentes y las fases en ejecución ahora muestran un punto tenue en lugar de ⟳
  • Se mejoró el formulario Agregar mercado de /plugin en pantalla completa: ya no dibuja un cuadro dentro del panel y su texto y sugerencias clave se alinean con el resto de /plugin.
  • Se mejoró la vista detallada del /workflows en pantalla completa: ya no dibuja una segunda regla horizontal debajo del divisor del panel.
  • Bloques de código mejorados que no nombran un idioma: ahora están coloreados como código en línea, por lo que los comandos se destacan del texto circundante.
  • /btw mejorado se pregunta mientras una herramienta aún se está ejecutando: la pregunta secundaria ahora sabe que la llamada está en progreso en lugar de leerla como fallida.
  • Se mejoró el aviso de tiempo de espera del enlace UserPromptSubmit y el registro de depuración para indicar qué comando de enlace expiró.
  • Sugerencias de archivos @ mejoradas: un archivo cuyo nombre contiene la consulta ahora se ubica por encima de uno que solo coincide con los nombres de sus carpetas.
  • Páginas de artefactos mejoradas: sin botones Imprimir, cuadros de diálogo de confirmación ni funciones del dispositivo que el visor bloquea, detalles de correo electrónico y teléfono mostrados como texto, y modo oscuro que llega a los controles de formulario y barras de desplazamiento
  • Cargas de /ultrareview mejoradas: copias renombradas de archivos clave, como id_rsa copy o kubeconfig (1).yaml, ahora también permanecen en su máquina
  • Se mejoró la advertencia de inicio de mensajería entre sesiones para explicar que --debug-file escribe un registro de depuración en la ruta que usted elija.
  • Se cambió el modelo predeterminado en los planes Pro y Team Standard de Sonnet a Opus, coincidiendo con Max, Team Premium y Enterprise.
  • Se modificó un nivel de esfuerzo guardado antes de que /effort se convirtiera en por modelo para que ya no se aplique a los modelos recientemente lanzados como Opus 5.5; Comienzan en su valor predeterminado hasta que eliges un nivel.
  • Se modificó Opus 4.7, Opus 4.8 y Fable 5 para que dejen de mantener su esfuerzo de lanzamiento predeterminado sobre /effort en -p o el Agente SDK, un proyecto, administrado o --settings effortLevel, o un nivel por modelo.
  • Se cambió la sugerencia de pie de página de /autocompact para nombrar ←/→, las teclas que ajustan otros valores ordenados.
  • Se cambió el pie de página de /fast para nombrar Espacio como tecla de alternancia.
  • Ejecutor autohospedado: se modificó git en los enlaces del ciclo de vida para ignorar las carpetas de enlaces y los programas nombrados en los archivos git compartidos del corredor; Los controles remotos local-path y git:// ahora necesitan GIT_ALLOW_PROTOCOL
  • Se cambiaron los mercados de complementos cuyo nombre imita un nombre de mercado reservado para que se rechacen cuando se agreguen y para que dejen de cargarse si ya se agregó uno.
  • Se cambiaron los ganchos PermissionRequest: un gancho tipo agente ya no se ejecuta allí, ya que su respuesta nunca podría permitir o negar la solicitud; ahora muestra un error que apunta al comando o a los enlaces http
  • [VSCode] Se agregó un cuadro de diálogo de Estado, con /status escrito, que muestra la versión de la sesión, la cuenta, el modelo y los detalles del servidor.
  • [VSCode] Se agregó un cuadro de diálogo Sandbox para el modo Sandbox, el respaldo no sandbox y los comandos excluidos, que se abre desde el menú del panel o escribiendo /sandbox.
  • [VSCode] Se agregó un cuadro de diálogo de Claude en Chrome (estado de la extensión, las páginas de instalación, reconexión y permisos, la configuración habilitada por defecto), abierto desde el menú del panel o escribiendo /chrome
  • [VSCode] Se agregó Exportar conversación, con un /export escrito, para copiar o guardar la conversación como texto sin formato.
  • [VSCode] Se agregó la fuente de cada habilidad, la estimación del token y el estado activado/desactivado al cuadro de diálogo de comandos de barra diagonal, con un click para cambiar el estado y un /skills escrito que lo abre.
  • [VSCode] Se agregó un /plan escrito que cambia al modo de plan, envía un primer mensaje de planificación o muestra el plan de la sesión.
  • [VSCode] Manejo mejorado del texto pegado en el cuadro de chat: un pegado de más de 800 caracteres o más de 2 saltos de línea ahora está marcado para que Claude pueda distinguirlo de lo que usted escribió.
  • [VSCode] Manejo de avisos mejorado en el cuadro de chat: el formato Unicode invisible y los caracteres de etiqueta se eliminan del texto pegado con un aviso y de cualquier otra cosa antes de enviarlo.
  • [VSCode] Se cambió "Abrir en una pestaña nueva" para abrir Claude al lado del grupo de editores en el que estás trabajando en lugar de después del último grupo.
  • [VSCode] Se corrigió el chip de esfuerzo que mostraba un nivel de esfuerzo guardado obsoleto en lugar del nivel en el que se ejecuta la sesión.
  • [VSCode] Se corrigió que el Código Claude nunca comenzara cuando la extensión Python se bloquea mientras se activa; ahora comienza después de 60 segundos sin el entorno Python
  • [VSCode] Se corrigió la tarjeta de aprobación del plan que nunca ofrece el modo automático: cuando el modo automático está disponible, su primera opción ahora es "Sí, y usar el modo automático", como en la terminal.
  • [VSCode] Se corrigió la navegación con las teclas de flecha en la lista de sesiones que se detenía después de archivar o desarchivar una sesión desde el teclado.
  • [VSCode] Se corrigieron las líneas de marcador de pegado que se muestran en sus propios mensajes después de reabrir una sesión.
  • [Claude Code en la web] Se cambió la configuración de activación/desactivación de las Rutinas de administrador para vivir en Configuración de administrador → Capacidades → Sesiones remotas; la página de administración de Claude Code ahora enlaza con ella
  • [Código Claude en la web] Se corrigieron las llamadas gh y GitHub API dentro de una sesión en la nube en un repositorio de GitHub Enterprise Server que fallaban después de aproximadamente ocho horas; el token ahora se renueva automáticamente
  • [Claude Code en la web] Se corrigió una rutina que reanuda una sesión existente ejecutándose con su antiguo mensaje y nombre cuando se editó momentos antes de que comenzara la ejecución programada.
  • [Claude Code en la web] Se corrigieron enlaces de archivos en una transcripción de sesión en la nube que apuntan fuera del directorio de trabajo de la sesión, abriendo una tarjeta de archivo que nunca se carga; ahora están discapacitados y dicen por qué
  • [Claude Code en la web] Se corrigió el modo automático que se negaba a volver a intentar una llamada de herramienta porque un mensaje de aprobación que expiró sin respuesta o fue reemplazado por un mensaje más nuevo se registró como su rechazo.
  • [Código Claude en la web] Sesiones en la nube mejoradas vistas en la aplicación Claude: Claude ahora guarda los archivos destinados a usted donde la aplicación puede abrirlos
  • [Claude Code en la web] Se eliminó el selector de repositorio vacío que se muestra al iniciar una sesión en un entorno autohospedado en una organización donde un administrador desactivó GitHub.
  • [Etiqueta de Claude] Se agregó el indicador de trabajo nativo de Slack, el botón Detener y el título del hilo a los hilos de Claude en los canales; el indicador permanece encendido hasta que Claude termina y Stop interrumpe la tarea
  • [Etiqueta de Claude] Se agregó un breve aviso en el canal de Slack cuando un invitado se une, o el último invitado se va, cambia la forma en que Claude responde allí bajo una configuración de invitado Restringir o Canalizar solo.
  • [Etiqueta de Claude] Se corrigieron rutinas programadas que fallaban silenciosamente al ejecutarse en espacios de trabajo de Slack que estaban conectados a Claude antes de que el espacio de trabajo se uniera a Enterprise Grid.
  • [Etiqueta de Claude] Se corrigió que Claude le pedía que volviera a cargar un archivo de Slack cuando el problema era una breve interrupción del escaneo de archivos, no el archivo; ahora vuelve a intentar el escaneo y se le indica cuando el escáner está inactivo
  • [Etiqueta de Claude] Se corrigió una viñeta en la respuesta de Claude en Slack cuyo texto comienza con +, - o * y se muestra como una viñeta vacía con un elemento anidado extraviado; ahora se muestra como una viñeta con el personaje conservado.
  • [Etiqueta de Claude] Se corrigió el aviso de Slack para un script de configuración fallido del entorno de nube que a veces era un "mencióname para volver a intentarlo" genérico; ahora nombra el script de configuración y dice que lo arregle primero
  • [Claude Tag] Se mejoró el banner de GitHub en la configuración de administración de Claude Tag para indicar por qué GitHub no está conectado: no ha iniciado sesión, la aplicación no está vinculada o no está instalada, el inicio de sesión expiró o el SSO no está autorizado.
  • [Revisión de código] Se mejoró la ejecución de verificación de revisión de código para indicar cuándo las instrucciones de REVIEW.md se cortaron o quedaron fuera de una revisión por exceder un límite de tamaño, nombrando el archivo y el límite.
