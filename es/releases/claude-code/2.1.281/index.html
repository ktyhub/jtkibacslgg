código-claude v2.1.281

¿Qué ha cambiado?

  • Se agregó compatibilidad con la puerta de enlace de aplicaciones de Claude para las nuevas claves de Claude Desktop en los bloques de políticas desktop, incluidos blockReadsOutsideWorkingDirectories y disableBypassPermissionsMode.
  • Se agregó assume_role en la puerta de enlace de aplicaciones de Claude Bedrock upstream: la puerta de enlace llama a Bedrock como un rol de IAM que asume a través de STS, en otra cuenta de AWS si es necesario, opcionalmente una sesión por desarrollador
  • Se agregó guardrail: {id, version} en la puerta de enlace de aplicaciones de Claude Bedrock upstream para aplicar una barrera de protección de Amazon Bedrock a cada solicitud enviada a través de ellos (configúrelo en todos los Bedrock upstream o en ninguno).
  • Se agregó telemetry.resource_attributes a la configuración de la puerta de enlace de aplicaciones de Claude, para colocar etiquetas fijas en la telemetría de las sesiones de Claude Desktop y /login.
  • Se agregó "attribution": false en settings.json para ocultar todos los compromisos y atribuciones de relaciones públicas; Las versiones anteriores de CLI omiten un archivo de configuración que lo contiene, así que mantenga el formato del objeto en archivos compartidos entre versiones.
  • Se agregó la obtención del modo URL de MCP en las conexiones del protocolo 2026-07-28, para que los servidores puedan pedirle a Claude Code que abra un flujo basado en navegador; no se deja ningún cuadro de diálogo de espera en la pantalla cuando el servidor no tiene forma de confirmar la finalización
  • Se agregaron comprobaciones del servidor MCP a claude plugin validate: informa entradas de .mcp.json que se eliminarían silenciosamente durante la carga, referencias de ${user_config.*} no declaradas y URL inseguras.
  • Se agregó una recomendación de modo automático a /insights que estima cuántas solicitudes de permiso podría haber manejado el modo automático en sus sesiones recientes.
  • Se agregó una barra de desplazamiento a las listas instaladas de /skills, /mcp y /plugin en modo de pantalla completa, como la que ahora tiene /workflows: aparece mientras el mouse está sobre la lista y se puede cli arrastrar o arrastrar.
  • Se corrigió un bloqueo ("error de interfaz irrecuperable") que podía finalizar una sesión mientras se reintentaba una solicitud API.
  • Se corrigió un giro que podía reintentar indefinidamente, ignorando --max-turns, cuando el modelo alternaba llamadas de herramientas no analizables y truncamiento del límite de salida.
  • Se corrigieron las sesiones reanudadas que reenviaban turnos anteriores en una forma modificada (un turno de llamada de herramienta paralelo, una entrada de llamada de herramienta MCP o un resultado de búsqueda de herramienta mientras su servidor aún se estaba reconectando, o un resultado de búsqueda de herramienta cuyo turno de carga fue interrumpido), lo que podría hacer que el API abandone el razonamiento anterior de la conversación.
  • Se corrigió que al reanudar una sesión muy grande a veces se restauraran solo los últimos mensajes.
  • Se corrigió una sesión reanudada después de un reinicio durante una solicitud de permiso pendiente que enviaba un historial diferente al anterior, lo que rompía el caché de solicitud desde ese punto.
  • Se corrigió la reanudación de una sesión que finalizó durante una llamada de herramienta: Claude ahora ve la llamada y se le dice que su resultado es desconocido, y una reanudación manual ya no agrega un mensaje oculto "Continuar".
  • Se corrigieron las sesiones con un resultado de asesor anterior, el API ya no podía leer fallando una solicitud en cada turno y perdiendo repetidamente el razonamiento anterior; la historia ahora se repara una vez
  • Se corrigió la pérdida de caché del mensaje cuando un servidor MCP se desconecta en mitad de una conversación o aún se conecta después de una reanudación, mientras la búsqueda de herramientas está desactivada (por ejemplo, detrás de un proxy o puerta de enlace).
  • Se corrigieron las respuestas interrumpidas por un proxy o puerta de enlace que cierra la transmisión limpiamente y se muestra como completa sin previo aviso, y las llamadas a herramientas se ejecutan dos veces en eventos de transmisión duplicados.
  • Se corrigieron las respuestas que fallaban con "Bloque de contenido no encontrado" cuando un proxy descarta un evento de transmisión a mitad de respuesta; la respuesta parcial ahora se conserva y la búsqueda web conserva los resultados que ya llegaron

  • /diff mejorado: una barra de desplazamiento muestra dónde se encuentra en una larga lista de archivos modificados y las rutas largas ya no envuelven sus filas
  • /hooks mejorado: la pantalla de detalles de un gancho ahora dice qué tipo de gancho es y dónde cambiarlo, en lugar de apuntar siempre a la configuración. json, y los avisos de ganchos deshabilitados, modo seguro y solo ganchos administrados dicen lo que está sucediendo en una simple oración.
  • Salida del lector de pantalla mejorada en /mcp: un servidor deshabilitado se lee como "apagado" en lugar de "pendiente".
  • Se mejoró la confirmación del control remoto: sus opciones vuelven a estar brevemente inactivas después de que la ventana del terminal recupera el foco, por lo que una tecla presionada mientras se regresa no puede responder.
  • Se modificó el envío ahora (ctrl+enter o ctrl+x ctrl+s) para mover las herramientas en ejecución al fondo en lugar de cancelar el turno.
  • Se cambió el modo automático para que, cuando la revisión del clasificador se ejecute en el lado del servidor, los comandos de shell de solo lectura y de espacio aislado también esperen esa revisión y se bloqueen cuando los marque.
  • Se modificó CLAUDE_CODE_AUTO_MODE_SERVER para que también se aplique en una conexión Anthropic API directa: 0 opta por no participar en el clasificador de modo automático del lado del servidor (el clasificador local luego cuenta para el uso), 1 opta por participar.
  • Se cambió el mensaje peligroso rm en --dangerously-skip-permissions y en modo automático para esperar 2 minutos por una respuesta, luego denegar el comando con una sugerencia de reescritura para que las sesiones desatendidas continúen (CLAUDE_CODE_DISABLE_DANGEROUS_RM_TIMEOUT=1 desactiva esto).
  • Se modificó la puerta de enlace de aplicaciones de Claude para que se niegue a iniciarse cuando la ruta envHelper de una entrada managedMcpServers comienza con \??\ o /??/, una ruta desde el actual Claude Desktop se niega a ejecutarse.
  • Se cambiaron los ejecutores autohospedados para pasar los mensajes del sistema a Claude Code como archivos privados en lugar de texto de línea de comandos, de modo que los mensajes grandes ya no fallen en el inicio; un envoltorio o gancho command que agrega --system-prompt o --append-system-prompt debe cambiar a --system-prompt-file o --append-system-prompt-file
  • Se cambiaron los mensajes en cola para que se muestren en la conversación encima de la rueda giratoria en lugar de debajo de ella.
  • Se cambiaron los enlaces de artefactos de sesión bajo el mensaje a una pastilla de pie de página (⧉ name o ⧉ N) que abre /artifacts, que ahora enumera primero los artefactos de esta sesión.
  • Se modificó la herramienta Artifact para permitir que Claude cargue scripts desde unpkg.com en las páginas de artefactos.
  • Se cambió al pasar el cursor sobre una fila de la lista en modo de pantalla completa, incluso en /config, para teñir la fila en lugar de dibujar un segundo puntero ❯ al lado de la fila enfocada.
  • Se modificó /mcp: la fila de cada servidor ahora comienza con su ícono de estado y su nombre, dice su estado una vez y en una terminal estrecha deja caer datos finales como "administrado" antes de acortar el nombre.
  • Se modificó /flujos de trabajo: la fila de cada ejecución comienza con su ícono de estado y tiempo transcurrido, y una terminal estrecha mantiene el nombre y la hora de la ejecución, eliminando primero el conteo de agentes y tokens.
  • Se cambiaron las descargas de archivos adjuntos del Control remoto para reutilizar conexiones y omitir archivos ya descargados en la sesión.
  • Se modificaron las listas de recursos de MCP (la herramienta de lista de recursos y las sugerencias de @menciones) para omitir los recursos de la interfaz de usuario de las aplicaciones de MCP; leer uno por URI todavía funciona
  • Se modificó claude plugin uninstall --json y el cuadro de diálogo /plugin para indicar que los datos de un complemento se conservaron cuando su carpeta permanece porque otro complemento instalado los usa o los registros de instalación no se pueden leer.
  • Se modificó la lista de tareas en segundo plano (/tasks): al presionar x en un /ultrareview en ejecución ahora se solicita confirmación antes de detener la revisión.
  • Se eliminó la entrada sobrante "(eliminada)" /agents del menú de comandos y /help; escribir /agents todavía explica dónde fue el asistente
  • [VSCode] Se agregó un mensaje Continuar/Detener en los paneles VS Code y JetBrains cuando el modo automático vuelve a las solicitudes del clasificador facturadas, reemplazando la línea de advertencia sin respuesta.

  • [VSCode] Se corrigió una sesión de claude.ai/code que se abría vacía o con solo una parte de su conversación, sin errores, cuando el servidor no podía devolver su historial, parte de él no se cargaba o una página de inicio de sesión de red respondía en su lugar; Ahora muestra un error y se puede abrir de nuevo.
  • [VSCode] Se corrigieron las conversaciones en las pestañas del editor que se bloqueaban silenciosamente después de que se reinicia el host de la extensión; la pestaña ahora le indica que la vuelva a abrir desde la lista de sesiones
  • [VSCode] Se corrigió que Claude adjuntara vistas previas de opciones a preguntas de opción múltiple en el panel de chat, donde la tarjeta de preguntas nunca las muestra.
  • [VSCode] Se corrigió el bloqueo de costo y uso del administrador de sesión que envolvía el texto en mitad de una barra lateral estrecha y mostraba los totales de un inicio de sesión anterior después de un cambio de cuenta.
  • [Claude Code en la web] Se agregó un interruptor de modo rápido al menú del modelo del compositor en sesiones en la nube, que se muestra cuando su plan incluye el modo rápido y el modelo seleccionado lo admite.

  • [Claude Code en la web] Se corrigió el consejo de configuración de GitHub en claude.ai/code que cubría el cuadro de búsqueda y las filas del selector de repositorio mientras el selector está abierto; ahora se hace a un lado hasta que se cierra el selector
  • [Código Claude en la web] Se mejoró la tarjeta de archivo que se muestra cuando una sesión en la nube no puede abrir un archivo: ahora dice si el archivo ya no existe o si la configuración de permisos de la sesión bloquea su lectura.

  • [Etiqueta de Claude] Se corrigieron los canales de Slack donde Claude podía dejar de responder permanentemente a las respuestas dentro de los hilos; Los canales afectados ahora se recuperan solos con el próximo mensaje nuevo para Claude.

  • [Etiqueta de Claude] Se corrigió que las respuestas de Slack llegaran muchos minutos tarde, o nunca, después de que la sesión de Claude fallara a mitad de una tarea, como en un script de configuración fallido; ahora se reinicia solo en cuestión de minutos
  • [Etiqueta de Claude] Se corrigió que Claude en Slack prometiera un reinicio automático y luego fallara de manera genérica, cuando la configuración de una sesión es demasiado grande para iniciarla; El hilo ahora dice por qué y cómo volver a intentarlo.
