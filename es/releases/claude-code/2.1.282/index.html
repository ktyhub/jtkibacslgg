código-claude v2.1.282

¿Qué ha cambiado?

  • Se agregó una configuración maxProseWidth que limita el ancho de la prosa de Claude en terminales anchos, mientras que las tablas y los bloques de código mantienen el ancho completo.
  • Se agregó un aviso de inicio y entradas /status y claude doctor, que enumeran las variables de telemetría en los archivos de configuración de un proyecto que fueron ignoradas o que desactivaron la telemetría.
  • Se agregó la configuración administrada allowClaudeInChromeWithManagedMcp para permitir que claude --chrome se ejecute junto con un managed-mcp.json exclusivo; el error que se muestra cuando Chrome está bloqueado ahora lo nombra
  • Se agregó store.readiness_grace_seconds a la puerta de enlace de aplicaciones de Claude para que /readyz pueda permanecer listo durante una breve interrupción de Postgres, como una conmutación por error de la base de datos.
  • Se agregó una barra de desplazamiento a la lista de borradores de /feedback en modo de pantalla completa; aparece mientras el mouse está sobre la lista
  • Se corrigió cada solicitud que fallaba con un error 400 en conversaciones cuyo historial contiene resultados de búsqueda web que el API no puede descifrar (por ejemplo, de un turno respondido a través de una puerta de enlace de terceros).
  • Se corrigieron más casos de sesiones continuadas o reanudadas (--continue, --resume) que reenviaban mensajes anteriores en una forma modificada, lo que podía hacer que el API abandonara el razonamiento anterior de Claude.
  • Se corrigió que el pensamiento extendido anterior se eliminara cuando se usaba /model, /rename, /artifacts u otro comando de barra diagonal inmediata mientras Claude estaba trabajando.
  • Se corrigieron conversaciones continuadas o reanudadas que perdían el pensamiento extendido anterior cuando se relanzaban con una lista --tools que omite una herramienta incorporada que se ofrecía anteriormente en la conversación.
  • Se corrigieron las sesiones que fallaban en cada turno con el error API "data no válido en el bloque redacted_thinking"; Claude Code ahora elimina los bloques de pensamiento de la conversación y lo vuelve a intentar una vez.
  • Se corrigió el error de compactación cuando se rechaza la solicitud de resumen; ahora vuelve a intentar con un modelo alternativo
  • Se corrigió un giro fallido ("El esfuerzo 'xalto' no está disponible con el pensamiento desactivado") después de un cambio de modelo relacionado con la seguridad en sesiones con pensamiento apagado y esfuerzo por encima de alto.
  • Se corrigió un mensaje de cambio de modelos de uso de créditos de Fable sin respuesta en sesiones alojadas en SDK, como Claude Desktop; el turno ahora termina y el control remoto clients ahora ve el aviso de cambio de modelo
  • Se corrigió /model con una identificación de modelo de Fable completa que se detenía en un error API en lugar de abrir el mensaje de créditos de uso cuando el plan necesita créditos de uso que aún no están activados.
  • Se corrigieron solicitudes que fallaban por hasta un minuto con un error de inicio de sesión "otro proceso de Claude Code lo está actualizando" después de que ese otro proceso se cerró o se eliminó durante la actualización.
  • Se corrigieron las sesiones iniciadas mientras otra ventana de Claude Code estaba actualizando el inicio de sesión (común con varias ventanas de VS Code) y no reintentaba la búsqueda de políticas de su organización.
  • Se corrigió CLAUDE.md y las reglas que se leían al inicio a través de un enlace simbólico del repositorio que llegaba a /Network de macOS a través de .. o una ruta de kernel estilo /.vol, o se enumeraba un enlace de reglas a /home de macOS.
  • Se corrigieron las reglas de permisos de Bash con un patrón medio :* que se omitía en los archivos de configuración mientras que --allowedTools los respetaba; ahora funcionan desde todas las fuentes, con una advertencia de inicio sobre cómo coinciden
  • Se corrigió un comando aprobado en un mensaje de permiso restaurado que se ejecutaba dos veces cuando se reiniciaba el trabajador de una sesión remota.
  • Se corrigió la configuración administrada que ignoraba un valor mal escrito para claves de bloqueo booleanas como disableClaudeAiConnectors o allowManagedPermissionRulesOnly; el bloqueo ahora se aplica y el inicio nombra la clave
  • Se corrigió que las configuraciones administradas de permissions, autoMode, worktree y attribution se ignoraran por completo cuando un valor anidado no era válido; el resto del bloque ahora todavía se aplica
  • Se corrigieron los manifiestos del complemento del directorio de habilidades, comandos y habilidades del usuario y --add-dir que aprobaban previamente sus propias herramientas a través de allowed-tools bajo allowManagedPermissionRulesOnly administrado.
  • Se corrigieron los mensajes de bloqueo de protección en Amazon Bedrock y Bedrock Mantle que no mostraban una identificación de solicitud; bloquear mensajes ahora también muestra el ID del mensaje
  • Vertex AI: Se corrigió que la búsqueda web no se ofreciera para modelos que Claude Code aún no reconoce, como los recién lanzados.
  • Se corrigió que Bash y PowerShell ocultaran una cuota de disco completa detrás del "Código de salida 1" y dejaran archivos de salida grandes en temperatura.
  • Se corrigieron errores de validación de entrada de herramientas que nombraban solo un parámetro desconocido, faltante o mal escrito cuando otros parámetros en la misma llamada tampoco eran válidos; esos ahora también están listados
  • Se corrigió el texto pegado de varias líneas que se enviaba línea por línea después de que el modo de pegado entre corchetes del terminal se restableciera a mitad de sesión.
  • Se corrigió el texto de ejemplo del mensaje que parpadeaba y desaparecía al inicio en proyectos con un gancho SessionStart.
  • Se corrigió una pantalla en blanco que parpadeaba antes del primer cuadro al iniciar en modo de pantalla completa.
  • Se corrigieron filas confusas y mal colocadas en el renderizador que no era de pantalla completa después de que la pantalla se hacía más corta pero aún más alta que el terminal, p. eliminar una línea de aviso mientras un comando de shell transmite la salida
  • Se corrigió un carácter obsoleto que quedaba en la última columna de una diferencia cuando el carácter CJK o emoji de una línea redibujada pasaba a la siguiente fila.
  • Se corrigió el cursor que aterrizaba antes del final de un mensaje recuperado del historial cuando el mensaje contiene una pestaña.
  • Se corrigió la sugerencia de enviar ahora que mostraba Ctrl+Enter en terminales que lo envían como una nueva línea (Terminal de Windows anterior a 1.25); ahora muestra ctrl+x ctrl+s allí
  • Se corrigió el error de claude remote-control --debug con "Argumento desconocido: --debug", aunque el error de elegibilidad del control remoto dice que se ejecute con --debug.
  • Se corrigió que /install-github-app dijera "cancelado" y luego continuara presionando la rama y guardando la clave secreta API; salir ahora detiene los pasos restantes e informa lo que ya se hizo
  • Se corrigió /feedback, /bug y /share en Bedrock, Vertex y otros proveedores externos que aún guardaban el archivo de informe después de cancelar durante el guardado.
  • Se corrigió la desinstalación del complemento que informaba el éxito y eliminaba las opciones guardadas del complemento cuando su archivo de configuración aún lo habilitaba o no se podía leer; ahora se detiene y nombra el archivo
  • Se corrigió la desinstalación del complemento que eliminaba las opciones guardadas y los secretos de un complemento cuando la lista de complementos instalados no se podía leer después de la eliminación; Ahora se conservan y la desinstalación lo dice.
  • Se corrigió una tecla escrita justo después de / en /skills que movía la lista de habilidades en lugar de llegar al cuadro de búsqueda.
  • Se corrigió el cursor del terminal que saltaba del cuadro de búsqueda /skills a la lista de habilidades mientras se escribía, lo que podía ocultar el cursor y colocar la entrada de IME en el lugar equivocado.
  • Se corrigieron las listas con una barra de desplazamiento, como /skills y /mcp, siendo dos columnas más estrechas fuera del modo de pantalla completa, donde la barra de desplazamiento nunca puede aparecer.
  • Se corrigió el pie de página del panel del agente que se ajustaba a dos líneas con teclas de rebote largas y su sugerencia "Esc para contraer" ignoraba una tecla de colapso de rebote.
  • Se corrigió un separador · duplicado en el pie de página del cuadro de diálogo /tasks cuando el acceso directo para detener todos los agentes no está vinculado en keybindings.json.
  • Se corrigió el error de publicación de artefactos cuando Claude le dio a la versión una etiqueta de más de 60 caracteres; la etiqueta ahora está acortada
  • Se corrigió el modo de lector de pantalla, listas citadas y listas muy largas que eliminaban las líneas en blanco en la parte superior de un bloque de código que abre un elemento de la lista, directamente o dentro de una cita.
  • Se corrigieron mensajes de error de lectura de páginas PDF: las rutas con caracteres acentuados o no latinos ahora aparecen legibles, y una carpeta con el nombre "contraseña" o "no válido" ya no puede hacer que el nombre del error sea la causa incorrecta.
  • Se corrigió el modo vim >> que sangraba líneas vacías, r con un recuento más largo que la línea que cambiaba el texto, 2J unía una línea de más y un recuento en la última línea (2dd, 2>>) que la movía o eliminaba.
  • Se corrigió la ubicación del cursor en el modo vim: después de dd, dj, dG o una línea completa p/P, aterriza en el primero que no está en blanco, yy ya no lo mueve y Esc después de un emoji ya no lo deja dentro del emoji.
  • Se corrigió el modo vim que ignoraba un conteo escrito antes de . al repetir x, s, p, d o c, y la línea completa p/P, o, O, J, >> y << que actuaba en la línea incorrecta cuando había una línea arriba. envolturas
  • Se corrigió el modo vim que dejaba el cursor más allá del final de un mensaje recuperado del historial o retirado de la cola en modo normal, por lo que x no hizo nada.
  • Se mejoró el tiempo para reanudar sesiones muy grandes, incluidas aquellas que nunca fueron compactadas.
  • Se mejoró el error que se muestra en Windows cuando no se puede reanudar una sesión porque no se pudo leer su archivo de transcripción (EBADF): ahora nombra las posibles causas y qué intentar
  • Se mejoró el error de modelo desconocido de Claude Desktop para sugerir cambiar a un modelo diferente.
  • Representación mejorada de Unicode inusual en solicitudes de permiso
  • /artifacts mejorado: los títulos se alinean en una columna, los detalles se eliminan completos en lugar de cortarse a mitad de palabra, y la lista admite Re Pág/Av Pág, Inicio/Fin, la rueda del mouse y clicks
  • Se actualizó la habilidad claude-api: la facturación de rechazos previos a la salida ahora se vincula a los documentos Cómo se facturan los rechazos, los rechazos intermedios se facturan a tarifas normales y los rechazos previos a la salida cuentan contra los límites de tarifas.
  • Se actualizó la habilidad claude-api para recomendar ant apply para mantener los recursos de los agentes administrados como archivos controlados por versión.
  • Se cambió el modo automático para usar el clasificador del lado del servidor de forma predeterminada en una conexión Anthropic API directa cuando la telemetría está desactivada (CLAUDE_CODE_AUTO_MODE_SERVER=0 opta por no participar).
  • Se modificó sandbox.excludedCommands para ignorar las entradas de configuración local y del proyecto cuando la configuración administrada o --settings configura allowUnsandboxedCommands: false, o allowManagedDomainsOnly: true administrado.
  • Se modificó la configuración local y del proyecto para ignorar las variables OpenTelemetry que activan la exportación, establecen su punto final o capturan contenido, como CLAUDE_CODE_ENABLE_TELEMETRY y OTEL_LOG_*.
  • Se modificó la configuración administrada de Windows/WSL para que una política de administración presente pero no válida o ilegible (HKLM, managed-settings.json) impida que se apliquen HKCU y WSL /etc/claude-code en los que el usuario puede escribir.
  • Los cambios Skill(anthropic-skills:*) y Skill(claude-ai:*) permiten que las reglas cubran solo las habilidades sincronizadas desde claude.ai, no los complementos u otras habilidades que simplemente usan ese nombre.
  • Se cambiaron las carpetas de habilidades, los archivos de comandos y los comandos de flujo de trabajo en el espacio de nombres anthropic-skills o claude-ai para que ya no se carguen; un complemento llamado así todavía se carga pero genera vínculos de nombres con habilidades sincronizadas
  • Se cambiaron los servidores MCP configurados con el nombre anthropic-skills o claude-ai para que no muestren habilidades ni indicaciones (sus herramientas aún funcionan); cambie el nombre del servidor en su configuración MCP para enumerarlos nuevamente
  • Se cambiaron las imágenes de ultracode en /effort y la entrada de mensajes a un estilo simple (sin ondulaciones, florituras de bordes ni destellos de palabras clave) y se eliminó la sugerencia giratoria de flujos de trabajo dinámicos.
  • Se cambiaron los pies de la mascota Clawd en el cartel de inicio para que se coloquen debajo de las esquinas de su cuerpo.
  • [VSCode] Se corrigieron las respuestas largas que se retrasaban en la transmisión: el panel ya no vuelve a analizar la respuesta completa en cada actualización.
  • [VSCode] Se corrigió el botón del micrófono de dictado que cubría la barra de desplazamiento de la entrada del mensaje cuando la entrada es lo suficientemente alta como para desplazarse.
  • [VSCode] Se corrigieron las sesiones de control remoto iniciadas en esta computadora que no se abrían desde su entrada web en la lista de sesiones; ahora abren la conversación local a menos que se esté ejecutando en otro lugar
  • [VSCode] Se corrigió la pantalla de inicio de sesión de una pestaña del editor que se bloqueaba silenciosamente después de que se reinicia el host de la extensión; ahora también muestra el aviso "dejó de responder"
  • [Sesiones en la nube] Se agregó el estado de la aplicación Claude GitHub a Configuración › Conectores › GitHub: si la aplicación está instalada y es accesible para su cuenta, además de los pasos para conectarse, instalarse o volver a conectarse
  • [Sesiones en la nube] Se agregaron enlaces "Abrir repositorio" y "Abrir página de comparación" al menú del repositorio de una sesión en la nube cuyo repositorio está alojado en un servidor Git distinto de GitHub.
  • [Sesiones en la nube] Se agregó adjuntar un repositorio de un propietario diferente de GitHub, como una bifurcación ascendente, a una sesión en ejecución en la nube que ya tiene una, incluidas las sesiones iniciadas desde Slack.
  • [Sesiones en la nube] Se corrigió que el siguiente tiempo de ejecución mostrado para una rutina horaria fuera de 30 minutos para personas en zonas horarias con diferencia horaria de media hora, como India.
  • [Sesiones en la nube] Se mejoró la rapidez con la que se cargan la página Rutinas y la lista Programada de la barra lateral para las cuentas cuyas sesiones anteriores programaron muchos recordatorios de registro.
  • [Claude Tag] Se corrigieron los patrones de canal de unión automática guardados para un espacio de trabajo en la configuración de administración de Claude Tag que se ignoraban en una instalación de Enterprise Grid en toda la organización; Claude ahora se une a nuevos canales coincidentes
  • [Claude Tag] Se corrigió que Claude no respondiera en un canal Enterprise Grid compartido entre dos espacios de trabajo de una organización cuando la versión de Claude Tag del canal se guardaba desde el otro espacio de trabajo.
  • [Etiqueta de Claude] Se corrigió la tarjeta de progreso anterior de la aplicación Claude en Slack para sesiones en un repositorio de servidor empresarial GitHub: ahora nombra el repositorio y ofrece un botón Crear PR funcional
  • [Claude Tag] Se corrigieron los hilos de Slack cuyo modelo había sido retirado y volvían a otro modelo en cada respuesta, más lento y con una nota de respaldo cada vez; el hilo ahora pasa a un modelo funcional
  • [Etiqueta de Claude] Se corrigieron los archivos que Claude carga en Slack y no pueden incluir un título que contenga una tabla; Los subtítulos ahora se muestran con el mismo formato que las respuestas.
  • [Etiqueta de Claude] Se corrigió que los hilos de Claude en la vista Agentes y herramientas de Slack a veces aparecieran debajo de su primer mensaje en lugar de su nombre; Más tarde los cambios de nombre ahora actualizan la lista también.
  • [Claude Tag] Se corrigió que al eliminar la concesión de una organización GitHub de la pestaña Repositorios de un paquete de acceso en la configuración de administración de Claude Tag no se pudiera guardar después de que se desconectara esa organización GitHub.
  • [Etiqueta de Claude] Se corrigió que Claude siempre respondiera "No se pudo verificar este canal en este momento" en un canal compartido con un espacio de trabajo de Grid al que no está agregado; el aviso ahora dice qué espacio de trabajo necesita la aplicación
  • [Etiqueta de Claude] Se corrigieron los totales de costos y tokens en el pie de página de respuesta de Claude, que eran muchas veces demasiado altos después de que se reiniciaba el trabajador en la nube de la sesión.
  • [Etiqueta de Claude] Se cambiaron las tarjetas con bordes que Claude usa en las respuestas de Slack para planos, tablas y detalles para que se muestren anchas de forma predeterminada en lugar de estrechas.
  • [Etiqueta de Claude] Se cambiaron los espacios de trabajo de Slack recién conectados para que sigan el modelo predeterminado actual en lugar de mantener el modelo que era el predeterminado cuando se conectaron.
