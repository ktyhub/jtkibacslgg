incubadora-seata v1.1.0

La versión se actualiza de la siguiente manera:

característica:

  • [#2200] admite postgresql(client y servidor)
  • [#1746] integrar con httpClient
  • [#2240] admite una estrategia de recuperación de transacciones de saga personalizada en el tiempo de espera de la transacción
  • [#1693] soporte para carga de aislamiento de clase druida
  • [#2245] Soporte de resumen zookeeper
  • [#2239] compatibilidad dubbo 2.7.4+
  • [#2203] admite grupo de configuración de nacos
  • [#2086] admite el espacio de nombres de configuración de Apollo
  • [#2106] admite FastThreadLocalContextCore
  • [#1703] crear un analizador sql SPI y un analizador sql tipo druida
  • [#2151] Saga proporciona un interruptor para omitir el informe de sucursal sobre el éxito de la sucursal

corrección de errores:

  • [#2270] corrigió que el tamaño del trabajador no admitiera el tipo de enumeración y algún problema menor

  • [#2249] corrigió el estado incorrecto de la máquina de estado de saga en la rama de registro.
  • [#2126] corrige caracteres de escape para nombres de columnas y tablas
  • [#2234] corrige error de tipo cuando fastjson deserializa el tipo largo
  • [#2237] corrige el error DefaultCoordinatorTest en el sistema operativo Windows

  • [#2175] arregla el buffer directo OOM
