iotdb v1.1.0

#iotdbv1.1.0

Nuevas características

  • [IOTDB-4572] orden de soporte por tiempo en alineación por dispositivo
  • [IOTDB-4816] Compatibilidad con el comando Mostrar consultas
  • [IOTDB-4817] Admite comando de consulta de eliminación
  • [IOTDB-5077] Admite nuevos formatos de comando en MOSTRAR REGIONES
  • [IOTDB-5108] Migración de región de soporte
  • [IOTDB-5202] Soporte para mostrar regiones con una base de datos específica
  • [IOTDB-5282] Agregue variables de visualización SQL, que pueden mostrar las variables del clúster actual
  • [IOTDB-5341] Admite GRUPO POR VARIACIÓN en consulta de agregación
  • [IOTDB-5372] Admite conversión de tipos de datos en SELECT INTO
  • [IOTDB-5382] Admite DIFF como función escalar incorporada en IoTDB
  • [IOTDB-5393] Mostrar hora de creación de región al ejecutar mostrar regiones
  • [IOTDB-5456] Implementar la función de agregación incorporada COUNT_IF
  • [IOTDB-5515] Admite GRUPO POR CONDICIÓN en consulta de agregación
  • [IOTDB-5555] Habilite la modificación de dn_rpc_port y dn_rpc_address en datanode-engine.properties
  • Admite implementación de docker
  • Cambie el nombre de SeriesSlotId a SeriesSlotNum en las regiones del espectáculo

Mejoras

  • [IOTDB-4497] Mejorar la definición de NodeStatus
  • [IOTDB-5066] Se actualizaron los SQL de GetSlots
  • [IOTDB-5161] Agregar verificación de tipo de salida para la cláusula WHERE & HAVING y rechazar expresiones cuyo tipo de retorno no sea booleano en la cláusula WHERE & HAVING
  • [IOTDB-5185] Se corrigió que la instantánea anterior no se elimina en IoTConsensus
  • [IOTDB-5287] Se agregó el estado "Desalentado" a RegionGroup
  • [IOTDB-5449] Esperar el recurso de consulta mientras la cola de consultas está llena en lugar de generar una excepción directamente
  • cambiar STARTUP_RETRY_INTERVAL_IN_MS de 30s a 3s

Corrección de errores

  • [IOTDB-4684] Los dispositivos reparados con el mismo nombre pero con diferentes propiedades de alineación están compactados en la propiedad de alineación incorrecta
  • [IOTDB-5061] Agregar verificación de estado de inicialización al crear una instantánea
  • [IOTDB-5090] Se corrigió el NPE al ejecutar stop-datanode.sh
  • [IOTDB-5112] Se corrigió la sincronización de IoTConsensus bloqueada bajo carga baja o durante el reinicio.
  • [IOTDB-5126] Se corrigió que show-regions mostrara IP en lugar de nombre de host aunque se use el nombre de host al registrarse
  • [IOTDB-5165] Se corrige un error al pasar la validación de compactación cuando los recursos se degradan a FileTimeIndex
  • [IOTDB-5170] Soluciona el problema por el cual el nodo de datos se cierra al ejecutar stop-confignode.bat en la plataforma Windows
  • [IOTDB-5199] Se corrigió NPE en el proceso de carga de StorageExector
  • [IOTDB-5216] La corrección del orden por serie temporal no tiene efecto en la última consulta alineada
  • [IOTDB-5228] NPE si el archivo no existe al crear la instancia de TsFileSequenceReader
  • [IOTDB-5240] Se corrige el error de lectura/escritura de la serie temporal de la plantilla de esquema después del reinicio
  • [IOTDB-5245] Los datos de corrección están incompletos en la última consulta
  • [IOTDB-5277] Se corrigió el error de reinicio de DataNode cuando SchemaRegion cargaba la instantánea
  • [IOTDB-5278] Arreglar que el controlador JDBC no se pueda conectar al dbeaver
  • [IOTDB-5285] Se solucionó el error de TimePartition al reiniciar con una configuración de partición de tiempo diferente
  • [IOTDB-5269] Se deben eliminar los datos incorrectos de los dispositivos después de ejecutar delete from sql
  • [IOTDB-5324] La solución wal no se puede eliminar en destDataNode después de la migración de la región cuando data_replication_factor es 1 en IoTConsensus
  • [IOTDB-5389] Causa que el inicio de DataNode falle cuando wal_mode está deshabilitado en IoTConsensus
  • [IOTDB-5414] Se corrigió la serie temporal con alias eliminado correctamente pero aún se puede consultar por alias
  • [IOTDB-5426] No se puede activar la descarga para el archivo de secuencia cuando la descarga programada está habilitada
  • [IOTDB-5441] Se corrige NPE mientras se recupera el esquema que no está en la plantilla utilizada por el dispositivo relacionado
  • [IOTDB-5469] Se solucionó el error al obtener información del esquema después de crear correctamente la plantilla con caracteres de comillas invertidas.
  • [IOTDB-5474] Se corrigió el recuento de nodos usando el error de nivel
  • [IOTDB-5480] El retraso de sincronización de IoTConsensus puede ser negativo en una sola copia
  • [IOTDB-5488] Admite configurar el sistema en solo lectura en local
  • [IOTDB-5492] Omitir el archivo ts roto al recuperar el sistema
  • [IOTDB-5512] Se corrigió que IoTConsensus pudiera enviar algún registro repetidamente al reiniciar
  • [IOTDB-5516] Se corrigió el error al crear una serie temporal después de descartar todas las bases de datos.
  • [IOTDB-5526] Se corrigió el error al eliminar la serie temporal cuando pertenece a una plantilla de activación de dispositivo
  • [IOTDB-5548] Se solucionó el error de descartar la plantilla cuando se utiliza un número puro como nombre de plantilla
  • [IOTDB-5592] Se corrigió un error inesperado al usar la ruta completa (comenzando con la raíz) en la cláusula have/where
  • [IOTDB-5620] Se corrigió el vaciado bloqueado cuando había muchas particiones de tiempo en cada región de datos.
  • [IOTDB-5639] Arreglar la excepción de archivo no encontrado en el selector de compactación de espacio cruzado
  • [IOTDB-5657] La corrección LIMIT&OFFSET no tiene efecto en la última consulta
  • [IOTDB-5684] Se corrigió la generación de carpetas de registro cuando se utiliza el protocolo de consenso simple de ConfigNode
  • [IOTDB-5685] Se corrigió el mensaje de error al no poder crear una serie temporal en una ruta existente cuando el estado Solo lectura
  • [IOTDB-5686] Se corrigieron dispositivos con el mismo nombre pero diferentes propiedades de alineación y se produjo un error en la compactación de secuencia interna
  • [IOTDB-5700] Limpiar archivos temporales creados por la consulta UDF una vez finalizada
  • Agregar privilegio SHOW_CQ
