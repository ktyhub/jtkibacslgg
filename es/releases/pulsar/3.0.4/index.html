pulsar v3.0.4

¿Qué ha cambiado?

Corredor

  • [arreglo][broker] Evite ejecutar prepareInitPoliciesCacheAsync si se elimina el espacio de nombres (#22268)
  • [solución][broker] Evite los libros de contabilidad vencidos y no cerrados al verificar los mensajes vencidos según la hora de cierre del libro mayor (#22335)
  • [arreglo][broker] Verifique el estado del cursor antes de agregarlo al waitingCursors (#22191)
  • [solución][broker] Los despachadores cerrados se atascaron debido a una falta de coincidencia entre Dispatcher.consumerList y Dispatcher.consumerSet (#22270)
  • [solucionar] [broker] Solucionar el problema de NPE OpReadEntry.skipCondition (#22367)
  • [arreglar][broker] Arreglar el uso local del informe ResourceGroup (#22340)
  • [arreglar][corredor] Corregir la carga de grupos de recursos (#21781)
  • [solución] [broker] Solucionar el problema del campo 'tema' no está configurado cuando se maneja la solicitud GetSchema (#22377)
  • [arreglar][broker] Corregir el bloqueo incorrecto de doble verificación para readOnActiveConsumerTask en el despachador (#22279)
  • [arreglar][broker] corrige la discrepancia entre Dispatcher.consumerList y Dispatcher.consumerSet (#22283)
  • [fix][ml]Exponer la marca de tiempo del libro mayor (#22338)
  • [mejorar][admin] Arreglar que createMissingPartitions no responde correctamente (#22311)
  • [mejorar][broker] Agregue la opción createTopicIfDoesNotExist al constructor RawReader (#22264)
  • [mejorar][broker] Agregar autorización detallada a los puntos finales de administración de temas/ns (#22309)
  • [mejorar][broker] Agregar claves de configuración faltantes para almacenar en caché las lecturas de actualización (#22295)
  • [mejorar][broker] Cambiar el nivel de registro para reducir los registros duplicados (#22147)

Client

  • [solución][client] El consumidor perdió el reconocimiento de mensaje debido a una condición de carrera en reconocimiento con mensaje por lotes (#22353)
  • [fix][client] Corrige resultados incorrectos de hasMessageAvailable y readNext después de buscar por marca de tiempo (#22363)
  • [solución][client] GenericProtobufNativeSchema no implementa el método getNativeSchema. (#22204)
  • [arreglo][client] Mensaje de error poco claro al crear un consumidor con dos mismos temas (#22255)
  • [arreglo][client] arreglo Reader.hasMessageAvailable podría volver verdadero después de buscar la última versión (#22201)
  • [arreglar][client]Se corrigió la obtención de un valor maxMessageSize incorrecto al acceder a múltiples clústeres en el mismo proceso (#22306)
  • [mejorar][client] Agregar retroceso para seek (#20963)

Pulsar IO y funciones Pulsar

  • [fix][fn] habilita la autenticación de token de función Go y TLS (#20468)

Otros

  • [mejorar][misc] Eliminar la llamada a sun InetAddressCachePolicy (#22329)
  • [solución][misc] Hacer que el subproceso ConcurrentBitSet sea seguro (#22361)
  • [fix][ws] Verifique la validez de la configuración antes de iniciar el servicio websocket (#22231)

Actualizaciones de la biblioteca

  • [arreglo][seg] Actualice jose4j a 0.9.4 (#22273)
  • [arreglo][seg] Pasar google.golang.org/grpc de 1.38.0 a 1.56.3 en /pulsar-function-go (#21444)
  • [arreglo][seg] Actualizaciones de seguridad de Go Functions (#21844)
  • [arreglo][seg] Actualice Zookeeper a 3.9.2 para abordar CVE-2024-23944 (#22275)
  • [arreglar][seg] Actualice prometheus client_golang a v1.12.2 para corregir CVE-2022-21698 (#20579)
  • [arreglar][compilar] Actualice la versión de alluxio a 2.9.3 para arreglar CVE-2023-38889 (#21715)
  • [mejorar][varios] Incluir biblioteca epoll nativa para Netty para arm64 (#22319)
  • [mejorar][misc] Pin versión Netty en pulsar-io/alluxio (#21728)
  • [mejorar][varios] Actualizar la versión Netty a 4.1.105.Final (#21923)

Pruebas y CI

  • [fix][ci] Tolerar el cambio de opción de montaje fallando en CI (#22241)
  • [fix][ci][branch-3.0] Aumenta el tamaño del montón de Maven de 1024 ma 1500 m como está en master
  • [arreglar][prueba] Corregir el error ManagedLedgerErrorsTest.recoverAfterZnodeVersionError (#22368)
  • [arreglar][prueba] Arreglar RGUsageMTAggrWaitForAllMsgsTest inestable (#22252)
  • [arreglar][prueba] Corregir la prueba inestable BrokerServiceAutoSubscriptionCreationTest (#22190)
  • [arreglar][prueba] Corregir la prueba inestable ManagedLedgerTest.testGetNumberOfEntriesInStorage (#22344)
  • [arreglar][prueba][branch-3.0] Arreglar ManagedLedgerTest.testGetNumberOfEntriesInStorage roto
  • [arreglar][prueba] Corregir las pruebas con el mismo nombre de espacio de nombres (#22240)
  • [mejorar][prueba][branch-3.0] Mejorar ManagedLedgerTest.testGetNumberOfEntriesInStorage
  • [mejorar][misc] Actualizar estilo de verificación a 10.14.2 (#22291) Para obtener la lista completa, consulte el changelog completo.
