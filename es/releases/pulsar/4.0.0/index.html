pulsar v4.0.0

2024-10-21

Cambios en la versión 4.0.0 desde que se inició la preparación de la versión 3.3.0. Para obtener la lista completa, consulte changelog completo y lista completa de PR. ¿Qué hay de nuevo en Apache Pulsar 4.0? cubre temas como:

  • Implementación mejorada de suscripción Key_Shared
  • Tiempo de ejecución seguro Docker basado en Alpine Linux y Java 21
  • Controles de calidad de servicio mejorados para implementaciones multiinquilino
  • Limitación de tarifas como base para la gestión de recursos multiinquilino
  • Rutas de actualización de versiones anteriores
  • Compatibilidad con Client e importancia de actualizar Java clients para abordar CVE-2024-47561
