QwenPaw v1.1.1

✨ Agregado

Proveedores y Modelos

  • Proveedor OpenRouter: proveedor OpenRouter integrado con descubrimiento de modelos, exploración de series y filtrado por modalidad y precio (#1192)
  • Proveedor OpenCode: proveedor OpenCode (Zen) compatible con OpenAI integrado con modelos gratuitos (#2463)
  • Autocompletar ID de modelo: menú desplegable de autocompletar para la selección de ID de modelo al agregar modelos, con descubrimiento de modelo habilitado de forma predeterminada para todos los proveedores (#3175, #3341) Sistema multiagente
  • Herramientas de colaboración de agentes integradas: nuevas herramientas integradas list_agents y chat_with_agent con una habilidad dedicada y comandos de agente CLI optimizados para la comunicación entre agentes (#3292) Canales
  • Matrix Channel Rewrite: cifrado de extremo a extremo (E2EE), manejo de menciones, soporte de historial de mensajes y representación de rebajas (#2509)
  • Mensajes citados de Feishu: manejo de mensajes de cadena de respuesta con extracción de texto, publicaciones, imágenes y contenido de archivos (#3207)
  • Autenticación QR de DingTalk: autenticación de flujo de dispositivo con código QR para la configuración del canal DingTalk en la consola (#3315) Seguridad
  • Guardias de comando de Shell extendidas: nuevas reglas de protección que cubren la inyección $IFS, caracteres de control, espacios en blanco Unicode, acceso a /proc/*/environ, indicadores peligrosos de jq y funciones integradas riesgosas específicas de Zsh (#3303) Herramientas y habilidades
  • Requisitos de habilidades de ClawHub: compatibilidad con requisitos de habilidades en formato ClawHub con resolución de espacio de nombres de metadatos múltiples (#3310)
  • Visualización de URL de medios: las herramientas view_image y view_video ahora aceptan URL HTTP/HTTPS para visualización directa de medios sin descarga (#3358)

🔄 Cambiado

Proveedores y Modelos

  • Unificación de sonda multimodal: la prueba de soporte de imágenes entre proveedores Anthropic, Gemini y OpenAI ahora comparte una única ruta de evaluación con detección mejorada de falsos positivos (#3367)
  • Normalización de mensajes para cambio de modelo: los mensajes se normalizan en el momento de la solicitud para que los archivos adjuntos multimedia se conserven en la memoria al cambiar entre proveedores de modelos (#3359)
  • Desduplicación de medios Anthropic: los medios base64 duplicados en los resultados de la herramienta se reemplazan con marcadores de posición de texto para evitar exceder el límite de tamaño de mensaje de Anthropic (#3372) Canales
  • Migración de DingTalk SDK: canal migrado a la nube oficial de Alibaba SDK con comentarios de reacción emoji durante el procesamiento y la entrega de medios en modo Tarjeta AI (#3236, #3337, #3374)
  • Estabilidad de Feishu WebSocket: manejo del bucle de eventos refactorizado para mejorar la confiabilidad entre subprocesos durante las reconexiones (#3360)
  • Advertencia de límite de respuesta de WeChat: la configuración del canal ahora muestra una advertencia sobre el límite de respuesta de context_token para WeChat iLink (#3376) Herramientas y habilidades
  • CDP administrado por navegador: la estrategia de inicio del navegador predeterminada cambió a CDP administrado con detección automática de Chromium, asignación de puertos y administración del ciclo de vida del proceso (#3164) Consola y interfaz de usuario
  • Rediseño de gestión de modelos: modal de gestión de modelos de proveedor rediseñado con etiquetas de capacidad, búsqueda de modelos y diseño de tarjeta simplificado (#3273, #3294)
  • Pestañas de configuración del agente: página de configuración del agente refactorizada desde tarjetas apiladas a una interfaz con pestañas (#3354)
  • IU de selección de habilidades: selección de habilidades mejorada con sugerencias de etiquetas, información sobre herramientas para nombres largos, comportamiento de carga refinado y acciones de selección masiva (#3320, #3362, #3373)
  • Página de descargas: página de descargas del sitio web rediseñada con agrupación de versiones estable y de vista previa (#3353)

🐛 Fijo

Canales

  • Apagado de QQ WebSocket: stop() ya no se bloquea durante 8 segundos al cerrar a la fuerza el WebSocket al apagarse (#3188) Consola y interfaz de usuario
  • Se corrigió el contraste del botón de fijación de sesión de chat en modo oscuro (#3267)
  • Los enlaces de Markdown en el encabezado ahora navegan dentro de la aplicación en lugar de abrir nuevas pestañas (#3186)
  • Alineación del diseño de los contribuyentes del sitio web para la configuración regional china (#3332) Proveedores
  • Se corrigió el error de descarga del modelo local en Windows ([Errno 22] Invalid argument) (#3321)
  • Omita tool_choice=auto por compatibilidad con vLLM para evitar errores 400 en implementaciones sin --enable-auto-tool-choice (#3295)

📚 Documentación

  • Tutorial RESTful API: tutorial completo de REST API que cubre puntos finales de chat, autenticación, sesiones de varios turnos, transmisión y cambio de agente (#3335)
  • Comandos de chat de habilidades: se agregó una referencia de comando de chat de habilidades a la documentación de comandos (#3330)
