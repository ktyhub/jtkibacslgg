agno v2.6.20

#Changelog

Nouvelles fonctionnalités :

  • ClickhouseDB pour les traces : Ajout de la prise en charge de ClickHouse pour l'acquisition de traces de gros volumes et les analyses OLAP. Voir les documents.
  • Scavio Search Toolkit : Nouvelle intégration de la boîte à outils de recherche avec Scavio.

Améliorations :

  • OpenAI : les citations issues des réponses de recherche sur le Web apparaissent désormais sur response.citations pour les fournisseurs OpenAIChat et OpenAILike.
  • AgentOS : prend en charge FastAPI >= 0.137 afin que get_routes() répertorie chaque itinéraire.
  • LiteLLM : prise en charge des sorties structurées natives et des sorties de schéma JSON (activées par fournisseur avec supports_native_structured_outputs ou supports_json_schema_outputs).
  • Google Toolkits Auth Refactor : classe de base d'authentification unifiée pour les kits d'outils Google.
  • AgentOS : mis à jour pour ne pas limiter quick_prompts à 3 par agent/équipe/workflow.

Corrections de bugs :

  • MCP : préserve _meta et structuredContent des résultats de l'outil MCP sur ToolResult.metadata.
  • Compression des résultats de l'outil : Correction d'une erreur de comptage de jetons pour les outils avec des paramètres d'énumération numériques, afin que la compression se déclenche au bon moment.
  • Workflow : isolez step_id lors des exécutions simultanées tout en le gardant stable lors des pauses/continuations dans les exécutions HITL.
  • Outils : Toolkit et Searxng ne réutilisent plus une liste par défaut mutable entre les instances.
  • Traces : utilisez la clé de conditions canoniques lors de la portée des filtres de trace pour les utilisateurs ciblés.
  • Reddit : les actions d'écriture sont désormais limitées aux sous-reddits autorisés configurés.
  • MoviePy : les sorties générées sont écrites de manière atomique pour éviter les fichiers partiels.
  • OpenAI : Correction de OpenAIResponses pour prendre en charge les schémas de sortie json_schema de type Chat Completions.
