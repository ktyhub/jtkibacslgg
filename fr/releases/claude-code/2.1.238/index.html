claude-code v2.1.238

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.238

Qu'est-ce qui a changé

  • Ajout d'un paramètre keybindingFlavor : définissez-le sur "readline" pour que Ctrl+W dans l'invite supprime l'espace précédent, comme dans Bash ; la valeur par défaut ("classic") est inchangée
  • Places de marché de plugins : headersHelper sur une place de marché d'URL ou une entrée de catalogue exécute une commande qui crée des en-têtes HTTP (par exemple un jeton de courte durée) pour les récupérations de catalogue et d'archives de même origine.
  • Le headersHelper d'une entrée de catalogue s'exécute uniquement lorsque vous installez ou mettez à jour ce plugin, après l'affichage de sa commande ; claude plugin install/update demande [y/N] (ou passe -y)
  • Ajout de claude self-hosted-runner --defer-shutdown-max-min <minutes> : sur SIGTERM, continuez à servir les sessions attachées, garez ce qui reste après autant de minutes, puis quittez
  • Ajout de claude self-hosted-runner --proxy-authorization-command / --proxy-authorization-file pour les proxys de sortie qui nécessitent un en-tête Proxy-Authorization fraîchement émis à chaque connexion
  • Correction d'une croissance illimitée de la mémoire lors de longues sessions interactives : les résultats de l'outil de sous-agent sont désormais publiés dès qu'ils quittent la fenêtre d'affichage récente.
  • Correction des styles de sortie personnalisés, de projet et de plugin revenant à la voix par défaut à mi-session
  • Correction de CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true ne conservant pas les suggestions rapides lorsque votre compte est proche, mais pas dépassé, de sa limite d'utilisation
  • Correction des refus de Bash worktree-isolation vous indiquant de supprimer une redirection lorsque la commande n'en avait pas
  • Correction des coureurs auto-hébergés qui étaient parfois supprimés par le serveur après une seule demande de sondage lente ou perdue, confiant leur session saine à un autre coureur
  • Correction des boîtes de dialogue d'élicitation MCP n'affichant rien pour les URL de plus de 4 096 caractères et des invites d'autorisation supprimant l'option "Ne plus demander" lorsque le chemin du projet ne correspondait pas à la largeur du terminal.
  • Correction des fichiers /tmp/claude-*-cwd restants lorsqu'une commande Bash est supprimée, expire ou est interrompue
  • Correction du retour arrière maintenu ignoré sur les terminaux qui envoient Ctrl+H pour le retour arrière lorsque les frappes arrivent en grandes rafales (liens SSH/mosh lents)
  • Correction de l'habillage du texte dans les différences d'invite d'autorisation : les lignes contenant de larges caractères à plusieurs points de code (tels que les emoji) ou des tabulations ne sont plus clippées
  • Correction de la suppression d'une session suspendue (Ctrl+Z), laissant parfois le terminal en mode collage entre crochets avec le curseur masqué
  • Correction des serveurs MCP stdio recevant une requête server/discover avant initialize, forçant les serveurs paresseux à démarrer leur backend à chaque session ouverte
  • Correction du refus d'une connexion d'un proxy signalé comme une erreur réseau générique au lieu de nommer le proxy
  • Correction de l'avertissement d'absence de cache /model et /effort apparaissant lorsque le cache d'invite avait déjà expiré
  • Correction d'un arrêt par tâche depuis le panneau des tâches de contrôle à distance ne faisant rien sur les sessions hébergées par CLI
  • Correction des sessions à distance se terminant lorsqu'un client délivrait un message utilisateur sans rôle valide
  • Correction des sessions de contrôle à distance démarrées par claude remote-control héritant des variables d'environnement de portée session du shell de lancement
  • Correction d'une session de contrôle à distance dont le processus plantait et restait indisponible jusqu'au redémarrage de claude remote-control ; il peut désormais être réutilisé lors de votre prochain message
  • Correction des messages de contrôle à distance envoyés depuis le Web ou le bureau alors que Claude est à mi-tour, disparaissant de la transcription une fois le tour terminé.
  • Correction des sélections de modèles de télécommande effectuées sur un téléphone ou sur le Web ne mettant pas à jour le modèle affiché dans le terminal
  • Correction de la déconnexion de la télécommande avec « connexion expirée » lorsqu'un bref problème de réseau retarde le renouvellement de votre connexion ; il réessaye maintenant et reste connecté
  • Correction du contrôle à distance signalant un échec de reconnexion lors de la déconnexion ; la déconnexion termine maintenant la session avec un message clair
  • Correction du rapport ListAgents/SendMessage "La télécommande n'est pas connectée" dans les sessions exécutées par claude remote-control (mode serveur) ou par des hôtes Desktop/IDE ; ils répertorient et atteignent désormais les pairs de contrôle à distance
  • Correction de ListAgents et SendMessage exposant le travailleur inactif que la vue de l'agent préchauffe pour votre prochaine session en arrière-plan ; il n'apparaît désormais qu'une fois qu'une tâche le réclame
  • Messagerie inter-session : l'envoi à une session sur cette machine qui refuse les messages entrants (par exemple crossSessionInbound: "refuse") signale désormais "refusé" à l'expéditeur au lieu d'un succès silencieux
  • Messagerie inter-session : une session dont la boîte de réception supprime vos messages (limite de débit ou file d'attente pleine) informe désormais votre session, au lieu que les messages disparaissent silencieusement
  • Démarrage amélioré : le claude nu démarre plus tôt sur macOS
  • Amélioration de la vérification des autorisations de l'outil Bash pour la syntaxe spécifique à zsh dans les conditions du shell
  • Amélioration de la résilience des connexions de contrôle à distance : de brefs refus HTTP 403 provenant d'un réseau périphérique, d'un VPN ou d'un proxy sont désormais tolérés jusqu'à 3 minutes, la partie refusant étant nommée lorsqu'un blocage persiste
  • Réactivité de démarrage améliorée : la vérification automatique des mises à jour s'exécute désormais environ 10 secondes après le lancement au lieu de rivaliser avec le démarrage pour le processeur
  • Mise à jour de la compétence claude-api fournie pour la version du 19 août des agents gérés : paramètres de domaine de recherche/récupération sur le Web et magasins de mémoire sur des bacs à sable auto-hébergés
  • Modification de Ctrl+L et Cmd+K en plein écran pour toujours simplement repeindre — le raccourci /clear en double-pression a été supprimé et les terminaux nvim à 1 rangée ne déclenchent plus les boucles automatiques /clear
  • Modification de claude mcp list et claude mcp get pour afficher les serveurs désactivés sous la forme ⊘ Disabled au lieu de s'y connecter pour un contrôle de santé
  • MCP headersHelper dans un projet .mcp.json et les serveurs MCP en ligne dans les fichiers de projet ou d'agent --add-dir nécessitent désormais que la boîte de dialogue trust de ce dossier ait été acceptée (également sous claude -p).
  • MCP headersHelper à partir d'un projet .mcp.json, d'un plug-in ou d'un fichier d'agent s'exécute sans variables d'environnement d'informations d'identification héritées ; Les assistants utilisateur, gérés et claude.ai-scope s'exécutent désormais à partir du répertoire de configuration Claude
