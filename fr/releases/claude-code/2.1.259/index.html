claude-code v2.1.259

Correctif Publié2 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.259

Qu'est-ce qui a changé

  • Ajout du paramètre géré managedMcpServers : les organisations peuvent fournir des serveurs HTTP/SSE MCP à chaque utilisateur (même forme d'entrée que .mcp.json) ; les entrées qui nomment une commande à exécuter sont ignorées
  • Ajout de --permission-prompts none pour les hôtes sans tête sans surveillance : tout ce qui pourrait être demandé est automatiquement refusé pendant que le mode d'autorisation actif (y compris le mode automatique) continue de décider
  • Ajout de la reconnaissance de glab mr create/merge/close/reopen/note/update afin que les demandes de fusion GitLab s'affichent sous la forme MR !N dans le résumé de l'outil réduit et actualisent le badge MR du pied de page
  • Ajout de --json à claude plugin validate pour un rapport de validation lisible par machine
  • Correction des sessions simultanées annulant silencieusement les modifications ~/.claude.json des autres — l'espace de travail trust ne se réinitialise plus et l'état MCP/projet n'est plus perdu lors de l'exécution de plusieurs sessions à la fois
  • Correction d'une conversation dont la pensée était rejetée une fois et qui était à nouveau rejetée à chaque tour ultérieur
  • Correction des règles de refus Bash Read() ne couvrant pas les fichiers donnés comme valeurs d'option (--ignore-revs-file=.env, -f.env, @file), les opérandes de fichier git diff/git grep ou les composés cd DIR && cat FILE ; grep -r/cp -r sur un répertoire contenant un fichier refusé demande maintenant
  • Correction du cache d'invite invalidé lorsque le jeton OAuth était actualisé lors des sessions avec la télémétrie désactivée
  • Correction du mode plein écran affichant une conversation vide après un long tour avec des centaines d'appels d'outils
  • Correction du mode automatique exécutant un tour sur un modèle qu'il ne prend pas en charge lorsqu'une commande ou une compétence model: en nomme un ; le tour conserve désormais le modèle de session
  • Correction de CLAUDE_CODE_MAX_CONTEXT_TOKENS étant ignoré pour les ID de modèle de style Vertex (suffixe @YYYYMMDD) des versions de modèle que Claude Code ne reconnaît pas
  • Correction de l'aperçu de la sortie en direct d'une commande shell en cours d'exécution masquant ses lignes les plus récentes lorsqu'une ligne précédente est renvoyée à la ligne.
  • Correction d'une vérification de connexion GitHub en arrière-plan qui s'exécutait à chaque lancement pour les utilisateurs de claude.ai ; le résultat est désormais mémorisé lors des lancements
  • Correction de l'échec de --resume (et de --continue ouvrant une conversation vide) lorsqu'une session enregistrée contient une entrée de pièce jointe sans charge utile
  • Correction du frontmatter model: sur les commandes et compétences personnalisées ignorées dans les sessions interactives.
  • Correction d'un échec de publication d'artefacts avec une erreur "paramètre inattendu note" dans les conversations continuées à partir d'une ancienne version
  • Correction du forceRemoteSettingsRefresh géré étant ignoré au démarrage lorsqu'un assistant de stratégie configuré par MDM ou le fichier de paramètres gérés était déjà exécuté
  • Correction de l'isolation de l'arbre de travail refusant les arbres de travail créés par hook sur les machines sur lesquelles git rev-parse échoue avec un message autre que "pas un référentiel git".
  • Correction des métriques et événements OpenTelemetry des sessions cloud manquant les attributs user.email, organization.id et user.account_uuid
  • Correction des serveurs MCP qui se déconnectent alors que leurs outils sont répertoriés au démarrage, s'affichant comme connectés sans outils au lieu de signaler l'erreur
  • Correction de la boîte de dialogue d'autorisation de modification de fichier affichant parfois une ligne modifiée coupée sans aucune indication
  • Correction de la détection du référentiel supprimant une identité de dépôt connue après un échec transitoire de la sonde git
  • Correction des paramètres gérés qui n'étaient pas appliqués silencieusement lorsque le fichier de paramètres gérés, un drop-in, la liste MDM ou la valeur HKLM ne pouvaient pas être analysés : Claude Code refuse désormais de démarrer et nomme la source.
  • Correction de l'arrêt n'arrêtant pas réellement les agents et les flux de travail en arrière-plan dans les sessions de contrôle à distance : les tâches interrompues restent désormais visibles et peuvent être réarrêtées jusqu'à la fin de leurs processus.
  • Correction de la reprise d'une exécution de workflow alors que son exécution précédente arrêtée était toujours en cours, ce qui pouvait exécuter des copies en double de ses agents
  • Correction des URL de dépôt du marché sur github.com avec une barre oblique finale ou ?/# pendant produisant une URL de clone .git inutilisable
  • Correction des crochets d'arrêt de blocage faisant perdre au tour suivant un blocage le raisonnement du modèle à partir de ce tour et, sur certains modèles, manquer le cache d'invite
  • Correction des sessions à distance (claude.ai) prenant 60 secondes pour démarrer un tour après la disparition de la page d'un serveur MCP hébergé par un navigateur
  • Correction des sessions isolées par arbre de travail refusant les boucles Bash courantes, les pipelines xargs et les commandes enveloppées dans le lanceur qui ne peuvent pas atteindre la caisse principale
  • Amélioration du redimensionnement du terminal et des performances de premier rendu pour les réponses longues grâce à la réutilisation des mesures de texte
  • Détails améliorés de l'agent /workflows : les résultats JSON sont joliment imprimés avec des couleurs de syntaxe et de vrais sauts de ligne, et les résultats longs se replient derrière une bascule d'expansion.
  • Démarrage de session headless/SDK amélioré : le premier tour commence jusqu'à 50 ms plus tôt lorsque les serveurs MCP ont fini de se connecter
  • /install-github-app amélioré pour expliquer qu'il est uniquement GitHub et pointer vers la documentation CI/CD GitLab lorsqu'il est exécuté dans un référentiel GitLab
  • Amélioration des résultats des sous-agents en arrière-plan imbriqués à enregistrer dans la transcription du sous-agent parent, afin que les sous-agents repris les conservent et que les transcriptions partagées affichent la livraison.
  • Modification de allowedMcpServers pour gouverner uniquement les serveurs que les utilisateurs ajoutent : un serveur managed-mcp.json littéral que votre liste autorisée utilisait pour filtrer se charge désormais lors de la mise à niveau ; utilisez deniedMcpServers pour le garder éteint
  • [VSCode] Ajout d'un filtre rapide actif et d'un menu de filtre d'état (Entrée nécessaire, En cours, Terminé) à la barre latérale de la liste des sessions.
  • Correction des sessions à distance et planifiées ne faisant rien après l'approbation d'une invite d'autorisation de l'outil de connecteur alors que la session était en pause
