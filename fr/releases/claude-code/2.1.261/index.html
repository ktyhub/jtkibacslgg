claude-code v2.1.261

Correctif Publié4 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.261

Qu'est-ce qui a changé

  • Ajout d'une ligne « Politique de l'organisation » à /status et claude doctor qui indique pourquoi la politique de votre organisation n'a pas pu être chargée, par exemple un proxy ne transmettant pas le point de terminaison.
  • Ajout des paramètres bashOutputMaxChars et taskOutputMaxChars pour augmenter la quantité de commandes et de tâches en arrière-plan que Claude reçoit en ligne avant d'être enregistré dans un fichier, jusqu'à 128 000 caractères.
  • Ajout de --append-subagent-system-prompt-file pour lire l'invite système du sous-agent à partir d'un fichier, pour les invites trop volumineuses pour être transmises sur la ligne de commande
  • Ajout de /skill-doctor pour montrer quelles compétences chargées ne sont pas utilisées et ce qu'elles coûtent dans leur contexte, afin que vous puissiez les élaguer
  • Correction des caractères tapés ou collés atterrissant occasionnellement dans le désordre ou étant supprimés lors d'une saisie rapide ou d'une répétition de touche
  • Correction de /add-dir <subdirectory> affichant une fausse erreur "Impossible de résoudre" lorsque le répertoire de travail est sur un montage automatique /net
  • Correction de l'assistant de configuration de Bedrock qui se bloquait lorsqu'AWS ou un assistant d'identification AWS ne répondait jamais (il expire désormais avec une erreur claire) et ses vérifications de modèle échouaient derrière un proxy d'inspection TLS.
  • Correction des sessions cloud rejetant un plugin synchronisé depuis claude.ai lorsque les paramètres gérés l'activent de force dans enabledPlugins, puis reviennent à un clone de marché qui pourrait échouer
  • Correction de l'impossibilité de supprimer le caractère immédiatement avant une puce [Image #N] en ligne dans la saisie rapide
  • Correction de la reprise d'une session perdant la sortie du hook et d'autres contextes autour des appels d'outils parallèles, ce qui modifiait la demande de reprise
  • Correction de la télécommande affichant un mode d'autorisation obsolète lorsqu'un téléphone, un navigateur ou une application claude.ai se connecte à une session de terminal ou après un changement de mode dans le terminal
  • Correction des sessions de contrôle à distance qui fonctionnent toujours (spinner bloqué et bouton Stop) après l'arrêt d'un tour depuis un téléphone ou un navigateur connecté, ou après une commande slash locale comme /clear
  • Correction de SDK et des sessions cloud ignorant un Stop ou une interruption envoyée juste après la première invite, avant le début du tour ; le tour s'arrête désormais au lieu de se terminer
  • Correction du téléchargement par télécommande d'une session extraite avec /teleport dans la session connectée, qui apparaissait annexée à l'original sur le téléphone et sur le Web.
  • Correction du flux d'événements entrants de Remote Control échouant derrière les proxys d'entreprise inspectant TLS sur Windows natif
  • Correction des sessions de contrôle à distance affichant le niveau d'effort par défaut sur claude.ai lorsque l'effort provient des paramètres
  • Correction de gcpAuthRefresh ouvrant un navigateur au démarrage lorsque la vérification des informations d'identification Google était lente, même si les informations d'identification étaient toujours valides
  • Correction des connecteurs claude.ai restant absents pendant toute la session lorsque la récupération du connecteur de démarrage a expiré - le CLI réessaye désormais en arrière-plan
  • Correction d'une utilisation élevée et soutenue du processeur lorsqu'un agent en arrière-plan ne pouvait pas être repris et que son réveil était réessayé en boucle serrée
  • Correction des indicateurs de fonctionnalité liés à une version plus récente s'appliquant occasionnellement à une ancienne version de Claude Code exécutée sur la même machine
  • Correction de /usage et du panneau d'utilisation de VS Code supprimant une ligne de limite hebdomadaire spécifique au modèle lorsque le point de terminaison d'utilisation est limité en débit ou lorsqu'il est ouvert juste après le démarrage.
  • Correction de claude -p --resume <file> adoptant un identifiant de session mal formé enregistré dans la transcription ; il reprend maintenant sous un nouvel identifiant de session
  • Correction de l'indicateur de progression du terminal (iTerm2, Ghostty, ConEmu) affichant la session comme terminée alors qu'un workflow ou un agent en arrière-plan était toujours en cours d'exécution
  • Correction d'un problème de mise en page rare où une boîte pouvait s'afficher avec une hauteur incorrecte après que son conteneur ait basculé entre la direction des lignes et celle des colonnes.
  • Correction de l'adresse IP client de la passerelle des applications Claude lorsqu'un proxy trusted ajoute un port à X-Forwarded-For ; avec une liste d'accès définie, une entrée illisible obtient désormais 403
  • Correction de la passerelle des applications Claude indiquant à Claude Desktop d'exporter OpenTelemetry en tant que JSON même lorsque le terminal CLI utilise protobuf, donc les collecteurs uniquement protobuf rejetaient les données de Desktop
  • Correction du bureau et du Web affichant une session comme étant occupée alors qu'il ne surveille qu'un artefact pour les mises à jour
  • Correction de l'échec de Claude dans Chrome file_upload avec "chemins : tableau attendu, reçu non défini" dans les sessions Cowork locales exécutées à partir de l'application Claude Desktop
  • Correction du SendMessage sur une session de contrôle à distance hors ligne sur une autre machine en train de lire tel que livré ; le résultat indique maintenant que la livraison est mise en file d'attente jusqu'à ce que cette machine se reconnecte
  • Correction des astuces d'installation du plugin des CLI exécutés en arrière-plan des commandes Bash : elles sont désormais détectées et la balise brute <claude-code-hint> ne fuit plus dans la conversation.
  • Correction des coéquipiers de l'équipe d'agents en cours renvoyant leurs annonces d'outils et de compétences du premier tour au deuxième tour, ce qui modifiait le préfixe de la demande et manquait le cache d'invite.
  • Amélioration du sélecteur /model et de la pilule de modèle VS Code pour afficher le nom d'un modèle au lieu de son ID brut de passerelle Bedrock, Vertex AI ou LLM lorsque Claude Code le reconnaît
  • Démarrage amélioré sur Google Vertex AI lorsque GOOGLE_APPLICATION_CREDENTIALS est défini : la création de API client ne réexécute plus la découverte de projet Google Cloud ou ne génère plus de processus gcloud supplémentaires
  • Performances de streaming améliorées : les blocs déjà rendus ne sont plus revérifiés par mise en page à chaque mise à jour
  • Amélioration de l'invite de sécurité dangereuse-rm pour détecter également rm -rf sur les paramètres de position et dans les scripts sh -c entre guillemets
  • Amélioration de la gestion lorsque le API n'envoie aucun en-tête de réponse : la nouvelle tentative attend désormais jusqu'à API_TIMEOUT_MS (10 minutes par défaut) au lieu de 3 minutes supplémentaires, et les messages indiquent ce qu'il faut changer
  • Modification d'une passerelle d'applications Claude 403 lors du chargement des paramètres gérés (au démarrage ou après /login) pour indiquer que Claude Code ne peut pas être activé pour l'organisation, au lieu de conseiller une nouvelle connexion
  • Modification des machines dont les paramètres gérés épinglent forceLoginMethod: "gateway" pour ignorer une clé API restante ou une connexion claude.ai et demander /login ; Les sessions Bedrock, Vertex AI et Foundry ne sont pas affectées
  • Modification du mode automatique pour traiter un lien qui regroupe le contenu dans l'URL d'un moteur de rendu de diagramme public comme un téléchargement sur ce site : n'est plus approuvé automatiquement, sauf si vous le demandez.
  • Modification des touches d'édition de mots de l'invite pour qu'elles correspondent à Bash : Ctrl+W supprime les espaces, Alt+F et Alt+D s'arrêtent à la fin du mot, la ponctuation sépare les mots ; keybindingFlavor n'a plus aucun effet
  • Modification du comptage de jetons /context pour utiliser une estimation locale lorsque le comptage de jetons API n'est pas disponible, au lieu de requêtes supplémentaires de petit modèle
  • [VSCode] Ajout d'une procédure pas à pas "Créer un style personnalisé" au menu Styles de sortie qui écrit un fichier de style de sortie personnalisé et le répertorie immédiatement
  • [VSCode] Ajout d'un formulaire Ajouter un serveur et d'une action Supprimer dans la boîte de dialogue des serveurs MCP, afin que les serveurs MCP puissent être ajoutés et supprimés sans quitter l'IDE.
  • [VSCode] Ajout d'un anneau creux dans la liste des sessions pour les sessions ouvertes dans un terminal, une autre fenêtre VS Code ou Claude Desktop, afin qu'elles n'aient plus l'air fermées
  • [VSCode] Ajout d'un bouton de pliage aux invites d'autorisation et de questions afin que la conversation derrière elles puisse être lue sans les ignorer ; l'espace à côté de l'invite fait désormais défiler la conversation
  • [VSCode] Ajout de "Session d'archivage" au menu click de droite de la liste des sessions et a donné à Unarchive sa propre icône
  • [VSCode] Correction d'une session téléportée depuis Claude Code sur le web traitant une question qui était coupée lors de la fermeture de la session cloud comme declined
  • [VSCode] Correction de la boîte Renommer de l'onglet session s'ouvrant vide pour un onglet restauré avec la fenêtre ; il commence maintenant par le nom actuel
  • [VSCode] Correction des sections réduites dans le panneau de liste de sessions s'affichant brièvement à chaque chargement du panneau.
  • [VSCode] Correction de la vue Focus affichant un appel d'outil comme étant toujours en cours après le départ de Claude, par exemple pendant qu'une question attendait votre réponse
  • [VSCode] Correction de la surbrillance de la ligne active de la liste de sessions qui devenait obsolète lorsque l'ID de session d'un onglet Claude non ciblé est corrigé
  • [VSCode] Correction de la réouverture Cmd/Ctrl+Shift+T et de l'ouverture du lien profond plaçant l'onglet Claude en dehors du groupe de l'éditeur Claude lorsqu'un onglet Claude a le focus
  • [VSCode] Correction de l'onglet "Ajouter au groupe" de l'onglet session mettant une session ouverte depuis Claude Code sur le Web en deux groupes ; il déplace maintenant l'entrée affichée par la liste des sessions
  • [VSCode] Correction du sélecteur de modèles affichant les modèles qu'une organisation a depuis désactivés jusqu'à ce que la fenêtre soit rechargée deux fois.
  • [VSCode] Correction d'un onglet ouvert à partir de la liste des sessions revenant à cette session, et d'un onglet ouvert à partir d'une session Web redémarrant sa téléportation ou restant vide, après que VS Code recharge la vue de l'onglet
  • [VSCode] Correction de l'historique des questions secondaires du /btw des sessions précédentes étant écrasé lorsqu'une question est posée juste après le rechargement d'une fenêtre ou lorsqu'un fichier de paramètres contient des erreurs.
  • [VSCode] Correction de la carte de questions en attente ne réapparaissant pas après le rechargement du panneau Claude lorsque vous êtes connecté avec un compte Claude.ai ou Console
  • [VSCode] Correction des fonctionnalités réservées à claude.ai restant visibles dans les autres panneaux Claude d'une fenêtre après qu'un panneau ait récupéré un fournisseur tiers à partir d'un fichier de paramètres.
  • [VSCode] Correction de l'écran de connexion apparaissant malgré le paramètre Désactiver l'invite de connexion lorsque Claude Code ne signale aucune connexion ou qu'une demande échoue faute de connexion.
  • [VSCode] Correction de l'invite d'autorisation suivante en file d'attente en conservant le texte tapé sur l'invite précédente et en acceptant une seconde click immédiate
  • [VSCode] Correction des liens d'installation-plugin ouvrant la barre latérale Claude sans la boîte de dialogue d'installation dans une fenêtre où seule la liste des sessions avait été affichée
  • [VSCode] Correction du compteur d'utilisation de la barre latérale restant vide dans une nouvelle fenêtre jusqu'à l'ouverture de la boîte de dialogue Compte et utilisation, et d'une limite d'utilisation de 0 % laissée en dehors du compteur.
  • [VSCode] Correction de "Démarrer une nouvelle session dans ce groupe" perdant le groupe après une nouvelle conversation et un point non lu manquant pour une session qui s'est terminée avant le chargement de la liste non lue de la barre latérale
  • [VSCode] Correction du badge de l'onglet éditeur affichant non lu pendant un tour en cours ou manquant sur un onglet ouvert à partir de la liste de sessions, et "Ajouter un onglet de session au groupe" ne faisant rien pour une session archivée
  • [VSCode] Correction de "Activer le contrôle à distance pour toutes les sessions", donc l'inverser s'applique également immédiatement aux sessions ouvertes dans d'autres fenêtres VS Code
  • [VSCode] Correction du filtre Ouvrir de la liste des sessions pour les sessions suite à claude.ai dont l'onglet était toujours enregistré sous la session Web, et étiqueté les sections du menu de filtrage pour les lecteurs d'écran
  • [VSCode] Modification du sélecteur de modèles en une liste plate de chaque modèle, avec des lignes conservées pour les orthographes de modèles plus anciennes répertoriées en dernier
