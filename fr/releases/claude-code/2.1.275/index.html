claude-code v2.1.275

code-claude v2.1.275

Qu'est-ce qui a changé

  • Ajout du compte connecté à la connexion à la passerelle des applications Claude : lorsque la passerelle le nomme, vous le confirmez avant que les informations d'identification ne soient enregistrées, et /status l'affiche
  • Ajout d'une touche d'envoi immédiat (ctrl+enter, ou ctrl+x ctrl+s) qui interrompt le tour en cours et envoie tous les messages en file d'attente en même temps ; les messages envoyés et en file d'attente s'affichent en gris jusqu'à ce que le modèle les reçoive
  • Ajout d'un avertissement de démarrage lorsqu'un otelHeadersHelper configuré échoue, afin que les sessions qui n'exportent silencieusement aucune télémétrie ne soient remarquées
  • Ajout de la synchronisation des compétences et plugins activés sur votre compte claude.ai avec les sessions de terminal connectées avec celui-ci ; se désinscrire avec syncClaudeAiSkills: false ou syncClaudeAiPlugins: false
  • Ajout de /plugin install <plugin> --marketplace <source>, qui propose d'ajouter la marketplace avant d'installer le plugin
  • Correction de la note d'âge d'un fichier de mémoire restauré changeant entre les requêtes après un compactage ou une reprise, ce qui provoquait des échecs de cache d'invite
  • Correction des sorties --forward-subagent-text stream-json et SDK supprimant les messages des sous-agents générés par une compétence context: fork et des compétences fourchues invoquées par un sous-agent ou une autre compétence fourchue.
  • Correction des suggestions de fichiers @-mention étant enfouies sous les ressources MCP lors de l'utilisation d'une commande fileSuggestion personnalisée ou de la saisie de @./@./
  • Correction du mode plein écran plaçant les avis d'achèvement des tâches en arrière-plan sous la ligne d'outils réduite d'un long tour au lieu de l'endroit où ils sont arrivés ; chaque avis ferme désormais la ligne ouverte
  • Correction de claude plugin marketplace update supprimant la copie locale d'un marché GitHub lorsque la récupération échouait et que le marché était nommé d'après son référentiel
  • Correction des messages, journaux et claude plugin marketplace list du plugin et du marché affichant un mot de passe ou un jeton stocké dans une URL git, ssh ou marché.
  • Correction d'une session cloud reprise laissant une question sans réponse ouverte dans la transcription après qu'un message en file d'attente l'ait remplacée
  • Correction du mode vim plaçant le curseur un caractère juste après un "!" ou un « i ! » tapé rapidement. basculé une invite non vide en mode shell
  • Correction du gel ou de la suppression du mode plein écran pendant plusieurs secondes lors du défilement vers le haut au-delà d'un fichier volumineux.
  • Correction d'une balise de fermeture parasite de style </ccmemory> apparaissant occasionnellement dans les réponses
  • Correction des messages du plugin, des journaux et de la boîte de dialogue du plugin VS Code affichant le mauvais serveur pour certaines adresses git
  • Correction d'un terminal API Error: 400 à chaque tour pour les utilisateurs derrière une passerelle réseau qui réécrit les réponses d'erreur API lorsqu'un en-tête de demande bêta est rejeté
  • Correction des commandes Bash en bac à sable sur Linux signalant le code de sortie 0 pour les commandes ayant échoué lorsque le shell est zsh
  • Correction du blocage de l'outil de lecture au lieu de signaler une erreur lorsqu'une partie d'un fichier volumineux ne pouvait pas être décodée sous la pression de la mémoire
  • Correction de --resume, de l'aperçu du sélecteur de CV, de la reprise des agents en arrière-plan et de l'affichage de la transcription échouant sur une session dont l'historique enregistré contient un rappel de tâche mal formé ou une entrée de pièce jointe @-file
  • Correction d'un crash lors de la reprise d'une conversation dont la transcription contient une entrée de message mal formée, et d'un crash en plein écran lorsqu'une telle conversation recevait de nouveaux messages alors qu'elle défilait vers le haut
  • Correction des sessions qui ne parvenaient pas à reprendre ou à démarrer lorsque leur transcription enregistrée contenait un bloc de contenu de message mal formé
  • Correction des suggestions Grep, Glob et @-file bloquées ou manquant de mémoire lors des recherches dépassant la limite de sortie de 20 Mo, et ripgrep système signalant "aucune correspondance" au lieu d'une erreur après un flot d'avertissements
  • Correction de /rewind dans une session forkée ou en arrière-plan, restaurant un fichier rempli de zéros ou tronqué lorsque les sauvegardes de l'historique des fichiers de la session ne pouvaient pas être entièrement copiées
  • Correction des sessions plein écran qui se fermaient parfois avec "Claude Code quitté après une erreur d'interface irrécupérable" lors d'une saisie rapide ou en maintenant une touche enfoncée avec la liste déroulante de commande slash ouverte
  • Correction des sessions en arrière-plan qui plantaient et redémarraient leur travailleur lorsqu'une commande transmise via stdin s'exécutait sur une machine qui n'avait plus de descripteurs de fichiers.
  • Correction d'un crash au lancement lorsque ~/.claude.json contient une valeur mcpNeedsAuthNoticed mal formée
  • Correction de --resume et --continue supprimant la réflexion antérieure d'une conversation lorsqu'un outil intégré avec lequel il avait démarré a depuis été désactivé par un indicateur côté serveur.
  • Correction du texte sélectionné avec la souris dans le sélecteur de session plein écran claude --resume n'atteignant jamais le clipboard
  • Correction des aperçus de rechargement du plugin remplaçant les fichiers de plugin extraits d'une session en cours lorsque le plugin était chargé à partir d'une archive --plugin-dir ou --plugin-url
  • Correction des coureurs auto-hébergés avec --drain-wait-sec perdant le résultat final d'un tour terminé lors d'un drain SIGTERM ; le coureur attend maintenant brièvement que le virage soit annoncé
  • Correction des hooks SubagentStop avec un déclenchement spécifique matcher pour chaque sous-agent d'arrêt dont le type d'agent était vide
  • Correction des commandes Bash en bac à sable ne pouvant pas écrire dans les répertoires de projet nommés hooks/ ou config/
  • Correction des mises à jour d'artefacts échouant avec "Fichier introuvable" après la reprise d'une session sur une autre machine ou après que son bloc-notes ait été effacé : la dernière version publiée de la page est restaurée
  • Correction de /update-config écrivant des règles d'autorisation Write(path), auxquelles les vérifications d'autorisation de fichier ne correspondent pas, au lieu des règles Edit(path)
  • Correction de quatre URL de documentation mortes (Prix, Utilisation de l'ordinateur, Compétences, CLI) dans le tableau des sources en direct de la compétence groupée claude-api
  • Amélioration de la mise en cache des invites pour un --system-prompt qui contient une ligne __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__ : le texte au-dessus est désormais mis en cache globalement, comme l'est déjà la forme de tableau du SDK.
  • Amélioration de l'erreur /desktop lorsque Claude Desktop ne s'ouvre pas : il indique désormais pourquoi et quoi faire ensuite
  • Amélioration des résultats de publication et de lecture de l'outil Artefact : ils indiquent désormais qui peut ouvrir la page et ce que propose le menu Partager du propriétaire.
  • Résultats de publication d'artefacts améliorés : ils nomment l'icône d'onglet envoyée, avertissent lorsque la page contient un octet NUL et réessayent une récupération irrégulière de la page la plus récente pour fusionner après une publication obsolète.
  • Amélioration des images collées et jointes : elles sont désormais enregistrées là où Claude peut les ouvrir sous forme de fichiers sans invite d'autorisation, y compris dans Desktop et VS Code
  • Amélioration des conseils de l'outil Artefact afin que Claude mette à jour un artefact partagé lorsque vous en avez accès en modification, au lieu de publier une copie séparée.
  • Lectures d'utilisation du plan améliorées : les fenêtres de l'éditeur et les sessions non interactives sur une machine partagent désormais une lecture effectuée dans la dernière minute au lieu d'appeler chacune le point de terminaison d'utilisation.
  • Amélioration de la description de l'outil ListPlugins afin que Claude sache qu'il répertorie les plugins activés sur votre compte claude.ai, et non les plugins installés localement avec /plugin
  • Réactivité améliorée lorsque le terminal est lent ou en pause : la sortie ne prend plus de retard pendant que le terminal rattrape son retard
  • Amélioration des résultats d'écriture et d'édition pour les fichiers dans le dossier compte-compétences synchronisé : ils indiquent maintenant que la modification n'est pas enregistrée sur votre compte et comment l'enregistrer
  • Mise à jour de /logout pour les connexions à la passerelle des applications Claude afin de mettre également fin à la session sur les passerelles qui annoncent la révocation du jeton.
  • Modification des sessions hébergées pour conserver une invite d'autorisation sans réponse après le redémarrage d'un conteneur, au lieu de demander à nouveau
  • Modification de l'outil Artefact pour demander une icône d'onglet d'un mot lors d'une première publication au lieu d'un favicon emoji
  • Modification de Claude dans Chrome en mode automatique pour ignorer la vérification par site de l'extension pour les appels approuvés par le classificateur, comme le fait le mode de contournement, corrigeant browser_batch "Autorisation refusée" après une redirection
  • Modification des plugins installés à partir d'une source npm pour qu'ils soient récupérés avec npm pack --ignore-scripts et vérifiés en intégrité, afin que les scripts d'installation d'un package ne s'exécutent plus
  • Modification des exécutions de routine planifiées et Exécuter maintenant pour enregistrer les données et republier la page d'un artefact que vous pouvez modifier sans demander ; artefacts publics, les premières publications et suppressions demandent toujours
  • Suppression de l'avis de démarrage qui vous informait qu'une routine planifiée ponctuelle s'était exécutée depuis votre dernière session
  • [VSCode] Ajout de l'affichage, de la modification et de la suppression d'une mémoire enregistrée dans la boîte de dialogue Mémoire
  • [VSCode] Ajout de l'envoi d'une image jointe sans saisir de texte
  • [VSCode] Ajout d'un lien Réessayer dans la boîte de dialogue des serveurs MCP lorsque la liste des serveurs ne parvient pas à se charger
  • [VSCode] Ajout de boutons d'acceptation et de rejet sous chaque modification dans l'onglet de comparaison des modifications proposées, afin qu'une modification puisse être examinée modification par modification.
  • [VSCode] Correction de la transcription glissant vers le bas par petites étapes pendant qu'une carte d'autorisation attend et que le contenu continue d'arriver
  • [VSCode] Correction des conversations rembobinées et fourchues ne conservant pas le mode d'autorisation que vous aviez choisi pour la conversation d'origine
  • [VSCode] Correction d'une entrée CLAUDE_CONFIG_DIR vide dans le paramètre environmentVariables obligeant Claude Code à conserver ses fichiers dans l'espace de travail
  • [VSCode] Correction des liens d'installation du plugin ouvrant la boîte de dialogue Gérer les plugins pour les noms de plugins et les adresses de marché qui ne peuvent pas être utilisés dans un lien
  • [VSCode] Correction de la télécommande restant affichée comme connectée après une mise hors tension signalée par Claude Code comme un échec ; ça s'affiche maintenant comme étant éteint
  • [VSCode] Correction du défilement vers le bas lors de l'envoi, s'arrêtant avant la réponse lorsque la réponse commence à arriver pendant le défilement
  • [VSCode] Correction de la carte des agents affichant aux agents un crash laissé inachevé comme étant arrêté au lieu d'avoir échoué une fois la session rouverte.
  • [VSCode] Correction de l'avis "Poursuite de l'étape" qui n'apparaissait pas et de la réinitialisation de la limite de continuation, après un rechargement suite à un crash avec des tâches en arrière-plan toujours en cours d'exécution.
  • [VSCode] Correction de la liste des sessions indiquant quand une session a été rouverte pour la dernière fois, comme après un rechargement de fenêtre, au lieu de quand son dernier message a été envoyé
  • [VSCode] Correction de l'échec de "Fork conversation from here" sur le message juste après celui envoyé pendant que Claude travaillait
  • [VSCode] Correction de l'horloge du cache d'invite affichant trop peu de minutes après la réouverture d'une session avec un message envoyé pendant que Claude travaillait
  • [VSCode] Correction d'un agent en arrière-plan qui se terminait alors que Claude exécutait un outil perdant son avis d'achèvement, et son résultat sur la carte de l'agent, après un rechargement de la fenêtre
  • [VSCode] Correction d'un cas rare où le texte sélectionné dans un fichier ignoré par Git pouvait être envoyé à Claude après que l'extension ne répondait pas pendant plusieurs secondes
  • [VSCode] Correction du renommage d'une session en cours en revenant au nom généré (régression dans 2.1.269)
  • [VSCode] Correction de certaines sessions claude.ai/code s'ouvrant dans VS Code comme une conversation vide sans message
  • [VSCode] Correction des commandes slash saisies pendant que Claude répond, envoyées au modèle sous forme de texte au lieu d'être exécutées une fois la réponse terminée.
  • [VSCode] Correction du code illisible dans l'aperçu du plan et dans les boîtes de dialogue des règles Hooks et Permission avec le thème High Contrast Light
  • [VSCode] Correction de /remote-control étant ignoré pendant que la télécommande est toujours en cours de connexion : l'exécuter à nouveau désactive désormais immédiatement la télécommande.
  • [VSCode] Correction de la conversation vous ramenant vers le bas pendant qu'une réponse était diffusée après un défilement vers le haut, et ajout d'un paramètre claudeCode.scrollToBottomOnSend pour désactiver le saut lors de l'envoi.
  • [VSCode] Correction de la boîte de dialogue Gérer les plugins affichant un mot de passe ou un jeton saisi dans une URL de marché.
  • [VSCode] Amélioration de la carte des agents : la pilule compte les agents en cours d'exécution et devient rouge après un échec, l'agent principal reste visible pendant que la carte défile, et les agents trient par état puis heure de fin.
  • [VSCode] Modification de la nouvelle session dans l'onglet de l'éditeur Claude pour qu'elle s'ouvre dans la barre latérale lorsque l'emplacement préféré est défini sur la barre latérale, au lieu de toujours ouvrir un autre onglet
  • [VSCode] Modification d'un message envoyé pendant que Claude travaillait pour attendre en bas de la conversation que Claude commence dessus
  • [Claude Code sur le web] Ajout d'un bouton "Nouvelle routine" à la page affichée lorsqu'un lien de routine ne se résout plus, à côté du lien retour vers votre liste de routines
  • [Claude Code sur le web] Correction des notifications de routine "en pause" et "en attente" coupées au milieu d'une phrase ; l'avis d'abonnement suspendu dit maintenant de reprendre la routine sur vous-même
  • [Claude Code sur le Web] Correction des environnements cloud avec une très longue liste de domaines autorisés qui enregistrent correctement puis échouent à chaque démarrage de session ; l'enregistrement échoue maintenant au départ et indique combien il faut couper
  • [Code Claude sur le Web] Correction du guidage de Claude lorsqu'une session cloud sur un compte personnel se voit refuser l'accès à GitHub : il renvoie désormais à claude.ai/connect-github au lieu d'une page de paramètres d'administration
  • [Claude Code sur le Web] Amélioration de ce que Claude vous dit lorsqu'on lui demande de modifier, supprimer ou exécuter une routine qu'il n'a pas créée : il renvoie désormais à la page de la routine afin que vous puissiez le faire vous-même
  • [Claude Tag] Ajout de conditions d'attachement pour les offres groupées d'accès dans les paramètres de Claude Tag : un propriétaire peut autoriser un ensemble à s'appliquer également aux chaînes avec des invités ou aux chaînes Slack Connect, et pas seulement aux membres uniquement.
  • [Claude Tag] Ajout des préréglages Amazon CloudWatch, CloudWatch Logs, Amazon SNS, Google Cloud Monitoring et Cloud Logging à l'onglet Informations d'identification d'un bundle d'accès dans les paramètres d'administration de Claude Tag
  • [Claude Tag] Ajout des préréglages Datadog pour les sites US3, AP1, AP2 et US1-FED ; les nouvelles connexions Datadog sont désormais limitées aux routes de lecture et de requête API de Datadog
  • [Claude Tag] Correction des téléchargements S3 à partir des versions récentes d'AWS CLI et SDK échouant avec une erreur 502 lorsqu'ils sont envoyés via une connexion AWS
  • [Claude Tag] Correction de Claude traitant un canal comme inactif et sautant les messages non tagués là-bas, alors qu'il était encore en train de publier dans ce canal à partir d'une routine ou d'un fil de discussion.
  • [Claude Tag] Correction du nom d'affichage d'un fil de discussion "Claude [tâche]" devenant simplement "Claude" après l'actualisation ou le redémarrage de la session derrière ce fil de discussion.
  • [Claude Tag] Correction du modèle vers lequel vous êtes passé dans un fil de discussion Slack, revenant silencieusement à la valeur par défaut du canal après le redémarrage ou l'actualisation de la session de ce fil de discussion.
  • [Claude Tag] Correction de Claude répondant parfois deux fois lorsqu'une autre application ou un autre bot @le mentionnait dans un message de chaîne de niveau supérieur
  • [Claude Tag] Amélioration des notifications de Claude dans les canaux Enterprise Grid partagés entre les espaces de travail : elles indiquent désormais quand aucun espace de travail n'est encore configuré ou pourquoi seules les valeurs par défaut de l'organisation s'appliquent.
  • [Code Review] Correction des révisions qui perdaient parfois une partie de leur analyse lorsqu'un des agents réviseurs renvoyait ses conclusions dans un format inattendu.
  • [Révision du code] Correction des demandes d'extraction avec plus de 100 révisions Claude obtenant une réévaluation complète à chaque fusion propre de la branche de base au lieu de la révision plus légère axée sur la fusion
