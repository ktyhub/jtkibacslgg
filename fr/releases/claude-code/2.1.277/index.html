claude-code v2.1.277

Correctif Publié18 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.277

Qu'est-ce qui a changé

  • Ajout du support AGENTS.md : dans un projet sans CLAUDE.md, Claude Code lit à la place AGENTS.md ; changez-le sous "Instructions du projet" dans /config (pas encore sur Bedrock, Vertex ou Foundry)
  • Ajout de CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 pour les passerelles d'applications Claude dont la seule sortie est un proxy direct : chaque requête sortante transmet au proxy le nom d'hôte au lieu de le résoudre localement.
  • Ajout d'une carte headers: facultative sur la passerelle des applications Claude en amont, pour envoyer des en-têtes statiques à un proxy que vous exécutez devant un fournisseur
  • Ajout d'une ligne indiquant que la mise à jour d'une tâche en arrière-plan est en attente lorsqu'elle se termine alors qu'un panneau tel que /tasks est ouvert
  • Correction des sessions claude -p et Agent SDK qui pouvaient se bloquer sans résultat après une erreur interne ; ils signalent maintenant l'erreur et sortent avec le code 1
  • Correction des conversations échouant à chaque requête avec "les blocs de contenu texte ne doivent pas être vides" lorsqu'un assistant précédent tenait un bloc de texte vide à côté d'un autre contenu, y compris après --resume
  • Correction d'une déconnexion inattendue lorsqu'une ancienne version de Claude Code (par exemple, CLI fourni avec une extension IDE) s'exécute sur la même machine que l'actuelle.
  • Correction du blocage du démarrage interactif ou de l'affichage d'une erreur pour les utilisateurs de ANTHROPIC_API_KEY lorsque ~/.claude.json contient une valeur customApiKeyResponses mal formée.
  • Correction des erreurs de vérification des mises à jour toutes les 30 minutes et du blocage de claude update lorsqu'une version minimale ou maximale est définie, si un proxy renvoie une version invalide ; un minimumVersion malformé est désormais ignoré
  • Correction de claude update sur les installations gérées par Winget ou apk signalant "à jour" lorsque la recherche de version échouait
  • Correction de claude plugin install qui échouait parfois et cassait la copie installée lors de la réinstallation d'une version de plugin qu'une session ou un autre programme utilisait ; une copie inchangée est maintenant laissée seule
  • Correction de Grep et Glob ne signalant aucune correspondance lorsque la recherche ne pouvait pas démarrer parce que le système manquait de processus, de mémoire ou de descripteurs de fichiers ; ils renvoient maintenant une erreur le disant
  • Correction de l'outil d'écriture mettant fin silencieusement au tour en tant qu'autorisation declined lorsque le chemin cible est un répertoire existant ; il signale maintenant une erreur claire
  • Correction de l'outil d'édition traitant une barre oblique inverse échappée suivie du texte uXXXX comme un échappement \uXXXX, ce qui pouvait faire qu'une modification d'un caractère non-ASCII réécrive une séquence de barre oblique inverse échappée à la place.
  • Correction de l'outil d'édition signalant « Expression régulière invalide : expression régulière trop grande » au lieu de « Chaîne introuvable dans le fichier » lorsqu'une modification très volumineuse contenant du texte non-ASCII ne correspondait pas au fichier.
  • Correction d'un tour se terminant plus tôt avec "Le chemin contient des octets nuls" lorsque le chemin du fichier d'un appel d'outil contenait \u0000 écrit sous forme de séquence d'échappement ; les caractères de contrôle échappés restent désormais sous forme de texte littéral
  • Correction des sessions en arrière-plan (claude --bg) se terminant lorsque le serveur LSP d'un plugin quittait ou fermait son stdin
  • Correction d'un crash ("Type error") lors de l'ouverture de /mcp ou /plugin manage avec une valeur claudeAiMcpEverConnected mal formée dans ~/.claude.json
  • Correction d'un crash au lancement lorsque ~/.claude.json contient une valeur theme mal formée
  • Correction d'un crash ("erreur d'interface irrécupérable") lorsque l'invite contenait du texte contenant des codes de couleur du terminal, par exemple une invite rappelée de l'historique ou du texte chargé depuis l'éditeur externe
  • Correction d'un crash lors de la reprise d'une session dont l'historique enregistré contient un message d'assistant stocké sous forme de chaîne simple
  • Correction de sessions sur des machines lentes ou très chargées se terminant parfois avec "Claude Code quitté après une erreur d'interface irrécupérable" lorsque le premier spinner apparaissait
  • Correction d'un cas rare où l'écran pouvait cesser de se mettre à jour pour le reste de la session après une erreur de rendu interne
  • Correction d'un cas rare sous Windows où un tour pouvait s'arrêter avec une erreur telle que "Mémoire insuffisante" juste après la réponse de Claude, de sorte que les appels de l'outil de réponse ne s'exécutaient jamais
  • Correction des sessions qui se poursuivaient après /clear (redémarrage, --continue, --resume) manquant une partie de leur premier message lorsqu'un hook SessionStart imprimait la sortie, provoquant un échec complet du cache d'invite
  • Correction des messages d'autres agents (tels que SendMessage d'un sous-agent) qui arrivaient au milieu du tour, apparaissant sous la ligne "Commandes du shell Ran N" au lieu de l'endroit où ils sont arrivés.
  • Correction de l'avis "copié" n'apparaissant pas après avoir sélectionné du texte par glisser-déposer dans le sélecteur plein écran /resume et dans d'autres panneaux qui couvrent la zone d'invite.
  • Correction de $TMPDIR se développant vide dans les commandes Bash qui s'exécutent en dehors du bac à sable lorsque le bac à sable est activé
  • Correction de WebFetch et WebSearch dans les sessions cloud Cowork n'indiquant pas à Claude pourquoi une demande a été refusée, comme un budget de récupération épuisé ou une politique d'administration
  • Correction du relais de télémétrie de la passerelle des applications Claude ignorant un nom d'hôte ou un domaine collecteur répertorié dans NO_PROXY lorsqu'un proxy est défini
  • Correction d'une entrée strictKnownMarketplaces ou blockedMarketplaces mal formée, désactivant silencieusement l'ensemble de la politique du marché de l'entreprise.
  • Correction des échecs de mises à jour automatiques laissant derrière eux de gros téléchargements par étapes dans ~/.cache/claude/staging
  • Correction de /plugin qui ne supprimait pas les caractères de contrôle du terminal des messages sur l'onglet Installé, comme l'erreur d'un échec de mise à jour du plugin
  • Correction de /plugin → Installé et /skills plantant lorsqu'une compétence ou une commande héritée est nommée comme une propriété d'objet intégrée telle que constructor ou toString
  • Correction de la fermeture de /plugin sans message lorsque chaque installation dans une sélection multiple échouait
  • Correction des plugins désinstallés réapparaissant sous la forme de lignes "échec du chargement" dans /plugin Installed, et Remove n'effaçant pas une telle ligne
  • Correction des plugins du marché officiel étant enregistrés sans leur commit dans installed_plugins.json, et installed_plugins.json conservant l'ancien commit après la mise à jour d'un plugin de commit épinglé
  • Correction des aperçus de rechargement du plugin en conservant chaque copie prévisualisée d'une archive de plugin décompressée jusqu'à la sortie, et en écrasant l'archive --plugin-url en cache sur laquelle un rechargement retombe lorsque son téléchargement échoue
  • Correction de l'échec de la comptabilité de session de contrôle à distance lorsque ~/.claude.json détient un enregistrement d'espace réservé mal formé.
  • Correction de l'erreur après une connexion claude.ai révoquée accusant un profil Anthropic expiré ; il mène désormais avec /login
  • Correction du texte tapé ou collé qui sortait parfois brouillé dans l'entrée de répartition du claude agents lors de la répétition d'une touche ou d'une saisie très rapide
  • Correction d'un crash ("erreur d'interface irrécupérable") lors de la reprise d'une session dont la transcription enregistrée contient un résumé du stop hook sans une liste de hooks bien formée
  • Correction d'Entrée sur une ligne du panneau d'agent sélectionnée ne faisant rien lorsque keybindings.json relie Entrée dans le contexte de discussion, par exemple à chat:queueSubmit
  • Correction d'un problème de lecture de page PDF sous Windows lorsque le chemin du dossier de travail est long (environ 120 caractères ou plus)
  • Correction d'un CV sans tête (claude -p --resume, le SDK, un rechargement de fenêtre d'extension VS Code) démarrant le coût et les totaux d'utilisation de la session à zéro ; les sessions sans tête enregistrent désormais leurs totaux à la sortie
  • Correction des compétences de projet du référentiel principal qui ne se chargeaient pas dans les sessions --worktree lorsque .claude/skills n'était pas suivi
  • Correction d'un glob sandbox.excludedCommands exemptant une commande Bash composée entière du bac à sable lorsqu'une seule partie correspondait ; chaque partie doit maintenant correspondre
  • Correction des sous-agents et des coéquipiers qui reprenaient les définitions de l'outil MCP qu'ils avaient chargées, ce qui interrompait la mise en cache des invites pour cet agent.
  • Correction d'un artefact à débit limité indiquant à Claude d'arrêter de réessayer ; Claude sait maintenant que rien n'a été publié et quand renvoyer la même publication
  • Correction des pièces jointes enregistrées plus tôt dans une conversation qui étaient restituées après une reprise ou une relance, ce qui supprimait la réflexion prolongée et manquait le cache d'invite
  • Correction de la connexion à la console affichant uniquement « Échec de la demande avec le code d'état 400 » lorsque le serveur refuse de créer une clé API ; il affiche maintenant le message du serveur
  • Correction des messages tapés alors que Claude travaille encore, parfois ignorés par le modèle
  • Démarrage de session amélioré pour l'utilisation du SDK et du headless (-p) : le premier tour n'attend plus la recherche CLAUDE.md par répertoire
  • Amélioration des messages d'erreur de bouclage de la passerelle des applications Claude pour nommer CLAUDE_GATEWAY_ALLOW_LOOPBACK
  • /plugin amélioré installé : un serveur MCP répertorié en dehors de son plugin montre désormais à quel plugin il appartient
  • claude plugin install amélioré sur un plugin déjà installé : il indique désormais quand le Marketplace propose une version plus récente et nomme la commande claude plugin update
  • Amélioration de la ligne de débordement des avis de démarrage sous le logo : elle indique désormais "N autres avis cachés" au lieu de "+N plus · /status"
  • Gestion améliorée des invites : le formatage Unicode invisible et les caractères de balise dans une invite sont supprimés et l'invite nettoyée est affichée pour examen avant d'être envoyée.
  • /ultrareview amélioré lorsqu'il n'y a rien à réviser : les messages indiquent dans quel cas vous vous trouvez, proposent une commande qui révise votre dernier commit, et le premier commit d'un nouveau référentiel est révisé dans son intégralité
  • Amélioration de la gestion des liens d'artefact afin que Claude lise les liens d'artefact claude.ai avec l'outil Artifact au lieu de WebFetch lorsque cet outil est disponible
  • Amélioration de l'invite d'autorisation dangereuse-rm pour nommer la commande rm signalée et suggérer un garde ${VAR:?}, afin que les exécutions sans tête puissent récupérer
  • Amélioration des invites d'autorisation de l'outil Artefact : phrases plus courtes, pages et artefacts nommés par titre ou nom de fichier, et liens répertoriés après le texte.
  • Modification de Fable pour qu'elle apparaisse toujours dans /model sur Anthropic API ; il est grisé uniquement lorsque les paramètres de votre organisation le désactivent
  • Modification des instructions du bac à sable Bash sur Bedrock, Vertex et Foundry par la formulation propriétaire, qui encadre le bac à sable comme la limite de la tâche qui a été confiée.
  • Modification de /ultrareview dans les sessions non interactives pour refuser lorsque le référentiel n'a pas de branche de base ni d'historique partagé
  • Modification des résultats du sous-agent pour atteindre l'agent principal sous un en-tête les marquant comme sortie du sous-agent, avec le résultat en retrait, afin que le texte dans le résultat d'un sous-agent ne puisse pas être transmis comme instructions propres à la session.
  • Modification des invites calculées agent() des scripts de flux de travail sur Bedrock, Vertex et Foundry pour atteindre le sous-agent encadré sous forme de texte créé par le script, afin que le classificateur de sécurité ne les lise pas en tant qu'utilisateur.
  • Suppression de la demande de titre automatique Haiku en arrière-plan des exécutions claude -p lancées en dehors d'un SDK ou d'un IDE
  • Suppression de l'outil obsolète TaskOutput ; Claude lit le fichier de sortie d'une tâche en arrière-plan avec Read à la place, et les paramètres taskOutputMaxChars et TASK_MAX_OUTPUT_LENGTH n'ont plus aucun effet
  • [VSCode] Ajout d'une ligne de déconnexion au menu du panneau, avec /logout dans le menu de commandes saisies
  • [VSCode] Ajout de shells d'arrière-plan et d'autres tâches en cours d'exécution à la carte des agents, chacun avec un Stop et un /tasks tapé qui l'ouvre
  • [VSCode] Ajout d'un bouton Copier la réponse sur les réponses et d'un /copy tapé
  • [VSCode] Ajout d'un avis unique lorsque les sessions inactives sont archivées automatiquement, et d'une action "Tout désarchiver" sur le groupe Sessions archivées
  • [VSCode] Ajout du coût de la session et de l'utilisation du jeton à la boîte de dialogue Compte et utilisation et au gestionnaire de session où les limites du plan ne s'appliquent pas (Vertex, Bedrock, Foundry, clé API)
  • [VSCode] Correction de la ligne de menu "Configuration générale" affichant le texte d'utilisation de /config au lieu d'ouvrir les paramètres, et fait en sorte que /mcp, /hooks, /memory, /rewind et les commandes similaires ouvrent leurs boîtes de dialogue
  • [VSCode] Correction du niveau du curseur d'effort ne persistant pas dans les sessions ultérieures sur un modèle qui avait déjà un niveau enregistré avec /effort
  • [VSCode] Correction de l'absence automatique dans le sélecteur de mode pour les conversations ouvertes dans un panneau déjà utilisé lorsque le paramètre de modèle enregistré est un alias avec une casse différente tel que "Sonnet".
  • [VSCode] Correction de /fast n'enregistrant pas le mode rapide par défaut, il était donc perdu lorsque l'extension relançait Claude Code
  • [Claude Code sur le Web] Ajout des sections Personnel et Organisation au sélecteur d'environnement sur les forfaits Team et Enterprise, et les administrateurs peuvent désormais partager un environnement personnel avec l'organisation.
  • [Claude Code sur le Web] Modification des environnements d'organisation pour s'ouvrir sous forme de résumé en lecture seule à partir de l'onglet Code sur les forfaits Team et Enterprise, avec modification sous Paramètres administrateur → Environnements cloud
  • [Claude Code sur le Web] Correction d'un environnement cloud enregistré avec un accès réseau personnalisé et aucun domaine ne revenant silencieusement à Trusted ; la boîte de dialogue demande maintenant au moins un domaine
  • [Claude Code sur le Web] Modification du paramètre d'administration Claude Code intitulé "Web" en "Sessions cloud" et suppression de la ligne mobile redondante en lecture seule située en dessous.
  • [Claude Tag] Correction des routines créées dans un canal Slack sur une installation à l'échelle de l'organisation Enterprise Grid qui ne parvenaient pas à lire les autres canaux publics dans leur espace de travail lors de leur exécution.
  • [Claude Tag] Correction des liens « En savoir plus » sur les préréglages d'informations d'identification dans les offres groupées d'accès Claude Tag pour ouvrir la page de configuration des informations d'identification de chaque fournisseur au lieu d'une référence générique API.
  • [Claude Tag] Modification du préréglage des informations d'identification Pylon dans les packs d'accès Claude Tag afin que les administrateurs puissent les pointer vers l'hôte européen de Pylon.
  • [Claude Tag] Correction des formulaires d'identification Google Cloud dans les offres groupées d'accès Claude Tag : un fichier de clé refusé indique désormais pourquoi, le site Web et les étendues restent verrouillés, et une rotation rejetée conserve la clé collée.
  • [Claude Tag] Correction du journal des événements réseau dans les paramètres d'administration de Claude Tag affichant aucun statut de réponse pour les demandes via des connexions utilisant la signature AWS, les certificats client ou une autorité de certification personnalisée.
