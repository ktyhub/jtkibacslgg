claude-code v2.1.282

Correctif Publié24 sept. 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.282

Qu'est-ce qui a changé

  • Ajout d'un paramètre maxProseWidth qui limite la largeur de la prose de Claude dans les terminaux larges tandis que les tables et les blocs de code conservent la pleine largeur
  • Ajout d'un avis de démarrage et des entrées /status et claude doctor, répertoriant les variables de télémétrie dans les fichiers de paramètres d'un projet qui ont été ignorées ou qui ont désactivé la télémétrie
  • Ajout du paramètre géré allowClaudeInChromeWithManagedMcp pour permettre à claude --chrome de fonctionner aux côtés d'un managed-mcp.json exclusif ; l'erreur affichée lorsque Chrome est bloqué le nomme désormais
  • Ajout de store.readiness_grace_seconds à la passerelle des applications Claude afin que /readyz puisse rester prêt lors d'une courte panne de Postgres telle qu'un basculement de base de données
  • Ajout d'une barre de défilement à la liste des brouillons /feedback en mode plein écran ; il apparaît lorsque la souris survole la liste
  • Correction de chaque échec de requête avec une erreur 400 dans les conversations dont l'historique contient des résultats de recherche sur le Web que le API ne peut pas déchiffrer (par exemple, à partir d'un tour répondu via une passerelle tierce)
  • Correction de davantage de cas de sessions continues ou reprises (--continue, --resume) renvoyant des messages précédents sous une forme modifiée, ce qui pouvait amener le API à abandonner le raisonnement précédent de Claude.
  • Correction de l'abandon de la pensée étendue lorsque /model, /rename, /artifacts ou une autre commande slash immédiate était utilisée pendant que Claude travaillait
  • Correction des conversations continues ou reprises qui perdaient la réflexion approfondie antérieure lors d'une relance avec une liste --tools qui omettait un outil intégré proposé plus tôt dans la conversation.
  • Correction des sessions échouant à chaque tour avec une erreur API « data invalide dans le bloc redacted_thinking » ; Claude Code abandonne désormais les blocages de réflexion de la conversation et réessaye une fois
  • Correction d'un échec de compactage lorsque la demande de résumé est refusée ; il réessaye maintenant sur un modèle de secours
  • Correction d'un virage raté ("L'effort 'xhigh' n'est pas disponible avec la réflexion désactivée") après un changement de modèle lié à la sécurité lors de sessions avec réflexion et effort supérieur à élevé
  • Correction d'une invite de changement de modèle de crédits d'utilisation Fable sans réponse dans les sessions hébergées par SDK telles que Claude Desktop ; le tour se termine désormais et les utilisateurs de la télécommande clients voient désormais l'avis de changement de modèle
  • Correction de /model avec un identifiant de modèle Fable complet s'arrêtant à une erreur API au lieu d'ouvrir l'invite de crédits d'utilisation lorsque le plan a besoin de crédits d'utilisation qui ne sont pas encore activés.
  • Correction des requêtes échouant pendant une minute maximum avec une erreur de connexion "un autre processus Claude Code le rafraîchit" après la fermeture ou la suppression de cet autre processus en cours d'actualisation.
  • Correction des sessions démarrées alors qu'une autre fenêtre Claude Code actualisait la connexion (commune avec plusieurs fenêtres VS Code) sans réessayer de récupérer leur politique d'organisation
  • Correction de CLAUDE.md et des règles lues au démarrage via un lien symbolique du référentiel atteignant le /Network de macOS via .. ou un chemin de noyau de style /.vol, ou un lien de règles vers le /home de macOS étant répertorié
  • Correction des règles d'autorisation Bash avec un motif intermédiaire :* ignoré dans les fichiers de paramètres alors que --allowedTools les honorait ; ils fonctionnent désormais à partir de toutes les sources, avec un avertissement de démarrage sur la façon dont ils correspondent
  • Correction d'une commande approuvée sur une invite d'autorisation restaurée s'exécutant deux fois lors du redémarrage du travailleur d'une session à distance
  • Correction des paramètres gérés ignorant une valeur mal saisie pour les clés de verrouillage booléennes telles que disableClaudeAiConnectors ou allowManagedPermissionRulesOnly ; le verrou s'applique maintenant et le démarrage nomme la clé
  • Correction des paramètres gérés permissions, autoMode, worktree et attribution étant entièrement ignorés lorsqu'une valeur imbriquée n'était pas valide ; le reste du bloc s'applique désormais toujours
  • Correction des manifestes du référentiel, des compétences utilisateur et --add-dir, des commandes et du répertoire de compétences en pré-approuvant leurs propres outils via allowed-tools sous allowManagedPermissionRulesOnly géré
  • Correction des messages de blocage de sauvegarde sur Amazon Bedrock et Bedrock Mantle n'affichant pas d'ID de demande ; bloquer les messages affiche désormais également l'ID du message
  • Vertex AI : correction de la recherche sur le Web qui n'est pas proposée pour les modèles que Claude Code ne reconnaît pas encore, comme les modèles récemment publiés
  • Correction de Bash et PowerShell masquant un quota de disque complet derrière le "Code de sortie 1" et laissant les fichiers de sortie volumineux en temporaire
  • Correction des erreurs de validation d'entrée de l'outil nommant uniquement un paramètre inconnu, manquant ou mal saisi lorsque d'autres paramètres du même appel étaient également invalides ; ceux-ci sont maintenant répertoriés aussi
  • Correction du texte multiligne collé soumis ligne par ligne après la réinitialisation du mode de collage entre crochets du terminal en cours de session
  • Correction du texte d'exemple de l'invite clignotant et disparaissant au démarrage dans les projets avec un hook SessionStart
  • Correction d'un écran vide clignotant avant la première image lors du démarrage en mode plein écran
  • Correction de lignes tronquées et mal placées dans le moteur de rendu non plein écran après que l'écran soit devenu plus court tout en restant plus haut que le terminal, par ex. supprimer une ligne d'invite pendant qu'une commande shell diffuse la sortie
  • Correction d'un caractère obsolète laissé dans la dernière colonne d'un différentiel lorsqu'un caractère CJK ou un emoji d'une ligne redessinée passait à la ligne suivante.
  • Correction de l'atterrissage du curseur avant la fin d'une invite rappelée de l'historique lorsque l'invite contient un onglet
  • Correction de l'indice d'envoi immédiat affichant ctrl+enter sur les terminaux qui l'envoient comme une nouvelle ligne (terminal Windows avant 1.25) ; il affiche maintenant ctrl+x ctrl+s ici
  • Correction de l'échec de claude remote-control --debug avec "Argument inconnu : --debug", bien que la propre erreur d'éligibilité de Remote Control indique de s'exécuter avec --debug.
  • Correction de /install-github-app disant "annulé", puis continuant à pousser la branche et à enregistrer la clé secrète API ; quitter maintenant arrête les étapes restantes et rapporte ce qui a déjà été fait
  • Correction de /feedback, /bug et /share sur Bedrock, Vertex et d'autres fournisseurs tiers enregistrant toujours le fichier de rapport après avoir annulé pendant la sauvegarde
  • Correction du problème de désinstallation du plugin signalant le succès et supprimant les options enregistrées du plugin lorsque son fichier de paramètres l'activait toujours ou ne pouvait pas être lu ; il s'arrête maintenant et nomme le fichier
  • Correction de la désinstallation du plugin supprimant les options et secrets enregistrés d'un plugin lorsque la liste des plugins installés ne pouvait pas être lue après la suppression ; ils sont maintenant conservés et la désinstallation le dit
  • Correction d'une touche tapée juste après / dans /skills déplaçant la liste de compétences au lieu d'atteindre le champ de recherche
  • Correction du curseur du terminal passant du champ de recherche /skills à la liste de compétences lors de la saisie, ce qui pouvait masquer le curseur et placer la saisie IME au mauvais endroit
  • Correction des listes avec une barre de défilement, telles que /skills et /mcp, étant deux colonnes plus étroites en dehors du mode plein écran, où la barre de défilement ne peut jamais apparaître
  • Correction du pied de page du panneau d'agent s'enroulant sur deux lignes avec de longues touches de rebond, et de son indice "Esc pour réduire" ignorant une touche de réduction de rebond.
  • Correction d'un séparateur · doublé dans le pied de page de la boîte de dialogue /tasks lorsque le raccourci arrêter tous les agents n'est pas lié dans keybindings.json
  • Correction de l'échec de la publication d'artefacts lorsque Claude donnait à la version une étiquette de plus de 60 caractères ; l'étiquette est maintenant raccourcie
  • Correction du mode lecteur d'écran, des listes citées et des listes très longues laissant tomber les lignes vides en haut d'un bloc de code qui ouvre un élément de liste, directement ou à l'intérieur d'une citation
  • Correction des messages d'erreur de lecture de page PDF : les chemins avec des caractères accentués ou non latins apparaissent désormais de manière lisible, et un dossier nommé comme "mot de passe" ou "invalide" ne peut plus donner une mauvaise cause au nom de l'erreur.
  • Correction du mode vim >> indentant les lignes vides, r avec un nombre plus long que la ligne changeant le texte, 2J joignant une ligne de trop et un nombre sur la dernière ligne (2dd, 2>>) la décalant ou la supprimant
  • Correction du placement du curseur en mode vim : après dd, dj, dG ou une ligne entière p/P, il atterrit sur le premier non vide, yy ne le déplace plus, et Esc après un emoji ne le laisse plus à l'intérieur de l'emoji
  • Correction du mode vim ignorant un compte tapé avant . lors de la répétition de x, s, p, d ou c, et des lignes entières p/P, o, O, J, >> et << agissant sur la mauvaise ligne lorsqu'une ligne au-dessus enveloppements
  • Correction du mode vim laissant le curseur après la fin d'une invite rappelée de l'historique ou retirée de la file d'attente en mode normal, donc x ne faisait rien
  • Amélioration du temps de reprise de très grandes sessions, y compris celles qui n'ont jamais été compactées
  • Amélioration de l'erreur affichée sous Windows lorsqu'une session ne peut pas être reprise car son fichier de transcription n'a pas pu être lu (EBADF) : elle nomme désormais les causes possibles et ce qu'il faut essayer
  • Amélioration de l'erreur de modèle inconnu de Claude Desktop pour suggérer de passer à un modèle différent
  • Rendu amélioré d'Unicode inhabituel dans les invites d'autorisation
  • /artifacts amélioré : les titres s'alignent sur une seule colonne, les détails sont supprimés en entier au lieu d'être coupés au milieu du mot, et la liste prend en charge PgUp/PgDn, Home/End, la molette de la souris et clicks.
  • Mise à jour de la compétence claude-api : la facturation des refus avant sortie est désormais liée aux documents Comment les refus sont facturés, les refus en cours de route sont facturés aux tarifs normaux et les refus avant sortie sont pris en compte dans les limites de taux.
  • Mise à jour de la compétence claude-api pour recommander ant apply pour conserver les ressources des agents gérés sous forme de fichiers à version contrôlée
  • Modification du mode automatique pour utiliser le classificateur côté serveur par défaut sur une connexion directe Anthropic API lorsque la télémétrie est désactivée (CLAUDE_CODE_AUTO_MODE_SERVER=0 se désactive)
  • Modification de sandbox.excludedCommands pour ignorer les entrées de projet et de paramètres locaux lorsque les paramètres gérés ou --settings définissent allowUnsandboxedCommands: false ou allowManagedDomainsOnly: true géré
  • Modification des paramètres du projet et locaux pour ignorer les variables OpenTelemetry qui activent l'exportation, définissent son point de terminaison ou capturent le contenu, comme CLAUDE_CODE_ENABLE_TELEMETRY et OTEL_LOG_*.
  • Modification des paramètres gérés par Windows/WSL afin qu'une politique d'administration présente mais invalide ou illisible (HKLM, managed-settings.json) empêche l'application de HKCU et WSL /etc/claude-code accessibles en écriture par l'utilisateur.
  • Les modifications Skill(anthropic-skills:*) et Skill(claude-ai:*) permettent aux règles de couvrir uniquement les compétences synchronisées depuis claude.ai, pas les plugins ou autres compétences qui utilisent simplement un tel nom.
  • Modification des dossiers de compétences, des fichiers de commandes et des commandes de workflow dans l'espace de noms anthropic-skills ou claude-ai pour ne plus se charger ; un plugin ainsi nommé se charge toujours mais génère des liens de nom avec des compétences synchronisées
  • Modification des serveurs MCP configurés sous le nom anthropic-skills ou claude-ai pour ne lister aucune compétence ni invite (leurs outils fonctionnent toujours) ; renommez le serveur dans votre configuration MCP pour les lister à nouveau
  • Modification des visuels de ultracode dans /effort et de la saisie rapide en style simple (pas d'ondulation, d'épanouissement de bordure ou de lueur de mot-clé) et suppression de la pointe tournante des flux de travail dynamiques
  • Modification des pieds de la mascotte Clawd dans la bannière de démarrage pour qu'ils soient assis sous les coins de son corps
  • [VSCode] Correction des réponses longues en retard sur le flux : le panneau ne réanalyse plus l'intégralité de la réponse à chaque mise à jour
  • [VSCode] Correction du bouton du micro de dictée couvrant la barre de défilement de la saisie du message lorsque l'entrée est suffisamment haute pour défiler
  • [VSCode] Correction des sessions de contrôle à distance démarrées sur cet ordinateur ne s'ouvrant pas à partir de leur entrée Web dans la liste des sessions ; ils ouvrent désormais la conversation locale à moins qu'elle ne se déroule ailleurs
  • [VSCode] Correction de l'écran de connexion d'un onglet d'éditeur suspendu silencieusement après le redémarrage de l'hôte d'extension ; il affiche désormais également l'avis « a cessé de répondre »
  • [Sessions Cloud] Ajout du statut de l'application Claude GitHub à Paramètres › Connecteurs › GitHub : indique si l'application est installée et accessible pour votre compte, ainsi que les étapes pour se connecter, installer ou se reconnecter.
  • [Sessions Cloud] Ajout des liens "Ouvrir le référentiel" et "Ouvrir la page de comparaison" vers le menu du référentiel d'une session cloud dont le référentiel est hébergé sur un serveur Git autre que GitHub
  • [Sessions Cloud] Ajout de l'attachement d'un référentiel d'un autre propriétaire de GitHub, tel qu'un fork en amont, à une session cloud en cours d'exécution qui en possède déjà un, y compris les sessions démarrées depuis Slack
  • [Sessions Cloud] Correction du temps d'exécution suivant affiché pour une routine horaire étant de 30 minutes de décalage pour les personnes situées dans des fuseaux horaires décalés d'une demi-heure comme l'Inde.
  • [Sessions cloud] Amélioration de la rapidité de chargement de la page Routines et de la liste planifiée de la barre latérale pour les comptes dont les sessions précédentes ont planifié de nombreux rappels d'enregistrement.
  • [Claude Tag] Correction des modèles de canal de jointure automatique enregistrés pour un espace de travail dans les paramètres d'administration de Claude Tag, ignorés lors d'une installation à l'échelle de l'organisation Enterprise Grid ; Claude rejoint maintenant les nouvelles chaînes correspondantes
  • [Claude Tag] Correction de Claude ne répondant pas dans un canal Enterprise Grid partagé entre deux espaces de travail d'une organisation lorsque la version Claude Tag du canal était enregistrée depuis l'autre espace de travail.
  • [Claude Tag] Correction de l'ancienne carte de progression de l'application Claude dans Slack pour les sessions sur un référentiel GitHub Enterprise Server : elle nomme désormais le référentiel et propose un bouton Créer PR fonctionnel.
  • [Claude Tag] Correction des fils de discussion Slack dont le modèle a été retiré et retombant vers un autre modèle à chaque réponse, plus lentement et avec une note de repli à chaque fois ; le fil passe maintenant à un modèle de travail
  • [Claude Tag] Correction des fichiers que Claude télécharge sur Slack ne pouvant pas contenir de légende contenant un tableau ; les légendes s'affichent désormais avec le même format que les réponses
  • [Claude Tag] Correction des fils de discussion de Claude dans la vue Agents et outils de Slack, parfois répertoriés sous leur premier message au lieu de leur nom ; les noms ultérieurs mettent également à jour la liste
  • [Claude Tag] Correction de la suppression de la subvention d'une organisation GitHub de l'onglet Référentiels d'un ensemble d'accès dans les paramètres d'administration de Claude Tag, qui ne parvenait pas à enregistrer après la déconnexion de cette organisation GitHub.
  • [Claude Tag] Correction de Claude répondant toujours « Impossible de vérifier cette chaîne pour le moment » dans une chaîne partagée avec un espace de travail Grid auquel elle n'est pas ajoutée ; l'avis indique désormais quel espace de travail a besoin de l'application
  • [Claude Tag] Correction des totaux de coût et de jetons dans le pied de page de réponse de Claude, plusieurs fois trop élevés après le redémarrage du cloud worker de la session.
  • [Claude Tag] Modification des cartes bordées que Claude utilise dans les réponses Slack pour les plans, les tableaux et les détails afin qu'elles s'affichent en largeur par défaut au lieu d'une largeur étroite.
  • [Claude Tag] Modification des espaces de travail Slack nouvellement connectés pour suivre le modèle par défaut actuel au lieu de conserver le modèle par défaut lors de leur connexion
