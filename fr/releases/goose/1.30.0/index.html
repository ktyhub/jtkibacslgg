🪿Oie v1.30.0 Release Notes

Publié : le 8 avril 2026

✨ Nouvelles fonctionnalités

🖥️ Refonte de l'interface utilisateur du terminal (TUI)

  • Appels d'outils extensibles par tabulation — la sortie de l'appel d'outil se réduit désormais proprement avec l'onglet à développer (#8136)
  • Rendu amélioré des messages — meilleur classement, streaming/défilement et amélioration visuelle globale pour les messages, les appels d'outils et la saisie de texte (#8144, #8156, #8214)
  • Mode --text indépendant — le mode texte est désormais découplé du TUI normal pour une expérience sans tête plus propre (#8210)
  • goose serve — nouvelle sous-commande pour exécuter Goose en arrière-plan (#8209)

🔌 Fournisseurs et modèles

  • Fournisseur OAuth Gemini : authentification basée sur OAuth de première classe pour Google Gemini (#8129)
  • Fournisseur Copilot ACP — nouveau fournisseur pour GitHub Copilot via ACP (#8154)
  • Fournisseur déclaratif Zhipu — ajoute l'IA Zhipu avec un remplacement configurable de ZHIPU_BASE_URL (#8204)
  • fast_model configurable pour les fournisseurs déclaratifs — vous permet de spécifier un modèle léger pour les tâches rapides (#8194)
  • Prise en charge du modèle local Gemma 4 — activez Gemma 4 comme option de modèle local (#8366)
  • Améliorations du fournisseur VMware Tanzu Platform — corrections de bugs, prise en charge du streaming et améliorations de l'interface utilisateur (#8126)

🛡️ Sécurité et observabilité

  • Inspecteur de journalisation de sortie — nouvelle fonctionnalité de sécurité pour enregistrer et inspecter les appels réseau sortants (#8149)
  • Autorisations restreintes des fichiers secrets — les fichiers secrets sont désormais créés avec des autorisations plus strictes au niveau du système d'exploitation (#8118)

🧩 Extensions et compétences

  • Afficher les compétences installées dans l'interface utilisateur — les compétences sont désormais visibles et consultables depuis l'application de bureau (#7910)
  • Extension de plateforme de compétences — les compétences sont désormais gérées comme une extension de plateforme dédiée (#8377)
  • Découvrez de manière récursive les compétences imbriquées — les compétences sous les racines configurées se trouvent désormais à n'importe quelle profondeur (#8082)
  • Délai d'expiration d'extension configurable — définissez les délais d'attente par extension via ACP _meta ou une valeur par défaut globale (#8295)
  • Contrôles du fournisseur ACP réutilisables — composants d'interface utilisateur partagés pour la configuration du fournisseur ACP (#8314)
  • Rust ACP client pour les méthodes d'extension (#8227)
  • Améliorations du serveur MCP pour les développeurs (#7770)

🌐 Internationalisation

  • Infrastructure i18n — ajout d'un cadre d'internationalisation basé sur react-intl à l'application de bureau (#8105)

🩺 Diagnostic

  • goose doctor — nouvelle commande pour diagnostiquer les problèmes courants de configuration et d'environnement (#8342)

⚙️Configuration

  • GOOSE_SHOW_FULL_OUTPUT — nouvelle option de configuration pour désactiver la troncature de la sortie de l'outil (#7919)
  • GOOSE_CLI_SHOW_THINKING — peut désormais être défini dans config.yaml (pas seulement dans les variables d'environnement) (#8097)
  • GOOSE_CONTEXT_LIMIT — désormais lisible depuis config.yaml (#7900)
  • GOOSE_DISABLE_KEYRING — désormais honoré de config.yaml au démarrage (#8219)
  • Remplacement max_turns par délégué (#8066)
  • skip_canonical_filtering pour les fournisseurs déclaratifs (#8052)

🏗️ Construction et emballage

  • Prise en charge facultative de native-tls — alternative à rustls pour les environnements nécessitant le système TLS (#8037)
  • Dépendances du fournisseur AWS liées aux fonctionnalités — derrière l'indicateur de fonctionnalité aws-providers pour les versions plus légères (#8080)
  • Télémétrie dépendante des fonctionnalités — la télémétrie est désormais derrière les indicateurs de fonctionnalité Cargo (#8119)
  • Onglet Paramètres du maillage d'inférence (#8094)
