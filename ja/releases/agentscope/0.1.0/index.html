エージェントスコープ v0.1.0

何が変わったのか

型式 APIs

  1. ZhipuAI API (https://github.com/modelscope/agentscope/pull/181) をサポート 2.サポートイーAPI (https://github.com/modelscope/agentscope/pull/343)
  2. AgentScope でのストリーミング モードのサポート (https://github.com/modelscope/agentscope/pull/347)
  3. LiteLLM (https://github.com/modelscope/agentscope/pull/204) をサポート
  4. モデル名に従って入力メッセージをフォーマットします (https://github.com/modelscope/agentscope/pull/381)

サービス

以下の新しいサービス機能を追加します

  1. トリップアドバイザーの検索
  2. DBLP検索
  3. ウィキペディア検索
  4. Webブラウザ制御
  5. OpenAI および DashScope マルチモーダル サービス機能

その他

  1. AgentScope での MoA メソッドの実装 (https://github.com/modelscope/agentscope/pull/327)
  2. 新しいプロンプトエンジニアリングモジュール (https://github.com/modelscope/agentscope/pull/242)
  3. RAGモジュールの改良（https://github.com/modelscope/agentscope/pull/184）
