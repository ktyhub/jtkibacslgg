agentscope v0.1.1

パッチ 公開日2024年11月8日 出典agentscope-ai/agentscope 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エージェントスコープ v0.1.1

何が変わったのか

  • ReActAgentでmax_retriesが動作しないバグを修正
  • 異なる dahscope api キーで複数の構成を設定すると、1 つの api キーのみが有効になるバグを修正
  • パーサー内でネストされた Pydantic BaseModel オブジェクトをサポートします
  • AgentScope for OpenAI (ビジョンおよび非ビジョン llms の両方)、Gemini、DashScope API でのトークン カウントのサポート、およびローカルでのトークン カウント機能の登録のサポート
  • ストリーミングモードのバグを修正
  • 誤解を招くことを避けるために、フォーマット関数内で基本的なプロンプトエンジニアリング戦略を調整します。
  • [実験的]環境モジュールの追加
