agno v2.4.8

#アグノv2.4.8 #Changelog

新機能:

  • ワークフロー ステップの CEL サポート: 条件、ループ、およびルーター ステップの評価子として CEL (共通式言語) 式を使用します。 CEL 式は文字列であるため、ワークフロー ステップを完全にシリアル化できます。
  • Neosantara モデル プロバイダー: OpenAI 互換の API を提供するインドネシアの LLM ゲートウェイである Neosantara のサポートを追加します。
  • Studio: AgentOS でエージェント、チーム、ワークフローを構築するためのビジュアル エディター。ツール、モデル、データベース、スキーマを管理するためのレジストリとのドラッグ アンド ドロップ インターフェイス。

改善点:

  • Workflow Router Step: ステップ自体ではなくステップの名前を返す機能と、ルーターの選択肢としてステップのグループを返すサポートが追加されました。
  • WebsiteReader Chunking: 特定のチャンカーを設定しない場合、OpenAI API キーの必要性を排除するために、デフォルトで Semantic の代わりにFixedSizeChunking を使用するようになりました。
  • スキル: スクリプト実行のためのシバン解析と Windows コマンド構築を追加します。

バグ修正:

  • LanceDB: 非推奨の table_names() に対する下位互換性を追加しました
  • 並列ステップ: 最初の位置引数として名前も受け入れるように、ワークフローの並列ステップを修正しました。
  • AzureOpenAI: azure_ad_token_provider を含むように AzureOpenAI 認証を修正しました
  • エージェント状態ツール: Agno 2.4.0 の Function クラスから _session_state が削除された後、run_context から session_state を正しく抽出するように update_session_state ツールを修正しました。
  • LearningMachine: クロード/ジェミニ互換性のためにユーザー メッセージを SessionContextStore に追加します。

何が変わったのか

  • 修正: https://github.com/agno-agi/agno/pull/6230 の @willemcdejongh によって OS 構成エンドポイントにナレッジ テーブルを設定する
  • 雑務: https://github.com/agno-agi/agno/pull/6229 の @kausmeows による並列ステップの最初の位置引数として名前を許可します
  • 功績: https://github.com/agno-agi/agno/pull/6215 の @kausmeows により Router のセレクター fn に step_choices を追加
  • 雑用: https://github.com/agno-agi/agno/pull/6192 の @willemcdejongh によるナレッジ リモート コンテンツ ハンドラーの再作成
  • 雑用: https://github.com/agno-agi/agno/pull/6255 の @ashpreetbedi による正しい帰属で LICENSE の著作権を更新する
  • 修正: AzureOpenAI 認証を強化して、https://github.com/agno-agi/agno/pull/6092 の @tanmaydarmorha による azure_ad_token_provider を含めるようにしました
  • 修正: https://github.com/agno-agi/agno/pull/6272 の @kausmeows による一貫したストリーミングのために、ワークフロー session_id をエグゼキューター イベントに伝播します。
  • 修正: LanceDB の下位互換性のために list_tables() を table_names() フォールバックとともに使用する (https://github.com/agno-agi/agno/pull/6273 の @harshsinha03 による)
  • 功績: https://github.com/agno-agi/agno/pull/6101 の @ysolanky によるすべてのワークフロー ステップ コンテナーのシリアル化サポートを追加
  • リファクタリング: https://github.com/agno-agi/agno/pull/6285 の @ysolanky によって RegistryContentType の名前が RegistryResourceType に変更されました
  • [feat] Neosantara モデル プロバイダー (#6271) を追加 (@kausmeows による https://github.com/agno-agi/agno/pull/6290)
  • [修正] https://github.com/agno-agi/agno/pull/6260 の @Sebastiao-Assuncao による update_session_state ツールの 'run_context' から 'session_state' を抽出します
  • クックブック: https://github.com/agno-agi/agno/pull/6212 の @guguoyi によるタイプミスの修正
  • [修正] https://github.com/agno-agi/agno/pull/6091 の @Samyak2 による WebsiteReader を使用するときに、必ずしも openai が必要なわけではありません
  • 功績: https://github.com/agno-agi/agno/pull/6241 の @uzaxirr によるスクリプト実行用のシバン解析と Windows コマンド構築を追加
  • 修正: https://github.com/agno-agi/agno/pull/6291 の @kepler により、Claude/Gemini の互換性のためにユーザー メッセージを SessionContextStore に追加
  • 雑用: @kausmeows による 2.4.8 を https://github.com/agno-agi/agno/pull/6288 でリリース
  • 修正: https://github.com/agno-agi/agno/pull/6293 で @pritipsingh によってエージェントが削除されると GET ワークフローが中断する
