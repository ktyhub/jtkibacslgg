agno v2.6.1

#アグノv2.6.1 #Changelog

新機能:

  • クロード プロンプト キャッシュ (マルチブロック): クロード モデル (#7662) を対象とした 3 つの Anthropic プロンプト キャッシュの拡張機能:
    • Claude の新しい system_prompt_blocks: List[SystemPromptBlock] — 各ブロックには、text、cache、およびブロックごとのモデル レベルの extended_cache_time フラグをオーバーライドするオプションの ttl ("5m" または "1h") があります。
    • クロードの新しい cache_tools: bool (Anthropic、AWS Bedrock、VertexAI)。最後のツールに cache_control を追加して、ツールのプレフィックスがキャッシュされるようにします。
    • Model._format_tools での決定的なツールの順序付け (名前による並べ替え) により、リクエストのプレフィックスは実行全体にわたって安定し、プロンプト キャッシュが実際にヒットします。 Anthropic、OpenAI、Gemini、Bedrock 全体に適用されます。
  • パラレル MCP バックエンド: WebContextProvider の新しい Web バックエンドとして ParallelMCPBackend を追加しました (#7667)。 search.parallel.ai/mcp にある Parallel のパブリック MCP サーバーと通信し、web_search + web_fetch (圧縮されたマークダウン出力) を公開します。デフォルトではキーレス。より高いレート制限のための PARALLEL_API_KEY 経由のベアラー認証。 use_oauth=True 経由のオプションの OAuth エンドポイント。 web_fetch は大きなページでは実行時間が長くなることが多いため、デフォルトのタイムアウトは 30 秒 (MCPTools の 10 秒から増加) です。

改善点:

  • OpenAI モデル文字列: "openai:" モデル文字列プレフィックスを OpenAIResponses (以前の OpenAIChat) にマップしました。依然として OpenAIChat が必要なユーザーのためのフォールバックとして "openai-chat:" を追加しました。 Agent(model="openai:gpt-5.4") は OpenAIResponses(id="gpt-5.4") に解決されるようになりました。

バグ修正:

  • A2A: リリース ワークフローで a2a-sdk>=0.3.0,<1.0 を固定しました。 a2a-sdk v1.0 には、フォローアップで採用する必要がある重大な変更があります。
  • クックブック:
    • 古い Redis クックブック ドキュメントを修正 - 不要になった依存関係のインストールおよびセットアップ コマンドを削除しました (#7615)。
    • Pydantic モデルで output_schema を示すために output_schema の例を修正しました (Web 検索で output_model を誤って使用していました)。
    • 存在しない agno_agent.py を参照していた cookbook/05_agent_os/README.md のタイプミスを修正しました (agno_assist.py に修正) (#7663)。

何が変わったのか

  • 雑務: "openai:" モデル文字列を OpenAIResponses にマップ (https://github.com/agno-agi/agno/pull/7655 の @kausmeows によって)
  • https://github.com/agno-agi/agno/pull/7663 の @asifshaikh による 05_agent_os Readme のタイプミスを修正
  • [クックブック] https://github.com/agno-agi/agno/pull/7615 の @edlng による Redis の古いドキュメントを修正
  • 功績: https://github.com/agno-agi/agno/pull/7667 の @Mustafa-Esoofally による Parallel MCP 経由の Web 検索用に ParallelMCPBackend を追加
  • 功績: クロードのマルチブロック プロンプト キャッシュ (https://github.com/agno-agi/agno/pull/7662 の @ysolanky による)
  • 雑用: @kausmeows による v2.6.1 を https://github.com/agno-agi/agno/pull/7666 でリリース
