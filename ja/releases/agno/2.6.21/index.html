agno v2.6.21

#アグノv2.6.21 #Changelog

改善点:

  • LocalFileSystemTools:
    • enable_read_file フラグを介してファイルを読み取ります。
    • デフォルトではファイル操作を target_directory 内に保ちます。 restrict_to_base_dir=False をオプトアウトに設定します。
  • ツール: 下位互換性のあるエイリアスを使用して、名前を StudioTool から StudioTools に変更しました。

バグ修正

  • レジストリ / MCP: レジストリでのサイレント MCP ツールの損失を防ぎます。
  • ワークフロー:
    • WebSocket ワークフロー ファクトリ実行用の trusted JWT コンテキストを伝播します。
    • 非同期データベースで使用すると、同期セッション メソッドがサイレントに中断される問題を修正しました。
  • Google ドライブ: Google ドライブのダウンロード ファイル名を制限します。
  • RunOutput: get_last_run_output は、エージェントおよびチームのサブクラスに対して None を返さなくなりました。
  • ナレッジ: コンテンツ DB なしでナレッジ フィルターを保存します。
  • MCP: MCP の再接続中に CancelledError を伝播し、冗長な build_tools をドロップします。
  • ナレッジ チャンキング: オーバーラップが適用される場合、チャンク ハッシュ ID をコンテンツと同期させます。
  • AgentOS: 設定なしテーブル 500 および A2A ストリーミング ターミナル イベントを修正しました。
  • シリアル化: Web 検索ツールの出力で Unicode シーケンスとしてエスケープされる非 ASCII 文字を修正しました。
  • CustomApiTools: 認証ヘッダーの漏洩を防ぎます。
  • PerformanceEval: 小さなサンプルの場合、p95 の実行時間とメモリを観察範囲内に保ちます。
  • CsvTools: 名前にハイフンまたはその他の特殊文字が含まれる CSV ファイルをクエリします。
  • ナレッジ: Reader(chunk=False) が設定されている場合、URL 取り込みでドキュメントがチャンク化されなくなりました。
  • ツール: 非同期ジェネレーター ツールの実行に失敗する問題を修正しました。

何が変わったのか

  • ドキュメント: https://github.com/agno-agi/agno/pull/8597 の @onyx679 による承認クックブックの実行コマンドを修正
  • [修正] https://github.com/agno-agi/agno/pull/8582 の @Fahmid-Arman による CustomApiTools 認証ヘッダーの漏洩を防止
  • 修正: https://github.com/agno-agi/agno/pull/8617 の @Copilot を使用した @VirusDumb により、Gemini のデフォルト モデルを gemini-flash-latest から gemini-3.5-flash に変更
  • クックブック: https://github.com/agno-agi/agno/pull/8613 の @dev-ishant によるジョブ アプリケーション トラッカー ワークフローの例を追加
  • 修正: [バグ] https://github.com/agno-agi/agno/pull/8637 で @michaelxer によって出力された JSON で中国語の文字が Unicode エスケープ シーケンスとして表示される
  • 修正: AgentOS 設定のテーブルなし 500 と A2A ストリーミング端末イベント (https://github.com/agno-agi/agno/pull/8614 の @harshsinha03 による)
  • 修正: https://github.com/agno-agi/agno/pull/8690 で @sannya-singal によって重複が適用される場合、チャンク ハッシュ ID をコンテンツと同期させます。
  • 修正: MCP 再接続中に CancelledError を伝播し、https://github.com/agno-agi/agno/pull/8666 の @sannya-singal によって冗長 build_tools をドロップ
  • 修正: https://github.com/agno-agi/agno/pull/8663 の @Success6666 によるコンテンツ データベースなしでナレッジ フィルターを保存する
  • 修正: [バグ] https://github.com/agno-agi/agno/pull/8647 の @michaelxer による AsyncPostgresDb を使用すると、Workflow._read_session() と Workflow.get_session() が待機なしで async db.get_session() を呼び出します。
  • [feat] LocalFileSystemTools で read_file ツールを公開し、https://github.com/agno-agi/agno/pull/8352 で @yaosongding によるクックブックを追加
  • 修正: https://github.com/agno-agi/agno/pull/8692 の @kausmeows により、get_last_run_output はエージェントとチームのサブクラスに対して None を返します
  • 修正: https://github.com/agno-agi/agno/pull/8698 の @ysolanky により、StudioTool の名前を下位互換性のあるエイリアスを持つ StudioTools に変更しました。
  • 修正: https://github.com/agno-agi/agno/pull/8704 の @Success6666 によって Google ドライブのダウンロード ファイル名を制限する
  • [クックブック] Dakera 永続メモリ統合を追加 — Agno エージェント用の自己ホスト型クロスセッション メモリ by @ferhimedmine (https://github.com/agno-agi/agno/pull/8671)
  • [修正] https://github.com/agno-agi/agno/pull/8697 で @adya07pandey によって実行される WebSocket ワークフロー ファクトリの trusted JWT コンテキストを伝播する
  • 修正: https://github.com/agno-agi/agno/pull/8696 の @ashpreetbedi によるレジストリ + StudioTool 永続化でのサイレント MCP ツールの損失を防止
  • [修正] https://github.com/agno-agi/agno/pull/8514 の @fengjikui によってローカル ファイルのターゲット ディレクトリへの書き込みを制限する
  • 修正: URL ナレッジの取り込みで Reader(chunk=False) が無視され、https://github.com/agno-agi/agno/pull/8708 の @sannya-singal によるドキュメントがチャンク化される
  • 修正: https://github.com/agno-agi/agno/pull/8714 で @kausmeows による validate_call でツールをラップするときに非同期ジェネレーターの ID を保持する
  • 修正: https://github.com/agno-agi/agno/pull/8716 の @harshsinha03 による小さなサンプルの PerformanceResult p95 を観測範囲内に維持する
  • 修正: CsvTools.query_csv_file 内の DuckDB テーブル名を https://github.com/agno-agi/agno/pull/8717 の @harshsinha03 によって引用
  • 雑用: @kausmeows による v2.6.21 を https://github.com/agno-agi/agno/pull/8707 でリリース
