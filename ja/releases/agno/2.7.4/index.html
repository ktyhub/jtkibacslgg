#アグノv2.7.4 #Changelog

新機能:

  • Superserve ツール: 長期実行エージェント用の Firecracker ベースのサンドボックス プラットフォームである Superserve で、エージェントが生成したコードを実行し、ファイルを管理するための SuperserveTools を追加しました。 ドキュメント を参照してください。
  • Plivo ツール: Plivo で SMS の送信、音声通話、電話番号検索を行うための PlivoTools を追加しました。 ドキュメント を参照してください。
  • The Context Company: The Context Company で実行されるエージェントを追跡するための可観測性統合が追加されました。 ドキュメント を参照してください。

改善点:

  • agno create の機能強化: インタラクティブなスターター テンプレートとプロジェクト名のプロンプト、4 つの新しいスターター (Azure、Helm、Modal、Render)、および自動 .env シード。
  • テレグラム ツール: pin_message、get_chat、get_file、react_with_emoji、さらに save_downloads と output_directory を追加して、ダウンロードしたファイルをディスクに保存します。
  • Tavily ツール: ドメイン、日付範囲、トピック、および国フィルターを検索に追加します。
  • Google ツール: Gmail、カレンダー、ドライブ、スライドにページネーションを追加します。
  • Oxylabs ツール: ページ全体のコンテンツをマークダウンとして返します。
  • ワークフロー: ルーター セレクターと条件エバリュエーターで run_context を受け入れ、session_state は非推奨になります。

バグ修正:

  • チーム:
    • 実行中に複数回一時停止するメンバーにユーザー入力を配信します。
    • メディアまたはメンバーの応答がすでに辞書になっている実行出力をシリアル化します。
  • エージェントOS:
    • チームの応答をストリーミングするときに、蓄積された実行出力をスキップします。
    • 履歴を上書きするのではなく、既存の ID を使用したセッションの作成を拒否します。
  • ワークフローとチームセッション: ゼロおよびマイナスの履歴制限を尊重します。
  • ワークフロー: ワークフローが途中で失敗した場合に、根本的なエラーを明らかにします。
  • Slack: チャネルごとにセッションの範囲を設定するため、チャネルが履歴を共有しなくなります。
  • Tavily ツール: 構成された抽出深さを適用します。
  • OpenRouter: 画像モデルから生成された画像を返します。
  • PostgresDb: コンポーネントがテーブル名をオーバーライドする場合は、create_schema=False を尊重します。
  • PubMed、Firecrawl、Spider ツール: 設定された通話ごとの結果制限を尊重します。
  • FixedSizeChunking: 重複部分がコンテンツを超える場合は、短いドキュメントを保持します。
  • CSVReader および ExcelReader: 各リーダーに独自のデフォルトの行チャンクを与えます。

何が変わったのか

  • 修正: CSVReader/ExcelReader は、https://github.com/agno-agi/agno/pull/8922 の @chuenchen309 による 1 つの変更可能なデフォルト RowChunking インスタンスを共有しなくなりました
  • 修正: https://github.com/agno-agi/agno/pull/8943 の @chuenchen309 によるオーバーラップ >= コンテンツの長さの場合、FixedSizeChunking がサイレントに短いドキュメントを削除する
  • [修正] https://github.com/agno-agi/agno/pull/8646 の @ormeilu により、既存の session_id に対して POST /sessions を冪等にします
  • [修正] https://github.com/agno-agi/agno/pull/8236 の @cyphercodes によるチーム SSE ストリームの実行出力アキュムレータをスキップする
  • 修正: WorkflowSession/TeamSession ヘルパーのゼロ/ネガティブ実行とメッセージ数をガード (https://github.com/agno-agi/agno/pull/8942 の @chuenchen309 により)
  • 功績: https://github.com/agno-agi/agno/pull/8868 の @sarveshpatil-plivo による SMS および音声用の PlivoTools ツールキットの追加
  • 修正: https://github.com/agno-agi/agno/pull/8938 の @Himanshu040604 による OpenRouter 応答から生成された画像を返す
  • 修正: https://github.com/agno-agi/agno/pull/6401 の @Orion7r による PubMed、Firecrawl、Spider ツールで設定された明示的な結果制限を尊重する
  • 修正: TeamRunOutput.to_dict メディア フィールド内の既にシリアル化された辞書と、https://github.com/agno-agi/agno/pull/8966 の @kausmeows による member_responses を処理
  • 功績: https://github.com/agno-agi/agno/pull/7369 の @flobo3 により、react_with_emoji ツールを TelegramTools に追加
  • 修正: https://github.com/agno-agi/agno/pull/8897 の @Mustafa-Esoofally によりクックブックから非推奨の show_tool_calls を削除
  • 修正: https://github.com/agno-agi/agno/pull/8933 の @Mustafa-Esoofally によるチャネル間の衝突を防ぐためのチャネル スコープの Slack セッション キー
  • クックブック: @rohilvagarwal による The Context Company の可観測性の例を https://github.com/agno-agi/agno/pull/8955 に追加
  • 修正: https://github.com/agno-agi/agno/pull/7547 の @shaun0927 による、resolve_db_from_config クローン パスで Postgres create_schema を保持する
  • 雑務: 共有のデフォルト OpenAI モデル ユーティリティを削除し、https://github.com/agno-agi/agno/pull/8384 の @maxpetrusenkoagent によってサンプル モデル ID を更新します
  • 功績: https://github.com/agno-agi/agno/pull/6548 の @shaunymca により pin_message、get_chat、get_file を TelegramTools に追加
  • 功績: https://github.com/agno-agi/agno/pull/8959 の @ashpreetbedi による agno create オンボーディングの改善
  • 功績: Gmail ツールにページネーションと max_results_per_request を追加 (https://github.com/agno-agi/agno/pull/8462 の @Mustafa-Esoofally により)
  • 功績: https://github.com/agno-agi/agno/pull/8896 の @Himanshu040604 により、tavily ツールで高度な検索パラメーターを公開
  • 雑用: https://github.com/agno-agi/agno/pull/9018 の @kausmeows による run_context を優先して、条件/ルーター ワークフローの session_state を非推奨にする
  • 修正: https://github.com/agno-agi/agno/pull/8937 の @Mustafa-Esoofally によるマルチラウンド チーム HITL の一時停止したメンバーの実行を維持する
  • 功績: Superserve サンドボックス ツールを追加 (@mohamedsobhi777 による https://github.com/agno-agi/agno/pull/8584)
  • 雑用: https://github.com/agno-agi/agno/pull/8831 の @Mustafa-Esoofally による pytest-split を使用して CI テストを並列化する

  • 修正: https://github.com/agno-agi/agno/pull/9025 の @kausmeows による「機能: Gmail ツールにページネーションと max_results_per_request を追加」を元に戻す
