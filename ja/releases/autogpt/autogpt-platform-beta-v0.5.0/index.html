AutoGPT autogpt-プラットフォーム-ベータ-v0.5.0

新機能 🎁

  • オンボーディング フロー - すべてのユーザーがプラットフォームを適切に理解できるようにします
    • feat(フロントエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9485 の @kcze によるオンボーディング フロー UI
    • 偉業(プラットフォーム): https://github.com/Significant-Gravitas/AutoGPT/pull/9511 の @kcze によるオンボーディング フロー バックエンド
  • 新しいエージェント ライブラリ エクスペリエンス - エージェントを実行し、そのステータスと出力を確認するための UX が大幅に向上しました。
    • 機能 (プラットフォーム/ライブラリ): エージェント ライブラリ v2 (@Pwuts 著、https://github.com/Significant-Gravitas/AutoGPT/pull/9407)
    • feat(プラットフォーム): https://github.com/Significant-Gravitas/AutoGPT/pull/9527 の @Pwuts によって実行されるエージェントのコスト表示
      • feat(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9520 の @majdyz によるノードとグラフの実行統計にコストを追加
    • 機能 (プラットフォーム): https://github.com/Significant-Gravitas/AutoGPT/pull/9546 の @Pwuts によるライブラリ エージェントの「削除」機能
    • 偉業(プラットフォーム): https://github.com/Significant-Gravitas/AutoGPT/pull/9547 の @Pwuts によるエージェント実行の「停止」+「削除」機能
    • 特技(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9568 の @majdyz によって作成されたエージェントのサムネイルを自動生成するための Ideogram を統合
    • 修正 (ライブラリ): https://github.com/Significant-Gravitas/AutoGPT/pull/9572 の @andrewhoker2 によるページの下部にメッセージをアンカーしました
    • 修正 (フロントエンド/ライブラリ): https://github.com/Significant-Gravitas/AutoGPT/pull/9591 の @Pwuts による I/O をレンダリングするために正しいグラフ バージョンを使用する
  • スマート意思決定者ブロック
    • 機能 (プラットフォーム) Smart Decision Maker Block by @Swiftyos (https://github.com/Significant-Gravitas/AutoGPT/pull/9490)
    • feat(blocks): https://github.com/Significant-Gravitas/AutoGPT/pull/9514 の @Swiftyos による Smart Decision Maker ブロックのブロックの使用法を有効にしました
    • 修正（プラットフォーム）: https://github.com/Significant-Gravitas/AutoGPT/pull/9531 の @Swiftyos による SDM ブロックのブロック コストを追加
    • 特技(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9540 の @majdyz によって出力されたスマート デシジョン ブロックとして会話履歴を追加します。
    • 修正 (バックエンド): 会話出力にプロンプトを追加し、https://github.com/Significant-Gravitas/AutoGPT/pull/9550 の @majdyz により SmartDecisionBlock の未使用の出力ピンを削除
    • 修正 (バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9551 の @majdyz による LLM の生のコンテンツを会話履歴として使用する
    • feat(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9552 の @majdyz によるスマート デシジョン ブロックにツール実行応答を追加
    • 機能 (バックエンド): SmartDecisionMaker エージェント ループ機能を改善し、https://github.com/Significant-Gravitas/AutoGPT/pull/9585 の @majdyz による Anthropics サポートを追加しました。
  • feat(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9534 の @ntindle によるバランス低下通知
  • feat(blocks): https://github.com/Significant-Gravitas/AutoGPT/pull/9583 の @ntindle によるリスト コメントの追加とコメント ブロックの更新

UI/UX の改善 ✨

  • 修正（フロントエンド）: マイナーな UI 調整、https://github.com/Significant-Gravitas/AutoGPT/pull/9504 の @majdyz による電話画面上のアクセスできないボタンを修正
  • 修正 (フロントエンド): UI のマイナーな変更。 https://github.com/Significant-Gravitas/AutoGPT/pull/9512 の @majdyz による LibraryV1 のバッジとボタンの位置を調整します
  • 特技(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9555 の @majdyz によるブロックの Web リクエストで安全な URL リダイレクトを有効にする
  • 修正（フロントエンド）: https://github.com/Significant-Gravitas/AutoGPT/pull/9482 の @Bentlybro による注目のエージェント カードのレイアウト + サイズ設定
  • feat(フロントエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9573 の @Pwuts によるボタン click ハンドラーの読み込みインジケーター

バグ修正 🐛🔨

  • 修正（フロントエンド）: https://github.com/Significant-Gravitas/AutoGPT/pull/9503 の @kcze によるビルダー ページ更新の Run/Stop ボタンを修正
  • 修正(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9582 の @ntindle による github チェックとステータス用に pydantic オブジェクトを正しくシリアル化しました。
  • 修正 (バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9578 の @Pwuts による add_marketplace_agent_to_library の破壊を解除

技術的な改善 ⚙️

  • HTTP RPC が Pyro を置き換えます
    • 偉業(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9508 の @majdyz によるマイクロ サービスの Pyro から FastAPI への移行
    • 修正（バックエンド）: https://github.com/Significant-Gravitas/AutoGPT/pull/9528 の @Pwuts によりデフォルトで RPC に Pyro を使用する
    • fix(backend): https://github.com/Significant-Gravitas/AutoGPT/pull/9529 の @majdyz による RPC エラーと欠落したグラフ Running ステータスの例外応答を修正
    • feat(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9533 の @majdyz による RPC 例外のエラー引数の伝播
    • 修正（バックエンド）: https://github.com/Significant-Gravitas/AutoGPT/pull/9535 の @ntindle によるタプルで複数の引数を許可します
    • 修正 (バックエンド): RPC サービスのログ レベルのしきい値を https://github.com/Significant-Gravitas/AutoGPT/pull/9576 の @majdyz によって WARNING に引き上げました
  • chore(backend/deps): https://github.com/Significant-Gravitas/AutoGPT/pull/9398 の @dependabot によって /autogpt_platform/backend の WebSocket を 13.1 から 14.2 にバンプします
  • 功績: https://github.com/Significant-Gravitas/AutoGPT/pull/9420 の @thomasrockhu-codecov による不安定なテストと失敗したテストに対する Codecov テスト分析を追加
  • chore(libs/deps-dev): https://github.com/Significant-Gravitas/AutoGPT/pull/9454 の @dependabot により、開発依存関係グループの /autogpt_platform/autogpt_libs で 1 つのディレクトリにある 0.9.3 から 0.9.6 に ruff をバンプします。
  • 特技(バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9506 の @ntindle による消印からのバウンスメールを処理する
  • 修正（フロントエンド）: https://github.com/Significant-Gravitas/AutoGPT/pull/9536 の @majdyz によりフロントエンドの未使用のストライプを削除
  • 修正 (バックエンド): https://github.com/Significant-Gravitas/AutoGPT/pull/9566 の @majdyz により利用可能な開始ノードがない場合に実行エラーが発生する
  • エラー処理とライフサイクルの改善によりプロセス管理を強化 (https://github.com/Significant-Gravitas/AutoGPT/pull/9565 の @rahmanlibi47 による)

ドキュメントの改善 📖

  • ドキュメント (セキュリティ): https://github.com/Significant-Gravitas/AutoGPT/pull/9581 の @ntindle による開示タイムラインの更新
  • Feat(Otto) https://github.com/Significant-Gravitas/AutoGPT/pull/9266 に @Bentlybro による初期 Otto Chat Bot コードを追加
