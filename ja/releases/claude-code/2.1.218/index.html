claude-code v2.1.218

パッチ 公開日2026年7月22日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.218

何が変わったのか

  • /code-review をバックグラウンド サブエージェントとして実行するように変更しました。そのため、レビュー作業が会話を埋めることはなくなり、スタックされたスラッシュ コマンドがレビュー ターゲットとして保持されます。
  • --ax-screen-reader モードでの単語および行の削除 (Option+Delete、Ctrl+W、Cmd+Backspace、Ctrl+U、Ctrl+K) の削除されたテキストのスクリーン リーダー アナウンスを追加しました。
  • ツール入力で \u プレフィックスが付いたセグメント (C:\Users\unicorn など) を含む Windows パスが CJK 文字に破損し、それらのファイルにアクセスできなくなる問題を修正しました。
  • 元に戻さずに会話を破棄する左矢印キーを修正しました。編集後にすぐに押すと確認を求められるようになり、エージェント ビューで Esc を押すとバックグラウンドで行われた会話に戻ります。
  • サーバーが接続に失敗した場合の HTTP ステータスとエラー テキストを claude mcp list および /mcp に追加し、先頭または末尾の空白が隠されている MCP 設定値に対する警告を追加しました。
  • ペーストされた改行を Ctrl+J としてエンコードする端末で、改行の代わりに j を使用すると複数行のペーストが 1 行に折りたたまれる問題を修正しました。
  • メッセージ ピッカーからの圧縮後に、圧縮前の古いトークンの使用状況を報告する /context を修正しました。
  • 「認証の変更を確認する」などの説明的な引数で失敗する /ultrareview を修正しました。検出結果のメモとして適用されたテキストを使用して、現在のブランチのレビューが実行されるようになりました。
  • 非対話型セッションでローカル レビューをサイレント実行する /code-review ultra を修正しました。クラウド レビューが起動されるようになりました。
  • Bedrock アプリケーション推論プロファイル ARN およびその他の構成マップされたアップストリーム モデル ID を構成されたモデルのレートで価格設定するためのゲートウェイ支出計測を修正しました
  • 長い IDE 選択が絵文字の途中で切り詰められたときの mojibake と、ツール エグゼキュータ エラーが通知なくドロップされる可能性がある問題を修正しました。
  • ファントムターンを開始して放棄する可能性があり、終了後にプッシュされた入力が一貫して拒否されるエンジン分解レースを修正しました
  • ツール呼び出しが中断された後の偽の「[リクエストがユーザーによって中断されました]」メッセージと、ツールが応答中に中止されたときにトランスクリプトに残るペアになっていない tool_use ブロックを修正しました
  • --ax-screen-reader モードで入力の最後に入力されたスペースをエコーするのではなく、VoiceOver が「改行」を読み上げる問題を修正しました。
  • プラグインと設定パネルがターミナル カーソルをフォーカスされた行に移動しない問題を修正したため、スクリーン リーダーと拡大鏡は矢印キー ナビゲーションに従うことができます
  • 深くネストされた監視ディレクトリ ツリーが削除または移動されたとき、および深くネストされた UI ツリーをレンダリングするときのクラッシュ (最大呼び出しスタックの超過) を修正しました。
  • PR を作成またはリンクした直後にセッションが終了すると、プル リクエスト イベントが時々失われる問題を修正しました
  • パーティション分割された AWS リージョンおよびプロキシ専用ネットワークでの役割引き受けプロファイルのプロファイル検証に失敗する Bedrock セットアップ ウィザードを修正しました
  • 単調クロックでターンのタイミングを調整することによってシステムクロックを調整した後の、まれにマイナスまたは不正確なターン持続時間の測定を修正しました
  • claude.ai に接続されていない claude.ai コネクタを過剰にカウントする「N MCP サーバーには認証が必要です」という起動通知を修正しました
  • 履歴の書き込みが競合または失敗したときに、プロンプト履歴エントリが削除または複製される問題を修正しました
  • 大量の思考予算によるコンテキスト オーバーフロー エラーの後に、同じ運命のリクエストを再送信する再試行ループを修正しました。 Ctrl+B バックグラウンド処理は、他のパスと同じバックグラウンド シェル キャップを適用するようになりました。
  • untrusted フォルダーから実行されるエージェント フロントマター フックを修正しました。フックでは、ワークスペース trust を受け入れるためにエージェント ファイルの独自のフォルダーが必要になりました。
  • ヘッドレスセッションおよびSDKセッションでの圧縮後にフォークセッションリネージが失われる問題を修正
  • 履歴に不正なデルタ添付ファイルが含まれている場合、再開されたセッションが毎ターン失敗するか、再開時にクラッシュする問題を修正しました
  • /ultrareview エラー フィードバックを改善し、クロードが無効な引数を変更せずに再試行するのではなく修正できるようにしました。
  • 自動モードの改善:angerous-rm、background-&、および疑わしい Windows-path チェックで許可ダイアログが開かなくなりました。代わりに自動モード分類子がそれらを判断します
  • IDE インタラクションに対するサンドボックス コマンド制限の改善
  • 許可が対象とするリポジトリのルートに名前を付けるための trust ダイアログを改善しました
  • /deep-research を手動で呼び出した場合にのみ開始するように変更しました。クロードは自分で起動しなくなりました
  • 計画モードを auto に変更し、静的アナライザーが読み取り専用であることを証明できない Bash コマンドのプロンプトを表示しなくなりました。代わりに自動モード分類子がそれらを判断します
  • /config model=<x>またはリモコン経由でモデルを切り替えた結果、高速モードが変更された場合のアナウンスを追加しました
  • サーバー管理の設定が変更され、無害な機能とコストの切り替えによって設定の承認プロンプトがトリガーされなくなりました
  • プラグインの名前空間用に予約されている : を含むエージェント名を拒否するようにエージェント マークダウン ファイルを変更しました。
  • context: fork のスキルをデフォルトでバックグラウンドで実行するように変更しました。 background: false を使用してスキルごとにオプトアウトする
  • true/false と並んで、スキルおよびプラグイン フロントマター ブール値の許容値として yes/no/on/off/1/0 (大文字と小文字を区別しない) を追加しました。
  • ワーカーが置き換えられた後もリモート セッションがハートビートを送信し続ける問題を修正しました。これにより、存続期間の長いデスクトップと IDE プロセスが数秒ごとに拒否されたリクエストを永久に再試行することになります。
