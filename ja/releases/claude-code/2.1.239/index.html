claude-code v2.1.239

パッチ 公開日2026年8月21日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.239

何が変わったのか

  • コスト見積もり (/cost、ステータス行、--max-budget-usd) には、データ常駐ワークスペースの 1.1× US のみの推論プレミアムが含まれるようになりました。
  • Bedrock、Vertex、Foundry、およびこれまで除外されていたその他のセットアップに 1 回限りのフルスクリーン レンダラー オファーを追加しました。新しいインストールが全画面で開始されるようになりました
  • Python プロジェクトを anthropic 0.x から 1.x に移行するための /claude-api upgrade を追加し、1.x 用のスキルの Python リファレンスを更新しました (タイムアウトは httpx.Timeout ではなく anthropic.Timeout を使用します)
  • クラウド セッション: claude.ai から同期されたプラグインは name@synced として表示され、claude plugin enable/disable <name>@synced と連携して動作し、インストールした同名のプラグインをオーバーライドすることはありません。
  • Alpine/musl ビルド: ネイティブ イメージ ペースト、clipboard、およびオーディオ キャプチャ アドオンがロードされるようになりました (ランタイムによって拒否された glibc バイナリの代わりに musl でビルドされたバイナリがロードされます)
  • 毎月の使用制限がすでに使い果たされているときに表示される使用制限メッセージには、セッションまたは週ごとの制限がリセットされたときにも表示されるようになりました。
  • 応答 Content-Type ヘッダーを削除するプロキシの背後での Bedrock ストリーミングを修正しました。非ストリーミングを毎ターン再実行することで、課金される API コールが静かに 2 倍になりました。
  • SSO プロファイルおよび awsAuthRefresh で Bedrock を使用する場合、HTTPS プロキシの背後で起動時にクロード コードがハングする問題を修正しました。資格情報の事前チェックでは HTTPS_PROXY が考慮されるようになりました。
  • 存在しないディレクトリから Claude Code を起動するときの生のクラッシュ ダンプを修正しました。明確なメッセージが表示されるようになりました
  • Claude Code プラグインが接続されている場合、JetBrains IDE ターミナルで編集および書き込み呼び出しが約 5 秒間一時停止する問題を修正しました
  • プロンプトがキューに入れられた状態で Esc キーを押すと、次のターンが早く終了し、クロードがまだ作業している間セッションがアイドル状態のままになり、後で再実行アクションを繰り返すことができるレースを修正しました
  • WebFetch が、意図した 15 分間ではなく、セッション全体にわたって期限切れのページ コンテンツをメモリに保持する問題を修正しました。
  • アイドル状態のワーカーの再起動後にプラン モードから再開されるクラウド セッション (Web、デスクトップ、モバイル アプリ上の Claude Code) を修正しました
  • フルスクリーン モードで clip される端末よりも高い MCP 引き出しフォームを修正しました。フォームはウィンドウに収まるようになり、スクロールすることで非表示のフィールドに到達でき、Accept/Decline が常に表示されます。
  • クラウド セッションまたは SDK setMcpServers() 経由でのセッション中の再接続で一時的な 5xx が発生した後、リモート MCP サーバーが失敗したままになる問題を修正
  • 名前変更後に約 64 KB を超える会話が書き込まれた後、カスタム セッション タイトルが /resume から消える問題を修正
  • パスが _、-、または . などの文字によってのみ異なる別のディレクトリからセッションを選択する claude -c/再開を修正しました
  • ファイルのみがタッチされた場合、または単に再度開かれた場合に、/resume とエージェント ビューでセッションが最近変更された (および並べ替えられた) と表示される問題を修正しました。
  • 全プロジェクト モードでの /resume が、削除されたディレクトリ (削除されたワークツリーなど) に cd を指示する問題を修正しました。このようなセッションは現在のディレクトリで再開されます
  • 背景と同じ色のテキストを含む全画面モードで拡張ツールの結果をレンダリングする dark-ansi テーマを修正しました
  • 起動するたびに応答できない場合に再表示される全画面レンダラー プロンプトを修正しました。 3 回の起動で表示された後に停止するようになりました
  • ターゲットが gitignored ディレクトリに存在する場合、**/ で始まる .worktreeinclude パターンが何も通知せずに一致する問題を修正しました。
  • .md ファイルが UTF-8 BOM で始まるエージェント、スキル、コマンドがサイレントに無視される問題を修正
  • 一部のモデルで応答内でリテラルの <message> タグをエコーする /insights を修正しました
  • 効果のないマーケットプレイス metadata.pluginRoot を修正しました。ドキュメントに記載されているように、裸のプラグイン ソース名がその下で解決されるようになりました。
  • マウスレポートが複数の書き込みに分割されて到着したときに、プロンプトに "35;150;7M" のようなテキストを挿入するブラウザベースの端末でのマウスの動きを修正しました。
  • エフォート/ウルトラコードステータスバッジの色が無視されるカスタムテーマのオーバーライドを修正しました
  • OpenTelemetry トレースの断片化を修正しました。PreToolUse フックによって延期されたツールの実行は、新しいトレースを開始するのではなく、元のターンのトレースで再開されるようになりました。
  • エージェント ビューの vim モードを修正: Escape は NORMAL モードに切り替わり、プロンプトをクリアせずにテキストを保持するようになりました。
  • Shift+矢印キーで拡張されたテキスト選択をサイレントに削除するselection:copyキーバインドを修正しました
  • voice.enabled設定で音声ディクテーションを有効にした後も/voiceスタートアップヒントが表示される問題を修正
  • シェルモード (!) のタブ補完で ./ が ./script パスから削除され、シェルが実行できないコマンドが残る問題を修正しました。
  • ターミナル ウィンドウを click したときにフォーカスを戻すためだけに、許可プロンプトに応答するかボタンを押すと全画面モードになる問題を修正しました
  • 最新のメッセージをカバーする全画面モードのスラッシュ コマンド パネル (/config、/model など) を修正しました。会話はパネルの上に固定されたままになります
  • クロードがまだ応答している間に開くと、/workflows 詳細ダイアログが端末からオーバーフローし、ヘッダーが画面外に消える問題を修正しました。
  • Linux サンドボックスが存在しない .git/config.worktree を読み取り不能にし、extensions.worktreeConfig が設定されたリポジトリ内のすべてのサンドボックス git コマンドが壊れる問題を修正しました。
  • セッションの作業ディレクトリが削除された後に「posix_spawn ENOENT」で失敗するフックを修正しました。代わりにプロジェクトのルートまたはホーム ディレクトリから実行されるようになりました。
  • パターンがターゲットではなくルール ディレクトリまたはシンボリック リンクを指定している場合、claudeMdExcludes がシンボリックリンクされた .claude/rules ファイルを除外しない問題を修正しました。
  • 2 つのクロード コード プロセスが 1 つのバックグラウンド ジョブの状態を共有する場合に、セッション タイトルがリモート コントロールに同期する暴走を修正しました (2.1.232 回帰)。タイトルの更新は重複排除され、レートが制限されるようになりました
  • タイトルが / で始まるセッションが SendMessage でアドレス指定できず、ListAgents で「(untitled)」と表示される問題を修正しました。
  • Ctrl+W、Ctrl+U、Ctrl+K、Option+Backspace、Option+D、vim df/dt でカーソルが中にあるときに破損した [Pasted text #N] プレースホルダーを残す問題を修正しました。
  • ログイン コード フィールドなどのマスクされた (パスワード スタイル) 入力を修正し、テキストを Ctrl+Y で別の場所に貼り付けたり、Esc を 2 回押してクリアしたときにプロンプト履歴に保存したりできるようにしました。
  • Ctrl+Backspace で検索ボックス内の単語ではなく 1 文字を削除する問題を修正しました
  • 組織のポリシーチェックによって拒否されたリクエストが、拒否が表示される前に再送信される問題を修正しました
  • スキルの元の引数が新しいリクエストとして再実行されないように、圧縮後に表示されるリマインダーを改善しました
  • ツール使用行の長いファイル パスが中央で切り詰められ、1 行に収まるようになりました。
  • 長い SessionStart または Setup フックが実行されている間、リモート セッションはキープアライブを送信し続けるため、フック中にコンテナーがアイドル状態で取得されません。
  • /goal: 長時間実行されるバックグラウンド作業でのチェックインの繰り返しが、30 分ごとに繰り返されるのではなく、バックオフ (30 分、次に 1 時間、その後 2 時間ごと) になりました。
  • /goal: claude --resume ピッカーからセッションを再開すると、アクティブな目標が復元されるようになりました。
  • ListAgents はセッションに自分の名前 (ピアがメッセージを送信するために使用する名前) を伝え、SendMessage は自分の名前に対して、「名前付きのエージェントはありません…」の代わりにそのように伝えます。
  • ListAgents と /list-agents にライブ チームメイトがリストされるようになりました (以前はサブエージェントと他のセッションのみが表示されていたため、連絡可能なチームメイトは不在のように見えました)
  • keybindingFlavor: "readline" は、Bash の単語キーにも一致するようになりました。Alt+F および Ctrl/Option+→ は単語の末尾で停止し、Alt+D で単語を削除し (Ctrl+Y で貼り付け戻します)、句読点で単語を区切ります。
  • 永続的再試行モード (CLAUDE_CODE_RETRY_WATCHDOG) は、組織の支出制限およびクレジット不足のエラーが発生した場合、リセットを無期限に待つのではなく、ただちに失敗するようになりました。
  • Chrome のクロード: /clear はセッションの Chrome タブ グループを閉じるようになり、空のグループは /resume とクロード コードの終了時に閉じられます。
  • リモート セッション: モバイルからアップロードされた画像には保存されたファイル パスが含まれるようになり、クロードは作成したファイルに画像をコピーできるようになりました。
  • Web 上の Claude Code: Bash やその他のツールから API 以外の anthropic.com ホスト (www、docs など) へのリクエストは、セッションのネットワーク プロキシを経由するようになりました。そのため、環境で許可されているドメインが適用されます。
  • リモート コントロール: アカウントでリモート コントロールが有効になっていない場合の、より明確なメッセージと claude doctor の文言
  • Windows: クロスセッション メッセージングが利用可能になったので、macOS や Linux と同様に、マシン間の Claude Code セッションが SendMessage でメッセージを送り合ったり、ListAgents でお互いを見つけたりできるようになりました。
  • [VSCode] 使用量制限バナーの「使用量の表示」は、バナーの中央にフローティングするのではなく、警告テキストとインラインに配置されるようになりました。
