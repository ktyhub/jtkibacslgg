claude-code v2.1.259

パッチ 公開日2026年9月2日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.259

何が変わったのか

  • managedMcpServers 管理設定の追加: 組織はすべてのユーザーに HTTP/SSE MCP サーバーを提供できます (.mcp.json と同じエントリ形式)。実行するコマンドを指定するエントリはスキップされます
  • 無人のヘッドレス ホスト用に --permission-prompts none を追加しました。アクティブな許可モード (自動モードを含む) が決定を続ける間、プロンプトが表示されるものはすべて自動的に拒否されます。
  • glab mr create/merge/close/reopen/note/update の認識を追加したため、GitLab マージ リクエストは、折りたたまれたツール サマリで MR !N として表示され、フッター MR バッジが更新されます。
  • 機械可読検証レポート用に --json を claude plugin validate に追加
  • 同時セッションがお互いの ~/.claude.json の変更をサイレントに元に戻す問題を修正 — ワークスペース trust がリセットされなくなり、一度に多くのセッションを実行しても MCP/プロジェクトの状態が失われなくなりました
  • 一度拒否された思考がその後のターンごとに再び拒否される会話を修正
  • オプション値 (--ignore-revs-file=.env、-f.env、@file)、git diff/git grep ファイル オペランド、または cd DIR && cat FILE コンパウンドとして指定されたファイルをカバーしない Bash Read() 拒否ルールを修正しました。拒否されたファイルを保持するディレクトリ上で grep -r/cp -r が質問するようになりました。
  • テレメトリが無効になっているセッションで OAuth トークンが更新されるとプロンプト キャッシュが無効になる問題を修正しました
  • 何百ものツール呼び出しで長いターンをした後、空白の会話が表示される全画面モードを修正しました
  • コマンドまたはスキルのフロントマター model: がモデルを指定したときに、サポートされていないモデルでターンが実行される自動モードを修正しました。ターンはセッション モデルを維持するようになりました
  • クロード コードが認識しないモデル バージョンの頂点スタイル モデル ID (@YYYYMMDD サフィックス) で CLAUDE_CODE_MAX_CONTEXT_TOKENS が無視される問題を修正
  • 実行中のシェルコマンドのライブ出力プレビューで、以前の行が折り返されたときに最新の行が非表示になる問題を修正しました。
  • claude.ai ユーザーの起動ごとに実行されるバックグラウンド GitHub 接続チェックを修正しました。結果は起動後も記憶されるようになりました
  • 保存されたセッションにペイロードのない添付ファイル エントリが含まれている場合に --resume が失敗する (および --continue が空の会話を開く) 問題を修正しました。
  • インタラクティブセッションで無視されるカスタムコマンドとスキルの前付け問題 model: を修正
  • 古いバージョンから続く会話で「予期しないパラメータ note」エラーが発生してアーティファクトの公開が一度失敗する問題を修正
  • MDM によって構成されたポリシー ヘルパーまたは管理対象設定ファイルがすでに実行されている場合、起動時に管理対象 forceRemoteSettingsRefresh が無視される問題を修正しました。
  • git rev-parse が「git リポジトリではありません」以外のメッセージで失敗するマシン上で、フックで作成されたワークツリーを拒否するワークツリー分離を修正しました。
  • user.email、organization.id、および user.account_uuid 属性が欠落しているクラウド セッションからの OpenTelemetry メトリクスとイベントを修正しました
  • 起動時にツールがリストされているときに切断される MCP サーバーが、エラーを報告する代わりにツールなしで接続されていると表示される問題を修正しました
  • ファイル編集許可ダイアログで、変更された行が何も表示されずに短く表示される場合がある問題を修正しました。
  • 一時的な git プローブの失敗後に既知のリポジトリ ID を削除するリポジトリ検出を修正しました
  • 管理設定ファイル、ドロップイン、MDM plist、または HKLM 値を解析できない場合に、管理設定がサイレントに適用されなくなる問題を修正しました。Claude Code は起動を拒否し、ソースに名前を付けるようになりました。
  • リモート コントロール セッションでバックグラウンド エージェントとワークフローを実際に停止しない Stop を修正しました。強制終了されたタスクはプロセスが終了するまで表示され、再停止できるようになりました。
  • 前回停止した実行がまだ終了している間にワークフローの実行を再開すると、エージェントの重複コピーが実行される可能性がある問題を修正しました。
  • github.com のマーケットプレイス リポジトリ URL の末尾にスラッシュまたはぶら下がっている ?/# があり、使用できない .git クローン URL が生成される問題を修正しました。
  • ブロック停止フックにより、ブロック後のターンがそのターンからのモデルの推論を失い、一部のモデルではプロンプト キャッシュを見逃す問題を修正しました。
  • ブラウザでホストされる MCP サーバーのページが消えた後、リモート (claude.ai) セッションがターンを開始するまでに 60 秒かかる問題を修正
  • メインチェックアウトに到達できない一般的な Bash ループ、xargs パイプライン、およびランチャーでラップされたコマンドを拒否するワークツリー分離セッションを修正しました
  • テキスト測定値を再利用することで、端末のサイズ変更と長い応答の最初のレンダリングのパフォーマンスが向上しました
  • /workflows エージェントの詳細の改善: JSON の結果は構文の色と実際の改行でわかりやすく表示され、長い結果は展開トグルの後ろに折りたたまれます。
  • ヘッドレス/SDK セッション開始の改善: MCP サーバーの接続が完了すると、最初のターンが最大 50 ミリ秒早く開始されます。
  • /install-github-app を改善して、GitHub のみであることを説明し、GitLab リポジトリ内で実行する場合に GitLab CI/CD ドキュメントを指すようにしました。
  • ネストされたバックグラウンド サブエージェントの結果が親サブエージェントのトランスクリプトに保存されるように改善され、再開されたサブエージェントはそれらを保持し、共有トランスクリプトに配信が表示されるようになりました。
  • ユーザーが追加したサーバーのみを管理するように allowedMcpServers を変更しました。ホワイトリストで除外するために使用したリテラルの managed-mcp.json サーバーが、アップグレード時に読み込まれるようになりました。 deniedMcpServers を使用してオフにしてください
  • [VSCode] セッション リストのサイドバーにアクティブなクイック フィルターとステータス フィルター メニュー (入力が必要、作業中、完了) を追加しました。
  • セッションの一時停止中にコネクタツールの許可プロンプトが承認された後、リモートセッションとスケジュールされたセッションが何も行われない問題を修正しました
