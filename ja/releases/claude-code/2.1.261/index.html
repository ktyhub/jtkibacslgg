claude-code v2.1.261

パッチ 公開日2026年9月4日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.261

何が変わったのか

  • プロキシがエンドポイントを通過しないなど、組織のポリシーを読み込めなかった理由を示す「組織ポリシー」行を /status および claude doctor に追加しました。
  • クロードがファイルに保存される前にインラインで受信するコマンドおよびバックグラウンド タスクの出力量を最大 128,000 文字まで増やす bashOutputMaxChars および taskOutputMaxChars 設定を追加しました。
  • プロンプトが大きすぎてコマンド ラインに渡すことができない場合に、ファイルからサブエージェント システム プロンプトを読み取るための --append-subagent-system-prompt-file を追加しました。
  • ロードされたどのスキルが未使用になるか、およびコンテキスト内でそれらのコストがいくらになるかを表示するための /skill-doctor を追加し、それらを削除できるようにしました
  • 入力または貼り付けた文字が、高速入力またはキーの繰り返し中に順序が崩れたり、ドロップされたりする場合がある問題を修正しました。
  • 作業ディレクトリが /net 自動マウント上にある場合に、誤った「解決できませんでした」エラーを出力する /add-dir <subdirectory> を修正しました。
  • AWS または AWS 認証情報ヘルパーが応答しない場合に Bedrock セットアップ ウィザードがハングし (明確なエラーが発生してタイムアウトするようになりました)、TLS 検査プロキシの背後でモデル チェックが失敗する問題を修正しました。
  • enabledPlugins で管理設定が強制的に有効にすると、claude.ai から同期されたプラグインが破棄され、失敗する可能性があるマーケットプレイスのクローンにフォールバックするクラウド セッションを修正しました。
  • プロンプト入力でインライン [Image #N] チップの直前の文字を削除できない問題を修正
  • セッションを再開すると、フック出力や並列ツール呼び出しに関するその他のコンテキストが失われる問題を修正しました。これにより、再開されたリクエストが変更されました。
  • 電話、ブラウザ、または claude.ai アプリが端末セッションに接続したとき、または端末でモードが変更された後、リモート コントロールで古い権限モードが表示される問題を修正しました。
  • 接続された電話やブラウザからターンを停止した後、または /clear などのローカル スラッシュ コマンドを実行した後、リモート コントロール セッションがまだ動作しているように表示される (スピナーと [停止] ボタンがスタックする) 問題を修正しました。
  • 最初のプロンプトの直後、ターンが開始される前に送信された停止または割り込みを無視する SDK およびクラウド セッションを修正しました。ターンは最後まで実行されずに停止するようになりました
  • /teleport でプルしたセッションをリモート コントロールが接続されたセッションにアップロードし、電話や Web 上で元のセッションに追加されて表示される問題を修正しました
  • ネイティブ Windows 上の TLS 検査企業プロキシの背後で Remote Control の受信イベント ストリームが失敗する問題を修正
  • 努力が設定からのものである場合、claude.ai でデフォルトの努力レベルを表示するリモート コントロール セッションを修正しました
  • Google 資格情報チェックが遅い場合、資格情報がまだ有効であるにもかかわらず、起動時にブラウザを開く gcpAuthRefresh を修正しました
  • 起動コネクタの取得がタイムアウトになった場合、セッション全体にわたって claude.ai コネクタが存在しない問題を修正しました。CLI はバックグラウンドで再試行するようになりました。
  • バックグラウンド エージェントが再開できず、タイトなループでウェイクアップが再試行された場合に高い CPU 使用率が持続する問題を修正しました。
  • 新しいバージョンにゲート設定された機能フラグが、同じマシン上で実行されている古いクロード コード バージョンに適用されることがある問題を修正しました
  • 使用量エンドポイントがレート制限されている場合、または起動直後に開かれた場合に、/usage と VS Code 使用量パネルでモデル固有の週次制限行が削除される問題を修正しました。
  • トランスクリプトに記録された不正な形式のセッション ID を採用する claude -p --resume <file> を修正しました。代わりに新しいセッション ID で再開されるようになりました
  • バックグラウンド ワークフローまたはエージェントがまだ実行されている間にセッションが終了したことを示すターミナルの進行状況インジケーター (iTerm2、Ghostty、ConEmu) を修正しました。
  • コンテナの行方向と列方向が切り替わった後、ボックスが間違った高さでレンダリングされる可能性があるまれなレイアウトの不具合を修正しました
  • trusted プロキシがポートを X-Forwarded-For に追加するときのクロード アプリ ゲートウェイ client IP を修正しました。アクセス リストが設定されている場合、読み取り不能なエントリは 403 を取得するようになりました。
  • 端末 CLI が protobuf を使用している場合でも、Claude アプリ ゲートウェイが Claude Desktop に OpenTelemetry を JSON としてエクスポートするように指示するため、protobuf のみのコレクターがデスクトップのデータを拒否する問題を修正しました。
  • アップデートのアーティファクトのみを監視している間、デスクトップと Web がセッションをビジーとして表示する問題を修正
  • Chrome file_upload の Claude が、Claude デスクトップ アプリから実行されるローカル Cowork セッションで「パス: 予想される配列、未定義を受け取りました」というエラーで失敗する問題を修正
  • SendMessage が、別のマシン上のオフライン リモート コントロール セッションで配信時の状態を読み取るように修正されました。結果は、マシンが再接続されるまで配信がキューに入れられることを示します
  • バックグラウンドの Bash コマンドで実行される CLI からのプラグイン インストール ヒントを修正しました。それらは検出されるようになり、生の <claude-code-hint> タグが会話に漏れなくなりました。
  • インプロセスエージェントチームのチームメイトが第 1 ターンのツールとスキルのアナウンスを第 2 ターンに再送信する問題を修正しました。これにより、リクエストのプレフィックスが変更され、プロンプトのキャッシュが見逃されました。
  • Claude Code がモデルを認識したときに、生の Bedrock、Vertex AI、または LLM ゲートウェイ ID の代わりにモデル名を表示するように、/model ピッカーと VS Code モデル ピルを改善しました。
  • GOOGLE_APPLICATION_CREDENTIALS が設定されている場合の Google Vertex AI の起動の改善: API client の作成で Google Cloud プロジェクトの検出が再実行されたり、余分な gcloud プロセスが生成されなくなりました
  • ストリーミング パフォーマンスの向上: 更新のたびに、すでにレンダリングされたブロックがレイアウトによって再チェックされなくなりました。
  • 位置パラメータおよび二重引用符で囲まれた sh -c スクリプト内の rm -rf もキャッチするように、危険な rm 安全プロンプトを改善しました。
  • API が応答ヘッダーを送信しない場合の処理が改善されました。再試行はさらに 3 分間ではなく API_TIMEOUT_MS (デフォルトでは 10 分間) まで待機するようになり、メッセージに変更内容が示されます。
  • 管理設定のロード (起動時または /login 後) でクロード アプリ ゲートウェイ 403 を変更し、新しいサインインをアドバイスするのではなく、組織に対してクロード コードが有効になっていない可能性があることを示すようにしました。
  • 管理設定が forceLoginMethod: "gateway" に固定されているマシンを、残りの API キーまたは claude.ai ログインを無視して /login を要求するように変更しました。 Bedrock、Vertex AI、Foundry のセッションは影響を受けません
  • パブリック ダイアグラム レンダラーの URL にコンテンツをパックするリンクをそのサイトへのアップロードとして扱うように自動モードを変更しました。要求しない限り自動承認されなくなりました。
  • Bash に一致するようにプロンプトの単語編集キーを変更しました。Ctrl+W は削除して空白に戻し、Alt+F と Alt+D は単語の終わりで停止し、句読点で単語を区切ります。 keybindingFlavor はもう効果がありません
  • トークン カウンティング API が利用できない場合に、特別な小規模モデルのリクエストではなく、ローカル推定を使用するように /context トークン カウンティングを変更しました。
  • [VSCode] カスタム出力スタイル ファイルを作成してすぐにリストする「カスタム スタイルの構築」ウォークスルーを出力スタイル メニューに追加しました。
  • [VSCode] MCP サーバー ダイアログにサーバーの追加フォームと削除アクションを追加したため、IDE を離れることなく MCP サーバーを追加および削除できます。
  • [VSCode] ターミナル、別の VS Code ウィンドウ、または Claude デスクトップで開いているセッションのセッション リストに中空のリングを追加したため、セッションが閉じているように見えなくなりました
  • [VSCode] 許可プロンプトと質問プロンプトに折りたたむボタンを追加したため、それらの背後にある会話を無視せずに読むことができます。プロンプトの横のスペースで会話がスクロールされるようになりました
  • [VSCode] セッション リストの右側の click メニューに「セッションのアーカイブ」を追加し、アーカイブ解除に独自のアイコンを与えました
  • [VSCode] クラウド セッションがシャットダウンしたときに切断された質問を declined として扱う、Web 上のクロード コードからテレポートされたセッションを修正しました。
  • [VSCode] ウィンドウとともに復元されたタブでセッション タブの [名前の変更] ボックスが空で開く問題を修正しました。現在の名前で始まるようになりました
  • [VSCode] セッション リスト パネルの折りたたまれたセクションが、パネルがロードされるたびに一時的に展開されて表示される問題を修正しました。
  • [VSCode] 質問が回答を待っている間など、クロードが先に進んだ後もツール呼び出しがまだ実行中であるように表示されるフォーカス ビューを修正しました
  • [VSCode] フォーカスされていないクロード タブのセッション ID が修正されると、セッション リストのアクティブ行のハイライトが古くなってしまう問題を修正しました。
  • [VSCode] クロード タブにフォーカスがあるときに、Cmd/Ctrl+Shift+T を再度開くとディープリンクが開き、クロード タブがクロード エディター グループの外に配置される問題を修正しました。
  • [VSCode] Web 上のクロード コードから開かれたセッションを 2 つのグループに入れるセッション タブの [グループに追加] を修正しました。セッションリストに表示されているエントリが移動されるようになりました
  • [VSCode] ウィンドウが 2 回リロードされるまで、組織が無効にしたモデルを表示するモデル ピッカーを修正しました。
  • [VSCode] VS Code がタブのビューをリロードした後、セッション リストから開かれたタブがそのセッションにジャンプして戻る問題と、Web セッションから開かれたタブがテレポートを再開するか空のままになる問題を修正しました。
  • [VSCode] ウィンドウのリロード直後、または設定ファイルにエラーがあるときに質問が行われた場合、以前のセッションの /btw サイド質問履歴が上書きされる問題を修正しました。
  • [VSCode] Claude.ai または Console アカウントでサインインしたときにクロード パネルがリロードされた後、保留中の質問カードが再表示されない問題を修正しました。
  • [VSCode] あるパネルが設定ファイルからサードパーティプロバイダーを選択した後、ウィンドウの他の Claude パネルに claude.ai のみの機能が表示されたままになる問題を修正しました。
  • [VSCode] クロード コードがログインなしを報告するか、ログインがないためにリクエストが失敗した場合に、ログイン プロンプトを無効にする設定にもかかわらずサインイン画面が表示される問題を修正しました。
  • [VSCode] 前のプロンプトで入力されたテキストを保持し、すぐに 2 番目の click を受け入れる、次にキューに入れられる権限プロンプトを修正しました。
  • [VSCode] セッション リストのみが表示されていたウィンドウで、インストール ダイアログなしでクロード サイドバーを開くインストール プラグイン リンクを修正しました。
  • [VSCode] [アカウントと使用状況] ダイアログが開かれるまで、サイドバーの使用量メーターが新しいウィンドウで空のままになり、0% の使用量制限がメーターに表示されない問題を修正しました。
  • [VSCode] 新しい会話の後にグループが失われる「このグループで新しいセッションを開始」と、サイドバーの未読リストが読み込まれる前に終了したセッションの未読ドットが欠落する問題を修正しました。
  • [VSCode] 実行中のターン中に未読が表示されたり、セッション リストから開かれたタブでエディターのタブ バッジが表示されなかったり、アーカイブされたセッションに対して「セッション タブをグループに追加」が何も行われない問題を修正しました。
  • [VSCode] 「すべてのセッションでリモート コントロールを有効にする」を修正し、反転すると他の VS Code ウィンドウで開いているセッションにもすぐに適用されるようになりました。
  • [VSCode] タブがまだ Web セッションの下に記録されていた claude.ai から継続したセッションのセッション リストのオープン フィルターを修正し、フィルター メニューのセクションにスクリーン リーダーのラベルを付けました。
  • [VSCode] モデル ピッカーをすべてのモデルの 1 つのフラット リストに変更し、古いモデルのスペルの行が最後にリストされるようにしました。
