claude-code v2.1.267

パッチ 公開日2026年9月9日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.267

何が変わったのか

  • maxEffortLevel 設定の追加 (トップレベル、または modelSettings の下のモデルごと): Bedrock、Vertex、Foundry を含むすべてのプロバイダーの労力レベルに上限を設けます。ユーザーは引き続き低いレベルを選択できます
  • 会話の記録されたプロンプトを再利用するのではなく（プロンプト テキストを反復するため）、リクエストごとにシステム プロンプトを新たにレンダリングする --system-prompt-snapshot off を追加しました。
  • 管理設定にサンドボックスが必要な組織の起動時にクラウドでスケジュールされた Cowork タスクが失敗する問題を修正
  • モバイル client で空白になる /context およびその他のローカル コマンド出力を修正しました
  • エージェント ビュー内で tmux または ssh セッションに再接続した後、Shift+Enter および Option+Backspace が機能しない問題を修正しました。
  • 全画面モードで上にスクロールすると、会話の上部に薄暗いラストプロンプトヘッダーが表示されない問題を修正しました
  • 大規模な出力スキーマを含むワークフロー agent() 呼び出しが、安全分類子によってチェックされる代わりに自動モードで拒否される問題を修正しました。
  • バックスラッシュを含むマーケットプレイスのエントリ パスが、macOS および Linux 上でフェッチされたマーケットプレイスの包含チェックをバイパスする可能性があるケースを修正しました。
  • 再認証エラーが表示される前に、Claude Desktop などのホスト アプリで期限切れの AWS または Google Cloud 認証情報が一般的な「リクエストが失敗しました」で 10 回再試行される問題を修正しました。
  • /compact または -p --resume 経由で別のスラッシュ コマンドが実行された後のセッションの再開を修正しました。偽りの「中断したところから続行」です。ターンは挿入されなくなりました
  • 大規模なセッションの再開を修正しました (5 MB を超えるトランスクリプト): 並列ツール呼び出しとそのフック出力が、リロードされた会話からドロップされなくなりました
  • マネージド allowedHttpHookUrls、httpHookAllowedEnvVars、allowedChannelPlugins が読み取り不可能な場合に、すべてではなく何も許可しないように修正しました
  • 管理設定にクロード アプリ ゲートウェイのサインインが必要なマシン上の /login を修正しました。Esc キーは何もせずにダイアログを閉じるようになりました。
  • アップロード中に接続が切断されて切断されたアーティファクトのパブリッシュを修正しました。不明な結果を報告するのではなく、クロード コードがアップロードが完了しなかったと判断できる場合に、一度再試行するようになりました。
  • カスタムコマンド、スキル、およびサブエージェントのeffort:フロントマターが、デフォルトのエフォートがまだ固定されているモデルで無視される問題を修正しました（Opus 4.7、Opus 4.8、Fable 5）
  • ページ ファイルが有効な UTF-8 でない場合、または置換文字 (U+FFFD) が含まれている場合に、役に立たないエラーが発生してアーティファクトの公開が失敗する問題を修正しました。エラーは修正する行と列を指定するようになりました。
  • セッション開始後に作成されたリポジトリがリストされない claude agents @ ディレクトリ メニューを修正しました
  • Claude Desktop または VS Code セッションに参加するリモート コントロール clients が、再度変更されるまで古い権限モードを表示する問題を修正しました。
  • claude remote-control がサーバー資格情報の有効期限が切れると (開始から約 30 日後)、接続されているすべてのセッションが終了してドロップされる問題を修正しました。ホストは再登録して続行します
  • 異なるモデルまたはモードのリクエストが異なる制限ウィンドウを報告する場合、セッション中に使用制限警告がちらつく問題を修正しました
  • MCP サーバーが再送信するか、モデルが既にロードされているツールを組み込みツールが再レンダリングするときに、以前の推論が削除される問題を修正しました。
  • 切断された MCP サーバーまたはアップグレードにより会話中に消えるツールを修正し、ツール リストを書き換えて以前の考えを破棄しました
  • セッション中に EnterWorktree を会話のツール ブロックに追加する会話からフォークされたバックグラウンド ワーカーを修正しました。これにより、プロンプト キャッシュの再利用が壊れました。
  • ToolSearch を使用しないセッションで、セッション中の MCP およびプラグイン ツールがツール リストに追加され、プロンプト キャッシュの再利用が壊れる問題を修正しました。サポートされているモデルは、それらを遅延定義として受け取るようになりました。
  • /model によるすべてのツール定義の再送信によるモデルの切り替え (プロンプト キャッシュ ミス) を修正しました。コミットおよび PR 帰属テキストが、モデルの変更に関する最新情報を伝える会話メモとして届くようになりました
  • MCP コネクタが以前とは異なる時点で再接続したときに、再開されたセッションがインライン ツール セットを書き換える問題を修正しました。
  • 最初のターンでツールを実行したときに、記録されたものを再生するのではなく、ツールの説明を再レンダリングする再開されたセッションを修正しました
  • セッションと再開の間で claude.ai コネクタのツールが変更されるときのプロンプト キャッシュのミスと拡張思考の削除を修正しました
  • コネクタが再接続される前に、再開されたセッションが以前の MCP ツールのアナウンスを書き換える (そして拡張思考を削除する) 問題を修正しました。
  • 印刷モード (-p) 会話が対話的に再開されるときのプロンプト キャッシュの中断を修正しました。システム プロンプト プレフィックスは変更されなくなりました。
  • /diff パネルを改善しました。安定する前に「0 ファイルが変更されました」とスピナーが点滅しなくなり、空の状態がパネルの中央に表示されます。
  • Bash ツールの説明ガイダンスを改善し、クロードがコマンドをエコーするのではなく、わかりやすい言葉でコマンドの動作を説明するようにしました。
  • サンドボックス ガイダンスを改善し、サンドボックス内で pbcopy などの clipboard コマンドが失敗した場合にクロードが /copy を提案するようにしました。
  • 多くの Bash ツール呼び出しを伴うセッションの --resume の初回レンダリング時間の改善
  • プロンプト入力の応答性の向上: キーストロークがスピナーやストリーミング再描画の後で 1 フレーム待機することがなくなりました。
  • プロンプト キャッシュの安定性の向上: --system-prompt または --append-system-prompt で開始されたサブエージェントとセッションは、システム プロンプトとツール定義を再レンダリングするのではなく、一度記録するようになりました。
  • アーティファクト ツールのパブリッシュ エラーの改善: パブリッシュが拒否された場合、メッセージにその理由と対処方法が表示されるようになりました。
  • セルフホスト ランナー: --use-anthropic-git-proxy が登録時にサーバーに報告され、従来の Git プロキシを介してクローンを作成するセッションごとに警告を出力するように変更されました。
  • ゲートウェイ: 次のアップストリームにフェイルオーバーするのではなく、電子メールが転送された開発者に 429 をそのまま返すように forward_user_identity アップストリームを変更しました。これにより、プロキシのユーザーごとの制限が保持されます。
  • [VSCode] 保存されたトランスクリプトに cyclic 親リンクが含まれている会話でフォーク、以前のメッセージの編集、または巻き戻しを行うと、拡張機能ホストが CPU 100% でハングする問題を修正しました。
  • [VSCode] WSL2/WSLg にスクリーンショットを貼り付けて生の画像バイトをチャット入力に挿入する問題を修正しました。 clipboard が提供する場合は画像が添付されるようになりました。それ以外の場合、貼り付けは無視されます。
  • [VSCode] チャット diff ブロックが常にダーク エディター テーマでレンダリングされる問題を修正しました。ハイコントラストを含むアクティブな VS Code カラーテーマに従います。
  • [VSCode] メッセージ入力時に右から左へのテキストと英語のテキストが間違った順序で混在してレンダリングされる問題を修正しました。
  • [VSCode] Windows (CRLF) 行末を持つファイルの差分ビューでの編集の受け入れが「ファイル内に文字列が見つかりません」で失敗する問題を修正しました。
  • [VSCode] パスにスペースが含まれるファイルを削除する @ メンションを修正しました
  • [VSCode] ワークスペース フォルダーがリモート ホスト上にのみ存在する場合、リモート SSH 経由で接続された Windows でセッション リスト ビューの読み込みに失敗する問題を修正しました。
  • [VSCode] 大規模なワークスペースまたはシンボリックリンクの多いワークスペースでファイルを表示するときに暴走する ripgrep プロセスを修正しました
  • [Claude Code on the web] トークンの有効期限が切れると、GitHub アカウントが切断されたと表示される GitHub Enterprise Server セッションを修正しました。 PR および発行操作が自動的に更新されるようになりました
  • [Web 上の Claude Code] Claude GitHub アプリのない組織で gh および GitHub API 呼び出しが失敗する問題を修正しました。彼らは現在、あなたの接続されている GitHub アカウントを使用し、何も接続されていないときにそう言うようになります。
  • [Claude Tag] Claude Tag 管理設定のプリセット接続フォームに「カスタム コネクタを使用する」リンクを追加しました。これにより、最初からやり直すことなくカスタム接続に切り替えることができます。
  • [Claude Tag] 組織が使用クレジットを使い果たしたときに「API はリクエストを無効として拒否しました」とクロードが返信する問題を修正しました。返信にはその旨が表示され、さらに追加する方法が説明されています
  • [Claude Tag] クロードがチャンネルのトップレベルに投稿したメッセージの編集または削除を求めるスレッドリクエストが、投稿したセッションに到達せずに修正で応答される問題を修正しました。
  • [Claude Tag] [管理者設定] > [レビュー リクエスト] で [承認に失敗しました] で失敗するか、リクエストされたアクセス バンドルが削除済みとして表示される、ツール アクセス リクエストの 接続 を修正しました。
