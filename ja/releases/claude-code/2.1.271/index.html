claude-code v2.1.271

パッチ 公開日2026年9月14日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.271

何が変わったのか

  • Claude Code Remote セッション (クラウドおよびセルフホスト ランナー) に高速モードを追加: ホストの高速モード設定またはセッションに入力された /fast は、組織が許可する場合に適用されます。
  • フルスクリーン モードの /config パネルにマウス サポートを追加しました。ホイールで設定リストをスクロールし、設定値の click で設定値を変更し、ポインターの下の行が強調表示されます。
  • claude self-hosted-runner --drain-marker-file <path> を追加: そのファイルが SIGTERM ドレインに存在する場合、ランナーはその終了をホスト ドレインとしてサーバーに報告します (テレメトリのみ)
  • サンドボックスを使用した自動モードの Bash、PowerShell、およびモニターにコマンドごとの allowed_domains を追加しました。コマンドに必要なホストがレビューされ、コマンド専用に開かれます。他のホストは拒否されます
  • エージェント フロントマターに omitClaudeMd と --agents JSON を追加し、カスタム サブエージェントとプラグイン サブエージェントをユーザー、プロジェクト、ローカル CLAUDE.md ファイルなしで実行できるようにしました。管理ポリシー ファイルはまだ読み込まれています
  • -y の代わりに、以前の --json 実行時に表示されたコマンドを正確に受け入れるために、--accept-command <sha256> を claude plugin install および claude plugin update に追加しました。
  • マークアップされた内部チャージバック レートについて、modelPricing 管理設定とクロード アプリ ゲートウェイ pricing ブロックで 1 を超え、最大 10 までの multiplier のサポートを追加しました
  • Bedrock、Vertex AI、Foundry、LLM ゲートウェイ ユーザーをクロード デスクトップ アプリに示すスピナー チップを追加しました。 claude.ai デスクトップ アプリのヒントでは、アプリのダウンロードを提案する /desktop が提案されるようになりました。
  • アカウント、組織、または API キーを切り替えた後にキャッシュされた組織ポリシーが再利用され、セッション中に資格情報が変更されると 1 時間ごとのチェックが行われるまでポリシーが更新されない問題を修正しました。
  • 起動後に組織ポリシーの読み込みが完了したとき、またはセッション中に変更されたときに、ツールとコマンドのリストが更新されない問題を修正しました。
  • 読み取りも解析もできないエンタープライズ managed-mcp.json が無視される問題を修正しました。排他的な MCP 制御を保持し (ユーザー、プロジェクト、プラグイン サーバーはロードされません)、起動時に警告が表示されるようになりました。
  • ANTHROPIC_UNIX_SOCKET 経由で設定されたサードパーティのローカル プロキシによって組織ポリシーがフェッチされ、拒否される問題を修正しました。これらは再び、リモート コントロールを含め、他のカスタム ゲートウェイと同様に扱われます。
  • セッションのワーカーが再起動された後にワークフローまたはエージェントの承認が適用されると、すべてのサブエージェント ツール呼び出し (「updatedInput … スキーマ検証に失敗しました」) が拒否されるクラウド セッションを修正しました。
  • 組織で高速モードが無効になっている場合、/fast off が高速モードをオフにするのではなく、「高速モードは使用できません」と応答する問題を修正しました。
  • API が高速モードを拒否した後、毎ターン高速リクエストを再送信する CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK で開始されたセッションを修正しました。拒否は現在有効であり、その理由が示されています
  • CLAUDE_CODE_RETRY_WATCHDOG での高速モードが、使用量クレジット制限のオンに失敗したり、標準速度に戻るのではなく、高速でオーバーロードを再試行したりする問題を修正しました。
  • チェッカーが認識しないオプションに従う場合に、fmt、column、および同様のコマンドが読み取るファイルが見つからない Bash 権限チェックを修正しました。
  • ワイルドカードがコマンドのパターンまたはオプション値 (grep -v dir/* file など) にある場合に、ワイルドカードが展開されるファイルをスキップする Bash 権限チェックを修正しました。
  • シェル変数宣言フラグが実行中のコマンドを誤って表現できないように、Bash 権限チェックを修正しました。
  • 2 つのディレクトリ変更、サブシェル、または cd+git チェーンを含む Bash コマンドが、バイパスおよび自動モードで permissions.blockReadsOutsideWorkingDirectories の下のプロンプトをスキップする問題を修正しました。
  • サンドボックス コマンドの開始に失敗した後、残りのセッションで git checkout -b、git push -u、git config を破壊する古い .git/config.lock を修正しました (Linux)
  • システム ファイル イベント サービスが飽和している macOS マシン上で、セッション外で行われた設定ファイルの変更が認識されない問題を修正しました。ウォッチャーはポーリングに戻ります
  • すべてのツールが MCP サーバーからのものである再開された claude -p セッションが「少なくとも 1 つのツールには defer_loading=false が必要です」というエラーで失敗する問題を修正
  • LLM ゲートウェイが非ストリーミング応答を text/plain として返すと、「API が空または不正な応答を返しました」というエラーでターンが失敗する問題を修正しました。
  • MCP サーバーがタイトなループで list_changed 通知を送信する場合に、持続的に高い CPU 使用率が発生し、ツール リスト リクエストが繰り返される問題を修正しました。
  • MCP OAuth による client 登録の誤処理を修正しました。同意を拒否すると新しいリダイレクト URI が強制的に作成され、別のリダイレクト URI が再利用され、同時書き込みにより有効なリダイレクト URI が削除されたり、不一致なリダイレクト URI が保持されたりする可能性がありました。
  • クロードが完全な mcp__server__tool 名ではなく裸の名前で MCP ツールを選択すると、ツール検索で一致が返されない問題を修正しました。
  • Ctrl+O で保留中の MCP サーバーの再接続がキャンセルされ、トランスクリプト ビューが開いているときにリモート コントロールから送信された /mcp が失敗する問題を修正しました。
  • ToolSearch が利用できない場合に、ToolSearch を通じてツールをロードするようにモデルに指示する Chrome プロンプトのクロードを修正しました
  • 受信セッションの許可モード ポリシーによって保持され、痕跡が残らないクロスセッション メッセージを修正しました。ヘッドレス送信者は配信通知を受け取るようになり、SendMessage の結果は、メッセージが読まれたことを示唆しなくなりました。
  • 会話が圧縮された後も実行中のバックグラウンド コマンド (監視タスクや開発サーバーなど) の 2 番目のコピーをクロードが開始する問題を修正しました。
  • 会話が実際に実行されていたモデルに切り替えるときに会話キャッシュが失われることに関する /model 警告を修正しました
  • /cd後のスラッシュメニューと一致しないスキルカウントを報告する/reload-skillsを修正しました
  • ショート端末の全画面モードで 1 ～ 2 セッションのみを表示する /resume および /continue を修正
  • /resume と /teleport が前の会話のファイル読み取り追跡を維持するように修正したため、クロードは再開された会話で一度も読んでいないファイルを編集できました
  • 再開されたセッションのモデル ファミリが設定されたデフォルト モデルと異なる場合、--resume が 1M コンテキスト ウィンドウ ([1m]) をドロップする問題を修正しました。
  • /artifacts に添付されたアーティファクトが --resume の後にセッションから消える問題を修正
  • バックグラウンド セッション (claude --bg、claude agents) が、他の場所で作成された再公開のために公開されたアーティファクトを監視しない問題を修正しました。
  • Windows ドライブとしてマウントされた暗号化されたボールトなど、inode 0 を報告する仮想ドライブから読み込まれない最初のカスタム エージェント、スラッシュ コマンド、および出力スタイルを修正しました。
  • ホスト設定ディレクトリが 64 MiB を超えると、セルフホスト ランナー セッションがすべてのホスト設定 (設定、スキル、プラグイン、MCP サーバー) をサイレントに失う問題を修正しました。 --host-config-snapshot disk|memoryを追加しました
  • claude.ai から同期されたスキルがサインアウト後もディスク上に無期限に残る問題を修正しました。 cleanupPeriodDays 内で更新されなかったコピーは、次回の起動時に回復可能なゴミ箱に移動されるようになりました。
  • アカウントの種類で使用できないコマンド、またはセッションで無効になっているコマンドを示唆するスピナー ヒントを修正しました
  • /add-dir パス入力を修正しました。左右の矢印キーでカーソルが移動し、Enter キーを押すと、強調表示された補完も追加するのではなく、入力されたパスのみが追加されます。
  • メイン プロンプトの外側にあるテキスト フィールドを修正し、先頭の ! を入力内容の末尾に移動しました (!foo は foo! として表示されました)
  • フック マッチャーの名前が __proto__ や constructor などの継承されたオブジェクト プロパティにちなんで付けられている場合にクラッシュする対話型 /hooks メニューを修正しました。
  • 周囲のボックスの背景が失われた後、テキストが古い背景色のままになるフルスクリーン レンダリングの不具合を修正しました
  • 接続されたバックグラウンド セッションで機能しない rxvt-unicode の st の Delete キーと Alt+矢印キーを修正しました
  • クロード コードが終了、一時停止、または起動直後にエディタを開いたときに、シェル プロンプトまたはエディタに表示される機能クエリ (^[[?1;2c) に対するターミナルの応答を修正しました。
  • ターミナルのレンダリング パフォーマンスの向上: 大きな差分と長いトランスクリプトは、遅いフレームが減り、より高速にレンダリングされます。
  • 起動のたびに組み込みモデルデータの冗長な検証をスキップすることで、起動時間をわずかに改善しました。
  • フックのフィードバックの改善: SessionStart、UserPromptSubmit、PreToolUse、または SessionEnd フックの実行中、スピナーは経過時間に応じてその旨を通知し、Esc キーを押すと SessionStart フックを待機しているプロンプトがキャンセルされます。
  • 長い思考中のスピナーのステータスを改善しました。45 秒後に「深く考え込んでいる」と表示され、出力トークンの制限から回復している間は「考えを元に戻している」と表示されます。
  • 動的ワークフローが改善され、使用量制限に達すると一時停止し、リセットされると、影響を受けるエージェントを削除するのではなく自動的に続行するようになりました。
  • 不安定なネットワークでセットアップが失敗した場合に、claude.ai 上に残る空のセッションが少なくなるようにリモート コントロールを改善しました。
  • ブラウザーにアクセスできない場合のクラウド セッションでの Chrome のクロード メッセージを改善しました。インストールを提案する前にコンピューターがスリープ状態である可能性があると表示されるようになりました。
  • claude mcp serve の改善: 実行中のツール呼び出しは 30 秒ごとに進行状況の更新を送信するようになりました。そのため、clients はまだ実行中であることを示し、アイドル タイムアウトによって何も出力されない長いコマンドが中止されることはありません。
  • AWS セッション上の Foundry および Claude プラットフォームの改善: 会話中に接続を終了した alwaysLoad MCP サーバーは、ツール検索の往復を行わずに次のターンで使用可能になります。
  • アーティファクトとして公開される Markdown ファイルの改善: スタイル付きドキュメント ページ (タイトル ヘッダー、ドキュメント タイポグラフィ、構文強調表示されたコード) としてレンダリングされるようになりました。
  • アーティファクト ツールのパブリッシュ エラーの改善: ファイルなしでパブリッシュすると、最初にページをファイルに書き込むように指示され、ファビコンが見つからない前にサポートされていないファイル タイプが報告されます。
  • ページがその契約バージョンにない機能を宣言したときのアーティファクト ツールのエラーを改善しました。サポートされているすべての機能がリストされ、新しい契約バージョンにその機能がある場合にメモが表示されるようになりました。
  • アーティファクトの監視の改善: セッションでは、他の場所で再公開された公開アーティファクトを 5 つから最大 10 件まで同時に監視できるようになりました。
  • pdfinfo がページをカウントできない場合に、ファイル サイズから推測されるページ数ではなく「ページ数が不明」と表示されるように PDF の @-mentions を改善しました。
  • /mobile を改善して、claude.ai/mobile の単一の QR コードを表示し、携帯電話に適切なアプリ ストアを開きます
  • 自動モードを変更し、スキルまたはスラッシュ コマンドのインライン ! シェル コマンドが、分類子ではなくデフォルト モードの権限ルールに従うようになりました。ルールによって決定されないコマンドは、レビューされたツール呼び出しとして実行されます
  • 自動モードを変更し、最後のメッセージが事後にレビューされるのではなく、安全性分類子がレビューする専用のハンドバック呼び出しを通じてサブエージェントが呼び出し元に報告を返すようにしました。
  • モニター ウォッチに常に期限 (最長 30 分、シングル プロンプト -p 実行では 10 分) があり、クロードに再準備するように通知するように変更し、タイムアウトなしの persistent オプションを置き換えました。
  • プロンプト内の IDE 選択インジケーターを、複数行のプロンプトを圧縮するのではなく、テキストで折り返す [⧉ …] ピルに変更しました。バックスペースで削除して選択範囲を外します
  • Pro プランではデフォルトの動的ワークフロー サイズを小型に変更し、中規模のガイドラインを 15 エージェントから 10 エージェントに引き下げました
  • Claude アプリ ゲートウェイ、Bedrock、Vertex AI、Foundry セッションを変更し、セッションで使用されていない残りの claude.ai ログインを更新しないようにしました。
  • バンドルされている claude-api スキルを更新して、ストリーミング カスタム ツールで eager_input_streaming を有効にし、user.define_outcome で成果物形式の管理対象エージェントの作業を開始できるようにしました。
  • [VSCode] オフにすると、開いているファイルがメッセージに追加されないようにする、開いているファイルを添付する設定を追加しました。選択したテキストはまだ添付されています
  • [VSCode] 失敗した保存が報告されるフックと権限ルールのダイアログ、およびプラグインのみのポリシー ロックの下でフック ダイアログが空白になるか、保存エラーでカラー コードが表示される問題を修正しました。
  • [VSCode] フック ダイアログの保存を修正しました。置換時にフックが重複せず、他の capital で再入力されたヘッダー名は秘密を保持し、保存が返される前に settings.local.json が無視されます。
  • [VSCode] ワークスペースが Windows にマップされたネットワーク ドライブまたは SUBST ドライブ上にある場合に、現在のセッションのみが表示されるセッション履歴を修正しました。
  • [VSCode] フィルター メニューで [開く] もチェックされている場合、セッション リストのアクティブ フィルターが開いているアイドル セッションを非表示にする問題を修正しました。
  • [VSCode] セッションリストが更新されると、新しいチャットが前のチャットに戻る問題を修正しました。
  • [VSCode] environmentVariables 設定で CLAUDE_CONFIG_DIR が変更された後、ウィンドウがリロードされるまで、開いているタブとサイド バーが古い設定フォルダーを保持する問題を修正しました。
  • [VSCode] 拡張機能が git、ripgrep、サインイン ステータス チェックなどのバックグラウンド コマンドを実行するときに Windows 上で点滅するコンソール ウィンドウを修正しました。
  • [VSCode] 遅延後にのみ表示されるプロンプト キャッシュ クロックのホバー テキストと、ポップアップの横にブラウザー独自のツールチップを表示する自動圧縮アイコンを修正しました。
  • [VSCode] フック ダイアログを改善しました。設定ファイル自体が原因で保存が拒否されると、「設定ファイルを開く」ボタンと「コピー エラー」の理由が表示されるポップアップが開きます。

  • [Claude Code on the web] クラウド セッションがまだライブに見える間にプロセスが終了した後、応答するまでに約 10 分かかることがある問題を修正しました。メッセージを送信するとすぐに再起動されるようになりました
  • [Claude Code on the web] claude.ai/code の [ルーチン] ページを、[自分] タブと [テンプレート] タブ、および実行ステータスを表示する 2 列のルーチン カードを備えた新しいレイアウトに変更し、カレンダー ビューを削除しました。

  • [Claude Tag] Claude Tag 管理設定の環境ピッカーを改善しました。オプションには Anthropic-hosted または self-hosted というラベルが付けられ、その環境を編集または作成するためのリンクが付いています。
  • [コードレビュー] PR ごとに 1 回レビューされるリポジトリのプル リクエストが、レビューの開始を待っている間にコミットが到着するとレビューが得られない場合がある問題を修正しました。要求されたコミットをレビューするようになりました
  • [コード レビュー] GitHub が実際に作成したレビューのエラーを報告したときに、コード レビューが同じ結果を 2 回または 3 回投稿することがある問題を修正しました。
  • [コードレビュー] 後のプッシュによってアンカーされていた行が移動されたときに、人がすでに解決したセキュリティ発見事項を再投稿するフォローアップレビューを修正しました
  • [コード レビュー] クロード アプリで完了した /ultrareview クラウド セッションを再度開くと、プロンプトなしでレビュー全体が再度開始される問題を修正しました。
  • Windows: セッションの一時出力パスが 260 文字に達すると、PowerShell コマンドが「終了コード 1」で失敗し、出力がなくなる問題を修正しました。
