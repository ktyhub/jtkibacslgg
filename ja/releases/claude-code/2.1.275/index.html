claude-code v2.1.275

パッチ 公開日2026年9月17日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.275

何が変わったのか

  • サインインしたアカウントをクロード アプリ ゲートウェイのサインインに追加しました。ゲートウェイで名前を付けると、資格情報が保存される前にそれを確認し、/status にそのアカウントが表示されます。
  • 現在のターンを中断し、キューに入れられたすべてのメッセージを一度に送信する、今すぐ送信キー (ctrl+enter、または ctrl+x ctrl+s) を追加しました。送信およびキューに登録されたメッセージは、モデルが受信するまで灰色で表示されます
  • 設定された otelHeadersHelper が失敗した場合の起動警告を追加しました。これにより、テレメトリをサイレントにエクスポートしないセッションが認識されます。
  • claude.ai アカウントで有効になっているスキルとプラグインの、そのアカウントでサインインしているターミナル セッションへの同期が追加されました。 syncClaudeAiSkills: false または syncClaudeAiPlugins: false でオプトアウトします
  • プラグインをインストールする前にマーケットプレイスを追加することを提案する /plugin install <plugin> --marketplace <source> を追加しました
  • 圧縮または再開後のリクエスト間で復元されたメモリ ファイルの経過時間ノートが変更され、プロンプト キャッシュ ミスが発生する問題を修正しました。
  • --forward-subagent-text ストリーム - json および SDK 出力で、context: fork スキルによって生成されたサブエージェント、およびサブエージェントまたは別のフォークされたスキルによって呼び出されたフォークされたスキルのメッセージがドロップされる問題を修正しました。
  • カスタム fileSuggestion コマンドを使用するか、@./@./ を入力するときに、@ メンション ファイルの提案が MCP リソースの下に埋め込まれる問題を修正しました。
  • 全画面モードで、バックグラウンド タスクの完了通知が到着場所ではなく、長いターンの折りたたまれたツール行の下に表示される問題を修正しました。各通知により開いている列が閉じられます
  • フェッチが失敗し、マーケットプレイスがそのリポジトリにちなんで名付けられた場合に、claude plugin marketplace update が GitHub マーケットプレイスのローカル コピーを削除する問題を修正しました。
  • git、ssh、またはマーケットプレイスの URL に保存されているパスワードまたはトークンを示すプラグインおよびマーケットプレイスのメッセージ、ログ、および claude plugin marketplace list を修正しました
  • キューに入れられたメッセージが置き換えられた後、再開されたクラウド セッションでトランスクリプトに未回答の質問が残ったままになる問題を修正しました
  • ドット反復「!」の直後にカーソルを 1 文字配置する vim モードを修正しました。または高速に入力した「i!」空ではないプロンプトをシェルモードに切り替えました
  • 大きなファイルの差分を超えて上にスクロールすると、フルスクリーン モードで数秒間フリーズまたはブランクになる問題を修正しました。
  • 応答に時々表示される </ccmemory> スタイルの終了タグを修正しました
  • 一部の git アドレスに対して間違ったサーバーが表示されるプラグイン メッセージ、ログ、および VS Code プラグイン ダイアログを修正しました
  • ベータ要求ヘッダーが拒否された場合に API エラー応答を書き換える、ネットワーク ゲートウェイの背後にあるユーザーの毎ターンの端末 API Error: 400 を修正しました
  • シェルが zsh の場合、失敗したコマンドに対して終了コード 0 を報告する Linux 上のサンドボックス化された Bash コマンドを修正しました
  • メモリ不足で大きなファイルの一部をデコードできなかった場合に、エラーを報告する代わりに読み取りツールがハングする問題を修正しました。
  • --resume、再開ピッカー プレビュー、再開されたバックグラウンド エージェント、および保存された履歴に不正な形式のタスク リマインダーまたは @ ファイル添付エントリが含まれるセッションで失敗するトランスクリプト ビューを修正しました
  • トランスクリプトに不正なメッセージ エントリが含まれる会話を再開するときのクラッシュと、そのような会話が上にスクロール中に新しいメッセージを受信したときの全画面クラッシュを修正しました
  • 保存されたトランスクリプトに不正な形式のメッセージ コンテンツ ブロックが含まれている場合、セッションの再開または開始に失敗する問題を修正しました
  • 20MB の出力上限を超える検索で Grep、Glob、@-file の候補がハングしたりメモリ不足になったり、警告が大量に出た後にシステム ripgrep がエラーではなく「一致なし」を報告したりする問題を修正しました。
  • セッションのファイル履歴バックアップを完全にコピーできなかった場合に、フォークされたセッションまたはバックグラウンド セッションで /rewind がゼロ埋めまたは切り捨てられたファイルを復元する問題を修正しました。
  • 高速で入力するか、スラッシュ コマンド ドロップダウンを開いた状態でキーを押したままにすると、「回復不能なインターフェイス エラーが発生した後にクロード コードが終了しました」というメッセージが表示されてフルスクリーン セッションが終了することがある問題を修正しました
  • ファイル記述子が不足したマシン上で標準入力を介して入力されたコマンドが実行されたときにバックグラウンド セッションがクラッシュし、ワーカーが再起動する問題を修正しました。
  • ~/.claude.json が不正な形式の mcpNeedsAuthNoticed 値を保持している場合の起動時のクラッシュを修正しました
  • --resume と --continue で開始された組み込みツールがサーバー側のフラグによってオフになった場合、会話の以前の思考が削除される問題を修正しました
  • フルスクリーン claude --resume セッション ピッカーでマウスで選択したテキストが clipboard に到達しない問題を修正
  • プラグインが --plugin-dir または --plugin-url アーカイブからロードされたときに、実行中のセッションの抽出されたプラグイン ファイルを置き換えるプラグインのリロード プレビューを修正しました
  • --drain-wait-sec を備えた自己ホスト型ランナーが、SIGTERM ドレイン中に終了したターンの最終結果を失う問題を修正しました。ランナーは順番が報告されるまで少し待ちます
  • エージェント タイプが空の停止サブエージェントごとに特定の matcher が起動する SubagentStop フックを修正しました。
  • サンドボックス化された Bash コマンドが hooks/ または config/ という名前のプロジェクト ディレクトリに書き込めない問題を修正
  • 別のマシンでセッションが再開されるか、スクラッチパッドがクリアされた後、「ファイルが見つかりません」というエラーでアーティファクトの更新が失敗する問題を修正しました。ページの最後に公開されたバージョンが復元されます。
  • Edit(path) ルールの代わりに、ファイル権限チェックが一致しない Write(path) 権限ルールを書き込む /update-config を修正しました。
  • バンドルされた claude-api スキルのライブ ソース テーブル内の 4 つの無効なドキュメント URL (価格設定、コンピューターの使用、スキル、CLI) を修正しました。
  • __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__ 行を含む --system-prompt のプロンプト キャッシュの改善: SDK の配列形式がすでにキャッシュされているため、その上のテキストがグローバルにキャッシュされるようになりました。
  • Claude Desktop が開かない場合の /desktop エラーを改善しました。その理由と次に何をすべきかが表示されるようになりました。
  • アーティファクト ツールの公開結果と読み取り結果を改善しました。誰がページを開くことができるか、所有者の [共有] メニューが何を提供するかが表示されるようになりました。
  • アーティファクトのパブリッシュ結果の改善: 送信されたタブ アイコンに名前を付け、ページに NUL バイトが含まれている場合に警告し、古いパブリッシュ後にマージするために新しいページの不安定なフェッチを再試行します。
  • 貼り付けおよび添付された画像の改善: デスクトップや VS Code を含め、クロードが許可プロンプトなしでファイルとして開くことができる場所に保存されるようになりました。
  • アーティファクト ツールのガイダンスを改善し、共有アーティファクトへの編集アクセス権が与えられたときに、別のコピーを公開するのではなく、クロードが共有アーティファクトをその場で更新するようにしました。
  • プラン使用量読み取りの改善: 1 台のマシン上のエディター ウィンドウと非対話型セッションは、それぞれが使用量エンドポイントを呼び出すのではなく、直前に行われた読み取りを共有するようになりました。
  • ListPlugins ツールの説明を改善し、/plugin でローカルにインストールされたプラグインではなく、claude.ai アカウントで有効になっているプラグインがリストされていることがクロードにわかるようにしました。
  • 端末が遅い場合や一時停止している場合の応答性が向上しました。端末が追いつく間に出力がさらに遅れることがなくなりました。
  • 同期されたアカウント スキル フォルダー内のファイルの書き込みと編集の結果が改善されました。変更がアカウントに保存されていないことと、その保存方法が表示されるようになりました。
  • クロード アプリ ゲートウェイ サインインの /logout を更新し、トークン失効をアドバタイズするゲートウェイでのセッションも終了するようにしました。
  • ホストされたセッションを変更して、コンテナの再起動後に再度尋ねるのではなく、未回答の許可プロンプトを表示し続けるようにしました。
  • 最初の公開時に絵文字ファビコンの代わりに 1 単語のタブ アイコンを要求するようにアーティファクト ツールを変更しました
  • 自動モードの Chrome で Claude を変更し、バイパス モードと同様に、分類子が承認した呼び出しに対する拡張機能のサイトごとのチェックをスキップし、リダイレクト後の browser_batch "許可が拒否されました" を修正しました
  • npm ソースからインストールされたプラグインが npm pack --ignore-scripts でフェッチされ、整合性が検証されるように変更されたため、パッケージのインストール スクリプトは実行されなくなりました
  • スケジュール設定と今すぐ実行ルーチンを変更して、データを保存し、そのページを再公開するアーティファクトを、質問せずに編集できるようにしました。公開アーティファクト、最初の公開と削除はまだ質問されます
  • 最後のセッション以降、1 回限りのスケジュールされたルーチンが実行されたことを通知する起動通知を削除しました
  • [VSCode] メモリダイアログ内に保存されたメモリの表示、編集、削除を追加しました
  • [VSCode] テキストを入力せずに添付画像を送信する機能を追加しました
  • [VSCode] サーバー リストのロードに失敗した場合の MCP サーバー ダイアログに再試行リンクを追加しました。
  • [VSCode] 提案された変更の差分タブの各変更の下に承認ボタンと拒否ボタンを追加したため、変更ごとに編集を確認できます
  • [VSCode] 許可カードが待機し、コンテンツが到着し続ける間に、トランスクリプトが少しずつ下の方に向かって進んでいく問題を修正しました
  • [VSCode] 元の会話に対して選択した権限モードが維持されない、巻き戻しおよび分岐した会話を修正しました
  • [VSCode] environmentVariables 設定の空の CLAUDE_CONFIG_DIR エントリを修正し、クロード コードがファイルをワークスペースに保持するようにしました。
  • [VSCode] リンク内で使用できないプラグイン名とマーケットプレイス アドレスの [プラグインの管理] ダイアログを開くプラグイン インストール リンクを修正しました。
  • [VSCode] クロードコードが失敗したと報告した、電源をオフにした後もリモコンが接続済みとして表示されたままになる問題を修正しました。オフとして表示されるようになりました
  • [VSCode] スクロール中に返信が到着し始めると、送信時に一番下までスクロールが返信の手前で止まってしまう問題を修正しました。
  • [VSCode] セッションが再度開かれると、エージェントが未完了のままクラッシュした場合、失敗ではなく停止として表示されるエージェント マップを修正しました。
  • [VSCode] バックグラウンド タスクがまだ実行されている状態でクラッシュした後のリロード後に、「ステップを継続しています」という通知が表示されず、継続制限がリセットされる問題を修正しました。
  • [VSCode] 最後のメッセージが送信されたときではなく、ウィンドウのリロード後など、セッションが最後に再度開かれたときを示すセッション リストを修正しました。
  • [VSCode] クロードの作業中にメッセージを送信した直後に「ここから会話をフォーク」が失敗する問題を修正
  • [VSCode] クロードの作業中にメッセージが送信されたセッションを再度開いた後、プロンプト キャッシュ クロックが表示される時間が短すぎる問題を修正しました。
  • [VSCode] クロードがツールを実行している間に終了したバックグラウンド エージェントが、ウィンドウのリロード後に完了通知とエージェント マップ上の結果を失う問題を修正しました。
  • [VSCode] 拡張機能が数秒間応答しなかった後、git 無視ファイルで選択されたテキストがクロードに送信される可能性があるまれなケースを修正しました
  • [VSCode] 実行中のセッションの名前変更が生成された名前に戻る問題を修正しました (2.1.269 のリグレッション)
  • [VSCode] VS Code でメッセージのない空の会話として開くいくつかの claude.ai/code セッションを修正しました
  • [VSCode] クロードが応答中に入力されたスラッシュ コマンドが、応答終了後に実行されるのではなく、テキストとしてモデルに送信される問題を修正しました。
  • [VSCode] ハイ コントラスト ライト テーマを使用したプラン プレビューおよびフックとパーミッション ルールのダイアログで判読できないコードを修正しました
  • [VSCode] リモート コントロールの接続中に /remote-control が無視される問題を修正しました。再度実行すると、リモート コントロールがすぐにオフになるようになりました。
  • [VSCode] 上にスクロールした後に返信が流れているときに会話が一番下に引き戻される問題を修正し、送信時のジャンプをオフにする claudeCode.scrollToBottomOnSend 設定を追加しました
  • [VSCode] マーケットプレイスの URL に入力されたパスワードまたはトークンを表示するプラグインの管理ダイアログを修正しました
  • [VSCode] エージェント マップを改善しました。錠剤は実行中のエージェントをカウントし、失敗すると赤に変わります。マップがスクロールしている間、メイン エージェントは表示されたままになり、エージェントは状態、終了時刻で並べ替えられます。
  • [VSCode] 優先場所がサイドバーに設定されている場合、常に別のタブを開くのではなく、クロード エディター タブの新しいセッションがサイドバーで開くように変更されました。
  • [VSCode] クロードの作業中に送信されるメッセージを、クロードが会話を開始するまで会話の最後で待機するように変更しました。
  • [Web 上の Claude Code] ルーチン リンクが解決されなくなったときに表示されるページの、ルーチン リストに戻るリンクの隣に「新しいルーチン」ボタンを追加しました。
  • [Claude Code on the web] ルーチンの「一時停止」および「保留中」通知が文の途中で切れる問題を修正。サブスクリプション一時停止の通知には、ルーチンを元に戻すよう記載されています
  • [Claude Code on the web] 非常に長い許可ドメイン リストが正常に保存され、その後セッションが開始されるたびに失敗するクラウド環境を修正しました。保存は前もって失敗し、どれだけトリミングするかを指示するようになりました
  • [ウェブ上のクロード コード] 個人アカウントのクラウド セッションが GitHub アクセスを拒否された場合のクロードのガイダンスを修正しました。管理者設定ページではなく、claude.ai/connect-github にリンクするようになりました。
  • [Web 上のクロード コード] クロードが作成していないルーチンの編集、削除、または実行を求められたときにクロードが伝える内容が改善されました。ルーチンのページにリンクされるようになったので、自分で実行できるようになりました。
  • [クロード タグ] クロード タグの設定にアクセス バンドルの添付条件を追加しました。オーナーは、メンバー限定だけでなく、ゲストがいるチャネルや Slack Connect チャネルにもバンドルを適用できるようにできます。
  • [Claude Tag] Amazon CloudWatch、CloudWatch Logs、Amazon SNS、Google Cloud Monitoring、Cloud Logging のプリセットを、Claude Tag 管理設定のアクセス バンドルの [認証情報] タブに追加しました。
  • [Claude Tag] US3、AP1、AP2、US1-FED サイト用の Datadog プリセットを追加しました。新しい Datadog 接続は、Datadog の読み取りおよびクエリ API ルートに制限されるようになりました
  • [Claude Tag] 最近の AWS CLI および SDK バージョンからの S3 アップロードが、AWS 接続経由で送信されると 502 エラーで失敗する問題を修正しました。
  • [Claude Tag] ルーチンまたはスレッドからそのチャネルに投稿されている間に、Claude がチャネルを非アクティブとして扱い、そこにあるタグなしメッセージをスキップする問題を修正しました。
  • [Claude Tag] スレッドの背後にあるセッションが更新または再起動された後、スレッドの「Claude [タスク]」表示名がプレーンな「Claude」に戻る問題を修正しました。
  • [Claude Tag] Slack スレッドで切り替えたモデルが、スレッドのセッションが再起動または更新された後、サイレントにチャンネルのデフォルトに戻ってしまう問題を修正しました。
  • [Claude Tag] 別のアプリまたはボットがトップレベルのチャネルメッセージで@メンションしたときにクロードが2回返信することがある問題を修正
  • [Claude Tag] ワークスペース間で共有される Enterprise Grid チャネルのクロード通知を改善しました。ワークスペースがまだ設定されていない場合、または組織のデフォルトのみが適用される理由が表示されるようになりました。
  • [コード レビュー] レビュー エージェントの 1 人が予期しない形式で結果を返した場合に、レビューが分析の一部をドロップすることがある問題を修正しました。
  • [コード レビュー] 100 件を超えるクロード レビューを含むプル リクエストが修正され、軽量のマージに重点を置いたレビューではなく、ベース ブランチからのすべてのクリーン マージで完全な再レビューが行われるようになりました。
