claude-code v2.1.277

パッチ 公開日2026年9月18日 出典anthropics/claude-code 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.277

何が変わったのか

  • AGENTS.md サポートの追加: CLAUDE.md のないプロジェクトでは、Claude コードは代わりに AGENTS.md を読み取ります。 /config の「プロジェクト指示」で変更します (Bedrock、Vertex、Foundry ではまだ)
  • 唯一の出口がフォワード プロキシであるクロード アプリ ゲートウェイに CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 を追加しました。すべての送信リクエストは、ホスト名をローカルで解決するのではなく、プロキシに渡します。
  • プロバイダーの前で実行するプロキシに静的ヘッダーを送信するために、クロード アプリ ゲートウェイのアップストリームにオプションの headers: マップを追加しました
  • /tasks などのパネルが開いている間にバックグラウンド タスクの更新が完了すると、その更新が待機していることを示す行を追加しました
  • 内部エラー後に結果が得られずにハングする可能性がある claude -p およびエージェント SDK セッションを修正しました。彼らはエラーを報告し、コード 1 で終了します。
  • --resume の後など、以前のアシスタントのターンが他のコンテンツの横に空のテキスト ブロックを保持していた場合、「テキスト コンテンツ ブロックは空ではない必要があります」というメッセージが表示されてすべてのリクエストが失敗する会話を修正しました。
  • 古いクロード コード ビルド (IDE 拡張機能にバンドルされている CLI など) が現在のマシンと同じマシンで実行されている場合に予期せずログアウトされる問題を修正しました。
  • ~/.claude.json が不正な形式の customApiKeyResponses 値を保持している場合に、対話型起動がハングしたり、ANTHROPIC_API_KEY ユーザーにエラーが表示されたりする問題を修正しました。
  • 最小バージョンまたは最大バージョンが設定されている場合、プロキシが無効なバージョンを返した場合に 30 分ごとにエラーが発生する更新チェックと claude update のハングを修正しました。不正な形式の minimumVersion は無視されるようになりました
  • バージョン検索が失敗したときに「最新」と報告する winget または apk 管理のインストールでの claude update を修正しました
  • セッションまたは別のプログラムが使用していたプラグインのバージョンを再インストールするときに、claude plugin install が失敗してインストールされたコピーが壊れることがある問題を修正しました。変更されていないコピーはそのまま残されます
  • システムのプロセス、メモリ、またはファイル ハンドルが不足していて検索を開始できなかった場合に、一致しないと報告する Grep と Glob を修正しました。彼らは今、そう言うエラーを返します
  • ターゲット パスが既存のディレクトリである場合、書き込みツールが declined 権限としてサイレントにターンを終了する問題を修正しました。明らかなエラーが報告されるようになりました
  • エスケープされたバックスラッシュとそれに続く uXXXX テキストを \uXXXX エスケープとして扱う編集ツールを修正しました。これにより、非 ASCII 文字を編集すると、代わりにエスケープされたバックスラッシュ シーケンスが書き換えられる可能性がありました。
  • 非 ASCII テキストを含む非常に大きな編集がファイルと一致しない場合に、「ファイルに文字列が見つかりません」ではなく「無効な正規表現: 正規表現が大きすぎます」と報告する編集ツールを修正しました。
  • ツール呼び出しのファイル パスにエスケープ シーケンスとして記述された \u0000 が含まれている場合、「パスにヌル バイトが含まれています」でターンが早期に終了する問題を修正しました。エスケープされた制御文字はリテラル テキストとして残るようになりました
  • プラグインの LSP サーバーが終了するか標準入力を閉じたときに終了するバックグラウンド セッション (claude --bg) を修正しました
  • ~/.claude.json 内の不正な形式の claudeAiMcpEverConnected 値で /mcp または /plugin manage を開いたときのクラッシュ (「タイプ エラー」) を修正しました。
  • ~/.claude.json が不正な形式の theme 値を保持している場合の起動時のクラッシュを修正しました
  • プロンプトに端末のカラー コードを含むテキストが保持されている場合のクラッシュ (「回復不能なインターフェイス エラー」) を修正しました。たとえば、履歴から呼び出されたプロンプトや外部エディタから読み込まれたテキストなどです。
  • 保存された履歴にアシスタント メッセージがプレーン文字列として保存されているセッションを再開するときのクラッシュを修正しました
  • 最初のスピナーが表示されたときに、低速または高負荷のマシン上のセッションが「回復不能なインターフェイス エラーの後にクロード コードが終了しました」というメッセージで終了することがある問題を修正しました。
  • 内部レンダリングエラーの後、セッションの残りの間画面の更新が停止する稀なケースを修正しました
  • Windows で、クロードが返信した直後に「メモリ不足」などのエラーでターンが停止し、返信のツール呼び出しが実行されないというまれなケースを修正しました。
  • /clear (再起動、--continue、--resume) 後に続行されたセッションで、SessionStart フックが出力を印刷したときに最初のメッセージの一部が欠落し、完全なプロンプト キャッシュ ミスが発生する問題を修正しました。
  • ターン途中に到着した他のエージェント (サブエージェントの SendMessage など) からのメッセージが、到着場所ではなく「Ran N シェル コマンド」行の下に表示される問題を修正しました。
  • フルスクリーンの /resume ピッカーおよびプロンプト領域をカバーするその他のパネルでテキストをドラッグ選択した後に「コピーされました」通知が表示されない問題を修正しました
  • サンドボックスが有効になっているときにサンドボックスの外で実行される Bash コマンドで空を展開する $TMPDIR を修正しました
  • Cowork クラウド セッションの WebFetch と WebSearch が、フェッチ予算の使い果たしや管理ポリシーなど、リクエストが拒否された理由をクロードに伝えない問題を修正しました。
  • プロキシが設定されている場合、NO_PROXY にリストされているコレクターのホスト名またはドメインを無視するクロード アプリ ゲートウェイのテレメトリ リレーを修正しました
  • エンタープライズ マーケットプレイス ポリシー全体をサイレントに無効にする 1 つの不正な strictKnownMarketplaces または blockedMarketplaces エントリを修正しました
  • ~/.cache/claude/staging で大規模な段階的ダウンロードが残る失敗した自動更新を修正しました
  • /plugin が「インストール済み」タブのメッセージから端末制御文字を削除しない問題 (プラグインの更新が失敗した場合のエラーなど) を修正しました。
  • スキルまたは従来のコマンドが constructor や toString などの組み込みオブジェクト プロパティのように名前付けされている場合に、/plugin → インストール済みおよび /skills がクラッシュする問題を修正しました。
  • 複数選択でのすべてのインストールが失敗した場合に、メッセージなしで終了する /plugin を修正しました
  • アンインストールされたプラグインが「/plugin インストール済み」で「ロードに失敗しました」行として再表示され、削除してもそのような行がクリアされない問題を修正しました。
  • 公式マーケットプレイスのプラグインが installed_plugins.json でコミットなしで記録され、ピン留めされたコミット プラグインを更新した後も installed_plugins.json が古いコミットを保持する問題を修正しました
  • プラグインのリロード プレビューで、プラグイン アーカイブのすべてのプレビュー コピーが終了するまで解凍されたままになり、ダウンロードが失敗したときにリロードがフォールバックするキャッシュされた --plugin-url アーカイブが上書きされる問題を修正しました。
  • ~/.claude.json が不正なプレースホルダー レコードを保持している場合にリモート コントロール セッションのブックキーピングが失敗する問題を修正
  • 期限切れの Anthropic プロファイルのせいで claude.ai ログインが取り消された後のエラーを修正しました。 /login が先頭になります
  • キーリピートまたは非常に速い入力中に、claude agents ディスパッチ入力で入力または貼り付けられたテキストが時々スクランブルされて表示される問題を修正しました。
  • 保存されたトランスクリプトに整形式のフック リストのない停止フックの概要が含まれているセッションを再開するときのクラッシュ (「回復不能なインターフェイス エラー」) を修正しました。
  • keybindings.json がチャット コンテキストで Enter キーを再バインドすると、選択したエージェント パネル行で Enter キーが何も実行されない問題を修正しました (例: chat:queueSubmit)
  • 作業フォルダーのパスが長い（約 120 文字以上）場合、Windows で PDF ページの読み取りが失敗する問題を修正しました。
  • セッションのコストと使用量の合計がゼロから始まるヘッドレス レジューム (claude -p --resume、SDK、VS Code 拡張ウィンドウのリロード) を修正しました。ヘッドレスセッションは終了時に合計を保存するようになりました
  • .claude/skills が追跡されていない場合、メイン リポジトリからのプロジェクト スキルが --worktree セッションにロードされない問題を修正しました
  • 1 つの部分のみが一致した場合に複合 Bash コマンド全体をサンドボックスから除外する sandbox.excludedCommands グロブを修正しました。すべての部分が一致する必要があります
  • 再開されたサブエージェントとチームメイトがロードした MCP ツール定義を再レンダリングし、そのエージェントのプロンプト キャッシュが壊れる問題を修正しました。
  • クロードに再試行を停止するよう指示するレート制限アーティファクトのパブリッシュを修正しました。クロードには、何も公開されていないことと、いつ同じ公開を再度送信するかを通知されます。
  • 会話の前半に記録された添付ファイルが再開または再起動後に再レンダリングされる問題を修正しました。これにより、拡張思考が失われ、プロンプトのキャッシュが見逃されます。
  • サーバーが API キーの作成を拒否した場合、コンソールのサインインで「ステータス コード 400 で要求が失敗しました」のみが表示される問題を修正しました。サーバーのメッセージが表示されるようになりました
  • クロードがまだ作業している間に入力されたメッセージがモデルによって無視されることがある問題を修正しました
  • SDK およびヘッドレス (-p) 使用のためのセッション起動の改善: 最初のターンはディレクトリごとの CLAUDE.md ルックアップを待機しなくなりました。
  • クロード アプリ ゲートウェイのループバック エラー メッセージを CLAUDE_GATEWAY_ALLOW_LOOPBACK という名前に改善しました。
  • 改良された /plugin インストール: プラグインとは別にリストされた MCP サーバーに、どのプラグインに属しているかが表示されるようになりました。
  • すでにインストールされているプラグインの claude plugin install を改善しました。マーケットプレイスが新しいバージョンを提供し、claude plugin update コマンドに名前を付けると、それが表示されるようになりました。
  • ロゴの下の起動通知のオーバーフロー行を改善しました。「+N more · /status」の代わりに「N more Notices hidden」と表示されるようになりました。
  • プロンプト処理の改善: プロンプト内の目に見えない Unicode 書式設定とタグ文字が削除され、送信前に確認のためにクリーンアップされたプロンプトが表示されます。
  • レビューするものが何もない場合の /ultrareview を改善しました。メッセージには、どのケースに該当するかが示され、最新のコミットをレビューするコマンドが提供され、新しいリポジトリの最初のコミットが完全にレビューされます。
  • アーティファクト リンクの処理が改善され、ツールが使用可能な場合、クロードは WebFetch ではなく Artifact ツールを使用して claude.ai アーティファクト リンクを読み取るようになりました。
  • フラグが設定された rm コマンドに名前を付け、${VAR:?} ガードを提案するように、dangerous-rm 権限プロンプトを改善しました。これにより、ヘッドレス実行が回復できるようになります。
  • アーティファクト ツールの権限プロンプトを改善しました。短い文、タイトルまたはファイル名で名前が付けられたページとアーティファクト、およびテキストの後にリストされるリンク
  • Anthropic API の /model に Fable が常に表示されるように変更しました。組織の設定で無効になっている場合にのみグレー表示されます。
  • Bedrock、Vertex、Foundry の Bash サンドボックスの説明をファーストパーティの文言に変更し、サンドボックスをタスクに与えられたものの境界としてフレーム化しました。
  • リポジトリにベース ブランチまたは共有履歴がない場合に非対話型セッションで /ultrareview を拒否するように変更しました。
  • サブエージェントの結果がサブエージェントの出力としてマークされたヘッダーの下でメイン エージェントに到達するように変更され、結果がインデントされたため、サブエージェントの結果内のテキストはセッション独自の命令として渡すことができません。
  • Bedrock、Vertex、Foundry 上のワークフロー スクリプトの計算された agent() プロンプトが、スクリプト作成テキストとしてフレーム化されたサブエージェントに到達するように変更されたため、安全分類子はそれらをユーザーとして読み取らないようにしました。
  • SDK または IDE の外部で起動された claude -p 実行からバックグラウンドの Haiku 自動タイトル リクエストを削除しました。
  • 非推奨の TaskOutput ツールを削除しました。クロードは代わりに Read を使用してバックグラウンド タスクの出力ファイルを読み取り、taskOutputMaxChars 設定と TASK_MAX_OUTPUT_LENGTH は効果を失います。
  • [VSCode] パネル メニューにサインアウト行を追加し、入力コマンド メニューに /logout を追加しました。
  • [VSCode] バックグラウンド シェルとその他の実行中のタスクをエージェント マップに追加しました。それぞれに Stop と、それを開くための型指定された /tasks が含まれています。
  • [VSCode] 応答に [応答をコピー] ボタンと入力された /copy を追加しました。
  • [VSCode] 非アクティブなセッションが自動的にアーカイブされるときの 1 回限りの通知と、アーカイブされたセッション グループの「すべてアーカイブ解除」アクションを追加しました。
  • [VSCode] プラン制限が適用されないセッション マネージャー (Vertex、Bedrock、Foundry、API キー) に、セッションのコストとトークンの使用状況を [アカウントと使用状況] ダイアログとセッション マネージャーに追加しました。
  • [VSCode] 設定を開く代わりに /config の使用法テキストを表示する「一般設定」メニュー行を修正し、入力された /mcp、/hooks、/memory、/rewind および同様のコマンドでダイアログが開くようにしました。
  • [VSCode] /effort でレベルがすでに保存されているモデルで、エフォート スライダーのレベルが後のセッションに持続しない問題を修正しました。
  • [VSCode] 保存されたモデル設定が「Sonnet」などの大文字と小文字が異なるエイリアスである場合、すでに使用されているパネルで開かれた会話のモード ピッカーに自動が表示されない問題を修正しました。
  • [VSCode] /fast がデフォルトで高速モードを保存しないため、拡張機能がクロード コードを再起動すると失われる問題を修正しました。
  • [Web 上の Claude Code] チーム プランとエンタープライズ プランの環境ピッカーに個人セクションと組織セクションが追加され、管理者は個人環境を組織と共有できるようになりました。
  • [Web 上の Claude Code] チームおよびエンタープライズ プランの [コード] タブから読み取り専用の概要として開くように組織環境を変更しました。[管理者設定] → [クラウド環境] で編集できます。
  • [Claude Code on the web] カスタム ネットワーク アクセスとドメインなしで保存されたクラウド環境がサイレントに Trusted に戻る問題を修正しました。ダイアログは少なくとも 1 つのドメインを要求するようになりました
  • [ウェブ上のクロード コード] 「ウェブ」というラベルの付いた管理クロード コード設定を「クラウド セッション」に変更し、その下の冗長な読み取り専用モバイル行を削除しました。
  • [Claude Tag] Enterprise Grid 組織全体にインストールされた Slack チャネルで作成されたルーチンが、実行時にワークスペース内の他のパブリック チャネルを読み取れない問題を修正しました。
  • [Claude Tag] 一般的な API リファレンスではなく、各ベンダーの認証情報設定ページが開くように、Claude Tag アクセス バンドルの認証情報プリセットの「詳細」リンクを修正しました。
  • [Claude Tag] Claude Tag アクセス バンドルの Pylon 資格情報プリセットを変更し、管理者が Pylon の EU ホストをポイントできるようにしました。
  • [Claude Tag] Claude Tag アクセス バンドルの Google Cloud 認証情報フォームを修正しました。拒否されたキー ファイルにはその理由が表示されるようになり、ウェブサイトとスコープはロックされたままになり、拒否されたローテーションでは貼り付けられたキーが保持されます。
  • [Claude Tag] AWS 署名、client 証明書、またはカスタム CA を使用する接続を介したリクエストに対する応答ステータスが表示されない、Claude Tag 管理設定のネットワーク イベント ログを修正しました。
