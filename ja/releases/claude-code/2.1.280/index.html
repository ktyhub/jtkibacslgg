claude-code v2.1.280

クロードコード v2.1.280

何が変わったのか

  • Claude Opus 5.5 (claude-opus-5-5) を追加しました。デフォルトの Opus モデルになりました - 1M コンテキスト、$0.20/Mtok キャッシュ読み取りで Mtok あたり $4/$20
  • 全画面モードのより多くのリストにマウスのサポートを追加しました。ホイールは /skills リストをスクロールし、/plugin のスキルの状態オプションは cli 確認できます。
  • セッション内のすべての MCP サーバーの MCP ツール説明とサーバー命令の 2,048 文字の上限を変更する CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH を追加しました。
  • フック出力サイズとファイルに保存されるオーバーサイズ出力の数を hook_execution_complete OpenTelemetry イベントに追加しました。
  • ツリー内のスペルによって判断されるシンボリックリンクされたパスを介した書き込みを修正しました: 書き込みが到着するプロンプト名、および acceptEdits、許可ルールと自動モードは、外部への 1 つの到着を承認しなくなりました
  • 安全性チェック decli がレビューする際に自動モードでアクションを何度も再試行する問題を修正しました。アクションは一度拒否され、再試行しても役に立たないことがわかります
  • 安全性チェックで応答がなかった場合に、自動モードで一時停止せずにアクションが何度も拒否される問題を修正しました。再試行は後退し、10 回連続でメッセージが表示されてターンが停止します。
  • モデルが file_path および content の代わりに path、file_text、file_content、または野良 description を送信すると、書き込み呼び出しが検証に失敗する問題を修正しました。
  • ほとんどのダイアログ (/model、/effort、/config、/status、/usage、/plugin、/sandbox、/permissions、/artifacts、/mobile、/login、/upgrade、/usage-credits、 /install-github-app、/setup-bedrock、/setup-vertex) ダイアログを閉じる代わりにクロード コードを終了します。
  • ターミナル ウィンドウを前面に表示するだけで、検索ピッカー、タブ バー、エージェント/ワークフロー行、スラッシュ コマンド リンク、提案ドロップダウンなどのポインターの下の項目もトリガーする click を修正しました。
  • ダイアログを閉じる野良 n とダイアログを確認する野良 y を修正しました。 Enter キーと Esc キーを押して受け入れてキャンセルします (y/n を keybindings.json の confirm:yes/confirm:no にバインドして復元します)
  • ダイアログ内のテキストフィールドで、そのキーのキーバインドに入力した文字、数字、またはスペースが失われる問題を修正しました。
  • Enter キーで非表示の文字が削除された後、Windows 端末でプロンプト ラインがスクランブルされたままになる問題を修正しました。画面が再描画されるので、送信される正確なテキストを確認できます。
  • ペルシャ語とアラビア語のテキストがラテン語の単語や数字に接尾辞を付けるために使用するゼロ幅の非結合子を削除する非表示文字のクリーンアップを修正しました (「PDF」の複数形など)
  • Ctrl+C で音声ディクテーションが停止しない問題を修正しました (プロンプトはクリアされましたが、マイクは録音を続けました)、トランスクリプトの処理中に Esc キーがキャンセルされず、トランスクリプト ビューおよび vim NORMAL モードからスペースを押したままディクテーションが開始される問題を修正しました
  • クロードの動作中にホスト アプリ (クロード デスクトップ、VS コード、SDK) から行われたモデルの切り替えにより、次のプロンプトでプロンプト キャッシュ ミスが発生する問題を修正しました。
  • 再開されたフォーク サブエージェントが、最初に使用したツール リストを再送信するのではなく、ツール リストを再構築することで、そのエージェントのプロンプト キャッシュが壊れる問題を修正しました。
  • 詳細モード外で展開された場合に内部来歴プリアンブルを示すサブエージェント ハンドバック メッセージを修正しました
  • ブランチまたはタグを追跡する GitHub リポジトリまたは git URL からプラグインを更新した後、インストール時のコミットを維持する installed_plugins.json を修正しました
  • フォルダー内の manifest.json に名前がリストされている場合、~/.claude/skills/ のスキルが ~/.claude/skills/.trash/ に移動される問題を修正
  • ライトおよび ANSI テーマでホバー ハイライトが表示されないセッション フィードバック アンケートを修正しました
  • 唯一の実行を開く前に 1 行のリストを一時的に表示する /workflows を修正しました
  • フルスクリーン モードで、マウス ホイールが非表示のオプション (/model や /permissions など) を含む選択リストをスクロールしない問題を修正しました。
  • /plugin および /skills でロードに失敗したプラグインと同じ赤色の ✘ を表示するオフに切り替えたスキルを修正しました。オフでは薄暗い◯が表示されるようになりました
  • 複数選択オプションの説明がラベルの下ではなくオプション番号の下にインデントされる問題を修正
  • 全画面モードで /plugin、/skills、/mcp の検索ボックスの右枠が失われる問題を修正
  • /mcp がサーバー リストでは △ と表示されるが、同じサーバーの詳細ビューでは ⚠ が表示される問題を修正しました。リスト、詳細ビュー、/plugin がすべて表示されるようになりました ⚠
  • /config 設定リスト、/model、/memory、許可プロンプトなどの選択リストで Home と End が何もしない問題を修正
  • /skills メニューの PgUp/PgDn が最初または最後のスキルで停止せずに折り返される問題を修正しました
  • /config リストで選択された設定の値をタブがサイレントに変更する問題を修正しました。今はそこでは何もしません
  • 「ロール 'システム' は 'アシスタント' メッセージの前に置く必要があります」API エラーにより毎ターン失敗する会話を修正
  • サポートしていないプロキシまたはゲートウェイの背後で API エラー 400「入力タグ 'advisor_20260301'」が発生して毎ターン失敗するアドバイザーとの会話を修正しました。リクエストはそれなしで再試行されます
  • セッションが毎ターン失敗し、保存された履歴にロードできない MCP ツールに関する不正な通知が含まれていた場合の /compact を修正しました。
  • 保存されたトランスクリプトに不正な形式のシステム メッセージまたはファイル リストのないメモリ保存通知が保持されているセッションを再開するときのクラッシュを修正しました
  • 長時間実行されているフルスクリーン セッションが「回復不能なインターフェイス エラーの後にクロード コードが終了しました」で終了する原因の 1 つを修正しました。破損したキャッシュされたメッセージ リストが再構築されるようになりました。
  • 設定ファイル、または編集後に再読み込みするファイルが読み込み中に名前付きパイプに置き換えられると、クロード コードがハングする問題を修正しました。

  • 未完了のバックグラウンド エージェント、シェル、またはワークフローを使用してセッションを再開すると、何かを入力する前にモデル ターンが自動的に開始される問題を修正しました。
  • バックグラウンド サブエージェントに送信されたメッセージが、サブエージェントがターンを終了したときに、ヘッドレス セッションおよび SDK セッションでサイレントに失われる問題を修正しました。

  • ゼロ以外の良性の終了 (一致しない grep など) を失敗として報告するバックグラウンド シェル タスクを修正しました

  • Esc キーを押してプロンプトを編集したり、プロンプトに巻き戻したり、起動フックの実行中に Esc キーを押したりするなど、送信されたプロンプトが入力に戻ったときにドロップされる IDE の選択を修正しました。
