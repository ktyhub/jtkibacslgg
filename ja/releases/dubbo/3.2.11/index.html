dubbo 3.2.11

パッチ 公開日2024年1月27日 出典apache/dubbo 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.2.11

何が変わったのか

機能強化

  • DubboService アノテーションは、https://github.com/apache/dubbo/pull/13553 の @zhaoyunxing92 によるカスタム シリアル化をサポートします
  • https://github.com/apache/dubbo/pull/13586 の @suncairong163 による RESTEASY 応答ステータス コードをサポート
  • https://github.com/apache/dubbo/pull/13304 の @finefuture によるインターフェイス レベルの登録のカスタマイズ パラメータをサポート

バグ修正

  • https://github.com/apache/dubbo/pull/13617 の @MajaChen による REST プロトコルでの中国語の文字デコードを修正
  • https://github.com/apache/dubbo/pull/13633 の @shaowYe による MultipleRegistry キャッシュ ファイルのエラー名を修正
  • https://github.com/apache/dubbo/pull/13609 で @CycleMaker によって解放されない AbortPolicyWithReport セマフォ ロックを修正
  • https://github.com/apache/dubbo/pull/13593 の @namelesssssssssssss による MergeableClusterInvoker ログの問題を修正
  • https://github.com/apache/dubbo/pull/13597 の @namelesssssssssssss による protobuf クラスのディープ コピーの問題を修正
  • https://github.com/apache/dubbo/pull/13580 の @AlbumenJ による MethodKeyRt オーバーライドとエラー拡張を修正
  • https://github.com/apache/dubbo/pull/13583 で @AlbumenJ による遅延公開デッドロックを修正
  • https://github.com/apache/dubbo/pull/13592 の @namelesssssssssssss による NacosRegistry の Consumer.tag による dubbo.tag のオーバーライドを修正
  • https://github.com/apache/dubbo/pull/13582 の @namelesssssssssssss による StubMethodDescriptor 生成の問題を修正
  • https://github.com/apache/dubbo/pull/13559 の @namelesssssssssssss による proto パッケージと java_package の問題を修正
  • https://github.com/apache/dubbo/pull/13546 の @icodening による完全な既に例外を修正
  • https://github.com/apache/dubbo/pull/13558 の @baerwang による dubbo-go リンクと rust 言語を修正
  • https://github.com/apache/dubbo/pull/13551 の @CrazyHZM によるネイティブ デモのログバック依存関係を修正
  • REST サービスのメモリ リークを修正し、https://github.com/apache/dubbo/pull/13514 の @G-XD によって NettyHttpRequest フィールドの ByteBuf を解放

コードの拡張

関連する PR: #13600、#13601、#13622、#13557、#13556、#13515、#13507、#13554

CI とテストの機能強化

関連する PR: #13489、#13646
