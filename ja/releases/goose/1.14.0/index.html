#グースv1.14.0

グース v1.14.0

✨ 特徴

  • Mistral AI プロバイダー - 新しいプロバイダーとしての Mistral AI のサポート [#5009](https://github.com/block/goose/pull/5009)
  • 新しいウィンドウ オプションを備えた macOS ドック メニュー - macOS との統合を向上させるためのカスタム ドック メニュー [#5099](https://github.com/block/goose/pull/5099)
  • クイック ランチャー - UI のクイック ランチャー機能を復元 [#5144](https://github.com/block/goose/pull/5144)
  • 統一されたスタイル チェック - 包括的なコード品質検証のための新しい check-everything コマンド [#5650](https://github.com/block/goose/pull/5650)
  • GitHub Copilot AI モデル - 新しい Copilot AI モデル バージョン [#5603](https://github.com/block/goose/pull/5603) のサポート
  • 認証ブロックの環境置換 - 認証構成における動的な環境変数置換 [#5439](https://github.com/block/goose/pull/5439)
  • CLI を介したプラットフォーム ツール - コマンドライン インターフェイス [#5570](https://github.com/block/goose/pull/5570) を介したプラットフォーム ツールへのアクセス
  • 保留中の拡張機能インジケータ - 拡張パネルにロードされている拡張機能の視覚的なフィードバック [#5493](https://github.com/block/goose/pull/5493)

🐛 バグ修正

  • 暴走したサブエージェント チェーン - サブエージェントの無限再帰を防止する [#5659](https://github.com/block/goose/pull/5659)
  • 削除されたセッションで 404 エラーが繰り返されました - 削除されたセッションへのアクセス試行を停止します [#5644](https://github.com/block/goose/pull/5644)
  • レシピ リスト エントリの重複 - goose recipe list は一意のエントリ [#5645](https://github.com/block/goose/pull/5645) を返すようになりました
  • Bedrock 認証情報の更新 - AWS Bedrock 認証情報のローテーション [#5599](https://github.com/block/goose/pull/5599) を適切に処理します
  • クロード コード プロバイダーの自動モード - クロード コードの統合を向上させるため、デフォルトは自動モードになります [#5642](https://github.com/block/goose/pull/5642)
  • テトレート モデルの構成 - 壊れたデフォルトを haiku-4.5 [#5587](https://github.com/block/goose/pull/5587) に置き換えます
  • AGENTS.md の処理 - goosehints/AGENTS.md 処理を開発者拡張機能 [#5575](https://github.com/block/goose/pull/5575) からコア Goose に移動します。
  • 空の右 click メニュー - 標準のコンテキスト メニュー項目が適切に表示されるようになりました [#5616](https://github.com/block/goose/pull/5616)
  • トークン状態表示 - ロード時およびメッセージ完了後にトークン数が正しく表示されるようになりました [#5606](https://github.com/block/goose/pull/5606)
  • MCP スモーク テスト用の Gemini モデル - テストの信頼性を高めるために Flash から Pro に切り替える [#5574](https://github.com/block/goose/pull/5574)
  • Claude CLI の処理 - Claude コマンドライン インターフェイスの統合の改善 [#5594](https://github.com/block/goose/pull/5594)
  • レシピ YAML 解析 - カスタマイズされたレシピでの minijinja 解析エラーを防止 [#5494](https://github.com/block/goose/pull/5494)
  • MCP ツールの引数 - 適切な型処理のためのスキーマ認識型数値強制 [#5478](https://github.com/block/goose/pull/5478)
  • Flake.nix メイン ブランチ - Nix フレーク構成を修正 [#5600](https://github.com/block/goose/pull/5600)

🔧 改善点

  • 統合されたサブレシピとサブエージェント実行 - 一貫した動作のための共有レシピ パイプライン [#5082](https://github.com/block/goose/pull/5082)
  • 標準化された CLI 引数フラグ - 更新されたドキュメント [#5516](https://github.com/block/goose/pull/5516) による一貫性のあるコマンドライン インターフェイス
  • タスク ID としてのセッション ID - トレーサビリティを向上させるために、UUID の代わりにセッション ID を使用します [#5398](https://github.com/block/goose/pull/5398)
  • CLI プロバイダーの検索パスの改善 - プロバイダーの検出と処理の改善 [#5554](https://github.com/block/goose/pull/5554)
  • スケジューラーのクリーンアップ - パフォーマンスを向上させるための洗練されたスケジューリング システム [#5571](https://github.com/block/goose/pull/5571)
  • レシピ プロンプトからヒントを削除 - ヒントが乱雑にならない、よりクリーンなレシピ実行 [#5622](https://github.com/block/goose/pull/5622)
  • プロバイダー要求中の Ctrl-C 処理 - 長時間実行操作の割り込み処理の改善 [#5585](https://github.com/block/goose/pull/5585)
  • ユーザー向けテキストの改善 - 出力を向上させるために to_string_lossy の代わりに表示を使用する [#5666](https://github.com/block/goose/pull/5666)
  • 手動圧縮 - データベース圧縮のテストと修正 [#5568](https://github.com/block/goose/pull/5568)
  • ログの削減 - 不要なメッセージを削除することで、よりクリーンなログ出力 [#5631](https://github.com/block/goose/pull/5631)
  • エージェントの指示の明確さ - 内部エージェントの指示ドキュメントの改善 [#5655](https://github.com/block/goose/pull/5655)
  • ツール呼び出しの場所とキャンセル - ツールの追跡とキャンセルのサポートが向上し、ACP が強化されました [#5588](https://github.com/block/goose/pull/5588)

📚 ドキュメント

  • 2025 年 10 月コミュニティ オールスター スポットライト - ハクトーバーフェスト版コミュニティ ハイライト [#5625](https://github.com/block/goose/pull/5625)
  • 開発者チュートリアルのアクセス制御セクション - 拡張機能のアクセス制御に関する新しいドキュメント [#5615](https://github.com/block/goose/pull/5615)
  • 拡張子の記述要件 - CLI [#5573](https://github.com/block/goose/pull/5573)、[#5635](https://github.com/block/goose/pull/5635) 経由で拡張子を追加する場合に記述が必要であることを明確にしました。
  • レシピ パラメーター タイプ - 以前に欠落していたレシピ パラメーター タイプのドキュメント [#5584](https://github.com/block/goose/pull/5584)
  • リリース手順 - リリース プロセスのドキュメントを更新 [#5662](https://github.com/block/goose/pull/5662)
  • Copilot レビュー手順 - GitHub Copilot コード レビューのカスタム手順 [#5646](https://github.com/block/goose/pull/5646)

🔨メンテナンス

  • rmcp を 0.8.5 にアップグレード - MCP 依存関係を更新 [#5673](https://github.com/block/goose/pull/5673)
  • OpenAPI バージョン バンプ - OpenAPI バージョンの直接管理 [#5674](https://github.com/block/goose/pull/5674)、[#5611](https://github.com/block/goose/pull/5611)
  • メンテナーの更新 - 現在のチーム [#5675](https://github.com/block/goose/pull/5675) で MAINTAINERS.md を更新しました
  • ログ ディレクトリのクリーンアップ - 存在しない環境変数 [#5658](https://github.com/block/goose/pull/5658) の使用を削除します。
  • CI キャッシュの改善 - キャッシュ キーでのデバッグ/リリースの区別 [#5613](https://github.com/block/goose/pull/5613)
  • ビルド スクリプトの修正 - OpenAPI 生成で npx を使用する [#5664](https://github.com/block/goose/pull/5664)、[#5671](https://github.com/block/goose/pull/5671)
  • エラーの可視性 - デバッグを改善するために失敗時にエラーを表示 [#5643](https://github.com/block/goose/pull/5643)
  • JetBrains 拡張機能の削除 - 非推奨の JetBrains 統合 [#5602](https://github.com/block/goose/pull/5602) を削除しました
  • Web 二重書き込み防止 - 冗長な書き込み操作を回避します [#5601](https://github.com/block/goose/pull/5601)
  • 副操縦士のフィードバック調整 - 副操縦士レビューの軽微なテキストの問題を沈黙させます [#5665](https://github.com/block/goose/pull/5665)
