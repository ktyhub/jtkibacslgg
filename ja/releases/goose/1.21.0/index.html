goose v1.21.0

マイナー 公開日2026年1月22日 出典aaif-goose/goose 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#グースv1.21.0

特徴

  • マルチチャットのサポート - 複数のチャット セッションを管理する機能を追加しました (#6428) (@zanesq)
  • スタンドアロン MCP アプリ - スタンドアロン MCP アプリケーションのサポート (#6458) (@DOsinga)
  • ユーザーが構成可能なテンプレート - ユーザーがテンプレートをカスタマイズできるようにします (#6420) (@DOsinga)
  • Linux 用の Flatpak サポート - Linux ディストリビューション用に Flatpak パッケージを追加しました (#6387) (@The-Best-Codes)
  • 組織ポリシー フィルタリングを備えた GCP Vertex モデル リスト - 組織ポリシー サポートを備えた強化されたモデル リスト (#6393) (@rabi)
  • 分離エージェント状態の並列セッション - goose-acp で並列セッションを有効にする (#6392) (@codefromthecrypt)
  • CLI の許可プロンプト - CLI (#6475) (@DOsinga) で許可を求めます
  • CLI でのカスタマイズ可能な改行キーバインド - 改行キーバインドのカスタマイズを許可します (#5956) (@trobrock)
  • キーリング障害に対する正常なフォールバック - キーリングが利用できない場合の処理の改善 (#5808) (@sheikhlimon)
  • 読みやすいように大きい/小さいトークン数をフォーマットします - UI でのトークン数表示の改善 (#6449) (@aharvard)
  • MCP アプリのprefersBorder オプションをサポート - MCP アプリの UI 強化 (#6465) (@aharvard)
  • コード実行フィルタリングからサブエージェント ツールを除外します - コード実行モードでサブエージェントの委任を許可します (#6531) (@rabi)
  • セッション相関のためのエージェント セッション ID の標準化 - プロバイダー間のセッション追跡の改善 (#6626) (@codefromthecrypt)
  • レシピ用の MCP サーバー - レシピ用の MCP サーバーのサポートを追加しました (#6552) (@dianed-square)
  • GOOSE_PREDEFINED_MODELS からのオプションのリクエスト パラメーターとコンテキスト制限 - 拡張モデル構成オプション (#6489) (@zanesq)

バグ修正

  • 修正: CLI の platform_schedule_tool を除外 (#6442) (@lifeizhou-ap)
  • 修正: スラッシュ コマンドを使用するときにサブレシピを適用する (#6460) (@angiejones)
  • 修正: code_execution でのツール呼び出しによるモデルの癖の処理 (#6352) (@rabi)
  • 修正: コード モードの結果記録をクリーンアップ (#6343) (@alexhancock)
  • 修正: OpenRouter でのツール呼び出しに対する Gemini thoughtSignature の処理 (#6370) (@rabi)
  • 修正: レシピ スラッシュ コマンドが単一のオプション パラメーターでは機能しない (#6235)
  • 修正: グローバル .gooseignore および否定パターンをサポート (#6157) (@leocavalcante)
  • 修正: 非ループバック アドレスでグースを実行する場合は認証が必要 (#6478) (@michaelneale)
  • 修正: 無効なツール呼び出しのエラー メッセージを改善 (#6483) (@jasoncarr0)
  • 修正:tool_call 引数をオプションにし、サイレント ストリーム終了 (OpenAI) を修正 (#6309) (@rabi)
  • 修正: code_execution で Record_result の出力を JSON としてシリアル化します (#6495) (@rabi)
  • 修正: OpenRouter ストリーミングの 0 トークン (#6493) (@lifeizhou-ap)
  • 修正: MCP アプリのツール呼び出しから拡張子名を正しく解析します (#6482) (@aharvard)
  • 修正: リフレッシュ時にディープリンク UI が繰り返される (#6469) (@Yorisoft)
  • 修正: clicked 時に人気トピックがチャットを開始しない (#6508) (@zanesq)
  • 修正: escaping をコマンド フィールドに追加しないでください (#6519) (@jamadeo)
  • 修正: null としてシリアル化する代わりに、None の場合は Structured_content を省略します (#6499) (@aharvard)
  • 修正: MCP アプリのコンテンツに ContentBlock[] を使用するように ui/メッセージを更新します (#6546) (@aharvard)
  • 修正: goose/CONTRIBUTING.md に指示がありません (#6565)
  • 修正: サイドバー アニメーションのスクロールバーのちらつき (#6564) (@The-Best-Codes)
  • 修正: エージェントが応答する前に、すべての MCP プロンプト メッセージをセッションに同期します (#6566) (@angiejones)
  • 修正: 拡張機能の読み込みに関する回帰を元に戻す (#6568) (@michaelneale)
  • 修正: CLI にロードするすべての拡張機能を解決しました (#6464) (@lifeizhou-ap)
  • 修正: グローバル エージェント スキルのパス (#6591) (@emma-squared)
  • 修正: 実際にセッションから拡張機能の作業ディレクトリを設定します (#6612) (@zanesq)
  • 修正: 累積トークン数 (#6587) (@lifeizhou-ap)
  • 修正: session_id をプロバイダーと MCP に伝播 (#6584) (@codefromthecrypt)
  • 修正: 改行を修正 (#6459) (@angiejones)

  • パフォーマンス: 会話履歴全体で思考署名の蓄積を回避します (Google) (#6462) (@rabi)
