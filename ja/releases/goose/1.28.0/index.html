#グースv1.28.0

✨ 特徴

  • 情報漏洩などを防ぐ敵対的エージェント #7948
  • クロードの適応的思考サポート #7944
  • 新しいオンボーディング フロー #7266
  • セッション DB 経由でセッションごとに GooseMode を永続化 #7854
  • session.id を OpenTelemetry スパンとログ レコードに伝播する #7490
  • オートビジュアライザー拡張機能を MCP アプリに移行 #7852
  • ACP セッション/set_mode ハンドラー #7801
  • MCP ルーツサポート #7790
  • ネストされたサブディレクトリにヒントをロード #7772
  • ファイルシステム I/O を ACP に委任するための ACP 読み取りツール clients #7668
  • 確定的読み取りのための要約ツール #7054
  • クロード コードおよびコーデックス用の ACP プロバイダー #6605
  • OpenAI Responses API #7375 から推論の概要をキャプチャします
  • Anthropic 互換の API #7640 を備えた MiniMax プロバイダー
  • 宣言型プロバイダーとしての Tensorix #7712
  • スキルサポートファイルは召喚時のload()で個別にロード可能 #7583
  • LLM プロバイダーとしての Avian #7561
  • TUI UX と公開設定を組み合わせる #7683
  • カスタムプロバイダー構成のベースパスフィールド #7614
  • Slack ボットのプライベート チャネル検出の改善 #7680
  • 優先マイク選択 #7805
  • ストリーミング可能な HTTP 拡張 URL でのシークレット補間 #7782

🐛 バグ修正

  • クロードコード #7931 のユーザーメッセージの誤ったagent_visibleフィルターを削除
  • 認証情報の更新による認証失敗時の再試行 #7812
  • イテレータ型チェックの修正のために pctx_code_mode を 0.3.0 にバンプ #7892
  • スキルが検出されるように拡張機能をロードするときに session_id を渡します #7868
  • chatgpt_codex プロバイダーのツール選択とParallel_tool_calls のサポート #7867
  • 複数リクエスト時のツール確認処理 #7856
  • レシピ再試行パスの tokio::sync::Mutex デッドロックを解決 #7832
  • グースセッションリストの壊れたパイプにヒットしたときにエラーなしで書き込みを停止 #7858
  • 外部 HTTP バックエンドの upgrade-insecure-requests CSP をスキップ #7714
  • コマンドが子プロセスをバックグラウンドで実行するときにハングしないようにする #7689
  • ツール呼び出し JSON の解析に失敗した場合にエージェント ループを終了 #7840
  • SSE 接続ドロップによる応答の切り捨てを防止 #7831
  • Bedrock キーのみが設定されている場合に SageMaker TGI が設定済みとしてマークされないようにします #7284
  • $DISPLAY が検出されない場合にコンピューターコントローラーの機能を無効にする #7824
  • セッション再開時にMCP拡張機能を登録 #7806
  • ヒント ファイル フィルタリングのために、prompt_manager に .gitignore をロード #7795
  • OpenAI 互換プロバイダーの max_completion_tokens を max_tokens に再マッピング #7765
  • OpenAI レスポンスの保持 API ツール呼び出し/出力リンク #7759
  • プロンプトが有効な KV キャッシュ サイズを超えた場合に ContextLengthExceeded を返す #7815
  • Google 思考処理には includeThoughts/part.thought を使用 #7593
  • モデルセレクターのタブに間違ったモデルが表示される #7784
  • Windows シェル コマンドで単語をスペースで分割しないようにする #7810
  • GOOSE_PATH_ROOT 周りのパス解決を統一 #7335
  • OAuth スコープを DCR に渡し、トークン応答から Grant_scopes を抽出します #7571
  • config.yaml がシンボリックリンク #7669 の場合、実際のファイルに書き込みます
  • ゲートウェイ停止時にペアリングを保持 #7733
  • URL から派生したストリーミング可能な HTTP 拡張機能名をサニタイズ #7740
  • キーリングの可用性エラー検出を改善 #7766
  • GOOSE_EXTERNAL_BACKEND から安全でないデフォルトのシークレットを削除 #7783
  • ExtensionConfig バリアントの説明フィールドに #[serde(default)] を追加 #7708
  • スマート承認モードを復元 #7690
  • GOOSE_TLS 環境変数 #7686 を介して Goosed エージェントで TLS を構成可能にします
  • 最大回転数構成 #7612
  • add_extension をスキップする前に拡張機能の構成を比較 #7650
  • 表示可能なチャネルのみを Slack ボット コンテキストに追加する #7678
  • プラットフォームのバイナリが存在することを確認してください #7676
  • グローバル静的出力バッファーをインスタンスごとの TempDir #7632 に置き換えます。
  • 自動送信を使用して最初のメッセージ内のパラメーターを解決 #7659
  • 下位互換性を維持するためにレシピにアナライザー拡張機能を追加 #7652
  • セッションの混合を防ぐため、空のセッションの再利用範囲を現在のウィンドウに設定します #7602
  • ローカル推論での中止を防止 #7633
  • LRU によって削除されたセッションのプロバイダーと拡張機能を復元 #7616
  • pnpm コマンドの二重ダッシュを削除 #7951
