#グースv1.32.0

✨ 特徴

  • Exa AI を活用した検索ツール #8487
  • グースがタスクを完了したときのデスクトップ通知 #8647
  • @エージェントがチャットでサポートについて言及 #8571
  • /skills コマンド #8600
  • スレッドをプロジェクトに関連付ける #8745
  • goose2 コンテキスト ウィンドウ UX の自動圧縮 #8721
  • goose2のメッセージバブル+アクショントレイ#8720
  • goose2 の直接 ACP パターンによる音声ディクテーション #8609
  • Goose2 チャット入力でのコンテキスト ウィンドウの使用 #8613
  • StreamableHttp MCP の Unix ドメイン ソケット トランスポート #7860
  • 拡張ライブラリの Cash App 拡張 #8622
  • オンデマンドプロンプト編集用の/editコマンド #8566
  • 宣言型プロバイダーとしての Novita AI #8432
  • OAuth デバイス フロー認証を備えた Kim Code プロバイダー #8466
  • TUIの拡張機能管理画面 #8536
  • 拡張機能設定ページとコンテキスト パネル ウィジェット #8540
  • Client ID メタデータ ドキュメント (CIMD) の OAuth サポート #8550
  • ステータスバーでインラインでコンテキストウィンドウを使用する #7607
  • goose2 のチャット添付ファイル #8534
  • ui/goose2 用の Husky git フック #8577

🐛 バグ修正

  • 初回起動時の起動の遅さを回避するために、TLS 証明書をディスクにキャッシュします #8174
  • セッションのロード後にプリプロンプトが表示される #8744
  • ストリーミング チャンク内の欠落したデルタ フィールドの処理 #8700
  • OpenAI プロバイダーの両方の推論フィールドを持つストリーミング チャンクを受け入れる #8715
  • 既知のモデル #8636 に対する応答 API ツールおよび gpt-5.4 の場合は strict:false
  • アプリビューの説明の正しい文法 #8679
  • チャット内のリンクを開けません #8544
  • ログインシェルに関係なく、bash/sh でシェルツールを実行 #8659
  • プレフィックス付きの v1 ベース URL に /chat/completions を追加 #8521
  • キミコード モデルのメタデータをライブキミ コード API #8588 と調整します
  • TUI を OOM する可能性があるアイドル状態の 300 ミリ秒の再レンダリング ループを停止 #8616
  • チャット読み込み状態モデル プレースホルダー #8431
  • 応答スタイルが詳細である場合、デフォルトでツール呼び出しを展開します #8478
  • LLM リクエストログを書き込む前にログディレクトリを作成します #8522
  • Ollama プロバイダーのトークン使用状況追跡と構成可能なストリーム タイムアウトを有効にする #8493
  • 手動解析の代わりにスレッドのタイムスタンプに SQLX クロノ デコードを使用する #8575
  • チャットのコンテンツの二重枠を削除 #8545
  • 構成された外部 Goosed ホストからの自己署名証明書を受け入れる #8400
  • チャット履歴削除後のサイドバーセッションの同期 #7707
  • ヘッドレス モードでツールの承認が必要な場合のセッションのハングを防止 #7915
  • ローカル プロバイダー #8626 で [モデルの切り替え] パネルを開くときの最大 5 秒の遅延を解消します。
  • goose-acp-macro #8753 のハードコードされた依存関係を削除しました。
  • openapi 互換カスタム エンドポイント用のストップ ロード openai 高速モデル #8644

🔧 改善点

  • エージェントのセットアップを段階的なフェーズに分割して、起動のブロックを軽減します #8746
  • 拡張機能管理は ACP+ に移行されました #8733
  • 非同期状態とデフォルト解決のバグに対するコード レビュー スキルを強化 #8740
  • チャット モデルの選択を永続的かつ確実に適用する #8734
  • オーバーホールプロバイダーの在庫と代理店/モデルの選択 #8652
  • プロバイダー ACP メソッドをインベントリーに統合 #8710
  • ACP 経由でスキルをソースとして管理 #8675
  • 共有 OAuth デバイス フロー ヘルパーの抽出 #8619
  • goose2 の全角アシスタント メッセージ #8760
  • TUIの改善 #8736
  • Goose2 エージェント管理フロー #8737
  • サイドバーの改良: コピーの検索、分割線、プロジェクトの並べ替え、DnD の修正 #8568
  • サイドバーアクティビティインジケーター、プレースホルダートークン、および検索フィールドの絞り込み #8606
  • セッション開始時のウォーム シェル PATH ルックアップ #8631
  • 最初のメッセージでゲート パフォーマンス ログと build_config_update を削除 #8627
  • デフォルトが設定されている場合は、デフォルトのフォールバックプロバイダーとモデルを使用します #8650
  • git 変更ウィジェットで追跡されていない個々のファイルを表示 #8574
  • Goose2 セッションの作業ディレクトリ #8624
  • rmcp を 1.5.0 #8618 に更新します。
  • goose-acp クレートを goose にマージ #8726
  • 最新のエージェントclientprotocol/sdk パッケージ #8667 と互換性があるように、グース SDK および TUI をアップグレードします。
  • 1.91.1 #8670 の MSRV を宣言し、施行します
  • Databricks API 呼び出しでグローバルに一意の会話 ID を sessionId として渡します #8576
  • ツールを見つけやすくするためにエージェント スキルをリポジトリ ルートに移動 #8535
  • OAuth セットアップ中に ChatGPT Codex 認証をリセット #8569
  • ジム シナリオ カーゴ プロジェクトを親ワークスペースから分離 #8640
