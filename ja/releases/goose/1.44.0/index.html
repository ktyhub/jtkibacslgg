#グースv1.44.0

セキュリティ修正

  • goose review 経由の goose CLI での任意のコマンド実行 (git core.fsmonitor config 経由) - GHSA-r5pp-p5r8-466r (クレジットは @0xmagic0)

✨ 特徴

  • 最新の Gemini モデル #10630 のサポート
  • working_dir を Stop フック コンテキストに渡します #10296
  • OpenAI互換Fugu用宣言型Sakana AIプロバイダー API #10357
  • モデル インタラクション ビューアが復元されました #10205
  • セキュリティのために重複ウィンドウを使用したチャンクコマンド分類子入力 #10416
  • プロバイダー グリッド #10437 の検索フィルター
  • メタモデル API #10432 による Muse Spark 1.1 のサポート
  • GPT-5.6 サポート #10384
  • スリープおよび接続喪失後にデスクトップ ACP セッションを再接続します #10411
  • メッセージごとの使用状況統計 UI (トークン、コスト、TTFT、トークン/秒) #10210
  • 動的モデル検出とコンテキスト制限を備えた OllamaCloudProvider #10264
  • アプリ UI からカスタム アプリのサポートを削除 #10127
  • フォークする前に会話を編集するための --edit セッション フラグ #9799
  • iFlytek Spark および Astron MaaS プロバイダー #9837
  • Fireworks AI 宣言型プロバイダー #9990
  • OpenRouter リクエスト パラメーターのサポート #9276
  • フランス語、ドイツ語、イタリア語、ポルトガル語、インドネシア語、マレー語、ベトナム語、zh-TW デスクトップ ロケール #10072
  • MiniMax-M3 および欠落している M2.7 バリアント #10431

🐛 バグ修正

  • 拡張形式を通じてコマンド引数を保持 #10527
  • コードモードの手動承認を強制する #10528
  • アプリのファイル操作を制限する #10481
  • 削除時に注目のモデルのサイズを保持し、不足しているサイズを埋め戻す #10422
  • pctx 0.4.1 #10572 で再帰的なスキーマ タイプを保持する
  • スキーマ バージョン #10586 を使用してインベントリ テーブルをアトミックに作成します
  • OpenAI 互換バックエンドのツール スキーマで oneOf を anyOf に書き換えます #10571
  • 非ローカルプロバイダーのデフォルトとしてカスタムモデルを許可 #10438
  • 絶対グースパスルートが必要です #10454
  • リクエストによるスコープスマート承認 #10457
  • 固定サブレシピ値を保持する #10452
  • Flatpak に git をバンドルして、hermit がパッケージ レジストリ #10511 をクローンできるようにします
  • AGENT_SESSION_ID をシェル コマンドに公開する #10428
  • ライブ セッション中に画像コンテンツ チャンクを client に転送 #10485
  • ハングを防ぐためにメイン ランタイムでコード モード コールバックをディスパッチします #10484
  • OAuth トークン キャッシュの保護 #10516
  • コンテンツ視聴者の境界を保持 #10493
  • バインドされたスケジュールされたレシピ検証 #10509
  • 接続を強制終了する代わりに、ディスパッチ ハンドラーから JSON-RPC エラーを返す #10499
  • 準備ツールのテスト状態を分離 #10504
  • ローカル推論を回避する 金属分解クラッシュ #10508
  • musl ビルドのインデックスマップ serde サポートを有効にする #10507
  • セッション再開時にチャットをスクロールして最新の返信を表示 #10501
  • 大規模な応答流出ファイルを保護 #10482
  • LiteLLMをrefresh_onlyインベントリに登録して、モデルピッカーがモデルをリストするようにします#10489
  • CLI #10420 でプロバイダー セレクターの高さを制限する
  • 既存のシークレット ファイルのアクセス許可を強化 #10453
  • 画像アクセス機能の分類 #10451
  • ワンタイム権限スコープを保持 #10450
  • Flatpak デスクトップ エントリに goose:// スキーム ハンドラーを登録 #10461
  • 重複したレシピパラメータキーを拒否 #10448
  • GUI を閉じるときに孤立した Goose サーブ バックエンドを同期的に強制終了する #10292
  • コードモードスキーマの前に自己参照 $ref サイクルを中断する #10469
  • Windows での複数行の貼り付けの 1 行ずつの自動送信を停止 #10326
  • 構成エディターでネストされた構成値を非表示にする #10390
  • cwd からの TUI スクリプトの解決を停止 #10449
  • コード モード コールバックから MCP アプリ ツールを除外 #10290
  • 開発者シェルツール呼び出しにデフォルトの拡張タイムアウトを適用 #10348
  • マルチターンツール呼び出し時の DeepSeek 思考モードのreasoning_contentを保持する #10366
  • プロンプトのタイムスタンプをタイムゾーン明示的にする #10209
  • 承認中の圧縮を無効にする #10089
  • pnpm 11 プロジェクト構成の復元 #10395
  • ストリーミングで空の文字列finish_reasonを非終端として扱う#10258
  • Gemini OAuth オンボーディングを修正 #10363
  • サイレントに停止するのではなく、空のプロバイダー ターンを再試行します #10360
  • FMA/AVX2 なしの x86_64 CPU 上の SIGILL に対して llama.cpp バックエンド初期化をガード #10105
  • 応答関数呼び出し名をサニタイズ #10344
  • エージェントが実際に提供する ID からセッション モードを選択します #10320
  • インストール リンクのない拡張機能の手動セットアップ インジケーターを表示 #10321
  • 重複した署名付き思考ブロックを重複除去して Anthropic 400 #10083 を修正しました
