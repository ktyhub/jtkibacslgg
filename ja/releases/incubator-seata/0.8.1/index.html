incubator-seata v0.8.1

パッチ 公開日2019年9月18日 出典apache/seata 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

インキュベーターシート v0.8.1

バージョンは以下のように更新されます。

特徴：

  • [#1598] 絶対パスを使用するプロファイルをサポート
  • [#1617] サポートプロファイル（registry.conf）名を設定可能
  • [#1418] undo_log kryo シリアライザーをサポート
  • [#1489] protobuf Maven プラグインをサポート
  • [#1437] kryo コーデックをサポート
  • [#1478] データベースモックをサポート
  • [#1512] mysql および Oracle の複数挿入バッチ構文のサポートを拡張しました
  • [#1496] データソースの自動プロキシをサポート

バグ修正：

  • [#1646] ファイルモードでの selectForUpdate lockQuery 例外を修正しました。
  • [#1572] テーブル名が小文字の場合に Oracle でテーブルメタの取得が失敗する問題を修正しました
  • [#1663] テーブル名がキーワードの場合にテーブルメタの取得が失敗する問題を修正しました
  • [#1666] 復元接続の自動コミットを修正しました
  • [#1643] java.sql.Blob、java.sql.Clob のシリアル化と逆シリアル化を修正しました。
  • [#1628] Oracle サポート ROWNUM クエリを修正
  • [#1552] BranchSession サイズが大きすぎる場合の BufferOverflow を修正
  • [#1609] Oracle キーワードチェッカーの安全でないスレッドを修正
  • [#1599] mysqlキーワードチェッカーの安全でないスレッドを修正
  • [#1607] 使用されているドルイドのバージョンが 1.1.3 未満の場合の NoSuchMethodError を修正
  • [#1581] GlobalSession と FileTransactionStoreManager で一部の長さが欠落していたのを修正
  • [#1594] nacos のデフォルトの名前空間を修正
  • [#1550] xidBytes.length が欠落している BranchSession サイズの計算を修正しました
  • [#1558] rpcMessage の本文が null の場合の NPE を修正
  • [#1505] バインド パブリック ネットワーク アドレスのリッスンに失敗した問題を修正しました
  • [#1539] nacos 名前空間設定が有効にならない問題を修正
  • [#1537] nacos-config.txt で store.db.driver-class-name プロパティが欠落しているのを修正しました
  • [#1522] ProtocolV1CodecTest testAll がテストに合格しないように見える場合がある問題を修正
  • [#1525] getAfterImage エラー、trx 自動コミット時の修正
  • [#1518] EnhancedServiceLoader でロード クラス エラーが表示される可能性がある問題を修正しました
  • [#1514] シリアル化依存性の欠如によりアンドゥログを生成できず、true をレポートできない場合を修正しました。
  • [#1445] DefaultCoordinatorMetricsTest UT が失敗する問題を修正しました
  • [#1481] 複数のデータソースにおける TableMetaCache の更新問題を修正

最適化：

  • [#1629] etcd3のウォッチャー効率を最適化します。
  • [#1661] global_tableの挿入transaction_nameのサイズを最適化します。
  • [#1633] ブランチ トランザクションの繰り返しレポートを最適化する false
  • [#1654] slf4j の誤った使用法を最適化する
  • [#1593] サーバーログの最適化と標準化
  • [#1648] テーブル構築時のtransaction_nameの長さを最適化します。
  • [#1576] セッション非同期コミットタスクに対する命令の並べ替えの影響を排除します。
  • [#1618] アンドゥログ マネージャーを最適化し、アンドゥログ サポートの削除を修正しました。
  • [#1469] ロック競合例外の数を減らします。
  • [#1619] StringBuffer を StringBuilder に置き換えます
  • [#1580] LockKeyConflictExceptionの最適化と登録方法の変更
  • [#1574] コミット成功時に DB モードの GlobalSession ロックを一度削除して最適化します
  • [#1601] タイプミスを最適化
  • [#1602] セキュリティの問題のため、fastjson バージョンを 1.2.60 にアップグレードします
  • [#1583] Oracle プライマリ インデックスの取得を最適化します
  • [#1575] RegisterTMRequest に UT を追加
  • [#1559] 期限切れのUNDOログを削除するための遅延を最適化します。
  • [#1547] TableRecords はジャクソンの注釈を削除します
  • [#1542] AbstractSessionManager デバッグ ログを最適化します
  • [#1535] H2 を削除し、pgsql でプライマリ インデックス コードを取得し、resultSet を閉じます
  • [#1541] コードクリーン
  • [#1544] 中国語のコメントを削除
  • [#1533] マルチ構成分離のロジックのリファクタリング
  • [#1493] テーブルメタチェッカースイッチを追加
  • [#1530] テーブルにインデックスがない場合に例外をスローします
  • [#1444] マップの操作を簡素化
  • [#1497] Seata-all 依存関係を追加
  • [#1490] 不要なコードを削除 コードをコミットしてくれたこれらの貢献者に感謝します。意図しない省略があった場合はご報告ください。
