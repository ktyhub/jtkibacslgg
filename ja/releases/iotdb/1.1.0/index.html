iotdb v1.1.0

マイナー 公開日2023年4月3日 出典apache/iotdb 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#iotdbv1.1.0

新機能

  • [IOTDB-4572] デバイスごとに一致する時間による順序をサポート
  • [IOTDB-4816] クエリの表示コマンドをサポート
  • [IOTDB-4817] kill クエリ コマンドのサポート
  • [IOTDB-5077] SHOW REGIONS で新しいコマンド形式をサポート
  • [IOTDB-5108] リージョン移行のサポート
  • [IOTDB-5202] 特定のデータベースを使用した表示リージョンのサポート
  • [IOTDB-5282] 現在のクラスター変数を表示できる SQL 表示変数を追加
  • [IOTDB-5341] 集計クエリで GROUP BY VARIATION をサポート
  • [IOTDB-5372] SELECT INTO でのデータ型キャストのサポート
  • [IOTDB-5382] IoTDB の組み込みスカラー関数として DIFF をサポート
  • [IOTDB-5393] リージョンの表示を実行する際のリージョンの作成時間
  • [IOTDB-5456] COUNT_IF 組み込み集計関数を実装する
  • [IOTDB-5515] 集計クエリで GROUP BY CONDITION をサポート
  • [IOTDB-5555] datanode-engine.properties で dn_rpc_port と dn_rpc_address の変更を有効にする
  • docker の展開をサポート
  • 表示領域で SeriesSlotId の名前を SeriesSlotNum に変更します

改善点

  • [IOTDB-4497] NodeStatus 定義を改善
  • [IOTDB-5066] GetSlots SQL をアップグレードしました
  • [IOTDB-5161] WHERE & HAVING 句の出力型チェックを追加し、戻り値の型がブール値ではない式が WHERE & HAVING 句に存在することを拒否します
  • [IOTDB-5185] IoTConsensus で古いスナップショットが削除されない問題を修正しました
  • [IOTDB-5287] ステータス「非推奨」をリージョングループに追加しました
  • [IOTDB-5449] クエリ キューがいっぱいになっている間、例外を直接スローするのではなく、クエリ リソースを待機します。
  • STARTUP_RETRY_INTERVAL_IN_MS を 30 秒から 3 秒に変更します

バグ修正

  • [IOTDB-4684] 同じ名前を持つデバイスを修正しますが、異なる配置プロパティが間違った配置プロパティに圧縮される
  • [IOTDB-5061] スナップショット作成時に初期化状態チェックを追加
  • [IOTDB-5090] stop-datanode.sh 実行時の NPE を修正
  • [IOTDB-5112] 低負荷時または再起動中に IoTConsensus 同期が停止する問題を修正
  • [IOTDB-5126] 登録時にホスト名が使用されている場合でも、show-regions でホスト名ではなく IP が表示される問題を修正
  • [IOTDB-5165] リソースが FileTimeIndex にデグレードされると圧縮検証に合格しない問題を修正
  • [IOTDB-5170] Windows プラットフォームで stop-confignode.bat を実行すると datanode が閉じられる問題を修正
  • [IOTDB-5199] StorageExector inLoading プロセスの NPE を修正
  • [IOTDB-5216] 時系列による順序が整列された最後のクエリで有効にならない問題を修正
  • [IOTDB-5228] TsFileSequenceReader インスタンスの作成中にファイルが存在しない場合は NPE
  • [IOTDB-5240] 再起動後のスキーマ テンプレートの時系列読み取り/書き込みエラーを修正
  • [IOTDB-5245] 最後のクエリでデータが不完全であることを修正しました
  • [IOTDB-5277] SchemaRegion がスナップショットを読み込むときに DataNode が再起動できない問題を修正
  • [IOTDB-5278] JDBC ドライバーが dbeaver に接続できない問題を修正
  • [IOTDB-5285] 異なるタイム パーティション構成で再起動するときの TimePartition エラーを修正
  • [IOTDB-5269] delete from SQL の実行後に削除する必要があるデバイスの誤ったデータを修正
  • [IOTDB-5324] IoTConsensus で data_replication_factor が 1 の場合、リージョン移行後に destDataNode で wal を削除できない問題を修正
  • [IOTDB-5389] IoTConsensus で wal_mode が無効になっていると DataNode の起動が失敗する
  • [IOTDB-5414] エイリアスの削除に成功してもエイリアスでクエリできる timeseries を修正
  • [IOTDB-5426] 時間指定フラッシュが有効な場合、シーケンス ファイルのフラッシュをトリガーできない
  • [IOTDB-5441] 関連デバイスで使用されているテンプレートにないスキーマをフェッチする際の NPE を修正
  • [IOTDB-5469] 逆引用符文字を含むテンプレートを正常に作成した後のスキーマ情報の取得エラーを修正
  • [IOTDB-5474] レベルのバグを使用したカウントノードを修正
  • [IOTDB-5480] 単一コピーでは IoTConsensus の同期ラグがマイナスになる場合がある
  • [IOTDB-5488] ローカルでシステムを読み取り専用に設定することをサポート
  • [IOTDB-5492] システムを回復するときに壊れた tsfile をスキップする
  • [IOTDB-5512] 再起動時に IoTConsensus が一部のログを繰り返し送信する可能性がある問題を修正
  • [IOTDB-5516] すべてのデータベースを削除した後の timeseries の作成エラーを修正
  • [IOTDB-5526] デバイスアクティブ化テンプレートに属している場合の時系列の削除の失敗を修正しました
  • [IOTDB-5548] テンプレート名として純粋な数値を使用した場合のテンプレートの削除エラーを修正
  • [IOTDB-5592] Having/Where 句でフルパス (ルートで始まる) を使用する際の予期しないエラーを修正
  • [IOTDB-5620] 各 DataRegion に多数の時間パーティションがある場合にフラッシュがスタックする問題を修正
  • [IOTDB-5639] クロススペースコンパクションセレクターでのファイルが見つからない例外を修正
  • [IOTDB-5657] LIMIT&OFFSET が最後のクエリで有効にならない問題を修正
  • [IOTDB-5684] ConfigNode のシンプル コンセンサス プロトコルを使用する場合のログ フォルダーの生成を修正
  • [IOTDB-5685] ReadOnly 状態のときに既存のパスに timeseries を作成できないというエラー メッセージを修正
  • [IOTDB-5686] 同じ名前だが異なるアライメント プロパティを持つデバイスが内部シーケンス コンパクションでエラーに遭遇する問題を修正
  • [IOTDB-5700] UDF クエリの終了後に作成された一時ファイルを消去する
  • SHOW_CQ権限を追加
