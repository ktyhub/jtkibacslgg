pulsar v3.3.2

#パルサーv3.3.2

2024-10-04

ライブラリの更新

  • [修正][秒] CVE-2024-47561 (#23394) に対処するために Avro を 1.11.4 にアップグレードします
  • [修正][秒] CVE-2024-8391 (#23338) に対処するために、vertx を 4.5.10 にアップグレードします。
  • [修正][秒][ブランチ-3.3] protobuf-java を 3.25.5 にアップグレードします (#23356) (#23358)
  • [改善][その他] Netty を 4.1.113 に、netty-tcnative を 2.0.66 にアップグレードします (#23255)
  • [修正] commons-io:commons-io を 2.8.0 から 2.14.0 に変更 (#23393)
  • [修正] io.grpc を 1.56.0 から 1.56.1 にバンプ (#23276)
  • [修正][メタデータ] Oxia を 0.3.2 にアップグレード (#23140)
  • [feat][meta] oxia java バージョンを 0.3.2 から 0.4.5 に変更 (#23277)
  • [改善] docker 画像の Pulsar Python client を 3.5.0 (#23377) にアップグレードします
  • [改善] Apache Pulsar Helm チャートとの互換性を修正するために、docker イメージに openssl をインストールします (#23362)

ブローカー

  • [修正][ブローカー] cancelPendingRead で保留中のリプレイ読み取りをキャンセルする可能性がありました (#23384)
  • [修正][ブローカー] 受信リクエストの準備ができる前に、保留中のコールバックを順番に実行します (#23266)
  • [修正][ブローカー] 拡張可能ロードマネージャーの起動に失敗した場合に高速に失敗する (#23297)
  • [修正][ブローカー] 「無効化されたレプリケートされたサブスクリプション コントローラー」ロジックとログを修正 (#23142)
  • [修正][ブローカー] AuthenticationProviderList の認証順序を修正 (#23111)
  • [修正][ブローカー] トピックを閉じた後もブローカーがレプリケーションの開始を再試行する問題を修正しました (#23237)
  • [修正][ブローカー] PIP-344 の互換性の問題を修正 (#23136)
  • [修正][ブローカー] ブローカーの起動を妨げる不完全な NAR ファイル抽出を修正しました (#23274)
  • [修正][ブローカー] ConsistentHashingStickyKeyConsumerSelector の順序が乱れている問題を修正 (#23327)
  • [修正][ブローカー] エントリがキャッシュされていない場合、シャドウ トピックを利用できない問題を修正しました (#23147)
  • [修正][ブローカー] オフロードされたデータが含まれている場合にシステム トピックをロードできない問題を修正しました (#23279)
  • [修正][ブローカー] ブローカー レジストリがメタデータ ノードの削除から回復できない問題を修正しました (#23359)
  • [修正][ブローカー] 選出されたリーダーが自分をフォロワーだと認識するバグを修正 (#23138)
  • [修正][ブローカー] getOwnedServiceUnits が正常に失敗した場合の処理 (#23119)
  • [修正][ブローカー] メタデータ ストア セッションの再構築後、__change_events の内部リーダーを開始できません (#23018)
  • [修正][ブローカー] メタデータ ストア エラーが発生したときに、保留中の ACK ハンドラーが初期化を再試行できるようにします (#23153)
  • [修正][ブローカー] 閉じたカーソルからのエントリの読み取りをスキップします。 (#22751)
  • [修正][ブローカー] ブローカーが失敗したトピック作成を今後も維持するため、トピックをロードできません (#23184)
  • [修正][ブローカー] 例外が非表示になり、トピックのロード時にスタックする可能性がある問題を修正 (#23102)
  • [修正][ブローカー] pulsar-admin トピックの統計内部を修正すると、BK client スレッドでデッドロックが発生しました (#23258)
  • [修正][ブローカー] filterAndUnloadMatchedNamespaceAsync のレプリケートされた名前空間フィルターを修正 (#23100)
  • [修正][ブローカー] タイプの例外でキャストすると、例外的に呼び出し損失が発生する可能性があります (#23117)
  • [修正][ブローカー] ServerCnx で失敗したコンシューマ/プロデューサ フューチャは削除できません (#23123)
  • [改善][ブローカー] msgInReplay サブスクリプション統計とメトリックを追加して、Key_Shared の可観測性を向上させます (#23224)
  • [改善][ブローカー] サービスユニット状態チャネルの開始の再試行を追加 (ExtensibleLoadManagerImpl のみ) (#23230)
  • [改善][ブローカー] 可能な限りconsumer.seekによるサブスクリプションフェンスエラーを回避します (#23163)
  • [改善][ブローカー] フォロワーの再生時に LB 内部トピックを明示的に閉じる (ExtensibleLoadManagerImpl のみ) (#23144)
  • [改善][ブローカー] 正しい失敗時間を記録するために、pulsar_topic_load_failed メトリクスを改善しました (#23199)
  • [改善][ブローカー] 進行中の txn を持つトピックから消費する際の高い CPU 使用率を最適化します (#23189)
  • [改善][ブローカー] ShadowReplicator のメッセージ ペイロード トラフィックを最適化します (#23236)
  • [改善][ブローカー] トピックがシステムトピックである場合に最大トピックをチェックするパフォーマンスを最適化します (#23185)
  • [改善][ブローカー] 個々の確認応答のパフォーマンスを最適化します (#23072)
  • [改善][ブローカー] バージョン ID 比較を行わずにブローカーをメタデータ ストアに登録します (#23298)
  • [改善][ブローカー] ServiceUnitState の開始時にバンドル所有権リスナーの onLoad イベントを通知する必要があります (ExtensibleLoadManagerImpl のみ) (#23152)
  • [改善][ブローカー] カスタマイズされたシャドウ管理台帳の実装をサポート (#23179)
  • [改善][ブローカー] クラスターメタデータの初期化時に auth-plugin、auth-parameters、および tls-enable 引数を指定するサポート (#23087)
  • [改善][ブローカー] getAvailableBrokersAsync メソッドを再利用 (#23099)
  • [改善][管理者] PIP-369 ns-isolation-policy set 呼び出しに unload フラグを導入します (#23120)
  • [修正] StatsOutputStream: 文字列書き込み関数を追加 (#23227)

Client

  • [修正] バイトキーを適切に処理するための DLQ (#23172)
  • [修正][client] レタートピックと DLQ メッセージを再試行するために orderKey をコピーし、コピー時のバグを修正します (#23182)
  • [修正][client] 非同期再試行プロデューサーを作成します (#23157)
  • [修正][client] MultiTopicConsumer の初期ヒット beforeConsume を修正 (#23141)
  • [修正][client] Pulsar Admin client のタイムアウト処理を修正 (#23128)
  • [修正][client] TransactionCoordinatorClient サポートの再試行 (#23081)
  • [修正][client] msgMetadata の nullValue はデフォルトで true である必要があります (#22372)
  • [改善][client] maxConnectionsPerHost と connectionMaxIdleSeconds を PulsarAdminBuilder に追加 (#22541)
  • [改善][client] client によってロードされた各スキーマの情報ログを出力しません (#23206)
  • [改善][client] 新しい ServiceUrlProvider 実装を追加: SameAuthParamsAutoClusterFailover (#23129)

パルサー IO とパルサー関数

  • [修正][io] DebeziumMsSqlContainer の mssql サーバー docker タグをアップグレードします (#23318)
  • [改善][fn] PF_AdditionalJavaRuntimeArguments env によるAdditionalJavaRuntimeArguments のオーバーライドのサポートを追加 (#23130)

その他

  • [修正][ログ] トピックメタデータの取得を呼び出すときにテナント/名前空間が存在しない場合、エラーログを出力しないようにしました (#23291)
  • [修正][ログ] 台帳の公開と切り替えを同時に行うときに警告ログを出力しないようにしました (#23209)
  • [機能] BK RocksDB ini ファイルを更新するためのスクリプトを追加 (#23178)
  • [修正][メタ] Oxia メタデータ ストア: 操作が失敗した場合、エラーを MetadataStoreException に変換します (#23154)
  • [修正][その他] デバッグ レベルでの Log Conscrypt セキュリティ プロバイダーの初期化警告 (#23364)
  • [改善][その他] AES-GCM 暗号のパフォーマンスを改善 (#23122)
  • [改善][その他] 余分なバッファー コピーを省略して TLS パフォーマンスを最適化します (#23115)
  • [改善][pip] PIP-366: 構成とローカル メタデータ ストアに異なる構成を指定するサポート (#23041)
  • [改善][プロキシ] pulsar-proxy で認証インスタンスを再利用する (#23113)

テストと CI

  • [修正][テスト]不安定なSubscriptionSeekTest.testSeekIsByReceiveを修正 (#23170)
  • [修正][テスト] 不安定な UnloadSubscriptionTest.testMultiConsumer を修正 (#23243)
  • [修正][テスト] 不安定なテスト LeaderElectionTest.revalidateLeaderWithinSameSession を修正 (#22383)
  • [修正][テスト] pulsar-proxy の多くのテストが実行されていない問題を修正しました (#23118)
  • [修正][ビルド] イメージのタグ付けで git.commit.id.abbrev が欠落している問題を修正 (#23337)
  • [修正][ビルド] pom.xml から不要な Oracle Maven リポジトリを削除 (#23132)
  • [改善][ビルド] APK インストールの代わりに amazoncorretto:21-alpine イメージを使用する (#22973)
  • [改善][ci] CI のデフォルト JVM バージョンとして Java 21 に切り替えます (#23373) 完全なリストについては、完全な changelog を確認してください。
