pulsar v3.3.9

#パルサーv3.3.9

2025-09-27

ライブラリの更新

  • [修正][秒] CVE-2025-8916 (#24650) に対処するために、bouncycastle bcpkix-fips バージョンを 1.79 にアップグレードします。
  • [修正][秒] CVE (#24717) に対処するために、Netty を 4.1.127.Final にアップグレードします。
  • [修正][秒] CVE-2025-55163 (#24637) に対処するために、Netty 4.1.124.Final にアップグレードします。
  • [改善][ビルド] org.apache.commons:commons-lang3 を 3.17.0 から 3.18.0 にバンプ (#24514)
  • [改善][io] AWS SDK v1 および v2、Kinesis KPL および KPC バージョンのアップグレード (#24661)
  • [修正][その他] 依存関係をアップグレードして重大なセキュリティ脆弱性を修正 (#24532)
  • [改善][ビルド] JDK25 (#24763) を完全にサポートするために、Lombok を 1.18.42 にアップグレードします。
  • [改善][ビルド] Apache 親 POM をバージョン 35 にアップグレード (#24742)

ブローカー

  • [修正][ブローカー] 非永続カーソル作成のダブルチェックを追加 (#24643)
  • [修正][ブローカー] KeyShared スティッキー モード コンシューマーが割り当てられた範囲を尊重するようにします (#24730)
  • [修正][ブローカー] トリム元帳に最初のエントリを追加しているときに NonDurableCursor を開くと、最初のエントリがスキップされます。 (#24738)
  • [修正][ブローカー] 管理者 api によってブローカーを正常にシャットダウンできない問題を修正 (#24731)
  • [修正][ブローカー] セッション再確立後の重複ウォッチャー登録を修正 (#24621)
  • [修正][ブローカー] FastThreadLocalThread 以外のスレッドでメトリクスが更新されたときのメモリ リークを修正 (#24719)
  • [修正][ブローカー] 一貫性のない利用可能なブローカー リストのキャッシュを引き起こす MetadataStoreCacheLoader の競合状態を修正しました (#24639)
  • [修正][ブローカー] 単一パーティションのトピックへのメッセージを生成するように REST API を修正しました (#24450)
  • [修正][ブローカー] PulsarLedgerManager の無効な正規表現により、zk データ通知が無視されます (#23977)
  • [修正][ブローカー] ディスパッチャーの読み取りコールバックでの予期しないリサイクル失敗を防止 (#24741)
  • [改善][ブローカー] サービスにデッドロックがある場合、サービスが利用できない可能性があるため、プローブは失敗を返す必要があります (#23634)
  • [修正][メタ] データの損失を避けるために、getChildrenFromStore を使用して子データを読み取ります (#24665)
  • [改善][ブローカー]メッセージの期限切れ時にcursor.asyncGetNthという名前のブロックを呼び出すブロックを削除 (#24606)

Client

  • [修正][client] 異なるスレッド間で同じ ConcurrentBitSetRecyclable を recycling することを回避します (#24725)
  • [修正][client] SameAuthParamsLookupAutoClusterFailover の ArrayIndexOutOfBoundsException を修正 (#24662)
  • [修正][client] SameAuthParamsLookupAutoClusterFailover 使用時の ArrayIndexOutOfBoundsException を修正 (#23336)
  • [修正][client] メモリ制限なしの受信側キューの自動スケールを修正 (#24743)
  • [修正][client] プロデューサまたはコンシューマの作成時に不明な例外が発生した場合に再試行する (#24599)
  • [修正][client] 受信メッセージでスキーマ検証が失敗した場合の無限ループを回避するために、DLQ にメッセージを送信するときにスキーマ検証をスキップします (#24663)
  • [修正][client]MessagePayloadProcessor の使用時に ZeroQueueConsumer がバッチ メッセージを受信しないようにします (#24610)
  • [修正][client]PatternMultiTopicsConsumerImpl.closeAsync() メソッドの呼び出し時に TopicListWatcher が閉じられない (#24698)
  • [修正][client] ロールバック TopicListWatcher の再試行動作 (#24752)
  • [改善][client] RSA PKCS#8 秘密鍵のロードをサポート (#24582)

パルサー IO とパルサー関数

  • [修正][io] Kafka Connect ソース オフセット フラッシュ ロジックを改善 (#24654)
  • [改善][io] .nar ファイルの検証が ZipException で失敗した場合のエラー メッセージに依存関係ファイル名情報を追加 (#24604)
  • [改善][io] 1.0 バージョン固有のパスを使用した Kinesis KPL ネイティブ バイナリ パスの指定をサポート (#24669)
  • [feat][fn] PulsarMetadataStateStoreProviderImpl.init での STATE_STORAGE_SERVICE_URL の使用へのフォールバック (#24721)

その他

  • [修正][プロキシ] Pulsar プロキシでの TooLongFrameException を修正 (#24626)
  • [修正][その他] NamespaceBundleStats、TimeAverageMessageData、および ResourceUnitRanking の CompareTo コントラクト違反を修正 (#24772)
  • [改善][ドキュメント] 不適切な使用を避けるために sendAsync の JavaDocs を改善しました (#24601)
  • [修正][オフロード] 階層型ストレージプロバイダー/オフローダーの nar ファイルから不要な依存関係を除外します (#24649)

テストと CI

  • [改善][ビルド] org.apache.nifi:nifi-nar-maven-plugin:2.1.0 を SkipDocGeneration=true で使用します (#24668)
  • [修正][ci] Pulsar CI のコード カバレッジ メトリックを修正 (#24595)
  • [修正][テスト] Ipv4Proxy の ConcurrentModificationException を修正 (#24632)
  • [修正][テスト] Flaky テスト: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [修正][テスト]不安定な ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage を修正 (#24633)
  • [修正][テスト]不安定な ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage を修正 (#24630)
  • [修正][ブローカー] 不安定な testReplicatorsInflightTaskListIsEmptyAfterReplicationFinished を修正 (#24590)
  • [改善][ビルド] javadoc ビルドの失敗を無効にする (#24594)
  • [改善][ビルド] Maven リゾルバーの同期コンテキスト タイムアウトを増やします (#24666)
  • [改善][テスト] 最大未確認メッセージをブロックするデッドレター トピックのテストを追加 (#24535)
  • [改善][テスト] テスト イメージのビルド時に pulsar-io-debezium-oracle nar ファイルにパッチを適用する方法をリファクタリングします (#24586)
  • [修正][ci] Gradle Develocity Maven 拡張機能のアップグレードを含む Java 25 の CI を修正 (#24767) 完全なリストについては、完全な changelog を確認してください。
