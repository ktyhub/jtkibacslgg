QwenPaw v1.1.1

パッチ 公開日2026年4月14日 出典agentscope-ai/QwenPaw 英語原文

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#クウェンパウv1.1.1

✨ 追加しました

プロバイダーとモデル

  • OpenRouter プロバイダー: モデル検出、シリーズの参照、およびモダリティと価格設定によるフィルタリングを備えた組み込みの OpenRouter プロバイダー (#1192)
  • OpenCode プロバイダー: 無料モデルを備えた組み込みの OpenAI 互換 OpenCode (Zen) プロバイダー (#2463)
  • モデル ID オートコンプリート: モデルを追加する際のモデル ID 選択のオートコンプリート ドロップダウン。すべてのプロバイダーに対してモデル検出がデフォルトで有効になっています (#3175、#3341) マルチエージェントシステム
  • 組み込みエージェント コラボレーション ツール: エージェント間通信用の専用スキルと合理化された CLI エージェント コマンドを備えた新しい list_agents および chat_with_agent 組み込みツール (#3292) チャンネル
  • マトリックス チャネル リライト: エンドツーエンド暗号化 (E2EE)、メンション処理、メッセージ履歴サポート、およびマークダウン レンダリング (#2509)
  • Feishu 引用メッセージ: テキスト、投稿、画像、およびファイル コンテンツ抽出による返信チェーン メッセージの処理 (#3207)
  • DingTalk QR 認証: コンソールでの DingTalk チャネル設定用の QR コード デバイス フロー認証 (#3315) セキュリティ
  • 拡張シェル コマンド ガード: $IFS インジェクション、制御文字、Unicode ホワイトスペース、/proc/*/environ アクセス、危険な jq フラグ、および Zsh 固有の危険な組み込みをカバーする新しいガード ルール (#3303) ツールとスキル
  • ClawHub スキル要件: 複数のメタデータ名前空間解決を備えた ClawHub 形式でのスキル要件のサポート (#3310)
  • メディア URL 表示: view_image および view_video ツールは、ダウンロードせずに直接メディアを表示するために HTTP/HTTPS URL を受け入れるようになりました (#3358)

🔄 変更されました

プロバイダーとモデル

  • マルチモーダル プローブの統合: Anthropic、Gemini、OpenAI プロバイダーにわたるイメージ サポート プローブが、誤検知検出が改善された単一の評価パスを共有するようになりました (#3367)
  • モデル切り替えのためのメッセージの正規化: メッセージはリクエスト時に正規化されるため、モデルプロバイダー間の切り替え時にメディア添付ファイルがメモリに保存されます (#3359)
  • Anthropic メディアの重複排除: Anthropic のメッセージ サイズ制限を超えないように、ツール結果内の重複する Base64 メディアがテキスト プレースホルダーに置き換えられます (#3372) チャンネル
  • DingTalk SDK 移行: チャネルは、AI カード モードでの処理およびメディア配信中に絵文字反応フィードバックを備えた公式 Alibaba Cloud SDK に移行されました (#3236、#3337、#3374)
  • Feishu WebSocket の安定性: 再接続時のクロススレッドの信頼性を向上させるためにイベント ループ処理がリファクタリングされました (#3360)
  • WeChat 返信制限の警告: チャネル設定では、WeChat iLink の context_token 返信制限に関する警告が表示されるようになりました (#3376) ツールとスキル
  • ブラウザー マネージド CDP: デフォルトのブラウザー起動戦略が、自動 Chromium 検出、ポート割り当て、プロセス ライフサイクル管理を備えたマネージド CDP に変更されました (#3164) コンソールと UI
  • モデル管理の再設計: 機能タグ、モデル検索、簡素化されたカード レイアウトを使用してプロバイダー モデル管理モーダルが再設計されました (#3273、#3294)
  • エージェント構成タブ: エージェント構成ページがスタックされたカードからタブ付きインターフェースにリファクタリングされました (#3354)
  • スキル選択 UI: タグの提案、長い名前のツールチップ、洗練された読み込み動作、および一括選択アクションによるスキル選択の改善 (#3320、#3362、#3373)
  • ダウンロード ページ: Web サイトのダウンロード ページが安定版とプレビュー バージョンのグループ化で再加工されました (#3353)

🐛 修正済み

チャンネル

  • QQ WebSocket シャットダウン: stop() は、シャットダウン時に WebSocket を強制的に閉じることによって 8 秒間ブロックされなくなりました (#3188) コンソールと UI
  • ダークモードでのチャットセッションピンボタンのコントラストを修正 (#3267)
  • ヘッダー内のマークダウン リンクは、新しいタブを開くのではなく、アプリ内で移動するようになりました (#3186)
  • Web サイト寄稿者のレイアウトを中国語ロケールに合わせて配置 (#3332) プロバイダー
  • Windows でのローカル モデルのダウンロードの失敗を修正 ([Errno 22] Invalid argument) (#3321)
  • --enable-auto-tool-choice を使用しない展開での 400 エラーを回避するために、vLLM 互換性のために tool_choice=auto を省略します (#3295)

📚 ドキュメント

  • RESTful API チュートリアル: チャット エンドポイント、認証、マルチターン セッション、ストリーミング、エージェントの切り替えをカバーする包括的な REST API チュートリアル (#3335)
  • スキル チャット コマンド: コマンドのドキュメントにスキル チャット コマンドのリファレンスを追加しました (#3330)
