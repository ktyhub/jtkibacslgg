QwenPaw v1.1.2

パッチ 公開日2026年4月17日 出典agentscope-ai/QwenPaw 英語原文

#クウェンパウv1.1.2

✨ 追加しました

エージェントシステム

  • ミッション モード: 自律的な複数フェーズのタスク実行用の /mission コマンド - エージェントは繰り返し計画、実行、および自己修正を行います。実行中のミッションを監視するための /mission status および /mission list をサポート (#3364、#3480)
  • テキストのみで自動続行: 有効にすると、モデルがテキストで応答してもツール呼び出しがなかった場合、エージェントは最大 2 つの追加推論パスを自動的に再試行します (#3107)
  • カスタム エージェント ID: コンソールまたは API (#3333) からエージェントを作成するときにカスタム ID を指定します。
  • ACP 外部エージェント委任: 権限ガードとリアルタイム ストリーミング出力を備えた新しい delegate_external_agent ツールを介して、外部コーディング エージェント (OpenCode、Qwen、Claude Code、Codex) にタスクを委任します (#3340)
  • エージェント CLI: テンプレートの選択 (default、local、qa) とワークスペースの初期化 (#3385) を使用して、qwenpaw agents create を使用してコマンド ラインからエージェントを作成します。 CLI
  • qwenpaw doctor: 環境、構成、プロバイダー、チャネル、スキル、MCP、メモリ、セキュリティなどをチェックする診断コマンド — 自動修復用の doctor fix を使用 (#3371)
  • qwenpaw skills info: コマンド ラインからスキルの詳細 (有効な状態、チャネル、パス、説明) を検査します。チャットに /skills スラッシュ コマンドも追加 (#3459) メモリ
  • Memory Dream: スケジュールされた長期メモリの統合 — 「ドリーム」エージェントが定期的に MEMORY.md の重複を排除し、再編成します (#2177)
  • 再帰的ファイル ウォッチャー: メモリのインデックス作成にサブディレクトリ ファイルを含める新しい recursive_file_watcher オプション (#3347) コンソールと UI
  • スキル インポート ハブ: 既存のスキル (#2412、#3415、#3482) と競合するスキルをインポートする際の URL 検証、マーケットプレイスの統合、および上書き確認を備えたインポート モーダルの再設計
  • デバッグ ページ: バックエンド ログ ファイルをリアルタイムで表示する設定の新しいデバッグ ページ (#3478) チャンネル
  • WeChat の引用メッセージ: 引用/返信されたメッセージは、テキスト、画像、音声、ファイル、ビデオをサポートして解析されるようになりました (#3483)

🔄 変更されました

  • プロバイダーの並べ替え順序: 設定のプロバイダー リストが可用性順に並べ替えられるようになりました (#3458)
  • エージェント通信ツール: エージェント間通信ツールは、chat_with_agent (同期) と新しい submit_to_agent / check_agent_task (非同期バックグラウンド タスク) に分割されました (#3485)

🐛 修正済み

コンソールと UI

  • チャット履歴のクリア: /clear は、コンソール UI のチャット履歴を適切にクリアするようになりました (#3348)
  • トークン使用量の並べ替え: トークン使用量の「日付別」テーブルは、最新の日付から順に並べ替えられるようになりました (#3387)
  • Cron ジョブ ID ツールチップ: Cron ジョブ ID ツールチップがシステム生成の UUID として記述されるように修正されました (#3404)
  • メッセージ履歴ナビゲーション: スラッシュ コマンドの候補が表示されているときに ArrowUp メッセージ履歴がトリガーされなくなりました (#3444) プロバイダー
  • 画像 MIME 正規化: 厳密な API による拒否を防ぐために、データ URL 内の image/jpg を image/jpeg に正規化しました (#3313)
  • マルチモーダル ツール呼び出しの順序: プロモートされたイメージ メッセージが、OpenAI と Anthropic に必要な連続したツール結果ブロックを分割しなくなりました (#3299)
  • プロバイダー クラス ID: 同じプロバイダーが複数のインポート パスからロードされた場合の Pydantic クラス ID のクラッシュを修正しました (#3431) エージェントシステム
  • バックグラウンド タスクの追跡: AgentApp API 経由でディスパッチされたバックグラウンド タスクが TaskTracker によって追跡されるようになり、リロードまたはシャットダウン中のキャンセルが防止されます (#3305)
  • メモリ圧縮ガード: メモリ圧縮フックが推論ステップごとに 2 回実行されなくなりました (#3461) チャンネル
  • Discord スレッド ルーティング: Discord スレッド メッセージは、親チャンネルではなく正しいスレッド セッションにルーティングされるようになりました (#3144)
  • WeChat タイピング インジケーター: WeChat タイピング インジケーターはバックグラウンド タスクをリークしなくなりました。メッセージの受信時に入力が開始され、完了またはエラー時に確実に停止します (#3488) デスクトップ
  • Python 環境分離: パッケージ化されたデスクトップ ビルドは、ユーザーがインストールしたパッケージがバンドルされた依存関係と競合しないように PYTHONNOUSERSITE=1 を設定するようになりました (#3476)

🔧 CI とインフラストラクチャ

  • チャネル テスト インフラストラクチャ: チャネル品質保証のための契約テスト、単体テスト、CI ワークフロー、および Makefile ターゲット (#2506)
