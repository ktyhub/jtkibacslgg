何が変わったのか

※中国語の文献を見ていたら、引き算の演算であることが分かりました。 @zyh-future 著、https://github.com/apache/rocketmq/pull/3033

  • [問題 #3006] https://github.com/apache/rocketmq/pull/3001 の @zhenhe による例外中の他のタスクへの影響を避けるために、Timer の代わりに ScheduledExecutorService を置き換えます
  • [問題 3203] https://github.com/apache/rocketmq/pull/3204 の @gorden5566 により、クラス 'StringBuffer' を 'StringBuilder' に置き換えます
  • [問題 #3215] litePullConsumer シーク ロジック #3216 を修正 (https://github.com/apache/rocketmq/pull/3283 の @guyinyou による)
  • [問題 #3284] https://github.com/apache/rocketmq/pull/3285 の @zhangjidi2016 によるベンチマーク コードの最適化
  • [問題 #3136] TraceDataEncoder は、https://github.com/apache/rocketmq/pull/3137 の @StyleTang によって SubAfter トレース Bean タイムスタンプを追加します
  • [問題 #3284] https://github.com/apache/rocketmq/pull/3317 の @keepal7 によるベンチマーク コードの最適化
  • [問題 #3194] [パート A] パフォーマンスを向上させるには、BrokerStatsService で AtomicLong の代わりに LongAdder を使用します。 @areyouok 著、https://github.com/apache/rocketmq/pull/3195
  • [問題 #3284] https://github.com/apache/rocketmq/pull/3324 の @zhangjidi2016 による buildMessage メソッドの最適化
  • [問題 #3333] https://github.com/apache/rocketmq/pull/3334 の @areyouok によるコモンズ コードの依存関係を削除
  • [問題 #3339] (doc) https://github.com/apache/rocketmq/pull/3339 の @WuHang1 による更新 Operation.md のタイプミスを修正
  • [ISSUS #3340] (ドキュメント) はじめに client リポジトリへのハイパーリンクを追加。 @TrumanDu 著、https://github.com/apache/rocketmq/pull/3338
  • [問題 #3326] https://github.com/apache/rocketmq/pull/3325 で @yuz10 によってブローカーが tls.server.mode=enforcing を設定した場合にトレース送信が失敗する問題を修正
  • [問題 #2724] https://github.com/apache/rocketmq/pull/3318 の @maixiaohai による最大再消費時間に達すると、メッセージを DLQ に直接再送信します
  • [問題 #3296] https://github.com/apache/rocketmq/pull/3302 の @Git-Yang によるスケジュール トピックの取得統計と単一キュー統計を追加
  • [問題 #3314] mqClientApi リクエストのタイムアウトを https://github.com/apache/rocketmq/pull/3313 の @lizhiboo によって設定できるようにする
  • [問題 #3245] df アルゴリズムを使用して、https://github.com/apache/rocketmq/pull/3344 の @aaron-ai によるディスク使用率を計算します
  • [問題 #3346] https://github.com/apache/rocketmq/pull/3345 の @WJL3333 による rpcHook 呼び出しでの二重解析の RemoteAddr を回避する
  • [問題 #3225] https://github.com/apache/rocketmq/pull/3220 の @lfz757077613 によりブローカーの Random を ThreadLocalRandom に変更
  • [問題 #1848] https://github.com/apache/rocketmq/pull/1858 に @coder-zzzz による write perm admin コマンドを追加
  • [問題 #3281] トピックのパーマ リストとグローバル ホワイト アドレス (#3128) の削除に失敗する問題を修正 (https://github.com/apache/rocketmq/pull/3280 の @yuz10 による)
  • [問題 #3194] [パート C] https://github.com/apache/rocketmq/pull/3351 の @areyouok により、StatsItem.java の AtomicLong を LongAdder に置き換えてパフォーマンスを向上させます
  • [問題 #2436] https://github.com/apache/rocketmq/pull/2437 の @maixiaohai による DLQ トピックのデフォルトのパーマの変更
  • [問題 #3361]DefaultMQProducer のコンストラクターは、オーバーロードされたコンストラクターを呼び出すことができます。 @zhangjidi2016 著、https://github.com/apache/rocketmq/pull/3362
  • [問題 #2726] https://github.com/apache/rocketmq/pull/2729 の @wz2cool による応答コードのカスタマイズによる再試行
  • [問題 #2964] mqadmin に query Consumer config コマンドを追加します。 @zhangjidi2016 著、https://github.com/apache/rocketmq/pull/2965
  • [問題 #XXXX] https://github.com/apache/rocketmq/pull/3335 の @zhouwentong1993 による rocketmq client Maven バージョンを更新します
  • [問題 #3347] ExpandIP のパフォーマンスが向上し、https://github.com/apache/rocketmq/pull/3322 の @844392610 によって読み取れるようになりました。
  • [問題 #3308] https://github.com/apache/rocketmq/pull/3295 の @lwclover による実稼働レベルのプル api デモ
  • https://github.com/apache/rocketmq/pull/3303 の @Silverados による RocketMQ_Example.md の更新
  • https://github.com/apache/rocketmq/pull/3304 の @Silverados による Example_Batch.md の更新
  • [問題 #1869] https://github.com/apache/rocketmq/pull/3358 の @RongtongJin によって、delayOffset.json の遅延オフセットが間違っている場合、遅延メッセージを消費できません
  • RIP-7 複数ディレクトリ ストレージのサポート (https://github.com/apache/rocketmq/pull/3357 の @Jason918 による)
  • [問題 #3379] https://github.com/apache/rocketmq/pull/3380 の @Git-Yang によるフォーマット エラーを修正
  • [問題 #3375] メッセージ検索時のみ GetMessageResult を遅延初期化します。 @WJL3333 著、https://github.com/apache/rocketmq/pull/3374
  • [問題 #2667] https://github.com/apache/rocketmq/pull/3278 の @Git-Yang による「このパスにファイルが存在しません」を修復する
  • [問題 #503] RocketMQ コンソールで NOT_CONSUME_YET が正しくありません (https://github.com/apache/rocketmq/pull/3091 の @sunbufu により)
  • [問題 #3384] https://github.com/apache/rocketmq/pull/3385 の @Git-Yang による SCHEDULE_TOPIC_XXXX 統計に SendBack メッセージを追加
  • [問題 #3288] https://github.com/apache/rocketmq/pull/3383 で @Loyilee による最初のメッセージの送信中にプロデューサーが常にタイムアウトになる問題を修正
  • [問題 #2962] https://github.com/apache/rocketmq/pull/3039 の @Aaron-He による DefaultMQAdminExt::examineTopicConfig 関数の実装
  • https://github.com/apache/rocketmq/pull/3400 の @MingJunDuan による間違ったコメントを修正
  • [問題 #3148] https://github.com/apache/rocketmq/pull/3149 の @panzhi33 によるメタデータのエクスポートをサポート
  • [問題 #3415] https://github.com/apache/rocketmq/pull/3416 の @Git-Yang による checkstyle の実行中に失敗する問題を修正
