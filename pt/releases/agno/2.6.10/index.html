agno v2.6.10

Changelog

Novos recursos

  • Provedores de modelos: quatro novos provedores de modelos foram adicionados:
    • Inception Labs integração do modelo
    • Xiaomi MiMo provedor do modelo
    • MiniMax provedor do modelo (M2.7)
    • Provedor de modelo do Cloudflare AI Gateway
  • YouTools: adição de YouTools para integração com You.com Search API.
  • Geração DOCX: Adicionado suporte à geração de arquivos DOCX.
  • Streaming de provedor de contexto: transmita eventos de subagentes de provedores de contexto.
  • Cadastro: Agregado conhecimento e suporte aos gestores no cadastro.
  • Persistência de execução: agente, equipe e fluxo de trabalho atualizados para persistir adequadamente as execuções canceladas.
  • Evento RunCompleted: campo files adicionado ao evento RunCompleted.
  • Analisador de string de modelo: adicionado o provedor google-interactions ao analisador de string de modelo.

Melhorias

  • DeepSeek: modo de pensamento e padrões atualizados do DeepSeek V4.
  • Cookbook: MCP paralelo atualizado para usar endpoint gratuito; image_search polido README; trocou exemplos de data_labeling para modelar abreviação de string.

Correções de bugs

  • MCP:
    • Evite que falhas de conexão MCP causem falhas de agentes.
    • Evite colisão kwarg quando as ferramentas MCP tiverem parâmetros team/agent/run_context.
  • JSON DB: Use codificação UTF-8 para arquivos de banco de dados JSON.
  • CSV Toolkit: leia arquivos do kit de ferramentas CSV como UTF-8.
  • Correções assíncronas:
    • Use Attachment.read() assíncrono em vez de bloquear requests.get no Discord client.
    • Substitua o bloqueio time.sleep por await asyncio.sleep em _async_create_collection_and_scope.
    • Substitua asyncio.get_event_loop() obsoleto por get_running_loop() em incorporadores.
    • Use o loop de corrida no leitor do YouTube.
    • As ferramentas usam ponto de entrada assíncrono na cadeia de execução assíncrona quando nenhum gancho está configurado.
    • CSVReader.async_read usa junção de nova linha para corresponder ao comportamento de leitura sincronizada.
  • Ferramentas OpenAI: feche o identificador do arquivo de áudio em OpenAITools.transcribe_audio.
  • Equipe:
    • Corrigidas dependências de continuidade de execução da equipe;
    • Adicionado _acontinue_run_background_stream para evitar AttributeError na execução contínua do SSE.
  • Modelo de analisador: ignora o modo de ferramenta estrito quando um parser_model é definido (Agente e Equipe); adicionou proteção parser_model a continue_run_dispatch e acontinue_run_dispatch.
  • RemoteTeam: Adicionados atributos de filtro de conhecimento.
  • Embeddings: Corrigido bug de embeddings NULL.
  • Bancos de dados vetoriais: compatibilidade do banco de dados vetorial Milvus com contents_db; removido o Tantivy FTS obsoleto e corrigido o erro Redis hset mypy.
  • SeltzTools: Atualizado para o SDK atual.
  • Fal: Corrigida a manipulação de array em fal.py.
  • Zendesk: consulta de pesquisa com codificação de URL na ferramenta Zendesk.
  • Memória: corrigida a incompatibilidade de assinatura memory_topics em back-ends de banco de dados.
  • Sessões: aumenta ValueError em delete_session quando chamado com banco de dados assíncrono.
  • Upload de arquivo: Corrigido o tratamento de mídia de upload de arquivo.
  • Slack HITL: truncar o corpo do cartão HITL para evitar a rejeição silenciosa do Slack.
