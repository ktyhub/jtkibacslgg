código claude v2.1.261

O que mudou

  • Adicionada uma linha "Política da organização" a /status e claude doctor que informa por que a política da sua organização não pôde ser carregada, como um proxy que não passa pelo endpoint
  • Adicionadas configurações bashOutputMaxChars e taskOutputMaxChars para aumentar a quantidade de saída de comandos e tarefas em segundo plano que Claude recebe em linha antes de ser salvo em um arquivo, até 128 mil caracteres
  • Adicionado --append-subagent-system-prompt-file para ler o prompt do sistema do subagente de um arquivo, para prompts muito grandes para serem transmitidos na linha de comando
  • Adicionado /skill-doctor para mostrar quais habilidades carregadas não são utilizadas e quanto custam no contexto, para que você possa eliminá-las
  • Corrigidos caracteres digitados ou colados que ocasionalmente ficavam fora de ordem ou eram descartados durante a entrada rápida ou repetição de tecla
  • Corrigida a impressão de um erro falso "não foi possível resolver" do /add-dir <subdirectory> quando o diretório de trabalho está em uma montagem automática /net
  • Correção do assistente de configuração do Bedrock travando quando a AWS ou um auxiliar de credencial da AWS nunca responde (agora expira com um erro claro) e suas verificações de modelo falham atrás de um proxy de inspeção de TLS
  • Correção de sessões na nuvem que descartavam um plug-in sincronizado de claude.ai quando as configurações gerenciadas forçavam sua habilitação no enabledPlugins e, em seguida, voltavam para um clone do mercado que poderia falhar
  • Corrigida a impossibilidade de excluir o personagem imediatamente antes de um chip [Image #N] embutido na entrada do prompt
  • Corrigida a retomada de uma sessão que perdia a saída do gancho e outro contexto em torno de chamadas de ferramentas paralelas, o que alterava a solicitação retomada
  • Corrigido o controle remoto mostrando um modo de permissão obsoleto quando um telefone, navegador ou aplicativo claude.ai é anexado a uma sessão de terminal ou após o modo ser alterado no terminal
  • Correção das sessões de controle remoto que ainda estavam funcionando (botão giratório e Parar travados) após parar uma curva de um telefone ou navegador conectado ou após um comando de barra local como /clear
  • Corrigido SDK e sessões de nuvem ignorando um Stop ou interrupção enviada logo após o primeiro prompt, antes do início do turno; o turno agora para em vez de correr até o fim
  • Corrigido o controle remoto carregando uma sessão puxada com /teleport para a sessão conectada, que aparecia anexada ao original no telefone e na web
  • Correção do fluxo de eventos de entrada do Controle Remoto falhando atrás de proxies corporativos de inspeção de TLS no Windows nativo
  • Corrigidas sessões de controle remoto mostrando o nível de esforço padrão em claude.ai quando o esforço vem das configurações
  • Corrigido gcpAuthRefresh abrindo um navegador na inicialização quando a verificação de credenciais do Google era lenta, mesmo que a credencial ainda fosse válida
  • Corrigidos conectores claude.ai que permaneciam ausentes durante toda a sessão quando a busca do conector de inicialização expirava - o CLI agora tenta novamente em segundo plano
  • Corrigido o alto uso sustentado da CPU quando um agente em segundo plano não podia ser retomado e sua ativação era repetida em um loop apertado
  • Correção de sinalizadores de recursos vinculados a uma versão mais recente que ocasionalmente se aplicavam a uma versão mais antiga do Claude Code em execução na mesma máquina
  • Correção do painel de uso do /usage e do VS Code que eliminava uma linha de limite semanal específica do modelo quando o endpoint de uso é limitado por taxa ou quando aberto logo após a inicialização
  • Corrigido claude -p --resume <file> adotando um ID de sessão malformado registrado na transcrição; agora ele é retomado com um novo ID de sessão
  • Corrigido o indicador de progresso do terminal (iTerm2, Ghostty, ConEmu) mostrando a sessão como concluída enquanto um fluxo de trabalho em segundo plano ou agente ainda estava em execução
  • Corrigida uma falha rara de layout em que uma caixa poderia ser renderizada com a altura errada após seu contêiner alternar entre a direção da linha e da coluna
  • Correção do IP client do gateway de aplicativos Claude quando um proxy trusted anexa uma porta ao X-Forwarded-For; com uma lista de acesso definida, uma entrada ilegível agora recebe 403
  • Correção do gateway de aplicativos Claude informando ao Claude Desktop para exportar OpenTelemetry como JSON mesmo quando o terminal CLI usa protobuf, então coletores somente protobuf rejeitaram os dados do Desktop
  • Corrigido o desktop e a web mostrando uma sessão ocupada enquanto observa apenas um artefato em busca de atualizações
  • Correção de falha de Claude no Chrome file_upload com "caminhos: array esperado, recebido indefinido" em sessões locais do Cowork executadas no aplicativo Claude Desktop
  • Corrigido SendMessage para uma sessão offline de Controle Remoto em outra máquina lendo conforme entregue; o resultado agora diz que a entrega está na fila até que a máquina se reconecte
  • Corrigidas dicas de instalação de plug-ins de CLIs executadas em comandos Bash em segundo plano: elas agora são detectadas e a tag <claude-code-hint> bruta não vaza mais na conversa
  • Foi corrigido um problema em que colegas de equipe da equipe de agentes em processo reenviavam seus anúncios de ferramentas e habilidades do primeiro turno no segundo turno, o que alterava o prefixo da solicitação e perdia o cache de prompt
  • Melhorado o seletor /model e a pílula de modelo VS Code para mostrar o nome de um modelo em vez de seu ID bruto de Bedrock, Vertex AI ou LLM gateway quando Claude Code o reconhece
  • Inicialização aprimorada no Google Vertex AI quando GOOGLE_APPLICATION_CREDENTIALS está definido: a criação de API client não executa mais a descoberta de projetos do Google Cloud nem gera processos gcloud extras
  • Melhor desempenho de streaming: blocos já renderizados não são mais verificados novamente por layout a cada atualização
  • Melhorado o prompt de segurança perigoso-rm para também capturar rm -rf em parâmetros posicionais e dentro de scripts sh -c entre aspas duplas
  • Tratamento aprimorado quando o API não envia cabeçalhos de resposta: a nova tentativa agora espera até API_TIMEOUT_MS (10 minutos por padrão) em vez de mais 3 minutos, e as mensagens dizem o que alterar
  • Alterado um gateway de aplicativos Claude 403 no carregamento de configurações gerenciadas (na inicialização ou após /login) para dizer que o Código Claude pode não estar habilitado para a organização, em vez de aconselhar um novo login
  • Máquinas alteradas cujas configurações gerenciadas fixam forceLoginMethod: "gateway" para ignorar uma chave API restante ou login claude.ai e solicitar /login; As sessões de Bedrock, Vertex AI e Foundry não são afetadas
  • Modo automático alterado para tratar um link que empacota conteúdo em uma URL de renderizador de diagrama público como um upload para esse site: não é mais aprovado automaticamente, a menos que você solicite.
  • Alteradas as teclas de edição de palavras do prompt para corresponder ao Bash: Ctrl+W exclui de volta para o espaço em branco, Alt+F e Alt+D param no final da palavra, a pontuação separa as palavras; keybindingFlavor não tem mais efeito
  • Contagem de tokens /context alterada para usar uma estimativa local quando a contagem de tokens API não estiver disponível, em vez de solicitações extras de modelo pequeno
  • [VSCode] Adicionado um passo a passo "Construir um estilo personalizado" ao menu Estilos de saída que grava um arquivo de estilo de saída personalizado e o lista imediatamente
  • [VSCode] Adicionado um formulário Adicionar servidor e uma ação Remover à caixa de diálogo de servidores MCP, para que os servidores MCP possam ser adicionados e removidos sem sair do IDE
  • [VSCode] Adicionado um anel vazio na lista de sessões para sessões abertas em um terminal, outra janela do VS Code ou Claude Desktop, para que não pareçam mais fechadas
  • [VSCode] Adicionado um botão de dobra aos prompts de permissão e perguntas para que a conversa por trás deles possa ser lida sem dispensá-los; o espaço ao lado do prompt agora rola a conversa
  • [VSCode] Adicionada "Sessão de arquivamento" ao menu direito da lista de sessões click e deu ao Unarchive seu próprio ícone
  • [VSCode] Corrigida uma sessão teletransportada de Claude Code na web tratando uma pergunta que era cortada quando a sessão na nuvem era encerrada como declined
  • [VSCode] Corrigida a caixa Renomear da aba da sessão abrindo vazia para uma aba restaurada com a janela; agora começa com o nome atual
  • [VSCode] Corrigidas seções recolhidas no painel da lista de sessões, mostrando brevemente a expansão cada vez que o painel era carregado
  • [VSCode] Corrigida a visualização do foco mostrando uma chamada de ferramenta ainda em execução após Claude ter seguido em frente, como enquanto uma pergunta aguardava sua resposta
  • [VSCode] Corrigido o destaque da linha ativa da lista de sessões que ficava obsoleto quando o ID de sessão de uma guia Claude desfocada era corrigido
  • [VSCode] Correção da reabertura de Cmd/Ctrl+Shift+T e abertura de deep-link colocando a guia Claude fora do grupo de editores Claude quando uma guia Claude está em foco
  • [VSCode] Corrigido o problema da aba de sessão "Adicionar ao grupo" colocando uma sessão aberta do Claude Code na Web em dois grupos; agora move a entrada que a lista de sessões mostra
  • [VSCode] Corrigido o seletor de modelo mostrando modelos que uma organização desativou desde então até a janela ser recarregada duas vezes
  • [VSCode] Corrigida uma aba aberta na lista de sessões voltando para aquela sessão, e uma aba aberta a partir de uma sessão da Web reiniciando seu teletransporte ou permanecendo vazia, após o VS Code recarregar a visualização da aba
  • [VSCode] Corrigido o histórico de perguntas paralelas do /btw de sessões anteriores sendo sobrescritas quando uma pergunta é feita logo após o recarregamento de uma janela ou enquanto um arquivo de configurações apresenta erros
  • [VSCode] Corrigido o cartão de pergunta pendente que não reaparecia após o painel Claude recarregar quando conectado com uma conta Claude.ai ou Console
  • [VSCode] Corrigidos recursos somente claude.ai que permaneciam visíveis em outros painéis Claude de uma janela depois que um painel selecionava um provedor terceirizado em um arquivo de configurações
  • [VSCode] Corrigida a tela de login que aparecia apesar da configuração Desativar prompt de login quando Claude Code relata nenhum login ou uma solicitação falha por falta de um
  • [VSCode] Corrigido o próximo prompt de permissão na fila, mantendo o texto digitado no prompt anterior e aceitando um segundo click imediato
  • [VSCode] Corrigidos links de plugins de instalação abrindo a barra lateral do Claude sem a caixa de diálogo de instalação em uma janela onde apenas a lista de sessões era mostrada
  • [VSCode] Corrigido o medidor de uso da barra lateral que ficava vazio em uma nova janela até que a caixa de diálogo Conta e uso fosse aberta, e um limite de uso de 0% era deixado de fora do medidor
  • [VSCode] Corrigido "Iniciar nova sessão neste grupo", perdendo o grupo após uma nova conversa e um ponto não lido ausente para uma sessão que terminou antes do carregamento da lista de não lidos da barra lateral
  • [VSCode] Corrigido o emblema da guia do editor mostrando não lido durante um turno de corrida ou ausente em uma guia aberta na lista de sessões, e "Adicionar guia de sessão ao grupo" não fazendo nada para uma sessão arquivada

  • [VSCode] Corrigido o filtro Abrir da lista de sessões para sessões continuadas de claude.ai cuja aba ainda estava gravada na sessão web, e rotulou as seções do menu de filtro para leitores de tela
