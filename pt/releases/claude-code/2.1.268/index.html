código claude v2.1.268

O que mudou

  • Adicionado ao gateway de aplicativos Claude: com pricing: definido em gateway.yaml, os Claude Code clients conectados recebem as mesmas taxas por meio de configurações gerenciadas, para que /cost e telemetria correspondam ao medidor de gastos
  • Adicionado um aviso de inicialização para gateways quando access_control.allow_cidrs está vazio e um aviso único na primeira vez que uma solicitação chega de um endereço público
  • Adicionada a configuração gerenciada gatewayInternalNetworks, permitindo que os administradores permitam o /login para um gateway de aplicativos Claude no bloco IPv4 público da própria organização
  • Adicionado claude self-hosted-runner --remove-session-state (padrão desativado): exclua os diretórios por sessão de cada sessão em <base-dir>/_sessions/ quando a sessão terminar
  • Adicionado configDirectory à saída de claude auth status --json
  • Adicionado --json a claude plugin install, uninstall, update, enable e disable, e errorDetails/noteDetails a cada linha de claude plugin list --json
  • Adicionados ícones de abas do navegador para artefatos publicados, escolhidos por Claude para corresponder a cada página
  • Corrigida falha em cada turno com HTTP 400 em endpoints compatíveis com Anthropic de terceiros (ANTHROPIC_BASE_URL) desde 2.1.265: um regex no esquema de entrada da ferramenta Artifact que esses endpoints rejeitam
  • Corrigido WebFetch travando indefinidamente em um servidor que mantém a resposta aberta sem finalizar; uma busca agora falha após 300 segundos. Configure CLAUDE_CODE_WEBFETCH_DEADLINE_MS para substituir o prazo (0 desliga)
  • Corrigido um colega de equipe respawnado em processo pegando ferramentas ou um prompt do sistema de um arquivo de agente com o mesmo nome em uma pasta que você não trusted
  • Corrigido o alto uso sustentado da CPU: um loop ocupado em sessões ociosas de longa duração não fixa mais um núcleo da CPU, e os relatórios de foco do terminal rapid durante uma recapitulação da sessão não mantêm mais a CPU alta
  • Correção de Claude que às vezes respondia "sua mensagem chegou vazia" após uma chamada da ferramenta MCP
  • Corrigidas regras de permissão de negação e solicitação em diretórios com links simbólicos (/etc, /tmp, /var no macOS; /bin no Linux) que não se aplicavam quando um caminho era fornecido por sua localização real e comandos Bash ignoravam regras de negação escritas em uma ortografia de caminho com link simbólico
  • Corrigido um caso em que uma regra de negação de leitura ou edição não se aplicava quando um comando env -C, eval ou similar que o verificador de permissão não consegue analisar estava na mesma linha
  • Corrigidos erros de plugin e mercado mostrando um token ou senha de um URL de origem git
  • Corrigidos detalhes do servidor /mcp e /plugin, claude mcp list/get e erros de login do MCP mostrando segredos resolvidos a partir de espaços reservados ${VAR} nas configurações do MCP
  • Corrigido cache de prompt e quebra de pensamento estendido no meio da sessão para sessões SDK usando excludeDynamicSections: a primeira mensagem não é mais renderizada novamente a cada solicitação
  • Correção de problemas de usuários autorizados sendo informados de que um modelo está restrito após a reinicialização ou na guia Desktop Code quando uma negação de acesso ao modelo em cache estava obsoleta
  • Correção de uma sessão em execução alternando silenciosamente para o modelo padrão da organização quando outro processo do Claude Code atualizava uma entrada de acesso ao modelo obsoleta
  • Corrigidos 429s de contexto longo em modelos Fable mostrando o prompt de consentimento de créditos de uso em vez da mensagem de contexto de 1M nos planos Pro e Team
  • Correção da federação de identidade da carga de trabalho por meio de um perfil (conforme claude-code-action a configura): processos que compartilham o perfil podem falhar no meio da execução com 401 … jti reused
  • Foi corrigida a falha de login do OAuth no servidor MCP com "Nenhuma porta disponível para redirecionamento OAuth" quando o intervalo de portas de retorno de chamada local não pode ser vinculado
  • Corrigido o resumo da conversa produzido por /compact e a compactação automática do texto que continha sequências $
  • Corrigida a retomada de uma conversa que terminava com /compact: as notas do arquivo restaurado agora são carregadas na mesma ordem em cada currículo
  • Corrigidas sugestões de prompt do SDK, perguntas paralelas e /rename enviando a conversa antes de uma compactação
  • Corrigido arquivo @ e sugestões de comando / que não apareciam após recuperar um prompt anterior com a seta para cima e editá-lo
  • Corrigido claude agents: pressionar ← novamente em um ritmo natural para voltar à lista de agentes não é mais ignorado até você pausar por mais de um segundo
  • Foi corrigida a exclusão da sessão claude agents que ficava travada quando uma árvore de trabalho não podia ser removida: a mensagem nomeia a causa e o próximo passo, e para uma árvore de trabalho git ctrl+x novamente exclui o diretório de qualquer maneira
  • Corrigidas linhas de agente em segundo plano e de fluxo de trabalho no painel de agentes que se expandiam para muitas linhas quando o texto continha quebras de linha
  • Foi corrigido um problema de Claude nas sessões do Slack, que perdia suas ferramentas do Slack quando as configurações gerenciadas pela organização definiam uma lista de permissões do MCP
  • Corrigido Claude no Chrome solicitando permissão do host "https" quando um URL de navegação tinha um esquema, mas um host que não podia ser analisado
  • Corrigida a quebra do spinner em diversas linhas quando o rótulo da tarefa atual é longo; o rótulo e a linha de tarefa "Próximo:" agora permanecem dentro de uma linha do terminal
  • Corrigido o campo de descrição /bug e /feedback mostrando nenhum cursor quando o cursor nativo do terminal está habilitado
  • Corrigidas sessões de controle remoto atendidas por claude remote-control mostrando um nome gerado em vez do título da sessão em ListAgents
  • Corrigido claude plugin validate rejeitando caminhos de plugins cujo nome de diretório começa com dois pontos, que o carregador de plugins aceita
  • Plugins corrigidos ignorando silenciosamente um arquivo de monitores padrão ou raiz SKILL.md que não pôde ser verificado
  • Corrigido o erro do WebFetch para localhost e outros nomes de host sem ponto para explicar por que o URL foi recusado e sugerir curl
  • Corrigidos ganchos PermissionRequest que não disparavam no modo --print
  • Corrigidos avisos do auxiliar de política que não eram impressos em execuções headless (-p)
  • Corrigido /resume listando uma sessão em segundo plano /fork sob o nome de seu pai em vez de seu próprio nome de fork ⑂
  • Corrigido /remote-control e outros comandos claude.ai-gated para sugerir /login quando desconectado em vez de mostrar uma mensagem de migração Claude for Enterprise
  • Corrigido CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS que não estendia ganchos SessionEnd que não tinham timeout por gancho (eles ainda eram cancelados após 1.5 segundos)
  • Corrigido /autofix-pr e outros comandos de sessão na nuvem dizendo para tentar novamente ou instalar o aplicativo Claude GitHub quando nenhuma conta GitHub estiver conectada; eles agora apontam para /web-setup ou para a página de conexão da web
  • Corrigidos comandos de sessão na nuvem, como /teleport e /remote-env, para explicar quando uma política da organização os desativa, em vez de responder "Comando desconhecido"
  • Corrigidas instruções de sandbox do Bash que exageram no confinamento: não há listas de caminhos não impostas quando o isolamento do sistema de arquivos está desativado e o modo estrito não reivindica mais comandos que nunca podem ser executados sem sandbox
  • Modo de tela cheia aprimorado: adicionar ou remover uma linha de prompt (Shift+Enter) agora é redesenhado tão rápido quanto digitar um caractere em vez de renderizar novamente a transcrição visível
  • --continue / --resume aprimorado: a conversa aparece imediatamente em vez de esperar pelos ganchos SessionStart, e a primeira mensagem não relê mais a transcrição inteira
  • Capacidade de resposta aprimorada durante turnos com muitas ferramentas, não redesenhando mais a transcrição para um lembrete oculto por lote de ferramenta
  • Melhor tempo de inicialização em projetos com scripts .claude/workflows/: listá-los não analisa mais cada script
  • Negações do modo automático aprimoradas: a mensagem que Claude recebe agora nomeia a regra que bloqueou a ação e pede a Claude para tentar um método mais seguro e terminar o trabalho não relacionado antes de parar para perguntar a você
  • Claude aprimorado no Chrome: leituras longas de páginas agora permanecem inline em vez de serem salvas em um arquivo e lidas novamente
  • Melhorado o aviso de truncamento do MEMORY.md para dizer quantas linhas foram cortadas e onde o corte começa
  • Melhorado o prompt de permissão do terminal para artefatos: agora ele inicia com a pergunta do pedido
  • Melhorado o rodapé do prompt: um editor ou seleção /diff agora é exibido dentro da entrada do prompt, e o modo de tela cheia mostra o status do Controle Remoto no cabeçalho em vez do rodapé
  • Melhorada a mensagem "Créditos de uso necessários para contexto de 1M" para informar que os créditos de uso ativados no meio da sessão entram em vigor após reiniciar o Claude Code
  • /plugin aprimorado: a instalação, ativação ou desativação de um plugin agora entra em vigor quando você fecha o menu; /reload-plugins não é mais necessário depois
  • Alterado o prompt do sistema em Bedrock, Vertex e Foundry para fornecer detalhes de ambiente, modelo e configurações como anexos, correspondendo a sessões primárias
  • Sessões Bedrock, Vertex e Foundry alteradas para manter a lista de ferramentas estável em bytes durante uma conversa (carregamento de ferramentas de conexão tardia adiado em vez de reescrevê-lo), combinando sessões primárias
  • Alteradas as ferramentas de rastreamento de tarefas (TaskCreate/Get/Update/List, TodoWrite) para serem oferecidas apenas em Claude 3.x, Opus 4.0–4.7, Sonnet 4.0–4.6, Haiku 4.5; definir CLAUDE_CODE_ENABLE_TODO_TOOLS=1 em outro lugar
  • Alterado o prompt de permissão de edição de dados do artefato no terminal para um cartão que mostra a contagem de documentos e quem pode abrir o artefato
  • Sessões locais do Cowork alteradas para ignorar todas as aprovações: a ferramenta Artefato agora recusa um arquivo local fora das pastas da sessão, ou atrás de um link simbólico, em vez de lê-lo sem perguntar
  • Alteradas as regras simples de negar e solicitar do WebFetch para não se aplicarem mais às leituras e atualizações da ferramenta Artifact; use uma regra Artifact (ou WebFetch(domain:claude.ai)) para bloqueá-los ou bloqueá-los
  • Alterado o aviso de inicialização "N servidores MCP precisam de autenticação" para anunciar cada servidor uma vez em vez de a cada inicialização
  • [VSCode] Corrigida a lista de sessões, alternadores de configurações e guias de bate-papo quando CLAUDE_CONFIG_DIR está definido em um arquivo de configurações ou na configuração environmentVariables
  • [VSCode] Corrigida a pílula de modelo, o seletor de modelo e o menu de comando que ficavam em branco nas guias abertas por alguns segundos após um login, logout ou troca de conta
  • [VSCode] Corrigido o desaparecimento automático do seletor de modo em conversas de nova guia ou recém-recarregadas quando um projeto ou configuração local substitui o modelo nomeado em ~/.claude/settings.json
  • [VSCode] Correção de nomes de sessão revertendo para o último prompt após o recarregamento de uma janela quando um gancho SessionStart é configurado
  • [VSCode] Corrigida a pílula do modelo do rodapé e a pílula do Controle Remoto aguardando o início do processo Claude da nova aba quando outra aba na janela já está aberta
  • [VSCode] Corrigido um segundo processo Claude em execução durante sua inicialização completa quando o lançamento de uma guia de sessão chegava mais de meio segundo após a leitura de sua configuração
  • [VSCode] Corrigida a retomada de uma sessão da lista de sessões ignorando claudeCode.preferredLocation: "sidebar" (sempre abria um painel), e aberturas programáticas redefinindo essa configuração para "painel"
  • [VSCode] Corrigidos problemas do Windows: o prompt de instalação do WSL não aparece mais em máquinas sem WSL instalado e os diagnósticos IDE agora são retornados corretamente para arquivos do Windows quando o WSL é instalado
  • [VSCode] Corrigido o construtor de estilo personalizado salvando um estilo de nível de usuário em uma pasta que o CLI não lê quando CLAUDE_CONFIG_DIR é definido nas configurações
  • [VSCode] Adicionadas teclas de seta para esquerda e direita para alterar onde uma regra de permissão sempre permitida é salva, para usuários de teclado e leitor de tela
  • [VSCode] Adicionado um comando "Claude Code: Focus last message" que move o foco do teclado para a mensagem mais recente na conversa, para usuários de teclado e leitor de tela
  • [VSCode] Alterada a caixa de diálogo Gerenciar plug-ins para aplicar instalações, ativar, desativar e desinstalar sessões abertas sem reiniciar
  • [VSCode] Alterados alguns prompts de permissão de artefato para omitir a opção "não perguntar novamente", correspondendo ao terminal
  • [Claude Code na web] Correção de sessões na nuvem que duravam mais de seis horas, perdendo silenciosamente arquivos salvos em pastas de sessão persistentes; os salvamentos agora persistem por até um dia
  • [Código Claude na web] Corrigidos erros de "Nível de esforço inválido" quando uma rotina retoma uma sessão, ou uma sessão inicia sem esforço definido, em organizações onde um administrador limita o esforço de um modelo
  • [Código Claude na web] Criação de rotina aprimorada a partir de uma conversa: quando a nova rotina não possui conectores, Claude agora diz isso e como adicioná-los em vez de apenas confirmá-la
  • [Claude Tag] Corrigida a página de configurações do administrador pendurada em um esqueleto de carregamento ou ficando em branco após uma falha transitória de carregamento; uma seção que não carrega agora mostra um botão Tentar novamente
  • [Claude Tag] Adicionado um link da página de configuração de um canal do Slack para o Claude da organização nas configurações de administração do Slack
  • [Claude Tag] Corrigido um canal Slack Enterprise Grid que perdia suas configurações Claude (repositório, ambiente, acesso) depois que um administrador do Slack o movia para outro espaço de trabalho
  • [Claude Tag] Melhoria na forma como Claude explica uma ação bloqueada: agora diz se uma verificação de permissão, sua própria decisão de confirmar primeiro ou a falta de acesso a interromperam
  • [Claude Tag] Velocidade de resposta aprimorada: Claude agora executa várias pesquisas somente leitura (pesquisar no Slack, ler um tópico, encontrar pessoas) de uma só vez, em vez de uma após a outra
  • [Claude Tag] Formatação aprimorada de comparações: comparações de comprimento de frase agora vêm como listas em vez de tabelas largas que rolam lateralmente e células longas da tabela são quebradas
  • [Claude Tag] Corrigido @Claude !restart em um tópico com sua própria sessão, às vezes também postando um aviso contraditório "este tópico é tratado pela sessão do canal"
  • [Claude Tag] Melhorou a mensagem mostrada quando sua conta Claude está em uma organização diferente do espaço de trabalho do Slack: agora explica como conectar o espaço de trabalho à sua organização
  • [Claude Tag] Correção de links Markdown cujo URL é colocado entre colchetes angulares, aparecendo como texto de colchete literal no Slack em vez de um link clickable
  • [Claude Tag] Corrigida a @menção de nível superior de um convidado do espaço de trabalho em um canal onde os convidados podem usar Claude às vezes recebendo uma resposta "sua conta do Slack não está conectada" em vez de uma resposta
  • [Claude Tag] Corrigida a substituição de uma sessão de longa duração de um canal por uma nova no meio da conversa; a atualização agendada agora espera até que o canal e seus threads fiquem quietos
  • [Claude Tag] Corrigidos cartões de configurações de canal clicked mais de uma vez informando à sessão proponente que a mudança foi recusada após já ter sido aplicada; o resultado agora é enviado uma vez
  • [Claude Tag] Memória alterada em canais públicos: cada canal agora mantém suas próprias notas, e Claude não se lembra mais de notas salvas em outros canais públicos; as notas do espaço de trabalho permanecem compartilhadas
  • [Revisão de código] Adicionada uma observação na lista de descobertas ainda abertas nas revisões de acompanhamento: resolver o tópico de uma descoberta, e não apenas respondê-la, impede que revisões posteriores a considerem como aberta
  • [Revisão de código] Corrigidas revisões que às vezes terminavam incompletas quando um dos agentes que verificava uma descoberta falhava no meio do caminho; a revisão agora substitui esse agente e chega a um veredicto
  • [Revisão de código] Corrigida uma revisão acionada por push que estava na fila atrás de uma revisão em execução ainda postando após a solicitação pull ter sido convertida em rascunho
  • [Revisão de código] Corrigidas revisões que ignoravam as convenções CLAUDE.md de um diretório quando o PR editava um arquivo raiz (por exemplo, README.md) que compartilha apenas um nome com um arquivo listado por CLAUDE.md
