claude-code v2.1.274

código claude v2.1.274

O que mudou

  • Adicionado um aviso visível quando o uso da memória é crítico, com etapas para liberar memória ou reiniciar com segurança
  • Adicionado CLAUDE_CODE_MCP_STARTUP_WAIT_MS para limitar quanto tempo o primeiro turno não interativo aguarda para conectar servidores MCP (0 = não espere)
  • Adicionado atributo effort ao intervalo de rastreamento claude_code.llm_request OpenTelemetry, correspondendo ao evento api_request
  • Adicionado evento claude_code.managed_settings_resolved OTel: fontes de configurações gerenciadas e estado do auxiliar de política; configurações e resumos editados com OTEL_LOG_MANAGED_SETTINGS=1
  • Adicionado store.connect_timeout_seconds à configuração do gateway de aplicativos Claude para prolongar o tempo limite de conexão do Postgres (padrão 5 segundos) e melhorou o erro de inicialização quando o banco de dados está inacessível para apontar para store.postgres_url e o tempo limite configurado
  • Adicionado enduser.sub, o assunto IdP, à telemetria que Claude Desktop e Cowork enviam através de um gateway de aplicativos Claude
  • Adicionado um aviso de gateway de aplicativos Claude quando uma réplica tem mais solicitações abertas do que as 256 que envia upstream de uma só vez, e uma linha de log de inicialização mostrando esse limite
  • Adicionado click-to-expand para mensagens recolhidas de colegas de equipe e agentes no modo de tela cheia
  • Correção de sessões que ficavam travadas interminavelmente repetindo erros "inesperados de tool_use_id" 400: transcrições corrompidas agora se auto-curam sempre que possível e, caso contrário, um erro claro (com uma dica /rewind) encerra o loop
  • Correção de servidores MCP configurados como http que falam apenas HTTP+SSE legado, falhando ao se conectar quando respondem à primeira solicitação com 422 ou outro erro 4xx
  • Foi corrigido o tempo limite das chamadas da ferramenta Streamable HTTP MCP após cerca de 5 minutos, mesmo quando um timeout mais longo por servidor foi definido
  • Corrigidos prompts e recursos do MCP que não eram atualizados quando um servidor envia notificações de alteração de lista sem declarar listChanged
  • Corrigidas chamadas de ferramenta MCP recusadas com 403 insuficiente_scope sendo relatado como um login expirado: o erro agora nomeia as permissões ausentes e aponta para a reautenticação /mcp
  • Corrigidas sessões controladas por gancho (como um /goal ativo) terminando com "O prompt é muito longo" em vez de compactar quando o contexto transbordava novamente após uma compactação reativa
  • Corrigido um /goal ativo sendo perdido ao retomar (--continue/--resume) uma sessão que havia compactado
  • Corrigido claude agents perdendo --model, --effort, --permission-mode, --allow-dangerously-skip-permissions e --agent após um relançamento de atualização automática
  • Corrigida uma lentidão por turno quando um servidor de idiomas publica diagnósticos de todo o projeto para milhares de arquivos
  • Corrigido subagentes com model: "opus" em Bedrock, Vertex ou Foundry saindo do modelo da sessão quando seu id não possui família de modelo reconhecível (a menos que ANTHROPIC_DEFAULT_OPUS_MODEL esteja definido)
  • Corrigidas sessões de executores auto-hospedadas que falhavam a cada turno com um 401 após algumas atualizações de token com falha, até a próxima atualização agendada; o runner agora continua tentando novamente e busca um novo token após um 401
  • Correção de links clickable para caminhos de arquivos locais, sem fazer nada no VS Code e outros terminais que exigem um URI file://
  • Corrigida a renumeração da transcrição de listas ordenadas em suas próprias mensagens (digitando "3. 2. 1." exibido "3. 4. 5."); números e marcadores "N)" agora aparecem conforme digitados
  • Corrigidas notas de visualização do AskUserQuestion anexadas a uma opção escolhida anteriormente em vez da opção destacada
  • Corrigido o modo de visualização do AskUserQuestion, eliminando a opção destacada ao enviar uma nota com Enter
  • Corrigido um agente em segundo plano retomado mantendo metade de um lote de ferramentas interrompido quando uma de suas chamadas era aprovada com uma mensagem
  • Corrigido um claude -p --resume local iniciado com CLAUDE_CODE_RESUME_INTERRUPTED_TURN não reportando tarefas em segundo plano que o processo anterior deixou inacabado
  • Corrigido o primeiro turno de uma sessão na nuvem que às vezes iniciava sem as ferramentas de um servidor MCP hospedado no SDK que ainda estava conectado
  • Corrigidas notificações de agentes em segundo plano, alegando que o agente não tinha trabalho em segundo plano quando ainda estava aguardando sua própria tarefa em segundo plano e iria retomar
  • Corrigidas dicas de erro nas sessões do Claude Desktop para sugerir comandos de barra como /usage-credits em vez de sinalizadores CLI que não podem ser usados lá
  • Corrigido /schedule salvando o prompt de uma rotina sem seu papel de mensagem quando Claude escreve a rotina no formato retornado pelas rotinas de listagem
  • Corrigido /status que não mostrava a falha apiKeyHelper que seu próprio banner de erro dizia para você verificar
  • Corrigido /fast on em sessões não interativas, reportando e depois desligando sob a política de modo rápido gerenciado de uma organização; agora diz que a organização o desativou
  • Corrigida a ferramenta Artefato solicitando que você aprovasse uma atualização para um artefato que ela recusou porque a sessão não leu a versão mais recente
  • Corrigidas sessões de nuvem do Cowork e claude.ai com acesso à rede ao tratar leituras do artefato de um colega de equipe como se o acesso à rede estivesse desativado
  • Corrigido um plugin ou diretório de mercado sem repositório git próprio, obtendo sua versão de um repositório git anexo, como um ~/.claude gerenciado por git
  • Corrigido --strict-mcp-config com um --mcp-config vazio segurando o primeiro turno não interativo para até MCP_TIMEOUT em servidores MCP incidentais
  • Corrigidos ganchos de prompt de parada reenviando todo o prompt em cada bloco de uma conversa; blocos de repetição agora nomeiam a condição com um rótulo de 500 caracteres
  • Corrigidas janelas extras de editor vazias abrindo na inicialização do Linux no Wayland ao executar dentro do Cursor ou do terminal VS Code
  • Corrigida uma rejeição de promessa não tratada no gateway de aplicativos Claude quando o Postgres interrompe uma conexão durante uma verificação de gastos
  • Correção do gateway de aplicativos Claude cortando todos os fluxos abertos no SIGTERM: agora permite que solicitações em andamento sejam concluídas por até 25 segundos antes de sair (CLAUDE_GATEWAY_DRAIN_TIMEOUT_MS)
  • Corrigido o installed_plugins.json sendo reescrito em quase todas as inicializações quando a política de plug-ins vem de configurações gerenciadas remotamente, o que fazia o Claude Desktop recarregar os plug-ins de todas as sessões abertas
  • Corrigidas sessões headless e SDK fazendo uma chamada de modelo separada para cada tarefa em segundo plano concluída; as conclusões já enfileiradas agora são atendidas por uma chamada
  • Corrigida a ferramenta Bash que recarregava o perfil do shell (uma parada de vários segundos no próximo comando) após cada recarga do plugin; agora isso acontece somente quando os diretórios bin/ dos plugins são alterados
  • Plugins corrigidos com um $schema de nível superior em hooks/hooks.json mostrando um aviso de "chave desconhecida"
  • Erros de conexão MCP corrigidos e a descrição da ferramenta de login MCP mostrando segredos resolvidos de espaços reservados ${VAR} nas configurações MCP
  • Corrigidas verificações de permissão do Bash para comandos que fazem loop ou atribuem certas variáveis especiais do shell; esses comandos agora pedem permissão
  • Corrigidas sessões isoladas da árvore de trabalho aceitando comandos Bash com certas expansões de shell aninhadas; estes agora são recusados
  • Corrigida a visualização do prompt de permissão de edição que às vezes mostrava um local diferente do da edição aprovada em arquivos com caracteres multibyte
  • Corrigidos comandos em segundo plano sendo interrompidos após 30 minutos ociosos em máquinas sob leve pressão de memória; agora eles são interrompidos apenas quando a memória está criticamente baixa e o log de depuração diz o porquê
  • Corrigida uma mensagem que um subagente envia para a sessão principal, desaparecendo da transcrição do Claude Desktop após um relançamento
  • Corrigido um plugin carregado de um .zip sendo servido a partir de uma extração obsoleta após várias recargas sobrepostas
  • Corrigido o resumo do progresso de um subagente sendo substituído por uma resposta descontrolada de vários parágrafos
  • Melhor inicialização nas sessões --input-format stream-json: o primeiro turno não espera mais até 2s por servidores MCP ainda conectados cujas ferramentas de busca adiam; eles chegam em uma curva posterior
  • Notificações aprimoradas da ferramenta Monitor: a saída final de um script e sua saída agora chegam como uma notificação em vez de duas, salvando uma mudança de modelo
  • Erros da ferramenta Artefato aprimorados: quando você não está conectado ao claude.ai, o terminal agora diz isso na primeira tentativa, e Claude é instruído a parar de tentar novamente uma chamada rejeitada mais cedo
  • Publicação de artefatos aprimorada: uma publicação criada em uma versão mais antiga é interrompida antes de ser enviada, com a página mais recente para mesclar
  • Verificações de segurança aprimoradas antes de remover uma árvore de trabalho de agente que contém verificações de submódulos
  • Saída OTEL_LOG_RAW_API_BODIES=file:<dir> aprimorada: novos atributos de evento index.jsonl e request_body_id / message.id vinculam cada resposta ao seu arquivo de solicitação e mensagem de transcrição
  • Inicialização do gateway de aplicativos Claude aprimorada: agora ele tenta a primeira conexão do Postgres até três vezes antes de sair, para que um banco de dados acessível com alguns segundos de atraso não falhe mais na inicialização
  • Melhorada a verificação de limite de gastos do gateway de aplicativos Claude sob carga: agora ele faz uma viagem de ida e volta ao banco de dados em vez de quatro, portanto, menos tempo limite de verificações em um gateway ocupado
  • Erros de limite de taxa de login do gateway de aplicativos Claude aprimorados: /login agora explica a recusa, e o log do gateway informa qual limite foi atingido e qual configuração deve ser alterada
  • Alterações nas instalações Bedrock, Vertex, Foundry e telemetria desabilitadas para usar a negociação v2 MCP client e MCP 2026-07-28 com servidores HTTP diretos por padrão, como outras instalações já fazem (opt out: MCP_SDK_GENERATION=v1 ou MCP_PROTOCOL_NEGOTIATION=legacy)
  • /code-review alterado para usar prompts de revisão em linha mais enxutos para cada modelo que não possui configurações próprias, em vez de gerar muitos subagentes de revisão
  • Entradas MCP "type": "sdk" alteradas em .mcp.json, configurações, plug-ins e arquivos de agente para serem ignorados com um aviso: apenas um aplicativo host SDK pode registrar servidores em processo
  • Alterada a observação de artefatos em sessões locais: uma nova versão publicada em outro lugar não inicia mais um turno; Claude fica sabendo disso por meio de um resultado posterior da ferramenta Artefato
  • Alterados plugins e clones do marketplace para deixar arquivos Git LFS como ponteiros em vez de baixá-los; git lfs pull na finalização da compra os busca
  • Corredores auto-hospedados alterados para ignorar um repositório somente leitura que o host git recusa na verificação de acesso em vez de falhar no início da sessão
  • Alterada a linha /status GitHub para ler "Sessões na nuvem", e /web-setup, /ultrareview e mensagens de teletransporte para dizer "sessão na nuvem" em vez de "Código Claude na web"
  • [VSCode] Adicionada continuação da etapa que um recarregamento de janela foi interrompido, rotulado no chat, com uma configuração Código Claude: Continuar após recarregar para desligá-lo
  • [VSCode] Adicionadas entradas de memória e instruções ao menu Personalizar: Memória mostra as alternâncias automáticas de memória, as memórias salvas e as pastas de memória, e Instruções edita os arquivos CLAUDE.md
  • [VSCode] Adicionada uma configuração claudeCode.lockEditorGroups para impedir que Claude bloqueie os grupos de editores em que abre
  • [VSCode] Corrigida uma pergunta paralela do /btw feita nos primeiros segundos de uma nova conversa, mostrando ocasionalmente o histórico de perguntas paralelas de outra sessão
  • [VSCode] Corrigido um breve congelamento quando a extensão procura pela primeira vez seu arquivo gitignore global
  • [VSCode] Corrigida uma mensagem enviada enquanto Claude estava executando uma ferramenta que desaparecia da conversa após recarregar uma janela
  • [VSCode] Corrigida a alternância de ativação de gerenciamento de plug-ins e as linhas de diálogo dos servidores MCP inacessíveis pelo teclado
  • [VSCode] Corrigidas entradas e saídas feitas em um terminal que não apareciam até uma recarga após CLAUDE_CONFIG_DIR ser alterado na configuração de variáveis de ambiente
  • [VSCode] Corrigidas diferenças de edição no chat sendo cortadas na parte inferior em algumas larguras de painel e para linhas longas quebradas; caixas de comparação agora cabem nas linhas mostradas
  • [VSCode] Corrigidas gravações de configurações sobrepostas da extensão, deixando ~/.claude/settings.json impossível de analisar ou eliminando uma configuração
  • [VSCode] Correção de abertura em nova aba (Ctrl/Cmd+Shift+Esc) que às vezes deixava a caixa de mensagem da nova aba sem foco, então a digitação não levava a lugar nenhum até que você cli a clicasse

  • [Claude Tag] Corrigida uma parada do filtro de segurança que redefinia silenciosamente o contexto de um thread do Slack quando ninguém estava esperando; Claude agora sempre diz isso e não cancela mais o trabalho em segundo plano ainda em execução
  • [Claude Tag] Corrigidos endereços de e-mail nas respostas de Claude no Slack renderizados com um prefixo mailto: visível; eles agora aparecem como o endereço clickable simples
