código claude v2.1.275

O que mudou

  • Adicionada a conta conectada ao login do gateway de aplicativos Claude: quando o gateway a nomeia, você a confirma antes que a credencial seja salva e /status a mostra
  • Adicionada uma tecla enviar agora (ctrl+enter, ou ctrl+x ctrl+s) que interrompe o turno atual e envia todas as mensagens na fila de uma só vez; mensagens enviadas e enfileiradas aparecem em cinza até que o modelo as receba
  • Adicionado um aviso de inicialização quando um otelHeadersHelper configurado falha, para que as sessões que exportam silenciosamente nenhuma telemetria sejam percebidas
  • Adicionada sincronização das habilidades e plugins habilitados em sua conta claude.ai para sessões de terminal conectadas com ela; cancelar com syncClaudeAiSkills: false ou syncClaudeAiPlugins: false
  • Adicionado /plugin install <plugin> --marketplace <source>, que oferece a possibilidade de adicionar o marketplace antes de instalar o plugin
  • Corrigida a alteração da nota de idade de um arquivo de memória restaurada entre solicitações após uma compactação ou retomada, o que causava falhas imediatas no cache
  • Correção da saída --forward-subagent-text stream-json e SDK descartando as mensagens de subagentes geradas por uma habilidade context: fork e de habilidades bifurcadas invocadas por um subagente ou outra habilidade bifurcada
  • Corrigidas sugestões de arquivo @-mention ocultadas abaixo dos recursos MCP ao usar um comando fileSuggestion personalizado ou digitar @./@./
  • Corrigido o modo de tela cheia colocando avisos de conclusão de tarefas em segundo plano abaixo da linha de ferramentas recolhidas de um turno longo, em vez de onde eles chegaram; cada aviso agora fecha a linha aberta
  • Corrigida a exclusão de uma cópia local do mercado claude plugin marketplace update quando a busca falhava e o mercado recebia o nome de seu repositório
  • Correção de mensagens de plugin e marketplace, logs e claude plugin marketplace list mostrando uma senha ou token armazenado em um URL git, ssh ou marketplace
  • Correção de uma sessão de nuvem retomada que deixava uma pergunta sem resposta aberta na transcrição depois que uma mensagem na fila a substituía
  • Corrigido o modo vim colocando o cursor um caractere logo após um "!" ou um "i!" digitado rapidamente. mudou um prompt não vazio para o modo shell
  • Corrigido o congelamento ou apagamento do modo de tela cheia por vários segundos ao rolar para cima após uma grande diferença de arquivo
  • Corrigida uma tag de fechamento perdida no estilo </ccmemory> que aparecia ocasionalmente nas respostas
  • Mensagens de plugin corrigidas, logs e a caixa de diálogo do plugin VS Code mostrando o servidor errado para alguns endereços git
  • Corrigido um terminal API Error: 400 em cada curva para usuários atrás de um gateway de rede que reescreve respostas de erro API quando um cabeçalho de solicitação beta é rejeitado
  • Correção de comandos Bash em sandbox no Linux, reportando o código de saída 0 para comandos com falha quando o shell é zsh
  • Corrigido o travamento da ferramenta de leitura em vez de reportar um erro quando parte de um arquivo grande não podia ser decodificado sob pressão de memória
  • Corrigido --resume, a visualização do seletor de currículo, os agentes em segundo plano retomados e a visualização da transcrição falhando em uma sessão cujo histórico salvo contém um lembrete de tarefa malformado ou uma entrada de anexo de arquivo @
  • Corrigido um travamento ao retomar uma conversa cuja transcrição contém uma entrada de mensagem malformada e um travamento de tela cheia quando tal conversa recebia novas mensagens enquanto rolava para cima
  • Correção de sessões que não eram retomadas ou iniciadas quando a transcrição salva continha um bloco de conteúdo de mensagem malformado
  • Corrigidas sugestões de Grep, Glob e @-file suspensas ou sem memória em pesquisas acima do limite de saída de 20 MB, e o ripgrep do sistema relatando "sem correspondências" em vez de um erro após uma enxurrada de avisos
  • Corrigido /rewind em uma sessão bifurcada ou em segundo plano, restaurando um arquivo preenchido com zero ou truncado quando os backups do histórico de arquivos da sessão não podiam ser totalmente copiados
  • Correção de sessões em tela cheia que às vezes terminavam com "Claude Code encerrado após um erro de interface irrecuperável" ao digitar rápido ou segurar uma tecla com o menu suspenso de comando de barra aberto
  • Correção de sessões em segundo plano travando e reiniciando seu trabalhador quando um comando alimentado por stdin era executado em uma máquina que estava sem descritores de arquivo
  • Corrigida uma falha na inicialização quando ~/.claude.json mantinha um valor mcpNeedsAuthNoticed malformado
  • Correção de --resume e --continue interrompendo o pensamento anterior de uma conversa quando uma ferramenta integrada com a qual ela foi iniciada foi desativada por um sinalizador do lado do servidor
  • Corrigido texto selecionado com o mouse no seletor de sessão de tela cheia do claude --resume, nunca alcançando o painel cli
  • Corrigidas as visualizações de recarga do plugin substituindo os arquivos de plugin extraídos de uma sessão em execução quando o plugin era carregado de um arquivo --plugin-dir ou --plugin-url
  • Correção de runners auto-hospedados com --drain-wait-sec perdendo o resultado final de um turno que terminava durante uma drenagem do SIGTERM; o corredor agora espera brevemente que a curva seja informada
  • Corrigidos ganchos SubagentStop com um disparo matcher específico para cada subagente de parada cujo tipo de agente estava vazio
  • Correção de comandos Bash em sandbox que não conseguiam gravar em diretórios de projetos chamados hooks/ ou config/
  • Correção de falha nas atualizações de artefato com "Arquivo não encontrado" após uma sessão ser retomada em outra máquina ou seu scratchpad ser limpo: a última versão publicada da página é restaurada
  • Corrigido /update-config escrevendo regras de permissão Write(path), cujas verificações de permissão de arquivo não correspondem, em vez de regras Edit(path)
  • Correção de quatro URLs de documentação inoperantes (preços, uso do computador, habilidades, CLI) na tabela de fontes ativas da habilidade claude-api incluída
  • Cache de prompt aprimorado para um --system-prompt que contém uma linha __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__: o texto acima dele agora é armazenado em cache globalmente, assim como o formato do array do SDK já é
  • Melhorado o erro /desktop quando o Claude Desktop não abre: agora diz por que e o que fazer a seguir
  • Melhorados os resultados de publicação e leitura da ferramenta Artefato: agora eles dizem quem pode abrir a página e o que o menu Compartilhar do proprietário oferece
  • Resultados de publicação de artefato aprimorados: eles nomeiam o ícone da guia enviado, avisam quando a página contém um byte NUL e tentam novamente uma busca fragmentada da página mais recente para mesclar após uma publicação obsoleta
  • Imagens coladas e anexadas aprimoradas: agora elas são salvas onde Claude pode abri-las como arquivos sem solicitação de permissão, inclusive no Desktop e no VS Code
  • Melhoria na orientação da ferramenta Artefato para que Claude atualize um artefato compartilhado quando você tiver acesso de edição a ele, em vez de publicar uma cópia separada
  • Leituras de uso do plano aprimoradas: janelas do editor e sessões não interativas em uma máquina agora compartilham uma leitura feita no último minuto em vez de cada uma chamar o endpoint de uso
  • Melhorada a descrição da ferramenta ListPlugins para que Claude saiba que ela lista plug-ins habilitados em sua conta claude.ai, e não plug-ins instalados localmente com /plugin
  • Melhor capacidade de resposta quando o terminal está lento ou pausado: a saída não fica mais para trás enquanto o terminal alcança
  • Resultados aprimorados de gravação e edição para arquivos na pasta de habilidades de conta sincronizada: agora eles dizem que a alteração não foi salva em sua conta e como salvá-la
  • /logout atualizado para logins de gateway de aplicativos Claude para também encerrar a sessão em gateways que anunciam revogação de token
  • Sessões hospedadas alteradas para manter uma solicitação de permissão sem resposta após a reinicialização do contêiner, em vez de perguntar novamente
  • Alterada a ferramenta Artefato para solicitar um ícone de guia de uma palavra na primeira publicação, em vez de um favicon de emoji
  • Claude alterado no Chrome no modo automático para ignorar a verificação por site da extensão para chamadas aprovadas pelo classificador, como faz o modo de desvio, corrigindo browser_batch "Permissão negada" após um redirecionamento
  • Plugins alterados instalados a partir de uma fonte npm para serem buscados com npm pack --ignore-scripts e com integridade verificada, para que os scripts de instalação de um pacote não sejam mais executados
  • Alteradas as execuções programadas e de rotina Executar agora para salvar dados e republicar a página de um artefato que você pode editar sem solicitar; artefatos públicos, primeiras publicações e exclusões ainda perguntam
