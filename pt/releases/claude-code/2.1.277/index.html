claude-code v2.1.277

código claude v2.1.277

O que mudou

  • Adicionado suporte AGENTS.md: em um projeto sem CLAUDE.md, Claude Code lê AGENTS.md; altere-o em "Instruções do projeto" em /config (ainda não em Bedrock, Vertex ou Foundry)
  • Adicionado CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 para gateways de aplicativos Claude cuja única saída é um proxy de encaminhamento: cada solicitação de saída entrega ao proxy o nome do host em vez de resolvê-lo localmente
  • Adicionado um mapa headers: opcional nos upstreams do gateway de aplicativos Claude, para enviar cabeçalhos estáticos para um proxy que você executa na frente de um provedor
  • Adicionada uma linha informando que a atualização de uma tarefa em segundo plano está aguardando quando termina enquanto um painel como /tasks está aberto
  • Corrigidas sessões do claude -p e do Agente SDK que poderiam travar sem resultado após um erro interno; eles agora relatam o erro e saem com o código 1
  • Correção de conversas que falhavam em todas as solicitações com "blocos de conteúdo de texto não devem estar vazios" quando um assistente anterior mantinha um bloco de texto vazio ao lado de outro conteúdo, inclusive após --resume
  • Corrigido o logout inesperado quando uma versão mais antiga do Claude Code (por exemplo, um pacote de extensão IDE CLI) é executada na mesma máquina que a atual
  • Correção da inicialização interativa travada ou mostrando um erro para usuários ANTHROPIC_API_KEY quando ~/.claude.json mantém um valor customApiKeyResponses malformado
  • Corrigido erros nas verificações de atualização a cada 30 minutos e claude update travando quando uma versão mínima ou máxima é definida, se um proxy retornar uma versão inválida; um minimumVersion malformado agora é ignorado
  • Corrigido claude update em instalações gerenciadas por winget ou apk relatando "atualizado" quando a pesquisa de versão falhava
  • Corrigido claude plugin install que às vezes falhava e quebrava a cópia instalada ao reinstalar uma versão de plugin que uma sessão ou outro programa estava usando; uma cópia inalterada agora é deixada sozinha
  • Corrigido Grep e Glob que não reportavam correspondências quando a pesquisa não podia ser iniciada porque o sistema estava sem processos, memória ou identificadores de arquivos; eles agora retornam um erro dizendo isso
  • Corrigida a ferramenta Write encerrando silenciosamente o turno como uma permissão declined quando o caminho de destino é um diretório existente; agora relata um erro claro
  • Corrigida a ferramenta Editar tratando uma barra invertida com escape seguida pelo texto uXXXX como um escape \uXXXX, o que poderia fazer com que uma edição de um caractere não-ASCII reescrevesse uma sequência de barra invertida com escape.
  • Correção do relatório da ferramenta de edição "Expressão regular inválida: expressão regular muito grande" em vez de "String não encontrada no arquivo" quando uma edição muito grande contendo texto não ASCII não correspondia ao arquivo
  • Corrigido um turno que terminava mais cedo com "Caminho contém bytes nulos" quando o caminho do arquivo de uma chamada de ferramenta continha \u0000 escrito como uma sequência de escape; caracteres de controle escapados agora permanecem como texto literal
  • Corrigidas sessões em segundo plano (claude --bg) que saíam quando o servidor LSP de um plugin saía ou fechava seu stdin
  • Corrigida uma falha (“Erro de tipo”) ao abrir /mcp ou /plugin manage com um valor claudeAiMcpEverConnected malformado em ~/.claude.json
  • Corrigido um travamento na inicialização quando ~/.claude.json mantinha um valor theme malformado
  • Corrigida uma falha ("erro de interface irrecuperável") quando o prompt continha texto contendo códigos de cores do terminal, por exemplo, um prompt recuperado do histórico ou texto carregado do editor externo
  • Corrigida uma falha ao retomar uma sessão cujo histórico salvo contém uma mensagem do assistente armazenada como uma string simples
  • Correção de sessões em máquinas lentas ou muito carregadas que às vezes terminavam com "Claude Code encerrado após um erro de interface irrecuperável" quando o primeiro botão giratório aparecia
  • Corrigido um caso raro em que a tela poderia parar de atualizar durante o resto da sessão após um erro interno de renderização
  • Corrigido um caso raro no Windows em que um turno poderia parar com um erro como "Sem memória" logo após a resposta de Claude, de modo que as chamadas da ferramenta de resposta nunca fossem executadas
  • Sessões corrigidas continuavam após /clear (reiniciar, --continue, --resume) perder parte de sua primeira mensagem quando um gancho SessionStart imprimia a saída, causando uma falha completa no cache de prompt
  • Mensagens corrigidas de outros agentes (como SendMessage de um subagente) que chegavam no meio do turno, aparecendo abaixo da linha "Executou N comandos shell" em vez de onde chegaram
  • Corrigido o aviso "copiado" que não aparecia após arrastar e selecionar o texto no seletor de tela cheia /resume e outros painéis que cobrem a área de prompt
  • Correção do $TMPDIR expandindo vazio em comandos Bash que são executados fora do sandbox enquanto o sandbox está ativado
  • Correção do WebFetch e WebSearch em sessões de nuvem do Cowork que não informavam ao Claude por que uma solicitação foi recusada, como um orçamento de busca esgotado ou uma política administrativa
  • Corrigida a retransmissão de telemetria do gateway de aplicativos Claude, ignorando um nome de host ou domínio do coletor listado em NO_PROXY quando um proxy é definido
  • Corrigida uma entrada strictKnownMarketplaces ou blockedMarketplaces malformada, desativando silenciosamente toda a política do mercado corporativo
  • Corrigidas falhas nas atualizações automáticas que deixavam para trás grandes downloads em etapas no ~/.cache/claude/staging
  • Corrigido /plugin que não retirava caracteres de controle de terminal de mensagens na guia Instalado, como o erro de falha na atualização do plugin
  • Corrigido /plugin → Instalado e /skills travando quando uma habilidade ou comando legado é nomeado como uma propriedade de objeto integrada, como constructor ou toString
  • Corrigido o fechamento do /plugin sem mensagem quando cada instalação em uma seleção múltipla falhava
  • Corrigidos plug-ins desinstalados reaparecendo como linhas "falha ao carregar" em /plugin instalado e Remover não limpando tal linha
  • Corrigido plugins do marketplace oficial sendo gravados sem seu commit no installed_plugins.json, e installed_plugins.json mantendo o commit antigo após atualizar um plugin de commit fixado
  • Correção das visualizações de recarga do plug-in, mantendo todas as cópias visualizadas de um arquivo de plug-in descompactadas até a saída e sobrescrevendo o arquivo --plugin-url em cache para o qual uma recarga volta quando o download falha.
  • Corrigida falha na contabilidade da sessão de controle remoto quando ~/.claude.json mantém um registro de espaço reservado malformado
  • Corrigido o erro após um login claude.ai revogado culpando um perfil antrópico expirado; agora lidera com /login
  • Corrigido texto digitado ou colado que ocasionalmente saía embaralhado na entrada de despacho do claude agents durante repetição de tecla ou entrada muito rápida
  • Corrigida uma falha ("erro de interface irrecuperável") ao retomar uma sessão cuja transcrição salva contém um resumo de ganchos de parada sem uma lista de ganchos bem formada
  • Correção do Enter em uma linha do painel do agente selecionado, sem fazer nada quando keybindings.json religa o Enter no contexto de bate-papo, por exemplo, para chat:queueSubmit
  • Corrigida falha na leitura de páginas PDF no Windows quando o caminho da pasta de trabalho é longo (cerca de 120 caracteres ou mais)
  • Corrigido um currículo headless (claude -p --resume, o SDK, um recarregamento da janela de extensão do VS Code) iniciando o custo da sessão e os totais de uso em zero; sessões headless agora salvam seus totais na saída
  • Corrigidas habilidades do projeto do repositório principal que não carregavam nas sessões --worktree quando .claude/skills não era rastreado
  • Corrigido um glob sandbox.excludedCommands isentando um comando Bash composto inteiro da sandbox quando apenas uma parte correspondia; cada parte agora deve corresponder
  • Correção de subagentes retomados e colegas de equipe que renderizavam novamente as definições da ferramenta MCP que haviam carregado, o que interrompeu o cache de prompt para esse agente
  • Corrigida publicação de artefato com taxa limitada informando a Claude para parar de tentar novamente; Claude agora é informado de que nada foi publicado e quando enviar a mesma publicação novamente
  • Correção de anexos gravados anteriormente em uma conversa sendo renderizados novamente após uma retomada ou reinicialização, o que eliminava o pensamento estendido e perdia o cache de prompt
  • Corrigido login no console mostrando apenas "Solicitação falhou com código de status 400" quando o servidor se recusa a criar uma chave API; agora mostra a mensagem do servidor
  • Corrigidas mensagens digitadas enquanto Claude ainda está trabalhando, às vezes sendo ignoradas pela modelo
  • Inicialização de sessão aprimorada para uso SDK e headless (-p): o primeiro turno não espera mais na pesquisa CLAUDE.md por diretório
  • Melhoradas as mensagens de erro de loopback do gateway de aplicativos Claude para nomear CLAUDE_GATEWAY_ALLOW_LOOPBACK
  • /plugin melhorado instalado: um servidor MCP listado além de seu plugin agora mostra a qual plugin ele pertence
  • claude plugin install aprimorado em um plugin já instalado: agora informa quando o mercado oferece uma versão mais recente e nomeia o comando claude plugin update
  • Melhorada a linha de aviso de inicialização abaixo do logotipo: agora lê "N mais avisos ocultos" em vez de "+N mais · /status"
  • Tratamento de prompt aprimorado: a formatação Unicode invisível e os caracteres de tag em um prompt são removidos e o prompt limpo é mostrado para revisão antes de ser enviado
  • /ultrareview aprimorado quando não há nada para revisar: as mensagens informam em qual caso você está, oferecem um comando que revisa seu commit mais recente e o primeiro commit de um novo repositório é revisado por completo
  • Melhor manipulação de links de artefatos para que Claude leia links de artefatos claude.ai com a ferramenta Artifact em vez do WebFetch quando essa ferramenta estiver disponível
  • Melhorado o prompt de permissão do perigoso-rm para nomear o comando rm sinalizado e sugerir um guarda ${VAR:?}, para que corridas sem cabeça possam se recuperar
  • Melhorados os prompts de permissão da ferramenta Artefato: frases mais curtas, páginas e artefatos nomeados por título ou nome de arquivo e links listados após o texto
  • Alterado Fable para aparecer sempre em /model no Antrópico API; ele fica esmaecido somente quando as configurações da sua organização o desativam
  • Alteradas as instruções do sandbox Bash em Bedrock, Vertex e Foundry para o texto original, que enquadra o sandbox como o limite do que a tarefa foi dada
  • Alterado /ultrareview em sessões não interativas para recusar quando o repositório não possui branch base ou histórico compartilhado
  • Alterados os resultados do subagente para alcançar o agente principal sob um cabeçalho marcando-os como saída do subagente, com o resultado recuado, para que o texto no resultado de um subagente não possa passar como instruções da própria sessão
  • Alterados os prompts agent() computados dos scripts de fluxo de trabalho em Bedrock, Vertex e Foundry para alcançar o subagente enquadrado como texto de autoria do script, para que o classificador de segurança não os leia como o usuário
  • Removida a solicitação de título automático do Haiku em segundo plano das execuções do claude -p iniciadas fora de um SDK ou IDE
  • Removida a ferramenta TaskOutput obsoleta; Claude lê o arquivo de saída de uma tarefa em segundo plano com Read, e a configuração taskOutputMaxChars e TASK_MAX_OUTPUT_LENGTH não têm mais nenhum efeito
  • [VSCode] Adicionada uma linha Sair ao menu do painel, com /logout no menu de comando digitado
  • [VSCode] Adicionados shells de segundo plano e outras tarefas em execução ao mapa do agente, cada um com um Stop e um /tasks digitado que o abre
  • [VSCode] Adicionado um botão Copiar resposta nas respostas e um /copy digitado
  • [VSCode] Adicionado um aviso único quando sessões inativas são arquivadas automaticamente e uma ação "Desarquivar tudo" no grupo Sessões arquivadas
  • [VSCode] Adicionado o custo da sessão e o uso de token à caixa de diálogo Conta e uso e ao gerenciador de sessão onde os limites do plano não se aplicam (Vertex, Bedrock, Foundry, chave API)
  • [VSCode] Corrigida a linha do menu "Configuração geral" mostrando o texto de uso do /config em vez de abrir as configurações, e fez com que /mcp, /hooks, /memory, /rewind e comandos semelhantes digitados abrissem suas caixas de diálogo
  • [VSCode] Corrigido o nível do controle deslizante de esforço que não persistia em sessões posteriores em um modelo que já tinha um nível salvo com /effort
  • [VSCode] Corrigida a ausência automática do seletor de modo para conversas abertas em um painel já usado quando a configuração do modelo salvo é um alias com caso diferente, como "Sonnet"
  • [VSCode] Corrigido /fast que não salvava o modo rápido como padrão, então foi perdido quando a extensão foi reiniciada Claude Code
  • [Claude Code na web] Adicionadas seções Pessoal e Organização ao seletor de ambiente nos planos Team e Enterprise, e os administradores agora podem compartilhar um ambiente pessoal com a organização
  • [Claude Code na web] Ambientes organizacionais alterados para abrir como um resumo somente leitura na guia Código nos planos Team e Enterprise, com edição em Configurações de administrador → Ambientes de nuvem
  • [Código Claude na web] Corrigido um ambiente de nuvem salvo com acesso de rede personalizado e nenhum domínio revertendo silenciosamente para Trusted; a caixa de diálogo agora pede pelo menos um domínio
  • [Código Claude na web] Alterou a configuração do código Claude do administrador chamada "Web" para "Sessões na nuvem" e removeu a linha móvel redundante somente leitura abaixo dela
  • [Claude Tag] Correção de rotinas criadas em um canal do Slack em uma instalação Enterprise Grid em toda a organização que falhava ao ler outros canais públicos em seu espaço de trabalho quando eram executados
  • [Claude Tag] Corrigidos os links "Saiba mais" nas predefinições de credenciais nos pacotes de acesso Claude Tag para abrir a página de configuração de credenciais de cada fornecedor em vez de uma referência genérica API
  • [Claude Tag] Alterada a predefinição de credencial Pylon nos pacotes de acesso Claude Tag para que os administradores possam apontá-la para o host da UE do Pylon
  • [Claude Tag] Foram corrigidos formulários de credenciais do Google Cloud em pacotes de acesso Claude Tag: um arquivo de chave recusado agora diz o motivo, o site e os escopos permanecem bloqueados e uma rotação rejeitada mantém a chave colada
  • [Claude Tag] Corrigido o log de eventos de rede nas configurações de administração do Claude Tag mostrando nenhum status de resposta para solicitações por meio de conexões que usam assinatura AWS, certificados client ou uma CA personalizada
