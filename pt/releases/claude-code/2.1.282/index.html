código claude v2.1.282

O que mudou

  • Adicionada uma configuração maxProseWidth que limita a largura da prosa de Claude em terminais largos, enquanto tabelas e blocos de código mantêm a largura total
  • Adicionado um aviso de inicialização e entradas /status e claude doctor, listando variáveis de telemetria nos arquivos de configurações de um projeto que foram ignoradas ou que desativaram a telemetria
  • Adicionada a configuração gerenciada do allowClaudeInChromeWithManagedMcp para permitir que o claude --chrome seja executado junto com um managed-mcp.json exclusivo; o erro mostrado quando o Chrome está bloqueado agora o nomeia
  • Adicionado store.readiness_grace_seconds ao gateway de aplicativos Claude para que /readyz possa ficar pronto durante uma curta interrupção do Postgres, como um failover de banco de dados
  • Adicionada uma barra de rolagem à lista de rascunhos do /feedback em modo tela cheia; aparece enquanto o mouse está sobre a lista
  • Corrigidas todas as solicitações que falhavam com um erro 400 em conversas cujo histórico contém resultados de pesquisa na web que o API não consegue descriptografar (por exemplo, de uma resposta respondida por meio de um gateway de terceiros)
  • Corrigidos mais casos de sessões continuadas ou retomadas (--continue, --resume) reenviando mensagens anteriores em um formato alterado, o que poderia fazer com que o API abandonasse o raciocínio anterior de Claude
  • Corrigido o pensamento estendido anterior que era eliminado quando /model, /rename, /artifacts ou outro comando de barra imediato era usado enquanto Claude estava trabalhando
  • Corrigidas conversas continuadas ou retomadas, perdendo o pensamento estendido anterior quando reiniciadas com uma lista --tools que deixa de fora uma ferramenta integrada oferecida no início da conversa
  • Corrigidas sessões que falhavam a cada turno com um erro API “data inválido no bloco redacted_thinking”; Claude Code agora elimina os bloqueios de pensamento da conversa e tenta novamente uma vez
  • Corrigida falha de compactação quando a solicitação de sumarização é recusada; agora ele tenta novamente em um modelo substituto
  • Corrigida uma curva falhada ("Esforço 'xalto' não está disponível com o pensamento desligado") após uma mudança de modelo relacionada à segurança em sessões com pensamento desligado e esforço acima do alto
  • Corrigido um prompt de troca de créditos de uso do Fable sem resposta em sessões hospedadas pelo SDK, como Claude Desktop; a curva agora termina e os controles remotos clients agora veem o aviso de troca de modelo
  • Corrigido /model com um ID de modelo Fable completo parando em um erro API em vez de abrir o prompt de créditos de uso quando o plano precisa de créditos de uso que ainda não estão ativados
  • Corrigidas solicitações que falhavam por até um minuto com um erro de login "outro processo do Claude Code está atualizando" depois que outro processo foi fechado ou eliminado no meio da atualização
  • Correção de sessões iniciadas enquanto outra janela do Claude Code atualizava o login (comum com várias janelas do VS Code) e não tentava novamente a busca da política da organização
  • Corrigido CLAUDE.md e regras sendo lidas na inicialização por meio de um link simbólico de repositório que chegava ao /Network do macOS via .. ou um caminho de kernel estilo /.vol, ou um link de regras para o /home do macOS sendo listado
  • Corrigidas regras de permissão do Bash com um padrão intermediário :* sendo ignorado nos arquivos de configurações enquanto --allowedTools as respeitava; eles agora funcionam de todas as fontes, com um aviso inicial sobre como eles correspondem
  • Correção de um comando aprovado em um prompt de permissão restaurado executado duas vezes quando o trabalhador de uma sessão remota era reiniciado
  • Corrigidas configurações gerenciadas que ignoravam um valor digitado incorretamente para chaves de bloqueio booleanas, como disableClaudeAiConnectors ou allowManagedPermissionRulesOnly; o bloqueio agora se aplica e a inicialização nomeia a chave
  • Corrigidas configurações gerenciadas de permissions, autoMode, worktree e attribution sendo totalmente ignoradas quando um valor aninhado era inválido; o resto do bloco agora ainda se aplica
  • Repositório corrigido, habilidades do usuário e --add-dir, comandos e manifestos de plug-in de diretório de habilidades pré-aprovando suas próprias ferramentas via allowed-tools sob gerenciamento allowManagedPermissionRulesOnly
  • Corrigidas mensagens de bloqueio de salvaguarda no Amazon Bedrock e Bedrock Mantle que não exibiam um ID de solicitação; bloquear mensagens agora também mostra o ID da mensagem
  • Vertex AI: Corrigida a pesquisa na web que não era oferecida para modelos que Claude Code ainda não reconhece, como os recém-lançados
  • Bash e PowerShell corrigidos ocultando uma cota de disco completa atrás do "Código de saída 1" e deixando grandes arquivos de saída em temperatura
  • Corrigidos erros de validação de entrada da ferramenta nomeando apenas um parâmetro desconhecido, ausente ou digitado incorretamente quando outros parâmetros na mesma chamada também eram inválidos; agora eles também estão listados
  • Correção de texto colado de várias linhas enviado linha por linha após o modo de colagem entre colchetes do terminal ser redefinido no meio da sessão
  • Corrigido o texto de exemplo do prompt piscando e desaparecendo na inicialização em projetos com um gancho SessionStart
  • Corrigida uma tela em branco piscando antes do primeiro quadro ao iniciar no modo de tela cheia
  • Correção de linhas distorcidas e mal posicionadas no renderizador que não é de tela cheia depois que a tela ficava mais curta e ainda mais alta que o terminal, por exemplo. excluindo uma linha de prompt enquanto um comando shell transmite a saída
  • Corrigido um caractere obsoleto deixado na última coluna de uma comparação quando o caractere CJK ou emoji de uma linha redesenhada passava para a próxima linha
  • Corrigida a posição do cursor antes do final de um prompt recuperado do histórico quando o prompt contém uma guia
  • Corrigida a dica enviar agora mostrando ctrl+enter em terminais que enviam como nova linha (Terminal Windows antes de 1.25); agora mostra ctrl+x ctrl+s lá
  • Correção da falha do claude remote-control --debug com "Argumento desconhecido: --debug", embora o próprio erro de elegibilidade do Controle Remoto diga para ser executado com --debug
  • Corrigido /install-github-app dizendo "cancelado" e ainda empurrando o branch e salvando o segredo da chave API; sair agora interrompe as etapas restantes e relata o que já foi feito
  • Correção de /feedback, /bug e /share em Bedrock, Vertex e outros provedores terceirizados que ainda salvavam o arquivo de relatório após você cancelar durante o salvamento
  • Corrigida a desinstalação do plugin relatando sucesso e excluindo as opções salvas do plugin quando seu arquivo de configurações ainda estava habilitado ou não podia ser lido; agora ele para e nomeia o arquivo
  • Corrigida desinstalação de plugins excluindo opções e segredos salvos de um plugin quando a lista de plugins instalados não podia ser lida após a remoção; eles agora são mantidos e a desinstalação diz isso
  • Corrigida uma tecla digitada logo após / em /skills movendo a lista de habilidades em vez de chegar à caixa de pesquisa
  • Corrigido o cursor do terminal saltando da caixa de pesquisa do /skills para a lista de habilidades durante a digitação, o que poderia ocultar o cursor e colocar a entrada do IME no lugar errado
  • Corrigidas listas com barra de rolagem, como /skills e /mcp, sendo duas colunas mais estreitas fora do modo tela cheia, onde a barra de rolagem nunca pode aparecer
  • Foi corrigido o quebramento do rodapé do painel do agente em duas linhas com teclas de rebote longas e sua dica "Esc para recolher" ignorando uma chave de rebote de rebote
  • Corrigido um separador · duplicado no rodapé da caixa de diálogo /tasks quando o atalho para parar todos os agentes é desvinculado em keybindings.json
  • Corrigida falha na publicação de artefatos quando Claude dava à versão um rótulo com mais de 60 caracteres; o rótulo agora está encurtado
  • Corrigido modo de leitor de tela, listas entre citações e listas muito longas deixando cair as linhas em branco no topo de um bloco de código que abre um item da lista, diretamente ou dentro de uma citação
  • Mensagens de erro de leitura de página PDF corrigidas: caminhos com caracteres acentuados ou não latinos agora aparecem de forma legível e uma pasta chamada "senha" ou "inválida" não pode mais tornar o nome do erro a causa errada
  • Corrigido o modo vim >> recuando linhas vazias, r com uma contagem maior que a linha alterando o texto, 2J juntando uma linha a mais e uma contagem na última linha (2dd, 2>>) mudando ou excluindo-a
  • Correção do posicionamento do cursor no modo vim: após dd, dj, dG ou um p/P de linha inteira, ele pousa no primeiro não-branco, yy não o move mais e Esc após um emoji não o deixa mais dentro do emoji
  • Corrigido modo vim ignorando uma contagem digitada antes de . ao repetir x, s, p, d ou c, e linha inteira p/P, o, O, J, >> e << agindo na linha errada quando uma linha acima embrulhos
  • Corrigido o modo vim deixando o cursor após o final de um prompt recuperado do histórico ou retirado da fila no modo normal, então x não fez nada
  • Melhorou o tempo para retomar sessões muito grandes, inclusive aquelas que nunca foram compactadas
  • Melhorado o erro mostrado no Windows quando uma sessão não pode ser retomada porque seu arquivo de transcrição não pôde ser lido (EBADF): agora nomeia possíveis causas e o que tentar
  • Melhorado o erro de modelo desconhecido do Claude Desktop para sugerir a mudança para um modelo diferente
  • Renderização aprimorada de Unicode incomum em prompts de permissão
  • /artifacts aprimorado: os títulos são alinhados em uma coluna, os detalhes são eliminados inteiros em vez de cortados no meio da palavra e a lista suporta PgUp/PgDn, Home/End, a roda do mouse e clicks
  • Atualizada a habilidade claude-api: o faturamento de recusa de pré-saída agora está vinculado aos documentos Como as recusas são cobradas, as recusas intermediárias são cobradas com taxas normais e as recusas de pré-saída contam contra os limites de taxa
  • Atualizada a habilidade claude-api para recomendar ant apply para manter os recursos dos Agentes Gerenciados como arquivos controlados por versão
  • Modo automático alterado para usar o classificador do lado do servidor por padrão em uma conexão direta Antrópica API quando a telemetria está desligada (CLAUDE_CODE_AUTO_MODE_SERVER=0 desativa)
  • sandbox.excludedCommands alterado para ignorar entradas de configurações locais e de projeto quando configurações gerenciadas ou --settings definem allowUnsandboxedCommands: false ou allowManagedDomainsOnly: true gerenciado
  • Alteradas configurações locais e de projeto para ignorar variáveis OpenTelemetry que ativam a exportação, definem seu endpoint ou capturam conteúdo, como CLAUDE_CODE_ENABLE_TELEMETRY e OTEL_LOG_*
  • Configurações gerenciadas do Windows/WSL alteradas para que uma política de administrador presente, mas inválida ou ilegível (HKLM, managed-settings.json) impeça a aplicação de HKCU e WSL /etc/claude-code graváveis pelo usuário
  • Skill(anthropic-skills:*) e Skill(claude-ai:*) alterados permitem que as regras abranjam apenas habilidades sincronizadas de claude.ai, não plug-ins ou outras habilidades que apenas usam esse nome
  • Pastas de habilidades, arquivos de comando e comandos de fluxo de trabalho alterados no namespace anthropic-skills ou claude-ai para não serem mais carregados; um plug-in com esse nome ainda carrega, mas produz vínculos de nome com habilidades sincronizadas
  • Servidores MCP configurados sob o nome anthropic-skills ou claude-ai alterados para não listarem habilidades ou prompts (suas ferramentas ainda funcionam); renomeie o servidor em sua configuração MCP para listá-los novamente
  • Alterados os visuais do ultracode no /effort e a entrada de prompt para estilo simples (sem ondulação, floreio de borda ou brilho de palavra-chave) e remoção da dica giratória de fluxos de trabalho dinâmicos
  • Mudamos os pés do mascote Clawd no banner inicial para ficarem sob os cantos de seu corpo
  • [VSCode] Corrigidas respostas longas que ficavam atrasadas no fluxo: o painel não analisa mais a resposta inteira a cada atualização
  • [VSCode] Corrigido o botão do microfone de ditado que cobre a barra de rolagem da entrada de mensagem quando a entrada é alta o suficiente para rolar
  • [VSCode] Corrigidas sessões de Controle Remoto iniciadas neste computador que não abriam a partir de sua entrada da Web na lista de sessões; eles agora abrem a conversa local, a menos que ela esteja em outro lugar
  • [VSCode] Corrigida a tela de login de uma guia do editor travando silenciosamente após a reinicialização do host da extensão; agora também mostra o aviso "parou de responder"
  • [Sessões na nuvem] Adicionado status do aplicativo Claude GitHub em Configurações › Conectores › GitHub: se o aplicativo está instalado e acessível para sua conta, além de etapas para conectar, instalar ou reconectar
  • [Sessões na nuvem] Adicionados links "Abrir repositório" e "Abrir página de comparação" ao menu do repositório de uma sessão na nuvem cujo repositório está hospedado em um servidor Git diferente de GitHub
  • [Sessões de nuvem] Adicionado anexar um repositório de um proprietário GitHub diferente, como o upstream de um fork, a uma sessão de nuvem em execução que já possui um, incluindo sessões iniciadas no Slack
  • [Sessões na nuvem] Corrigido o próximo tempo de execução mostrado para uma rotina horária com 30 minutos de folga para pessoas em fusos horários com diferença de meia hora, como a Índia
  • [Sessões na nuvem] Melhorou a rapidez com que a página Rotinas e a lista agendada da barra lateral são carregadas para contas cujas sessões anteriores agendaram muitos lembretes de check-in
  • [Claude Tag] Foram corrigidos padrões de canal de ingresso automático salvos para um espaço de trabalho nas configurações de administrador do Claude Tag sendo ignorados em uma instalação em toda a organização do Enterprise Grid; Claude agora se junta a novos canais correspondentes
  • [Claude Tag] Corrigido Claude que não respondia em um canal Enterprise Grid compartilhado entre dois espaços de trabalho de uma organização quando a versão do Claude Tag do canal era salva no outro espaço de trabalho
  • [Claude Tag] Corrigido o cartão de progresso do aplicativo Claude in Slack anterior para sessões em um repositório GitHub Enterprise Server: agora ele nomeia o repositório e oferece um botão funcional Criar PR
  • [Claude Tag] Corrigidos tópicos do Slack cujo modelo foi retirado, voltando para outro modelo a cada resposta, mais lento e com uma nota substituta a cada vez; o thread agora se move para um modelo funcional
  • [Claude Tag] Corrigido que os arquivos que Claude enviava para o Slack não conseguiam carregar uma legenda contendo uma tabela; as legendas agora são renderizadas com a mesma formatação das respostas
  • [Claude Tag] Corrigidos os tópicos de Claude na visualização de Agentes e ferramentas do Slack, às vezes sendo listados na primeira mensagem em vez de no nome; renomeações posteriores agora atualizam a lista também
  • [Claude Tag] Corrigida a remoção da concessão de uma organização GitHub da guia Repositórios de um pacote de acesso nas configurações de administrador da Claude Tag, falhando ao salvar depois que a organização GitHub foi desconectada
  • [Claude Tag] Corrigido Claude sempre respondendo "Não foi possível verificar este canal agora" em um canal compartilhado com um espaço de trabalho Grid ao qual não foi adicionado; o aviso agora diz qual espaço de trabalho precisa do aplicativo
  • [Claude Tag] Corrigido o custo e os totais de tokens no rodapé da resposta de Claude, que eram muitas vezes altos demais após o reinício do trabalhador em nuvem da sessão
  • [Claude Tag] Alterados os cartões com bordas que Claude usa nas respostas do Slack para planos, tabelas e detalhes para serem renderizados em largura por padrão em vez de em largura estreita
