#Deep Tutor v1.0.0-beta.1

🚀 DeepTutor v1.0.0-beta1 Release Notes

Data de lançamento: 2026.04.04 Temos o prazer de anunciar DeepTutor v1.0.0-beta1 — a primeira versão beta da nova arquitetura DeepTutor. Esta é uma reescrita completa que transforma o DeepTutor de um tutor RAG monolítico em uma plataforma de aprendizagem nativa do agente com um modelo de plug-in de duas camadas (ferramentas + recursos), três pontos de entrada unificados (CLI / WebSocket / Python SDK) e um shell de aplicativo da web completamente reconstruído. Encontre mais surpresas por conta própria!

⚠️ Aviso Beta: Este é o beta 1 do v1.0.0. A arquitetura principal é estável, mas algumas interações de UI e fluxos de trabalho extremos ainda podem conter bugs. Agradecemos sua paciência e recebemos relatórios de bugs via Issues. 📌 Nota da base de conhecimento: Nesta versão, o pipeline RAG foi simplificado apenas para LlamaIndex. Os pipelines LightRAG e RAG-Anything, juntamente com o conteúdo da base de conhecimento relacionado, foram temporariamente removidos para focar na estabilidade. Eles serão reintroduzidos nos próximos lançamentos. [!TIP] Chamada para Feedback: Estamos cientes de que alguns dos recursos antigos não estão incluídos na versão mais recente. Se você tiver algum comentário útil, encontrar algum bug ou solicitar algum recurso, por favor [abra um problema] (https://github.com/HKUDS/DeepTutor/issues)! PRs também são bem-vindos — consulte nosso Guia de contribuição. Escopo diferencial: main...dev (903 arquivos alterados, 92.701 inserções, 73.749 exclusões)

Resumo rápido

  • Arquitetura — Reescrita completa de src/ para deeptutor/ + deeptutor_cli/ com tempo de execução nativo do agente (Ferramentas + Capacidades).
  • Pontos de entrada — Três pontos de entrada unificados: CLI (deeptutor) independente, WebSocket API (/api/v1/ws) e fachada Python SDK.
  • Capacidades — Cinco recursos integrados: chat, deep_solve, deep_question, deep_research, math_animator.
  • Ferramentas — Sete ferramentas que podem ser chamadas de LLM: rag, web_search, code_execution, reason, brainstorm, paper_search, geogebra_analysis.
  • Aplicativo Web — Aplicativo Next.js reconstruído com grupos de rotas de espaço de trabalho/utilitários, novas páginas Playground, Co-Escritor, Agentes e Guia.
  • TutorBot — Agente bot multicanal com suporte para 12 plataformas de mensagens.
  • Infra — Persistência de sessão apoiada por SQLite, tempo de execução de turno, controle de tráfego LLM em nível de provedor e telemetria.

✨ Destaques

🏗️ Tempo de execução nativo do agente (ferramentas + recursos)

Introduziu um modelo de plug-in de duas camadas que separa a execução da ferramenta dos fluxos de trabalho de agentes de alto nível:

  • Contratos principais: ToolProtocol, CapabilityProtocol, UnifiedContext, StreamEvent e StreamBus — a base de toda execução em tempo de execução.
  • ChatOrchestrator: Coordenador central com dois registros:
    • ToolRegistry — descoberta de ferramentas, exportação e execução de esquema no estilo OpenAI.
    • CapabilityRegistry — capacidade de roteamento, gerenciamento de manifesto e streaming com reconhecimento de palco.

🖥️ Pontos de entrada unificados: CLI / WebSocket / Python SDK

Três pontos de entrada compartilham um único tempo de execução do ChatOrchestrator: | Ponto de entrada | Descrição | |:---|:---| | CLI (deeptutor) | CLI baseado em digitador com subcomandos: run, chat, bot, kb, memory, session, notebook, plugin, config, provider, serve | | WebSocket (/api/v1/ws) | Endpoint unificado com ciclo de vida de giro: start_turn, subscribe_turn, subscribe_session, resume_from, cancel_turn | | Python SDK (deeptutor.app.facade) | Fachada programática para integrações estilo SDK |

🧠 Camada de Capacidade

Cinco recursos integrados, cada um deles um pipeline de agente de várias etapas: | Capacidade | Etapas | Descrição | |:---|:---|:---| | chat | respondendo | Conversa padrão aumentada por ferramenta | | deep_solve | planejamento → raciocínio → redação | Resolução de problemas em vários estágios | | deep_question | ideação → avaliação → geração → validação | Geração inteligente de perguntas com modo de acompanhamento | | deep_research | pesquisar → analisar → sintetizar → relatório | Pesquisa multiagente com geração de relatórios | | math_animator | análise → design → codegen → revisão → renderização | Geração de vídeo de conceito matemático baseado em Manim |

🔧 Sistema de Ferramentas

Sete ferramentas unificadas que podem ser chamadas de LLM com dicas bilíngues (en/zh): | Ferramenta | Descrição | |:---|:---| | rag | Recuperação da base de conhecimento via LlamaIndex | | web_search | 10 provedores de pesquisa: Tavily, Exa, Jina, Serper, Perplexity, Brave, Baidu, SearXNG, DuckDuckGo, OpenRouter | | code_execution | Execução Python em sandbox com proteções de segurança baseadas em AST | | reason | Chamada LLM dedicada de raciocínio profundo | | brainstorm | Exploração ampla de ideias com justificativa estruturada | | paper_search | pesquisa de artigos acadêmicos arXiv |

🤖 TutorBot — Agente de bot multicanal

Novo sistema de bot autônomo (deeptutor/tutorbot/) que traz o DeepTutor para plataformas de mensagens:

  • 12 canais: Telegram, Discord, Slack, WeChat Work (WeCom), Feishu, DingTalk, WhatsApp, Matrix, QQ, Email, MoChat
  • Agent Loop: Loop LLM aumentado por ferramenta com memória, geração de subagentes e colaboração em equipe
  • Ferramentas integradas: Shell, sistema de arquivos, web, MCP, cron e ferramentas de mensagens
  • Serviços em segundo plano: verificações de integridade de pulsação e tarefas agendadas baseadas em cron

🌐 Reestruturação de aplicativos da Web

Reconstrução completa do front-end Next.js com novos grupos de rotas: Rotas do espaço de trabalho ((workspace)/): | Página | Descrição | |:---|:---| | Início (/) | Interface principal de chat com conversação aumentada por ferramenta | | Guia (/guide) | Guia de aprendizagem interativo com histórico de sessões, acompanhamento de progresso e resumos de conclusão | | Parque Infantil (/playground) | UI unificada de capacidade profunda (deep_solve, deep_question, deep_research, math_animator) | | Co-escritor (/co-writer) | Escrita colaborativa assistida por IA com agentes de edição e narradores | | Agentes (/agents) | Gerenciamento TutorBot — crie, configure e converse com bots personalizados | Rotas Utilitárias ((utility)/): | Página | Descrição | |:---|:---| | Conhecimento (/knowledge) | Gerenciamento de base de conhecimento com pipeline LlamaIndex | | Memória (/memory) | Memória do usuário e gerenciamento de preferências | | Configurações (/settings) | Configuração unificada para serviços LLM, Embedding, TTS e Search |

🏭 Reconstrução da infraestrutura de serviços

Serviços refatorados em domínios mais claros:

deeptutor/services/
├── config/       # Environment store, model catalog, provider runtime
├── llm/          # Multi-provider LLM: factory, registry, traffic control, telemetry
├── embedding/    # Adapter-based: OpenAI-compatible, Cohere, Jina, Ollama
├── rag/          # LlamaIndex pipeline with component-based architecture
├── search/       # 10 web search providers with result consolidation
├── session/      # SQLite store, turn runtime, context builder
├── memory/       # User memory persistence
├── notebook/     # Notebook management
├── prompt/       # Bilingual prompt template manager (en/zh)
├── settings/     # Interface settings
├── setup/        # Application initialization
├── tutorbot/     # TutorBot management
└── path_service  # Centralized data path resolution

🔒 Segurança e Estabilidade

  • Segurança de execução de código: Protetores de importação/chamada baseados em AST com listas de permissões configuráveis.
  • LLM Traffic Control: Disjuntor em nível de provedor, rastreamento de taxa de erro e mecanismos de repetição.
  • Validação de inicialização: Verificações de consistência da capacidade da ferramenta no momento da inicialização.

🧪 Cobertura de teste

Mais de 53 novos arquivos de teste em todas as camadas principais: tempo de execução (registro de ferramenta/capacidade, orquestrador), serviços (provedor LLM/fábrica/roteamento/telemetria, pipeline RAG, incorporação, pesquisa, sessão, memória, notebook, configuração), agentes (bate-papo, resolução, pergunta, math_animator), API (conhecimento, memória, resolução, tempo de execução de turno WebSocket), CLI e ferramentas (segurança do executor de código).

⚠️ Mudanças importantes

  • Layout do pacote: src/ → deeptutor/ + deeptutor_cli/. Antigo diretório src/ totalmente removido (140 arquivos).
  • Pacote renomeado: ai-tutor → deeptutor, versão 1.0.0.
  • Modelo de tempo de execução: Orquestração nativa de capacidade. chat é o padrão; modos profundos selecionados explicitamente por meio do comando run ou WebSocket.
  • Rotas da Web: Todas as páginas reorganizadas em (workspace)/ e (utility)/. Páginas herdadas (/solver, /question, /research, /ideagen, /notebook, /history) removidas.
  • Pipeline RAG: Somente LlamaIndex disponível. LightRAG e RAG-Anything removidos temporariamente.
  • Layout de dados: Dados de tempo de execução centralizados em data/user/workspace/....
  • Dependências: Dividido em requisitos em camadas: cli.txt, server.txt, dev.txt, math-animator.txt, tutorbot.txt.
