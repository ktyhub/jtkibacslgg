pulsar v4.0.0

2024/10/21

Mudanças no lançamento do 4.0.0 desde que a preparação do lançamento do 3.3.0 foi iniciada. Para a lista completa, verifique changelog completo e lista completa de PR. O que há de novo no Apache Pulsar 4.0? cobre tópicos como:

  • Implementação aprimorada de assinatura Key_Shared
  • Tempo de execução seguro do Docker baseado em Alpine Linux e Java 21
  • Controles aprimorados de qualidade de serviço para implantações multilocatários
  • Limitação de taxas como base para o gerenciamento de recursos multilocatários
  • Caminhos de atualização de versões anteriores
  • Compatibilidade com Client e importância da atualização do Java clients para resolver CVE-2024-47561
