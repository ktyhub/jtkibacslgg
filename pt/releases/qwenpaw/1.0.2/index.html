#QwenPaw v1.0.2

✨ Adicionado

Núcleo

  • Plugins: Instale extensões da pasta plugins/ do seu espaço de trabalho (#3101, #3131, #3132).
  • copaw task: Execute trabalhos únicos a partir do terminal sem servidor web (#3031).
  • /model no chat: troque de modelo, liste o que está disponível, redefina para o padrão e inspecione um modelo — sem abrir as Configurações (#3133). Modelos e fornecedores
  • SiliconFlow: endpoints chineses e internacionais prontos para uso para API compatível com OpenAI da SiliconFlow (#2886).
  • CoPaw Local: modelos com capacidade de imagem e vídeo, configurações mais avançadas no console e downloads mais confiáveis ​​e detecção de capacidade no Windows (#3021, #3087, #3140). Segurança
  • Segredos salvos com mais segurança: chaves API e valores semelhantes são criptografados no disco; sempre que possível, a chave de criptografia permanece nas chaves do sistema operacional (#3025). Console e IU
  • Histórico de entrada de bate-papo: Navegue pelas linhas anteriores do usuário com as teclas de seta (#2466).
  • Pesquisa de bate-papo: pesquise o texto da mensagem entre sessões (#2842).
  • Sessões fixadas: fixe tópicos para que fiquem no topo da lista (#3137).
  • Bate-papo por agente: restaure o último bate-papo aberto ao trocar de agente (#3155).
  • Aperfeiçoamento visual: ícones para ferramentas integradas e logotipos de fornecedores ao lado dos modelos (#3061, #3130). Habilidades e ferramentas
  • Comandos de habilidade: /skills mostra o que está habilitado para o canal; digite /<skill name> para abrir uma habilidade ou execute-a com sua mensagem (#3150).
  • Tags para habilidades de pool: Organize o pool compartilhado com tags (#2837, #3069).
  • Descoberta de ferramenta MCP: consulte cada servidor MCP conectado para obter nomes de ferramentas, descrições e parâmetros por meio do HTTP API (#3149). Canais
  • QQ: Envie arquivos e rich media de forma consistente entre tipos de mensagens (#3012).
  • WeCom: As mensagens recebidas mantêm o contexto de citação/resposta para que o agente veja o que foi referenciado (#3024).

🔄 Alterado

  • Seletor de fuso horário: os nomes das regiões seguem o idioma da UI selecionado (#2497).
  • Tamanhos de arquivo: tamanhos legíveis por humanos em qualquer lugar do console (#2808).
  • Inicialização do console: páginas de configurações mais pesadas são carregadas sob demanda para que a primeira tela abra mais rápido (#3122).
  • Listas grandes de habilidades: rolagem e interação mais suaves quando você tem muitas habilidades de pool (#3141, #3158).
  • Testes de conexão do provedor: Mensagens de status aparecem no seu idioma (#2913).
  • Código de erro: códigos de erro mais consistentes entre canais, APIs e CLI (#3110).

🐛 Corrigido

Canais

  • iMessage: os bate-papos privados agora respeitam sua política de DM e são permitidos da mesma forma que outros canais (#2491).
  • Discord: As respostas longas do assistente não quebram mais os blocos de código Markdown no meio da cerca (#2976).
  • Feishu: reconectar e executar vários agentes não tropeça mais em bloqueios compartilhados ou loops de eventos confusos (#3095, #3145). Ferramentas e habilidades
  • MCP: Fechar ou reconectar clients após recarregar não causa mais uso descontrolado da CPU (#3106).
  • Automação do navegador: Clicking elementos quando existem duplicatas direciona o correto; os documentos explicam os seletores com mais clareza (#3023).
  • Ferramenta Shell: Comandos com texto entre aspas mantêm suas quebras de linha intactas (#3070).
  • Habilidades: Metadados de habilidades corrompidos ou sem objeto não travam mais a análise de requisitos (#3072).
