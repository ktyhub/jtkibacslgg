#QwenPaw v1.1.2

✨ Adicionado

Sistema de Agente

  • Modo Missão: comando /mission para execução autônoma e multifásica de tarefas — o agente planeja, executa e se autocorrige iterativamente. Suporta /mission status e /mission list para monitorar missões em execução (#3364, #3480)
  • Continuação automática somente em texto: quando ativado, o agente tenta automaticamente até duas passagens de raciocínio extras se o modelo responder com texto, mas nenhuma chamada de ferramenta (#3107)
  • ID de agente personalizado: especifique um ID personalizado ao criar agentes a partir do console ou API (#3333)
  • Delegação de agente externo ACP: delegue tarefas a agentes de codificação externos (OpenCode, Qwen, Claude Code, Codex) por meio da nova ferramenta delegate_external_agent com protetores de permissão e saída transmitida em tempo real (#3340)
  • Agente CLI: Crie agentes a partir da linha de comando com qwenpaw agents create, com seleção de modelos (default, local, qa) e inicialização do espaço de trabalho (#3385) CLI
  • qwenpaw doctor: comando de diagnóstico que verifica ambiente, configuração, provedores, canais, habilidades, MCP, memória, segurança e muito mais — com doctor fix para correção automática (#3371)
  • qwenpaw skills info: Inspecione detalhes da habilidade (estado ativado, canais, caminho, descrição) na linha de comando; também adiciona o comando de barra /skills no chat (#3459) Memória
  • Memory Dream: Consolidação programada de memória de longo prazo — um agente "sonho" periodicamente desduplica e reorganiza MEMORY.md (#2177)
  • Recursive File Watcher: Nova opção recursive_file_watcher para incluir arquivos de subdiretórios na indexação de memória (#3347) Console e IU
  • Hub de importação de habilidades: modal de importação redesenhado com validação de URL, integração de mercado e confirmação de substituição ao importar habilidades que entram em conflito com as existentes (#2412, #3415, #3482)
  • Página de depuração: Nova página de depuração nas configurações para visualizar arquivos de log de back-end em tempo real (#3478) Canais
  • Mensagens citadas do WeChat: mensagens citadas/respondidas agora são analisadas com suporte para texto, imagem, voz, arquivo e vídeo (#3483)

🔄 Alterado

  • Ordem de classificação do provedor: a lista de provedores nas configurações agora é classificada por disponibilidade (#3458)
  • Ferramentas de comunicação entre agentes: ferramentas de comunicação entre agentes divididas em chat_with_agent (síncrona) e novas submit_to_agent/check_agent_task (tarefas assíncronas em segundo plano) (#3485)

🐛 Corrigido

Console e IU

  • Limpar histórico de bate-papo: /clear agora limpa corretamente o histórico de bate-papo na IU do console (#3348)
  • Classificação de uso de token: a tabela de uso de token "por data" agora é classificada primeiro pelas datas mais recentes (#3387)
  • Dica de ID do Cron Job: dica de ID do Cron Job corrigida para descrevê-lo como um UUID gerado pelo sistema (#3404)
  • Navegação no histórico de mensagens: o histórico de mensagens ArrowUp não é mais acionado quando sugestões de comandos de barra estão visíveis (#3444) Fornecedores
  • Normalização MIME de imagem: image/jpg normalizado para image/jpeg em URLs de dados para evitar rejeição por APIs estritos (#3313)
  • Ordenação de chamada de ferramenta multimodal: mensagens de imagem promovidas não quebram mais o bloco contíguo de resultado de ferramenta exigido por OpenAI e Anthropic (#3299)
  • Identidade da classe do provedor: Corrigida falha na identidade da classe Pydantic quando o mesmo provedor é carregado de vários caminhos de importação (#3431) Sistema de Agente
  • Rastreamento de tarefas em segundo plano: tarefas em segundo plano despachadas via AgentApp API agora são rastreadas pelo TaskTracker, evitando o cancelamento durante a recarga ou desligamento (#3305)
  • Memory Compaction Guard: o gancho de compactação de memória não é mais executado duas vezes por etapa de raciocínio (#3461) Canais
  • Discord Thread Routing: As mensagens do Discord Thread agora são roteadas para a sessão de thread correta em vez do canal pai (#3144)
  • Indicador de digitação WeChat: o indicador de digitação WeChat não vaza mais tarefas em segundo plano; a digitação começa no recebimento da mensagem e para de forma confiável na conclusão ou erro (#3488) Computador
  • Isolamento de ambiente Python: compilações de desktop empacotadas agora definem PYTHONNOUSERSITE=1 para evitar que pacotes instalados pelo usuário entrem em conflito com dependências agrupadas (#3476)

🔧 CI e infraestrutura

  • Infraestrutura de teste de canal: testes de contrato, testes de unidade, fluxo de trabalho de CI e metas Makefile para garantia de qualidade de canal (#2506)
