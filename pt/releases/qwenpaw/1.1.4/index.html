#QwenPaw v1.1.4

✨ Adicionado

Sistema de Agente

  • Refator de memória e contexto: Refatore o módulo de memória de longo prazo com back-ends conectáveis, resumo automático de memória a cada N conversas, recuperação automática de memória e uma nova interface de gerenciamento de contexto (#3548)
  • Modo de plano: modo de planejamento estruturado opcional — use /plan para criar planos de tarefas passo a passo que o agente segue, com um painel de plano ao vivo no console (#3686, #3787) Fornecedores
  • Modelos DeepSeek V4: Adicionados DeepSeek V4 Flash e V4 Pro como modelos integrados (#3797) Segurança
  • Verificações de evasão de shell configuráveis: ative ou desative regras individuais de detecção de evasão de shell na página de configurações de segurança, com marcação de tipo de risco por verificação (#3694, #3715, #3781)
  • Auth-Bypass Host Whitelist: Lista allow_no_auth_hosts configurável para acesso API sem autenticação, com validação de IP e avisos de segurança no console (#3739) Ferramentas
  • Parâmetros de inicialização do navegador: passe sinalizadores personalizados do Chromium e um caminho executável do navegador personalizado para browser_use (#3556)
  • Tempo limite do comando Shell: tempo limite padrão configurável para execute_shell_command por agente (#3732) Console e IU
  • Atribuição de modelo por agente: atribua um modelo LLM específico a cada agente em Configurações → Agentes (#3599)
  • Botão Visualizar sessão: ação "Visualizar" na tabela Sessões para ir diretamente para a sessão de chat correspondente (#3615)
  • Menu de contexto da sessão Right-Click: Right-click nos itens da sessão de bate-papo para ações rápidas de abertura, renomeação, fixação/desafixação e exclusão (#3770) Canais
  • Canal de voz SIP: novo canal de telefone SIP com back-ends de modo duplo — pyVoIP para desenvolvimento e LiveKit para produção (#3449)
  • Reconhecimento de voz DingTalk: use o reconhecimento de voz integrado do DingTalk em vez de baixar e transcodificar o áudio localmente (#3681)
  • Menu de comando do Telegram: exponha /model e /stop no menu de comando do bot do Telegram para descoberta (#3714)
  • Suporte a mensagens citadas QQ: analisa metadados de resposta/citação e injeta texto citado e anexos em solicitações de agente (#3735)
  • Mensagens Markdown DingTalk: Envie respostas mais curtas como markdown DingTalk Open API para uma renderização de mensagem mais rica (#3771)
  • DingTalk Cron Message Type: tipo de mensagem independente para envios agendados/cron, permitindo mensagens em estilo de cartão para cron enquanto usa markdown para bate-papo interativo (#3778)
  • WeChat Interactive Wizard: assistente interativo configure_weixin no fluxo de configuração do canal CLI (#3699)

🔄 Alterado

  • Tool Guard Approval System: Tool Guard refatorado com cartões de aprovação interativos no console, roteamento de aprovação entre sessões (aprovar chamadas de ferramenta de subagente da sessão principal), níveis de execução configuráveis (estrito/inteligente/automático/desligado), comando REST API e /approval CLI (#3656, #3737)
  • Registro de plug-in dinâmico: substituído o registro do módulo host gerado em tempo de construção pelo registro baseado em import.meta.glob em tempo de execução (#3676, #3692, #3696)
  • Melhorias na compilação do Docker: Inicialização do config.json movida do build da imagem para o ponto de entrada do contêiner para implantações montadas em volume e substituição do pip pelo uv para instalações de pacotes mais rápidas (#3698, #3723, #3769)
  • Sincronização de idioma do agente: novos agentes agora herdam o idioma da UI do console (#3720)
  • Persistência de seleção de agente: o estado de seleção do agente persistiu em localStorage para que ele sobreviva às reinicializações do navegador (#3772)
  • Buffering de uso de token: gravação assíncrona de uso de token em buffer com liberação periódica de disco (#3766)

🐛 Corrigido

Canais

  • Mensagens da ferramenta de filtro: respeite a configuração filter_tool_messages para eventos de conteúdo em andamento (#3660)
  • Codificação de URL de arquivo: codificação percentual de caracteres não ASCII em URLs file:// para corrigir falhas de envio de arquivo no Windows e caminhos com caracteres CJK (#3625)
  • Resposta de envio do WeChat: Corrigida falha do WeChat send_text em respostas API vazias ou não ditas (#3685)
  • Mapeamento de ícones do WeChat: Corrigida a chave do canal wechat que não era mapeada para o ícone correto do WeChat na barra lateral do histórico de bate-papo (#3691)
  • Tempo limite de login QR do WeChat: Tempo limite de pesquisa de status QR do WeChat estendido para 60 segundos com tempo limite de nova tentativa de leitura durante o login (#3700) Console e IU
  • Estatísticas do agente: corrigida falha de página causada por importações incorretas da biblioteca de gráficos e estatísticas não atualizadas ao trocar de agente (#3724, #3743) Fornecedores
  • Aviso de modelo duplicado: mostra um aviso localizado ao adicionar um ID de modelo que já existe (#3773)
  • Bloco de arquivo Antrópico: Converta blocos de arquivo não suportados em espaços reservados de texto no histórico formatado pelo Anthropic para evitar erros API (#3786) Embalagem
  • Discord.py Conda-Unpack: Adicionado discord.py à lista de reinstalação do conda-unpack para corrigir corrupção de caminho do Windows (#3730)

📝 Documentação

  • Agente proativo e de evolução de memória: adicionadas páginas de documentação dedicadas para recursos de agente proativo e de evolução de memória (#3755, #3764)
  • Guia prático da equipe do agente: adicionado um guia prático abrangente para colaboração da equipe do agente (#3784)
  • Integração ACP: Documentação de integração ACP reestruturada e aprimorada, com link de documentação na UI (#3741)
  • Volume de backup Docker: Adicionada documentação de montagem de volume Docker para backup e restauração (#3736)
  • Figuras de backup: Figuras atualizadas da documentação de backup (#3678)

🧪 Teste e CI

  • Testes de Unidade de Agente: Adicionados testes de unidade para ganchos, memória e módulos utilitários (#3630)
